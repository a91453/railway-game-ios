# Save version 115

A map opened whole (decision 992): the world's `"wholeMapOpen": true`,
written only when the player chose to open the whole of a city's map
from the start (Hong Kong's or Japan's) rather than start with part of
it and buy the rest. The app counts no achievements for such a game, as
for the whole of Taiwan. A build that reads only an earlier version
would drop it and count the game's achievements, so it says the save is
newer than it instead.

A save of any earlier version was never opened that way: nothing to
turn. An old Hong Kong game, whose map was whole before maps were
bought, keeps counting its achievements.

`v115-whole-map-open.json` is the fixture.
