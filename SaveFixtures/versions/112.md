# Save version 112

Track systems (decision 951): a track edge's `"system"`, written only
for a guideway (`"straddle"`, `"maglev"`, `"suspended"`); ordinary track
writes none, as every edge before. A build that reads only an earlier
version would drop it and save the guideway as ordinary track, so it
says the save is newer than it instead.

A save of any earlier version is turned when it is read
(`GameWorld.layGuideways()`): a piece of the track network (the edges
joined to each other through their nodes) becomes the guideway of one
system when a line whose trains are all of that system (`MONORAIL`,
`MAGLEV` or `SKYRAIL`) runs on it and nothing else does: no line with a
train of another system, no train of another system standing on it, no
mountain track in it. Every other piece stays ordinary track, and a
guideway train on a line there stays on its line and runs as before;
once taken off, it cannot be put back. Nothing is charged and no book
value changes. A guideway's speed limit (80, 100 or 75 km/h) holds from
the next run a train starts.

`v112-track-system.json` is the fixture.
