# Save version 113

Maps that grow (decision 969): a world's `"geoAnchorBounds"`, the part
of the world, from its north-west corner, whose middle its `"geoAnchor"`
is, written only for a map that grew to the south and the east
(`GameWorld.growMap(to:)`); and a map bought tile by tile says how many
tiles the company was `"granted"` as the buying began, written only
when more than the one a new game owns (a game played over a map that
was whole keeps the ground it had). A build that reads only an earlier
version would drop both and save the world as if its anchor were the
middle of the whole of it, so everything in it would lie somewhere else
on the Earth, and price the next tile by every tile owned; so it says
the save is newer than it instead.

A save of any earlier version reads as before: no world in one grew, and
every map bought was given one tile.

`v113-grown-map.json` is the fixture.
