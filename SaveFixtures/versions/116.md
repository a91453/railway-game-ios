# Save version 116

Where land lies (decision 1025): the world's `"landLocations"`, runs of
256 m squares along a row (`{"row", "column", "factors": [n, …]}`), each
the factor in thousandths its place sets its land value by, read with a
Taiwan map's land from the real-price registry. A build that reads only
an earlier version would drop them, and the land would be worth what a
blank map's is again, so it says the save is newer than it instead.

A save of any earlier version has none: its land is worth what it was,
nothing to turn.

`v116-land-locations.json` is the fixture.
