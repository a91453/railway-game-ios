# Save version 114

Track gauges (decision 970): an ordinary track edge's `"gauge"`, its
rails and loading gauge, written only where it is not the default
1,067 mm of the conventional loading gauge:
`{"rails": [1435], "loading": "shinkansen"}` for the high-speed
railway's track, `{"rails": [762]}` for the forest railway's,
`{"rails": [762, 1067]}` for track of two gauges. A guideway writes none.
A build that reads only an earlier version would drop it and lay every
edge at 1,067 mm, so it says the save is newer than it instead.

A save of any earlier version is turned when it is read
(`GameWorld.layGauges()`): each ordinary edge takes the gauges it is
needed at: the real gauge of a bought real line whose track it is
(`TrackGauge.ofRealLine`), and the gauge of each train of a real model
standing on it or on a line running over it. Two needs make track of
both rails, the wider loading gauge, so no train that ran before is
stranded. An edge nothing needs takes those of its piece of connected
track, else the default; mountain track is 762 mm. Nothing is charged
and no book value changes.

`v114-track-gauge.json` is the fixture.
