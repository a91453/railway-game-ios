# Save version 109

Station sounds (decision 866): a station can have `"chime"`, the
arrival chime the player set it to ring, and `"departureMelody"`,
the melody it plays as a train's doors close. A build that reads
only an earlier version would drop them, and the station would ring
what its place calls for again, so it says the save is newer than
it instead. A save of any earlier version needs no step: no station
was set to either.
