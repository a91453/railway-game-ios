# Real line fixtures

Data the tests read to rebuild a line as an older build bought it.

- `ankeng-runs-before-depot.json`: the Ankeng LRT (`ntalrt:K`) as
  `RailwayGameApp/Resources/RealRailways/metro_runs.json` had it before
  decision 535 (continued, ANKENGDEPOT, commit 8762afc), in the same
  format: four trains overnight at Shuangcheng and one each at Shisizhang,
  Taipei Xiaocheng and Rose China Town, five positioning runs. A game saved
  with the line bought then has no depot; `RealLineDepotAdditionTests`
  (decision 557) buys it so and adds the depot. Source: the light rails'
  station timetables, Ministry of Transportation and Communications TDX
  (fetched 2026-07-16), Open Government Data License, version 1.
