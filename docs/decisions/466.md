### 466. 3D 的三鶯線照實車畫兩節的 `Map3DSanying`

2026-10-28，遊戲規劃 session_01YGNNuknN8czzHmJ7zU9h3R 派工（派工單 BY），實作 session_01YGNNumbM7yQYmUdtepxynG（`claude/sanying-line-trains`）。號碼依 #1041：決策 466；存檔版本、golden schema 不動。GameCore、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/`、`TrainPack` 不動，只動 GamePresentation、測試、`tools/train-models/hashes.lock.json` 與文件。三鶯線開放收購是另一個 PR（`claude/sanying-line`，決策 400 的 10j-3 補記），兩個都「10/31 後合」。

**為什麼**：#1422（Codex）做的三鶯線兩節車 `Map3DSanying`（第三版，作者 2026-10-28 回「可以」）只在 `Map3DModelPack.studies`，遊戲裡看不到；實景地圖上的三鶯線（`Map3DRealTrains` 的 `sanying`）畫成文湖線的車。這次照決策 461 的做法把它接成會跑的編組。

**做了什麼**：

1. **新的 set**（`Map3DTrainSets.swift`）：`sanying(far:)`，key `sanying`／`sanyingFar`，`ownLengths: true`，`fixedCars: 2`：不管列車幾節都畫兩節，A 車在前、B 車轉過來在後（`tools/sanying/assembly.json` 的 A-B），一節 17.7 m。燈照決策 408 的 `lit(_:front:)`：頭車前面白、尾車後面紅。遠景用 `Map3DSanying.model(_:far: true)`（它本來就有）。`sanying` 加進 `nearOnly`：500 m 內近景、500–900 m 遠景、900 m 外盒子（決策 420）。
2. **沒有中間車的 set**：`Map3DModelPack.models(forType:)` 與 `layout(forType:count:)` 原本要求 set 有中間車；三鶯線永遠兩節，所以沒有中間車時用頭車代替（只在 `fixedCars` 兩節的 set 會發生，不會真的畫出來）。其他 set 的結果不變。
3. **誰畫成三鶯線的車**：
   - 實景列車（`Map3DRealTrains.formation`）：`sanying` 系統由 `wenhu` 4 節改成 `sanying` 2 節。
   - 玩家買下的三鶯線（決策 400 的收購，`LineAcquisition.realLine` 以 `sanying:` 開頭）：那條線的列車在 `Map3DTrains.Bodies` 用 `sanying`，不再照列車種類（捷運 B）畫通用車。只看收購記錄，不加 GameCore 的欄位。
   - 列車展示（`Map3DShowcase`）加一列「新北捷運三鶯線」，固定兩節。
4. **靜態研究留著**：`studies` 裡的 `sanying-a`、`sanying-b` 與遠景照舊（`tools/sanying/verify.mjs` 讀它們），和決策 461 留 610 研究一樣。

**模型包**（`Map3DModelPackSizeTests`）：583 → 591 個模型，3,332,082 → 3,374,106 個頂點（多 8 個模型、42,024 個頂點：近景與遠景各兩節，加上它們的窗燈模型）。

**三角形數**：近景一節 4,306（`Map3DTrainSetTests` 的預算加一行 4,200–4,400），遠景一節 2,058，不到近景的一半（決策 417、420）。

**雜湊**（`tools/train-models/run.sh OUT --lock`）：新增 8 個（`set-sanying-head/tail`、`set-sanyingFar-head/tail` 與它們的 `light-`），改 0 個，刪 0 個；`sanying-*` 研究模型與其他列車的雜湊都沒動（鎖檔另把 `sanying-*`、`taichung-green-*` 幾行照工具的排序換了位置）。

**沒選的**：

- **把研究模型從 `studies` 拿掉**：`tools/sanying/verify.mjs` 與 `SANYING_MODEL.md` 的重建流程讀它們；留著不佔遊戲的記憶體（`studies` 只給工具）。
- **給 set 一個假的中間車（頭車再放一次）**：多 4,306 個三角形進模型包，又永遠用不到。
