### 414. 放空模式：自動在自己的列車、車站、路線之間切鏡頭

2026-10-25，遊戲規劃 session_01KvN8GrLosqRswrXMQgVQir 派工（`docs/research/NEXT_PRIORITIES_2026-10-12.md` §22.2 第 19 名；來源 §15.2 第 4 名、§16 第 5.3 項），實作 session_01J7edxy3rWsd9gKqSFMyPa4。號碼依 #1041：決策 414；存檔版本、golden schema 不動。GameCore 不動，只動 GamePresentation、App 與測試。「這版新增」卡是決策 415，另一個 PR。

**做了什麼**：遊戲選單最後一列「設定」旁邊多一個「放空模式」。打開後：

- 按鈕、面板、狀態列、地圖角落的按鈕與小地圖都收起來（`ambientHidden`：不畫、不收觸碰、旁白不讀（透明的畫面旁白本來就不讀；不另加 `accessibilityHidden`，加了連平常 UI 測試都點不到地圖與縮放鈕），位置不動，所以收起與回來時版面不跳）；地圖本身、列車、天氣、票價與蓋章的浮字照常。
- 鏡頭自己換：跟一列車、看一個車站、看一整條路線，照下面的規則（`AmbientDirector`，GamePresentation，Linux 測試 `AmbientDirectorTests`）。跟車用已有的 2D 跟車（決策 219）與 3D 跟車（決策 333、337、403 的五個視角），不另寫鏡頭。
- 換鏡頭時畫面暗下再亮起（新的動態規則 `MotionRule.ambientCut`）；底下一行小字寫正在看什麼（「路線名・車名」、站名、線名）；剛打開的 5 秒多一行「碰一下螢幕就回來。」
- 配樂照放（照「音樂」開關，決策 219 第二階段）；跟車時行駛聲與配樂讓路照舊（決策 343）。
- 碰一下螢幕任何地方就回來：按鈕回來、停止跟車、3D 地圖直接關上；打開時遊戲是暫停的，回來時再暫停（放空時讓車跑）。月報、年報這類面板打開或教學開始時也自動回來。
- 放空時螢幕不自動鎖定（參考的 `acquireWakeLock`）。
- 教學進行中不能打開；什麼都還沒蓋時停在地圖原處。

**規則**（`AmbientDirector`）：

| 項目 | 值 | 來源 |
| --- | --- | --- |
| 鏡頭的順序 | 列車、列車、車站、列車、路線，循環；沒有那一種就往後找下一種 | 本作：參考只有列車與熱區，沒有玩家的車站與路線 |
| 跟一列車多久 | 60–120 秒（牆上時鐘，隨機） | 參考 `nextTourTrain`：`60000 + Math.random() * 60000` |
| 看車站、路線多久 | 20–30 秒 | 本作：1× 時約一兩班車進出 |
| 挑哪一列 | 在軌道上的列車；每條路線被挑到的機會一樣，不管它跑幾列（沒有路線的車自成一組） | 參考 `pickTourTrain` 把稀有車種的權重拉高（`TOUR_W`：其他 24、莒光 10、自強 5、區間 1），讓少見的車常上鏡；遊戲沒有車種的稀有度，用「每條線一樣」達到同一件事 |
| 不重複 | 最近 5 個看過的列車（車站、路線各自）在還有別的可選時不選 | 參考 `TOUR_RECENT = 5` |
| 挑哪一站 | 等車的人越多越容易被挑到（權重 1 + √人數） | 本作 |
| 挑哪一條線 | 跑的車越多越容易（權重 1 + 列車數）；兩站以上的線 | 本作 |
| 3D | 可用 3D 時，每隔一個列車鏡頭用 3D 跟車，視角輪流：旁邊、後方、從車站看、上後方、駕駛室；車站與路線都在 2D | 參考 9/7「放空的跟車視角改成貼著車身的立體視角」，所以第一個是「旁邊」 |
| 車站鏡頭的範圍 | 車站四周各 600 m | 本作：看得到月台與兩側的軌道 |
| 路線鏡頭的範圍 | 所有停靠站外加 400 m | 本作 |
| 換鏡頭 | 暗下 0.7 秒，多停 0.1 秒，換好亮起 0.7 秒；第一個鏡頭不暗 | 參考 `#veil`（`transition: opacity .7s ease`）與 `fadeSwitch` 的 800 ms；`_ambientFresh` |
| 鏡頭提早換 | 跟的車離開軌道（進機廠、被賣掉）、路線被刪、或 3D 不再能用 | 本作 |

亂數用導演自己的 SplitMix64，種子取自時鐘；測試給固定的種子，同一個種子同一串鏡頭。世界不抽任何亂數，GameCore 的決定性不受影響。

**減少動態效果**：

- 打開時不用 3D（3D 跟車的鏡頭每幀轉向、換視角時飛行），列車都在 2D 跟（2D 跟車本來就是平移跟著車，和平常跟車一樣）。
- 換鏡頭的暗下亮起只是淡入淡出，照 motion 規則留著，時間減半（0.35 秒）。
- 放空中途打開「減少動態效果」：下一秒就從 3D 換回 2D。

**五方**：

- 玩家：不用操作就能看自己蓋的鐵路跑，掛著當背景；碰一下就回來，回來時遊戲的暫停狀態和打開前一樣。
- 鐵道迷：跟車的五個視角都會輪到（旁邊、後方、從車站看、上後方、駕駛室），每條線平均上鏡，不會一直看同一條通勤線；規則照作者自己的台鐵網站的放空模式移植。
- 開發：只動畫面層；導演是純值型別，Linux 測試；3D 只多兩個參數，不寫新的鏡頭系統；不升存檔、不動 golden。
- 美術：介面收起只剩地圖與一行字，畫面乾淨；換鏡頭用暗下亮起，不用滑動或縮放。
- 音樂：配樂照放，是第一個讓配樂當主角的地方；跟車時的行駛聲與讓路也照舊。

**沒做的、之後可以做的**：

- 參考的「群車視角」（鏡頭停在列車最密的路段，慢慢漂移縮放）：遊戲的 2D 地圖還沒有鏡頭慢慢漂移的機制。
- 放空時的專屬配樂（參考播完整曲庫）：遊戲目前只有一首配樂，有第二首時再接。
- 夜間沒有車時快轉到早上（參考的 `nightReplay` 是倒回 18:00）：遊戲有「跳過安靜的夜晚」（決策 305），放空時沒有接上。
