### 926. 台北美麗華摩天輪與淡水紅毛城接進台灣 3D 地圖（TW-LANDMARKS-MIRAMAR-FORT）

2026-11-22，雲端工作串「兩個工作室地標接進遊戲」（協調者派工，趕 144 版）。號碼依 #2118 的登記。照決策 895 的地標登錄制，一座一檔，兩座同一個決策。

存檔版本、golden schema、GameCore、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/` 都不動。

## 2. 規則

1. **摩天輪的位置**：OSM node 5121602758（`attraction=big_wheel`，2026-11-22 由 OSM API 讀）25.0828070, 121.5577156。模型對稱，外框中心就是輪軸正下方。
2. **摩天輪的方向**：工作室照派工單推估輪面法線 315°（輪子平面沿東北－西南，「和購物中心長邊平行」）。OSM 的購物中心外框（way 155816458）邊都是正東西、正南北，東西寬約 164 m、南北約 110 m，長邊是東西向；所以照派工單的原意「和長邊平行」，`--turn -45`（順時針 45°）讓輪子平面沿東西、輪面朝南北。外框變成 79.89 × 14.00 × 83.34 m（東、北、上）。
3. **摩天輪站在屋頂上**：`baseHeight` 33.4 m＝遊戲在那裡的地面（`taiwan_heights.dat` 雙線性 16.7 m）＋屋頂高 16.7 m。屋頂高取 OSM node 的 `height=100`（輪頂離地 100 m）減模型的平台底到輪頂 83.34 m。沒有照參考庫的 30 m 猜。購物中心本體照舊畫（Overture 的外框與層數）：地標的 `landmarkPlans` 只蓋住模型自己的 80 × 14 m 地面，購物中心外框的中心不在其中、角點遠少於三分之一，所以不會被拿掉（`underLandmark`），不用新欄位。
4. **紅毛城的位置與方向**：OSM relation 3986680（2026-11-22 由 OSM API 讀，和工作室用的版本相同），模型已照外框轉 −16.3°，不再轉。經緯度是模型外框中心：OSM 各點平均往北 4.66 m、往西 3.03 m（工作室 `layout.json`），25.1753837, 121.4329044。地面取四角最低（`baseHeight` 0），石台只墊到自己腳下（日月潭經驗第 10 點）；那裡的遊戲地面約 20 m。
5. 顏色全是色票，照兩個派工單第 5 節的順序：摩天輪 `tileWhite`、`mtrRoofSilver`、`mastSteel`、`steel`、`mtrRed`、`tankWhite`、`concrete`、`tunnelLamp`；紅毛城 `templeWall`、`redBrick`、`brick`、`dark`、`gymGreen`、`stone`、`mastSteel`、`awningCream`。沒有新顏色，沒有帷幕玻璃。
6. 軌道：摩天輪離文湖線劍南路站約 300 m、紅毛城離淡水站約 1.4 km，都不在軌道或月台旁（`isClearOfTrack`）。
7. 這兩座近景共 7,400 個三角形；加上決策 927 的八卦山大佛與龍虎塔，台灣地圖的登錄地標仍在每張地圖 60,000 的預算內（`Map3DLandmarkRegistryTests`）。

## 3. 留下的

- 購物中心在遊戲裡畫的高度由 Overture 的層數決定，沒有在場景裡量過；畫得比 16.7 m 高時平台會埋進屋頂，矮時平台會浮在屋頂上（UNVERIFIED）。
- 摩天輪的方向是由購物中心外框推的，OSM 沒有輪面的方向；要是實機看起來不對，改 `--turn` 重出 mesh 與鎖檔。
- 紅毛城的磚房可能太大、從上面看主堡屋頂和磚房顏色太近（工作室 README 第 9 節），等下一輪。
- 摩天輪的暖光帶用 `tunnelLamp` 的顏色，登錄制的地標不另外在夜裡發光。

## 4. 五方

- 玩家：台北大直多了一眼認得出的紅白摩天輪，淡水多了紅毛城。
- 鐵道迷：摩天輪在文湖線劍南路站旁、紅毛城在淡水線終點附近；位置照 OSM。
- 開發：只加 GamePresentation 的四個檔、清單兩行、兩個鎖檔；沒有新欄位，其他地標的位置與雜湊不變。
- 美術：全色票；兩座都是工作室對照片過審的模型。
- 音樂：無。
