### 983. 路線頁逐線選列車塗裝；700T 預設改真車橘帶（TRAIN-LIVERY-CHOICE）

2026-11-25，雲端工作串「讓玩家逐線選塗裝」（協調者派工；作者 11-25 問「玩家改塗裝功能好像一直沒上線」），分支 `claude/project-thread-40kinx`。評分在 `a91453/railway-assets-private-2` `docs/priorities/TRAIN-LIVERY-CHOICE.md` 第 1 列（3.30），總表第三版功能第 7 名。號碼依 #2118 登記。

不動 GameCore、存檔版本、golden schema、golden、replay。

## 1. 玩家看到什麼

- 路線頁的設定區，路線上有「可換塗裝的車款」時多一列選單，例如「700T 塗裝：橘色帶」。點開有這款車的每一套塗裝（色點加名字），選了之後這條路線上這款車在 3D 地圖立刻換色。
- 選單下一個按鈕「同款列車的路線全部套用」：把這條線選的那一套，一次套到現在跑這款車的每一條路線。
- 選擇照路線記在這台裝置上（和聖誕塗裝一樣跟著存檔列），重開 App 還在。
- **700T 的預設改成真車的橘色帶**；10 月選的青綠帶留成可選塗裝「青綠帶」。
- 沒有可換塗裝車款的路線，不多任何東西。

對照圖：`docs/art/train-paint-choice-2026-11-25/overview.jpg`。

## 2. 做法

- **一款車、多套塗裝**（`Sources/GamePresentation/TrainPaint.swift`）：
  - `TrainPaintFamily`：一款車（近景 set 與它的遠景 set）、配方本身那一套的名字與色點，以及其餘可選的 `TrainPaint`。
  - `TrainPaint`：一串換色 `Swap(from:to:heights:)`。車上「`from` 的每一種深淺」換成「`to` 的同一種深淺」：配方的明暗與烘焙的遮蔽陰影（決策 439）都是顏色乘一個係數，所以用最小平方求出係數、各色版誤差在 1.5 以內才算同一色，再把係數乘到新顏色。`heights` 可以只換某個高度範圍（之後白車身換色、車頂不換時用）。
  - 只換不透明的車漆：玻璃、燈、會發光的面、路線色帶（alpha 小於 1）不動；不鏽鋼面漆過之後變成一般漆。太暗（最亮色版不到 8）的面不認領，免得黑線被當成任何顏色的暗部。
- **模型包不變**：不加模型、不改任何模型的頂點。App 第一次要畫某節車的某套塗裝時，從那節車 GPU 上的頂點做第二份頂點緩衝（`Map3DModelBuffers.dressed`），和聖誕塗裝（決策 795、806）同一條路；兩者可以同時穿（先換色、再掛裝飾）。`Map3DInstance.paint` 是塗裝的編號（0 是自己的），畫的時候依模型、塗裝、聖誕分組。
- **選擇放哪**：`GameSession.trainPaintChosen`（路線 → 車款 id → 塗裝 id），由 `GameLauncher` 照存檔列寫進裝置偏好 `LauncherPreferences.trainPaints`；沒手動存過的局在第一次選的時候拿到自己的列（決策 814 的做法）。不是指令、不進存檔。
- **這條線有哪些車款**：`Map3DTrains.paintFamilies(on:in:locked:)` 用和 3D 地圖畫車同一套判斷（車種、車號的變體、節數、買下的真實路線自己的車）。
- **路線頁**：`TrainPaintRows`（`LinesPanel.swift`），選單包在 `TickStable` 裡，遊戲在跑也不會重畫打開著的選單。
- **700T**：`Map3DTrainShapeRefresh` 的帶色從 `shopAwnings[0]`（青綠）改成新色票 `Map3DPalette.highSpeedOrange`（`0xEA6A1E`，和 2D 地圖 `TrainLivery.highSpeed` 同一個橘），青綠登記成塗裝 `teal`。
- **工具**：`tools/train-models/run.sh OUT --ids … --paint <塗裝 id>` 匯出穿著那套塗裝的車，給 `render.mjs` 拍圖。

### 加一套塗裝怎麼做

- 註冊車（決策 782）：在自己的 `Map3DTrainRegistration` 加 `paints: TrainPaintFamily(id:sets:…paints:[…])`，別的檔都不用改。
- 手寫的 set：照 `Map3DTrainShapeRefresh.highSpeedPaints` 寫一個，加進 `TrainPaintFamily.all` 開頭的清單。
- 新顏色放自己檔裡的 `extension Map3DPalette`。`id` 發布後不能改（裝置上記的就是它）。
- `TrainPaintTests` 會擋：id 重複、set 不存在、近景有遠景卻沒列、某個換色在這款車上一個頂點都沒換到。

## 3. 雜湊

刻意改的只有 700T：`set-highSpeed-*`、`set-highSpeedFar-*`、`refresh-700t-*` 共 12 個模型的雜湊（`tools/train-models/hashes.lock.json` 只改這 12 行，三角形數不變）。`Map3DFarSets422Tests` 釘的 700T 近景雜湊跟著換。把帶色暫時改回青綠重新匯出，`check.mjs` 對 main 的鎖 8 個全部相同：這次只改了帶的顏色，形狀沒動。

## 4. 五個角度

- 玩家：高鐵一眼就是真車的橘色；想要原本的青綠可以逐線選回來，也可以一次全部套用。
- 鐵道迷：預設就是真車塗裝；2D 地圖的高鐵本來就是橘色，現在 3D 和它一致。
- 開發：每款車之後加塗裝只動自己的檔；模型包、存檔、GameCore 都不動；每套塗裝第一次畫時多一份那節車的頂點緩衝（700T 近景一節 0.7 到 1.1 MB，車頭、中間車、集電弓車、車尾四種合計約 3.5 MB），不選就不佔。
- 美術：真車色與遊戲色都留；換色保留明暗與遮蔽陰影，不會變成平塗。
- 音樂：無。

## 5. 其他做法（沒選）

- 選擇放進存檔：要升存檔版本、動 GameCore，而它只影響外觀；聖誕塗裝已經用裝置偏好跑過一季，照它做。代價是換裝置或把存檔傳給別人時選擇不跟著走。
- 每套塗裝各做一份模型：模型包變大、每個雜湊鎖多一組，之後的莒光、E500、EMU500 每款都要翻倍。
- 整個公司一個選擇：作者要的是逐線選；全部套用用按鈕補上。

## 6. 找過什麼

- 參考庫：`Railway/rail-reference` 的車型有塗裝色（`LIVERIES`），沒有「玩家逐線選塗裝」的介面或換色做法；這次沒有從參考庫搬程式。橘色用的是遊戲 2D 地圖已經照作者城市視圖取的 `0xEA6A1E`。
- 外部專案：沒有搬任何程式；換色是這個專案自己寫的。

## 7. 還沒做、要知道的

- 只有 3D 地圖的列車換色；2D 地圖、列車展示、車庫與列車肖像畫的是車款自己的那一套。
- 900 m 以外的方塊車不換。
- 「全部套用」只套到現在跑這款車的路線；之後新開的路線自己選。
- 開著列車包時，單數車號的高鐵是 N700S（決策 432），不是 700T，所以不跟著換。N700S 正在換成舊版車模（決策 979）；它的深綠線要當可選塗裝時，在它的註冊加一個 `paints:` 就可以。
- 灰、白這種顏色的換色會認到所有同比例的灰，要用 `heights` 或挑車上獨有的顏色。
- 之後的 LIVERY-CHUKUANG、LIVERY-E500-PP、EMU500 等改真車色都接在這個機制上；LIVERY-BODY-COLOUR（自選底色）還要一個選色畫面。
