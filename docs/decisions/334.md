### 334. 車站卡的「即將進站」：點一班車，3D 飛到它停的月台

2026-10-22，遊戲規劃 session_014rYHMtmqA5bEMkBBuKu6PV 派工（NEXT_PRIORITIES §22 的派工單第 2 項），實作 session_01RU6kM49KUK5VFvU5osr8eP。號碼依 #231：決策 334；存檔版本、golden schema 不動。GameCore 不動。接在決策 333（3D 跟車）之後，共用它的飛行 `Map3DFlight`。

**做了什麼**：車站卡「即將進站」的每一班停靠本站的玩家列車（不是通過的、不是還沒發車的時刻表班次），點一下就打開 3D 地圖，從車站上空 1.2 秒飛到那班車停的月台，列車外面多一圈暖黃色的框。這一行在分鐘數後面多一個 3D 圖示。

- **哪一個月台**（`Map3DNextDeparture.platform(of:at:in:)`）：遊戲的月台是調度在列車進站前才選的（沒有每一站固定的月台欄位），所以照這個順序找：列車正停在這站的月台 → 它已經排好、接下來要走的軌道上這站的第一個月台 → 都還沒排到，就是這站的第一個月台。
- **鏡頭停在哪**（`Map3DNextDeparture.camera(platformAt:along:length:from:)`）：看著月台中點；遠近剛好放得下月台再多五分之一（150–600 m 之間）；傾斜回到地圖自己的（到了就是一般的 3D 地圖，可以照常拖曳、縮放）；方向轉最少的那一邊，讓橫放的畫面月台左右橫躺、直放的畫面月台上下直立。
- **圈**（`Map3DTrains.frame(ringed:)`、`Map3DMesh.addRing(round:)`）：寬 0.7 m 的平帶，離車廂兩側與兩端各 0.6 m，比軌道高 1.3 m（月台邊緣蓋不住它），顏色是 2D 地圖選車外圈的 `trainSelection` `#FFC86B`（決策 205），晚上自己發亮。實心、平的，不做光暈（art-style：不用發光、漸層）。圈留到關掉 3D 地圖。
- **動態**：飛行是 `MotionRule.cameraFlight`（決策 333），「減少動態效果」打開時直接出現在月台上方。飛行中手指一碰就停在那裡。
- 正在跟車時點，先停止跟車。教學中不能點（和地圖的 3D 按鈕一樣）。

**五方**：
- **玩家**：看板上「3 分後進站」的那班車在哪個月台，點一下就看得到；不用自己在 3D 裡找車站、找車。
- **鐵道迷**：從看板到月台，是車站裡看發車表、走到月台等車的順序；月台是調度真的排的那一個（還沒排到時才先看第一個）。
- **開發**：只動 GamePresentation 與 App；月台與鏡頭在 `Map3DNextDeparture`，圈在 `Map3DTrains`/`Map3DMesh`，Linux 測試 `Map3DNextDepartureTests`；飛行與決策 333 共用。
- **美術**：圈用 2D 選車的同一個暖黃，實心平帶，不加新素材。
- **音樂**：無。

**沒選的做法**（預覽用文字，App 的畫面要 macOS 才拍得到）：
- **看板每一行加一個「3D」按鈕**：一行已經擠了線號、車名、分鐘數、狀態膠囊（直放的手機橫拿時會擠到一字一行，見 `departureRow` 的註解），再加 44 點的按鈕會再擠；整行可點、分鐘數後面放一個小圖示提示。
- **不開 3D，在 2D 地圖上把鏡頭移到月台**：2D 已經看得到車與站；派工單要的是 3D 的月台。
- **跟著那班車（決策 333 的跟車）**：飛到月台後車還沒到時，鏡頭會離開月台去追車；派工單要的是看月台與在那裡的車。
- **柔光光暈**（作者參考庫 `train-halo.js`）：畫風不用發光、漸層。
- **真實列車（台鐵、高鐵）**：要等 §22 的 3D 真實列車，下一步。
