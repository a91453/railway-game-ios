### 855. 冬季活動的 App 圖示：台灣站長黃山雀戴聖誕帽

2026-11-18，雲端工作串「做聖誕帽版 App 圖示」，分支 `claude/project-thread-rqxstt`，協調者派工（作者：「好」，同意冬季活動 12/1–1/6 換聖誕帽版的圖示；又說黃山雀「好像都沒出場的戲份」）。號碼依 #2118 的登記。不動 GameCore、存檔版本、golden、replay、任何 Swift 檔。

## 1. 做了什麼

- `RailwayGameApp/Resources/AppIcon.icon`（決策 680 的分層圖示）最前面多一組 5 層，都是 `christmas-` 開頭的 SVG：
  - `christmas-hat-white`：帽緣與毛球，白 `#FFFFFF`（`Map3DPalette.houseWalls[0]`）；
  - `christmas-hat-red`：帽身，紅 `#8C1C1C`（`Map3DPalette.trainRed`）；
  - `christmas-hat-outline`：帽子的外框，藏青 `#262C57`；深色與染色樣式是淺底 `#ECEEF6`；
  - `christmas-bird`：台灣站長黃山雀（決策 122 定稿的 `StationMasterTaiwanNormal`，造型、顏色一點都沒改，只放大 2.5 倍、拿掉底色與腳下的軌道）；
  - `christmas-bird-ring`：鳥外圍一圈淺底色 `#ECEEF6`，淺色時把鳥和藏青的高樓隔開，深色時是鳥的描邊（不然藏青的鳥會沒入藏青的底）。
- 鳥坐在中間那棟高樓頂上，蓋住樓頂的小突出物與最上面那扇窗。其他四組（黃點、建物、軌道）一個位元組都沒動。
- 沒有新色：兩個 3D 色票（`Map3DPalette`）的顏色與圖示原本的四色。
- 所有尺寸由 Xcode 從 `.icon` 產生（決策 680），不另外存 PNG。App 裡的平面品牌圖 `BrandMark` 不換。

## 2. 什麼時候換回

這一版是主圖示本身，不是「替代圖示」：iOS 換替代圖示一定跳系統對話框，不能照日期悄悄換。所以**活動結束後的第一版（1/6 之後）把這組拿掉**：刪掉 `icon.json` 的第一組與 `Assets/christmas-*.svg` 五個檔，圖示就回到決策 680 的原樣（其他圖層沒動過）。這一項記在私有素材庫的交接檔。

## 3. 選了哪一種

預覽在 `docs/art/app-icon-christmas-2026-11-18/options.jpg`（每列：淺色 300／120／60 點、深色同、模糊、灰階）：

- A 只加帽子，戴在中間高樓頂上；
- B 黃山雀戴帽站在左邊矮樓上（鳥太小，60 點就糊成一團）；
- **C 黃山雀戴帽坐在中間高樓頂上（選這個）**。

成品各尺寸在 `final.jpg`（由 commit 的 SVG 與 `icon.json` 組出來的，淺色、深色各 360／180／120／87／58 像素）。

- 玩家：12 月打開手機就看到站長戴聖誕帽，認得出是遊戲裡的角色；黃色的鳥加紅帽，主畫面大小一眼看得出。
- 鐵道迷：無。
- 開發：只加一組圖層，換回時整組刪掉，不碰原本的圖層。
- 美術：站長照決策 122 的定稿不改；帽子是平塗、藏青外框，和站長同一種畫法；顏色只取現有色票。A 最乾淨，但看不出是誰在過節，作者要的是讓黃山雀出場。
- 音樂：無。

## 4. 驗證

- VERIFIED（Linux 雲端容器）：`icon.json` 用 JSON 解析；五個 SVG 只用 art-style 第 3 節允許的元素與屬性；用 Chromium 照 `icon.json` 的層序與深色指定組出淺色、深色兩張，和作者看過的預覽 C 是同一張。
- UNVERIFIED LOCALLY：Xcode 的 `actool` 編得過（看 CI 的 `release-archive.yml`、`ios-build.yml`）；玻璃、陰影與透明／染色樣式的實際樣子（`ictool` 只在 Mac）；實機主畫面。一層裡有多種顏色的 SVG（`christmas-bird`）在 Icon Composer 是否照原色顯示，Mac 上用 `ictool` 看一次。
