### 855. 冬季活動的 App 圖示：中間高樓戴聖誕帽

2026-11-18，雲端工作串「做聖誕帽版 App 圖示」，分支 `claude/project-thread-rqxstt`，協調者派工（作者：「好」，同意冬季活動 12/1–1/6 換聖誕帽版的圖示）。號碼依 #2118 的登記。不動 GameCore、存檔版本、golden、replay、任何 Swift 檔。

## 1. 做了什麼

- `RailwayGameApp/Resources/AppIcon.icon`（決策 680 的分層圖示）最前面多一組 3 層，都是 `christmas-` 開頭的 SVG，一頂聖誕帽戴在中間那棟高樓頂上：
  - `christmas-hat-white`：帽緣與毛球，白 `#FFFFFF`（`Map3DPalette.houseWalls[0]`）；
  - `christmas-hat-red`：帽身，紅 `#8C1C1C`（`Map3DPalette.trainRed`）；
  - `christmas-hat-outline`：帽子的外框，藏青 `#262C57`（和高樓同色，帽子像長在樓頂上）；深色與染色樣式是淺底 `#ECEEF6`（和建物同一套指定）。
- 其他四組（黃點、建物、軌道）一個位元組都沒動。沒有新色。
- 所有尺寸由 Xcode 從 `.icon` 產生（決策 680），不另外存 PNG。App 裡的平面品牌圖 `BrandMark` 不換。

## 2. 什麼時候換回

這一版是主圖示本身，不是「替代圖示」：iOS 換替代圖示一定跳系統對話框，不能照日期悄悄換。所以**活動結束後的第一版（1/6 之後）把這組拿掉**：刪掉 `icon.json` 的第一組與 `Assets/christmas-*.svg`，圖示就回到決策 680 的原樣。這一項記在私有素材庫的交接檔。

## 3. 選了哪一種

預覽在 `docs/art/app-icon-christmas-2026-11-18/`：`options.jpg` 是第一輪（A 只加帽子、B 台灣站長黃山雀戴帽站在左邊矮樓、C 黃山雀戴帽坐在高樓頂），`round2.jpg` 是第二輪（C、A2 只戴帽、C2 鳥小一號）。第一輪先做了 C，作者看了說「看起來有點怪」：站長是有細節的角色插畫，圖示是幾何色塊，放在一起像貼紙，深色時外圍那圈淺色更明顯。改成 **A2**。

- 玩家：12 月主畫面一眼看得出過節，縮到最小也乾淨。
- 鐵道迷：無。
- 開發：只加一組三層，換回時整組刪掉，不碰原本的圖層。
- 美術：帽子是平塗加藏青外框，和圖示本身同一種畫法；顏色只取現有色票。站長的戲份放到遊戲裡比放在圖示上自然。
- 音樂：無。

## 4. 驗證

- VERIFIED（Linux 雲端容器）：`icon.json` 用 JSON 解析；三個 SVG 只用 art-style 第 3 節允許的元素與屬性；用 Chromium 照 `icon.json` 的層序與深色指定組出淺色、深色（`final.jpg`），和預覽 A2 是同一張。
- UNVERIFIED LOCALLY：Xcode 的 `actool` 編得過（看 CI 的 `release-archive.yml`、`ios-build.yml`）；玻璃、陰影與透明／染色樣式的實際樣子（`ictool` 只在 Mac）；實機主畫面。
