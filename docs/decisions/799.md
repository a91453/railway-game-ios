### 799. 羅瓦涅米地圖的建物、雪地與 1,524 mm 軌距（ROVANIEMI-MAP-2）

2026-11-16，ROVANIEMI-MAP-2（雲端 session_01JMHz9ZMDXyXPV7QMGtNCaN，`claude/rovaniemi-map-2`），遊戲規劃派工，接決策 789（ROVANIEMI-MAP-1）。企劃在 [`research/WINTER_EVENT_2026-11-15.md`](../research/WINTER_EVENT_2026-11-15.md) §3–4。GameCore、存檔（107）、golden、SaveFixtures、ReplayFixtures 都不動；`OverseasMaps.open` 仍沒有羅瓦涅米，玩家還看不到這張地圖。

## 看到什麼

決策 789 的地圖包有鐵道、時刻、底圖、地形與人口，3D 地圖上卻沒有一棟建物；地面是台灣地圖的草綠、田綠與林綠，北極圈上的城看起來像夏天；鋼軌照台灣的 1,067 mm 畫，芬蘭是 1,524 mm。

## 決定

1. **建物**（`tools/rovaniemi-map/build_rovaniemi_buildings.py` → `MapPacks/rovaniemi/buildings.pmtiles`）：格式是台灣與香港的 `footprints/2`，用台灣那支工具的編碼器、香港那支工具的讀檔與用途表，遊戲原本通用的讀法（`MapPack.buildingsFile`）直接讀，Swift 不用改。
   - 來源全是 OpenStreetMap（osmtoday 的 `europe/finland.pbf` 切出的同一份 `rovaniemi.pbf`，pyosmium）。讀到 59,726 棟，收 42,648 棟；不到 30 m² 又沒標成住人或營業用途的 17,078 棟（每戶旁的柴房、車棚、小倉庫）不收，否則每棟房子旁邊會撒一圈小方塊。
   - 樓層：有 `building:levels` 或 `height`（每層 3.2 m）的 1,116 棟照標的；其餘 41,532 棟用有標的去猜，依序找第一個有 30 棟以上樣本的：同類、同人口密度、同面積 →（任何類）同密度同面積 → 同類同面積 → 同面積 → 1 層；取樣本的第 25 到 75 百分位之間，照位置的雜湊挑。第二階（同密度）是量過才加的：沒有它時村裡的大房子會照市中心公寓猜成 3–4 層。台灣工具自己的後備（2–4 層）不用，那是台灣的鎮。
   - 結果：1 層 37,754、2 層 3,321、3–5 層 1,553、6 層以上 20，最高 8 層；7,519 個圖塊。
   - **地圖包變大 1,007,139 bytes**（13,358,067 → 14,365,206，約 13.4 → 14.4 MB）。
2. **雪地**（`Map3DSnowGround`，`Map3DNorthernMap.swift`）：地圖錨點在北緯 60° 以北時（不寫死羅瓦涅米），場景上完模型風格後把地面的綠色換掉。只換地面的顏色，不加頂點、貼圖或繪製。
   | 原本 | 雪地 | 色 |
   |---|---|---|
   | 田、草地、公園（#E2EBCF、#C8DFC0） | 雪原 | `Map3DPalette.sidewalk` #F7F7F4（既有） |
   | 沙地（#F2E2BD）、矮房子的院子（#DEEACF 與它在格角的混色） | 一般地面 | `Map3DPalette.ground` #ECEEF6 與既有的 `groundMixes` |
   | 路基的草坡（#9DB07E） | 淺鋪面 | `Map3DPalette.paved` #E4E3DF（既有） |
   | 樹林（#B6DDCA） | 積雪的樹林 | **新提 #D1E6E0**（林色與地面色各半），`Map3DSnowGround.wood` |
   | 濕地 #D7E4EA、水 #86D3E3、道路、鋼軌、道碴、建物、樹 | 不變 | |
   新色只有一個。河與湖結冰、樹冠積雪、屋頂積雪留給之後的雪景；遊戲沒有季節，所以整年都是雪地。
3. **軌距**（`Map3DTrackGauge`）：查過，3D 軌道的軌距是寫死的（`Map3DScene.Builder.gauge = 1.067`，只用在鋼軌的位置）。改成依地圖錨點：芬蘭範圍（北緯 59.5–70.2、東經 19.0–31.6）1.524 m，其餘（台灣、香港、沒有錨點的地圖）照舊 1.067 m。道床寬度不變（3.4 m，放得下）。列車模型的輪距是各車型自己的（決策 410 的 `gauge`），這張沒有芬蘭車，沒動。
4. **資料來源頁**：羅瓦涅米一節加「羅瓦涅米的建物」（OpenStreetMap，ODbL 1.0；沒記錄的樓層是本遊戲的估計），地圖開放後才會出現。

## 備用車擋住夜車一分鐘：量過，沒有改

派工單的第一項。資料（a）與收購時的停放股道（b）都試過，量法是收購後跑一整週、每分鐘問 `deadlock`，數被判卡住的分鐘（週一到週日）：

| 做法 | 凱米耶爾維線 | 穆羅拉線 |
|---|---|---|
| 現在的資料（凱米耶爾維過夜 1 列） | 1,0,0,0,1,2,2（共 6） | 3,0,0,3,1,2,7 |
| 三列都在羅瓦涅米過夜 | 0,0,0,1,3,4,2（共 10） | 一樣 |
| 凱米耶爾維過夜 2 列／3 列 | 共 7／共 6（回送 3／7 班） | 一樣 |
| 穆羅拉過夜 0／1／3／4 列 | 一樣 | 都不比現在少；4 列時最長 2 分鐘 |
| 過夜車改停最後幾股 | 0,1,1,1,1,2,2 | 7,6,6,8,6,3,7，最長 2 分鐘 |

沒有一種整週比現在少，所以資料、收購配置與測試（最多 1 分鐘）都不改。原因在 GameCore：被擋的是**已經在路上**的車（`departs == false`）。有閉塞區間（決策 212）時，終點月台還被閒置的車占著它也能先出發、拿前半段路；走到盡頭才等。這時站裡有空月台（`alternativeRoute` 找得到），但改走空月台（決策 57、571）只在出發時做，路上的車只能等調度下一分鐘把閒置的車移開。要到 0 得讓路上等月台的車也能改走空月台，會動 golden 與 replay，另開一張（見交接）。

## 五方

- **玩家**：城有房子、地是雪，一眼看得出在北極圈；猜的樓層寧低勿高，湖邊小屋不會變四層樓。
- **鐵道迷**：軌距照芬蘭的 1,524 mm；建物外形與有標的樓層是 OpenStreetMap 的真實資料，猜的部分在資料來源頁說明是估計。
- **開發**：建物不改 Swift（包裡多一個檔）；雪地與軌距各是一個依錨點的純函式，其他地圖的畫法逐色、逐毫米有測試保證不變；不加頂點，畫面成本不變。
- **美術**：只用 `Map3DPalette` 既有的白與一個新色；雪原比一般地面亮一階、樹林仍看得出是樹林、路基用淺鋪面色才不會和雪混在一起。預覽 `docs/art/rovaniemi-map-2026-11-16/`。
- **音樂**：無。

## 其他選項（沒選）

- 全部地面一律 `ground`：田、公園、樹林全消失，地圖只剩路。
- 雪地寫死 `OverseasMap.rovaniemi`：之後別的北方地圖要再改一次；用緯度不用。
- 把芬蘭加成 `Map3DStreetRegion` 的一區（順便拿掉機車格、紅線、綠色人行道）：動很多街道檔，和 WINTER-LIGHTS 同一批檔案，留在交接。
- 小建物全收：多 17,078 個小方塊、圖塊再大約四成，畫面更亂。
