### 1010. 全地圖解鎖：遊戲唯一的內購（一個地區免費）

2026-11-26，雲端工作串「做 1.1 海外地圖一次解鎖內購」（分支 `claude/project-thread-fc2z9c`），協調者派工。
收費定案（作者 2026-11-26「我不知道」，由收費研究串拍板）：12/1 免費上架 0.7.0、不放內購；下一版
（0.8.0）加一個非消耗性內購「海外地圖全解鎖」，約 US$4.99，台灣永遠免費，免費版就下載的玩家自動送。
不賣遊戲幣、不放廣告、不訂閱，不拿真實公司的車當付費商品。號碼依 #2118 的登記：決策 1010；
存檔版本、golden schema、GameCore 都不動。**0.7.0 送審之後才合**，跟 0.8.0 一起送審（第一個內購
要跟新版一起審）。**改為 0.7.0「審過」之後才合**（獨立審查第 2 點：testflight 只從 main 出版，合了之後出的每個
build 都帶鎖；0.7.0 若被退件要從 main 重出、或要出 0.7.x 修正，出去的就是帶鎖、內購還沒過審的版本）。還可能出
0.7.x 修正時，等那一版出完再合。

**改版（2026-11-26 下午，作者「第一次選免費 類似 香港 要解鎖台灣就要買」「台灣解鎖香港也要買」）**：不再是「台灣免費、海外付費」，
改成**玩家自己選一個地區免費**（台灣、香港、日本九州、芬蘭羅瓦涅米擇一），其餘地區（包含台灣）用同一個內購一次買齊。
商品顯示名稱改「全地圖解鎖」／"Unlock All Maps"，描述「一次解鎖全部地圖，包含之後新增的地圖」／"Unlock every map,
including future ones"（協調者已給作者）。Product ID 照舊 `overseas_maps`（建了不能改），程式裡的型別名 `OverseasUnlock` 也照舊。

## 1. 玩家會看到什麼

- **地區**：台灣（全台灣與台灣各地的實景開局）、香港、日本九州（福岡、佐賀、熊本、長崎同一區）、芬蘭羅瓦涅米，各算一區。
  空白地圖、教學、課程與挑戰、台灣以外沒有地圖包的小地圖都不算地區，永遠免費。
- **還沒選**：新遊戲 →「實景地圖」最上面一列「全地圖解鎖」，寫「可以先免費選一個地區：第一次開新局的地區就是你的免費地區，
  選了之後不能換。」，下面有「購買 · NT$…」與「恢復購買」。所有地區都能點。
- **第一次在實景地圖開新局**：先跳一個確認「把香港當成你的免費地區？選了之後不能換。之後在其他地區開新局，需要『全地圖解鎖』。」
  ［選香港］［取消］。按了才開局、記成免費地區。朋友傳來的路網選「用這個路網開新局」也算一次開新局（沒有確認視窗，因為那是朋友
  的路網畫面，不在選地圖清單）。
- **選了之後、沒買**：那一列改寫「你的免費地區：香港。」；其他地區（台灣也一樣）的列上鎖，寫「購買本頁上方的『全地圖解鎖』後，
  就能在這裡開新局。」；硬要開會說「你的免費地區是香港。在其他地區開新局，需要『全地圖解鎖』。」
- **買了**：那一列消失，**全部地區立刻能開**，不用再等航線（決策 712 的開航對買了的人只剩新聞）。理由：名字叫「全地圖解鎖」，
  付了錢還要等開航會被當成騙人，審查也可能以「買了沒拿到」退件。
- **免費版就下載的玩家**（0.7.x 的 build）：等同買了，一打開就全開，設定裡寫「已解鎖：你在免費版時就下載了遊戲，送你完整版。」
- **已經存的遊戲**：不管哪一區、有沒有買都能讀、照常玩、照常存。只有「開新局」看免費地區與內購。
- **匯入的存檔檔案**（別人的 `.railwaygame` 存檔，`importSave`）也算存檔，照玩。理由：存檔就是存檔，不分是誰的；
  要分就得在存檔裡記「誰開的局」，換手機、iCloud、備份還原都會被誤擋，比漏掉幾個人更糟。
- **朋友傳來的路網**：「只看」照舊；「用這個路網開新局」是那一區的新局，照上面的規則。空白地圖的路網不算地區。
- **設定**：多一節「購買」：免費地區那一行（或「可以先免費選一個地區…」）、買、恢復購買；解鎖了寫為什麼。

## 2. 規則

- 商品：非消耗性，Product ID `overseas_maps`（`OverseasUnlock.productID`）。
- 誰算全開（`GameLauncher.allMapsOpen`）：買了（`Transaction.currentEntitlements` 裡有它、沒有被撤銷；
  恢復購買、家人共享都算），**或**是免費版玩家，**或**演示模式開著（測試版才有，決策 351）。全開時 `airRoutes` 的
  `opened` 是全部地圖，所以航線不再擋。
- 免費地區（`LauncherPreferences.freeMap`，`GameLauncher.freeMap`）：還在賣（`sellsAllMaps`：App Store 有回答、又不是全開）
  時，第一次在實景地圖開新局（`takeMap(_:)` 通過）的那一區，記在裝置上（和存檔同一個資料夾的 `launcher-preferences.data`），
  之後不改。`mayStartNewGame(on:)`：不賣、或還沒選、或就是免費地區才能開；`takeMap` 先問它（被擋的不會被記成免費地區或第一張地圖），
  再問決策 712 的航線。羅瓦涅米不靠航線，但一樣是一區。
- 沒有 App Store 的地方（`overseasUnlock == nil`：Linux 測試、headless、Debug build 沒加 `-overseas-lock`）什麼都不賣、不選，
  地圖照決策 712 開（UI 測試與網站截圖照舊）。
- 免費版玩家（`OverseasUnlock.isFreeVersionPlayer`）：`AppTransaction.originalAppVersion` 在 iOS 是玩家第一次
  下載的 **build 號**（`CFBundleVersion`，`testflight-preflight.sh` 的 run 號，重跑是「148.2」），不是
  0.7.0 這種版號。取開頭的整數，小於 `OverseasUnlock.firstLockedBuild` 就送。只認 App Store 正式環境的答案：
  沙盒（TestFlight）一律回「1.0」，所以測試員看到的是要買的畫面，可以在沙盒免費買來測。
- `firstLockedBuild`：**這個 PR 合進 main 之後第一個 TestFlight build 的號碼**（合併前最後一個上傳的 build 號
  加 1）。在它之前的 build 都沒有鎖，App Store 上的 0.7.x 都在它之前；在它之後的 build 都有鎖。合併前要照當時
  最後一個 build 號改這個常數（現在填 150：11-26 時最新是 147）。合併之後出的 build 都帶鎖、也都賣解鎖，
  所以從那些 build 開始下載的玩家不送是對的。
- 鎖在哪裡：`GameLauncher.takeMap`（全台灣、台灣各地的實景開局、海外地圖 `startOverseasMap`）、`overseasMapRows`
  （每列 `needsPurchase`，蓋過航線與下載的理由）、`taiwanClosed(in:)`（全台灣那一列與「在這裡建造」），以及朋友路網的開新局
  （`play(_:as: .newGame)`，`paidMap(of:)`：城市的地圖、在台灣範圍內的實景地圖算台灣、其他不算）。讀檔、匯入存檔、
  自動存檔、只看路網都不經過鎖。
- 選地圖清單（`RealWorldPicker`）在 `choosesFreeMap` 時，開局前先跳 `confirmationDialog`。
- App 回到前景時再問一次 App Store（第一次剛好沒網路的老玩家，下次回來就好）；恢復購買時老玩家的答案用
  `AppTransaction.refresh()` 重問。讀購買狀態有遞增序號，只算最新那次，啟動時的讀取不會蓋掉剛完成的購買。
- 裝置記住上一次的答案（`overseasUnlock.purchased`、`overseasUnlock.freeVersionPlayer`，UserDefaults），一打開就
  照它，不會每次啟動先鎖一下、也不會沒網路就鎖；之後 App Store 的答案蓋過購買的值（退款會再鎖），老玩家的值
  一旦是真就留著。
- App Store 那一側在 App（`RailwayGameApp/App/OverseasStore.swift`，StoreKit 2）：啟動時讀、聽
  `Transaction.updates`（別台裝置買的、家長核准的、退款），購買用 SwiftUI 的 `@Environment(\.purchase)`，
  恢復購買是 `AppStore.sync()`。規則與字在 GamePresentation（`OverseasUnlock.swift`、`AirRoutes.swift`），Linux 測試
  `OverseasUnlockTests`。
- 已知的漏洞，接受：刪掉 App 重裝會清掉裝置上的免費地區（存檔也一起沒了，除非在 iCloud），可以再選一次。要擋就得把選擇存到
  伺服器或 iCloud 鍵值，多一個帳號相依；為了讓人重玩一次別區，不值得。

## 3. 五個角度

- 玩家：任選一區免費玩（不一定要台灣）、買一次全部開、不用等開航；選之前會問一次；老玩家自動送；舊存檔永遠能玩；沒有遊戲幣、廣告、訂閱。
- 鐵道迷：無（資料與路線不變）。
- 開發：不動 GameCore、存檔、golden、replay；規則接在決策 712 原本的「第一張地圖」上（`takeMap`），StoreKit 只在 App，規則有 Linux 測試。
- 美術：無（用系統按鈕、確認視窗與 SF Symbol）。
- 音樂：無。

## 4. 作者在 App Store Connect 要做的

見 PR 描述「App Store Connect 內購欄位」：建非消耗性內購、Product ID 必須和 `overseas_maps` 一字不差，
顯示名稱「全地圖解鎖」／"Unlock All Maps"，描述「一次解鎖全部地圖，包含之後新增的地圖」／"Unlock every map, including future ones"，
審查截圖、價格；送審時把它加進 0.8.0 版本頁的「App 內購買項目」一起送（不要掛在 0.7.0）。

## 5. 還沒做的

- 冬季活動（12/1–1/6）：**不另外開羅瓦涅米**，和其他地區一樣（協調者轉達作者不做設計抉擇，由這串拍板最簡單
  的做法）。理由：活動任務在任何地圖都能做、聖誕老人的雪橇在台灣地圖也會飛；0.7.0 從 12/1 開始免費，活動前段下載的
  玩家都是老玩家、全部本來就開著；多一個限時例外，要多一套日期判斷與說明，過了 1/6 還得收回。
- 沒有 StoreKit 設定檔（`.storekit`）；本機測購買用 TestFlight 沙盒。
