### 408. 高鐵兩款列車接進營運：#1201 的 700T 與作者的 N700S-G 各跑一半（單號 N700S-G、雙號 700T），E200 換成 #1201 的新車頭，各車照自己的長度，700T 遠處換成 #900 的輕模型

2026-10-25，遊戲規劃 session_01B2kaku5NRz2J2CMzc8z3cZ 派工（作者 10-25 同意），實作 session_01EYjQttfohUR8HPL2aYisHw。號碼依 #1041：決策 408；存檔版本、golden schema 不動；GameCore、SaveFixtures、ReplayFixtures 都不動。

開工時：高鐵（`HSR`）畫的是 #900 的 700T（場景套件 `02_HSR_MRT_3x2-01`，每節 20 m），莒光號的 E200（`E200CK`）是 `Map3DTrainLocomotive.e200`。#1201 的 E200 與 700T 第十版（`Map3DTrainShapeRefresh`）、#1214 作者的 N700S-G（私庫 `Railway/n700s-n700st-2026-10-24/n700s-g/`）都只是靜態素材，營運的列車沒有用到。

**做法**（只改 GamePresentation）：

1. **700T**（`Map3DTrainSet.highSpeed700T()`）：#1201 的頭車、中間車、集電弓車、尾車照原樣（外形不改），集電弓在第 4、9 節（同 #900 的 `pantographCars: [3, 8]`），每節照模型自己的長度（頭尾 25.24 m、中間 25.48 m，十二節 305.3 m；決策 399 的 `ownLengths`）。#1201 的燈罩（`Map3DPalette.tunnelLamp`）點亮：頭車前端白、尾車後端紅（`Map3DTrainSet.lit(_:front:)`）。
2. **遠景**：700T 每節 5,600–9,100 個三角形，十二節 74,528 個，是 #900 的 9.6 倍，所以只在 500 m 內畫它（`nearOnly`，同決策 331、399）；500–900 m 換成 #900 的 700T（新 set `highSpeedFar`，`Map3DTrainSet.far`），一節換一節（`Map3DModelPack.farModel(of:forType:count:)`、`model(_:forType:count:at:)`）；900 m 外照舊是方塊。每節照舊一個實例，CPU 的負擔（PLAYER_FEEDBACK 72.1 的遠景瓶頸）不變。
3. **N700S-G**（新檔 `Map3DN700SG.swift`）：用決策 230 的列車建模（`Map3DTrainBuilder`，其他高鐵、對號列車同一套）照作者的 mesh 重建成遊戲的「F 台灣版＋」：霧面、平塗、只用調色盤的頂點色。作者的 mesh 只量尺寸，不搬頂點。保留：
   - 長鼻（作者 7.7 單位 → 9.36 m）與鼻頂、側面、下巴收到鼻尖的曲線（`drop`、`lift`、`tuck`）；風擋在鼻上的位置（作者 x 4.9–6.5、寬 ±0.72，做成一片獨立的玻璃，邊緣不被頂點色暈開）；頭燈的位置（作者 x 8.75–9.21）。
   - 深綠 `#1D4A44` 在窗下分兩條（作者 z 2.16–2.26 細、2.31–2.52 粗）。
   - A–E 五種車的差別：每種的門位（作者的門 ×1.22，`Map3DN700SG.doors`）、D 的集電弓罩（作者 −7.8…−3.1 單位，高 5.18）、E 後端的鰭（−10.2…−9.7）。
   - 作者的顏色本來就是調色盤的（車身 #F6F6F4、裙 #8F959B、頂 #C5C9CD、玻璃 #26313D、門 #5D6670、燈 #FFF4D6）。
   - 三角形：頭車 1,154、中間 442–466（現有高鐵的頭約 1k、中間約 400）；十二節 6,872。作者的整列 95,624 個不用。
4. **N700S-G 的車長與編組**（我決定，同決策 399）：作者的尺寸 ×1.22（沿車長與寬），所以中間車 20.5 單位 = 25.0 m、頭車 20.75 = 25.3 m、車寬 2.8 = 3.36 m；高度照 700T 的斷面（地板 0.62 m、車頂 3.65 m）。25 m 是 GameCore 高鐵的車長（`carMetres` 25），也是真的 N700S 的中間車長。編組照 `assembly.json` 的單元：作者的十節是 A B C D E | E D C B A（它自己標 `VISUAL_DRAFT_NOT_REAL_FORMATION`）；遊戲的十二節在中間多兩節 C，後半是前半反過來（`Map3DN700SG.formation(cars:)`）：A B C D E C | C E D C B A，集電弓罩（D）落在第 4、9 節，跟 700T 同一處。其他節數同一條規則，一節就是 A。後半的車是同一個單元轉過來（`-reversed`），尾車的燈紅色。
5. **兩款怎麼分給營運的列車**：單號的高鐵列車是 N700S-G，雙號是 700T（`Map3DTrainSet.variant(of:number:)`；玩家的列車看 `TrainID`，實景時刻表的列車看它當天的班次序號 `number(ofRealTrain:)`）。只是畫面：同一列車每次都是同一款，存檔不用記。
6. **E200**（`hauled("E200CK", head: …)`）：#1201 的 E200 照原樣，前端燈點亮；後面照舊是橘色的莒光客車。#1201 的車頭是暖白綠松，跟橘色客車不同色，這是 #1201 的塗裝，照它。舊的 `Map3DTrainLocomotive.e200` 留著（不再被 set 用到）。
7. **玩家看的文字**：設定的資料來源加一條「白色高速列車」，只說它畫的是什麼、照作者的模型、經作者同意（`DataSourceCredits` 的 `highSpeedTrainModel`），不寫型號與程式名。

**作者模型的來源**：N700S-G 是作者自己的模型（#1214，私庫 `Railway/n700s-n700st-2026-10-24/n700s-g/`，`source_record.json` 的 producer commit `989c38d8`；私庫目錄最後一次 commit `dbbd528c`）。作者 10-25 確認可以放進這個公開的 repo 與 App。遊戲裡的是照它量的尺寸重建的，沒有搬作者的頂點、貼圖或圖片。App 的資料來源頁寫明「照遊戲作者自己做的模型、經作者同意」。

**五方**（分配：單號 N700S-G、雙號 700T）：
- 玩家：同一條高鐵線上兩款車輪流來，不用解鎖或設定就看得到新車；有兩列以上就兩款都有。
- 鐵道迷：台灣高鐵真的是 700T 與 N700S 系的新車同時在跑，十二節、集電弓在第 4、9 節都照 700T；但一半一半比真的車隊（新車約四分之一）多，綠線也是作者給遊戲的塗裝，不是高鐵的橘色，所以遊戲不叫它 N700ST。
- 開發：只動 GamePresentation，不碰 GameCore、存檔、golden、replay；款式由列車的號碼算出來，不用存；一個 `variant` 函式，玩家的列車與實景列車共用。
- 美術：兩款都是遊戲的畫風；700T 照 #1201 不改外形，N700S-G 照作者的形狀重建成平塗；700T 近處細、遠處換 #900，900 m 外照舊是方塊。
- 音樂：無。

**沒有選的做法**（預覽 `docs/art/hsr-trains-408/assignment.png`）：
- 照真實車隊的比例（約四分之一是新車）：比較真，但玩家只有兩三列高鐵時可能一列 N700S-G 都沒有。
- 每條線一款：玩家只有一條高鐵線時只看得到一款。
- 讓玩家每列自己選：要在存檔裡記，這次派工不能動存檔；寫進下一步。
- 放進列車包（決策 338）：作者要它跑在營運裡，不是收藏。
- 全部換成一款：另一款就看不到了。
- N700S-G 照作者的單位每節 20.5 m 再拉到 20 m 的固定節距：跟 700T 的 25 m 並排時短一截；GameCore 的高鐵車長是 25 m。
- N700S-G 照作者的十節：GameCore 的高鐵是十二節，少兩節後面就空了。

**限制**：
- 實景時刻表的列車照舊用固定節距（`Map3DRealTrains.carPitch`），模型拉到那個長度，沒有照自己的長度。
- E200 沒有遠景模型，900 m 內都是 #1201 的 5,512 個三角形（同其他機車的 900 m）。
- 700T 在 500 m 換成 #900 時外形會變（#900 是較舊的 700T），實機看跳不跳。
