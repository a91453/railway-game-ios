### 347. 3D 地圖的天空：漸層穹頂、太陽、夜裡的星星與月亮

2026-10-22，遊戲規劃 session_014rYHMtmqA5bEMkBBuKu6PV 派工（NEXT_PRIORITIES §22.10「3D 畫面追上網頁試作」第 1 項），實作 3D session_01ShaLWGSyEn9fYcNjS8j5Gz，換手後由 session_01H2iSUj5f1cCXAwjvuFvbsp 收尾。號碼依 #231：決策 347；存檔版本、golden schema 不動。GameCore 不動，只動 GamePresentation 與 App。

**做了什麼**：3D 地圖沒畫到東西的地方（地平線以上），以前是一片單色的背景，現在是天空：地平線是霧的顏色（遠處地面融進去），往上漸漸變成這個時辰的天頂色（`Map3DLighting.zenith`，決策 229 的時辰表裡一直有、但沒用到）。白天有太陽的光暈與日面；晴朗的夜裡有星星和月亮。下雨時天頂帶雨的灰，看不到太陽、月亮與星星。

**怎麼畫**（`Map3DSky`，GamePresentation，Linux 測試；`map3dSkyVertex`／`map3dSkyFragment`，`Map3DShaders.metal`）：

- 一個蓋住整個畫面的三角形，深度 0（反轉深度的最遠處，決策 342），在不透明的東西之後、地面陰影之前畫；深度比較 `greaterEqual`、不寫深度，所以只填到深度還是清除值 0 的像素，也就是什麼都沒畫到的地方。一次繪製、一個三角形，不加 pass。
- 每個像素由相機的方向、右、上與鏡頭的半寬半高（`Map3DSky.floats(camera:)`，36 個 float）算出看出去的方向 d，顏色：
  - 底色 `mix(地平線, 天頂, sqrt(max(d.y, 0)))`，地平線以下都是地平線色；
  - 太陽：光暈 `pow(·,12)×0.18 + pow(·,180)×0.5`，日面 `smoothstep(0.9994, 0.9998)`（sky.js 的數字）；太陽的路徑和 `Map3DLighting` 的光一樣，6 時東方升起、12 時偏南最高、18 時西方落下；
  - 月亮：只畫滿月一種形狀，18 時東方升起、0 時最高、6 時西方落下，比太陽低一點（`rise` 0.9 對 1.15）；光暈 `pow(·,80)×0.12`；顯示量 = 晴朗 × 夜的程度；
  - 星星：sky.js 的雜湊格（220 格、門檻 0.9975、離地平線越近越少，`smoothstep(0.1, 0.5, d.y)`），顯示量 = 晴朗 × `smoothstep(0.5, 1, night)`。sky.js 一格就是一顆星；駕駛室的 68° 廣角下一格有好幾個像素，會畫成方塊，所以 shader 改成在有星的格子裡、照雜湊挑的位置畫一個約一像素的圓點（用 `fwidth` 換算像素，近看遠看都一樣大）；Swift 的 `colour(toward:)` 仍以整格計，測試只看哪些格有星；
  - 晴朗 = 1 − 天空混雨色的比例 ÷ 雨天的比例（`Map3DWeather.rain.skyMix`）。
- `Map3DSky.colour(toward:)` 用 Swift 算同一個公式，測試拿它驗證；改公式時兩邊一起改。`Map3DLighting` 多記一個 `hour`（0–24）。

**量到的**：自由視角最多斜 42°、鏡頭高 35°，畫面最上緣仍在地平線下 30°，所以一般看地圖時**看不到天空**，這個三角形的像素全在深度測試就被丟掉。看得到天空的是跟車（決策 333、337）：「後方」（85°）畫面約 36% 是天空，駕駛室（約 89°、68° 鏡頭）約 49%，「上後方」（60°）0%。每幀多 1 次繪製、1 個三角形。Linux 測試（`Map3DSkyTests`）：地平線與地平線以下是霧色、天頂是天頂色；正午天頂是亮藍、子夜暗；白天有日面、子夜有月亮與星星、傍晚月亮在東邊、清晨在西邊；雨天三者都沒有；星星稀疏且地平線附近沒有；畫面上一點算出的方向經相機投影回到同一點。App 的 Metal 部分：UNVERIFIED LOCALLY（要 macOS CI 編譯，實機看樣子）。

**五方**：

- 玩家：跟車與駕駛室視角裡，畫面上半不再是一片平的顏色，有晨昏的漸層、白天的太陽、晴夜的星星和月亮；下雨時天也陰。
- 鐵道迷：無（天空和鐵道資料無關）；太陽與月亮的東升西落和時辰一致。
- 開發：GameCore 不動；公式在 GamePresentation 有 Linux 測試，shader 照抄；不加 pass、不加貼圖，一般視角沒有額外的像素成本。
- 美術：色彩沿用決策 229 的時辰色（天頂色本來就有），地平線是霧色，遠處地面與天空接得起來；星星稀、小、只在高處，不搶畫面。
- 音樂：無。

**沒選的**：

- **體積雲或 sky.js 的 fbm 雲**：派工說不做；fbm 每像素五層雜訊，跟車時畫面一半是天，iPad 上不值得。之後要雲，先做一張雲的貼圖。
- **先畫天空**（sky.js 的做法）：每個像素都要算一次天空，再被建物蓋掉；後畫只算真的看得到的像素，而反轉深度清成 0 讓「沒畫到」一比就知道。
- **月光跟著月亮走**：場景的夜光方向（`sunDirection` 在夜裡）維持原樣，只動看得到的月亮；改光的方向會動到陰影（決策 232）與窗的亮法，另開一項。
- **月相**：只畫滿月；月相要日期，遊戲的日曆不是真的陰曆。
- **天空寫進霧與反光**：第 2 項（調色、高度霧）與第 5 項（玻璃、水面映天空色）會用 `Map3DSky` 的地平線與天頂色。
