### 947. 單軌、磁浮、懸吊式單軌的軌道梁

2026-11-23，雲端工作串 GUIDEWAY-BEAM，分支 `claude/guideway-beam`。作者的話：「你做了磁浮跟單軌列車但沒做軌道啊」。補決策 930 §4 留下的「單軌、磁浮、懸吊式單軌仍站在一般軌道上，沒有軌道梁」。號碼依 #2118 的登記。

不動 GameCore、存檔版本、golden、replay。

## 1. 做了什麼

1. **哪一段是軌道梁**（`Map3DGuideway.edges(in:)`，只在畫面層推得）：一條路線的列車全是同一種導軌車（`MONORAIL` 跨座式單軌、`MAGLEV` 磁浮、`SKYRAIL` 懸吊式單軌），它開的路（本線與每個有車的停站模式，`lineJourney` 與 `legEdges`）畫成那種梁。一段路同時有一般列車的路線、或兩種不同的導軌車在走，就仍畫成一般軌道。沒有車的路線不算。一般列車的路線只看和導軌線共站的那些（其他的不會走到同一段）。
2. **梁取代鋼軌、枕木、道碴與架空線**（`addTrackPiece` 的 `guideway`、`addOverheadLine` 跳過 `guidedTrackLines`）。梁的斷面照工作室三款車的 GLB 量，沿軌道線掃出（同 `metro-kit.js` 的 `strips`）：
   - 跨座式：混凝土梁寬 0.85 m、深 1.5 m，兩側深色供電軌；每 20 m 一根 1.0 × 1.2 m 的墩。
   - 磁浮：T 形梁，頂板寬 2.8 m、腹板寬 1.6 m、深 2.0 m，頂板下緣深色定子；每 25 m 一根 1.1 m 見方的墩（尺寸取自參考庫 `taiwan-maglev-world.js`）。
   - 懸吊式：鋼箱梁寬 1.8 m、下方開 0.5 m 的槽，車掛在下面；每 25 m 一座門形架（腳距 4.4 m、腳與橫梁 0.6 m）。
   - 梁底離地不到 0.3 m 的地方不立墩；隧道裡照舊是隧道，不立墩。
3. **車在梁上跑**：梁的行走面畫在「鋼軌頂 + 車的 `lift`」，`lift` 改由梁決定（`Map3DGuideway.Kind.runningSurface`：跨座式 1.3、磁浮 0.75、懸吊式 4.1 m），所以列車的程式與模型都沒動，車在原本的高度剛好落在梁上（跨座式與磁浮的裙板包住梁，懸吊式的轉向架在箱梁裡）。
4. **月台與車門齊平**：月台面 = 行走面 + 門檻（照網格量：跨座式 1.15、磁浮 0.95、懸吊式 −3.93 m），即比鋼軌頂高 2.45、1.70、0.17 m；月台線整條跟著升降，雨棚、設施、候車的人、月台燈一起走。磁浮車寬 3.70 m，月台邊離中心 1.9 m（其他 1.6 m）。懸吊式在月台旁不立門形架的腳。
5. **遠景與夜裡**：梁身在每個距離都畫（遠景就是一根方梁，沒有另做），深色細部只在近景。梁沒有自己的燈，夜裡和其他結構一樣暗；月台燈跟著月台的新高度。
6. **重建場景**：App 的 `Map3DSceneKey` 多一個 `Map3DGuidewaySignature`（有導軌車的路線、種類、停站與停站模式有沒有車），一變就整個重建（不是只換軌道）；`Map3DSharedBuild` 快取每個世界的判斷。

總覽：`docs/art/guideway-beam-2026-11/overview.png`（三列：跨座式、磁浮、懸吊式；四欄：車站、沿線、遠景、夜裡車站）。

## 2. 五個角度

| 角度 | 理由 | 分數（1–5） |
| --- | --- | ---: |
| 玩家 | 單軌與磁浮不再站在鋼軌上，看得出是另一種交通；月台和車門齊平 | 4 |
| 鐵道迷 | 三種導軌各自的梁形（跨座、T 形、懸吊箱梁）與墩、門形架；不畫架空線 | 4 |
| 開發 | 只在畫面層推得，不動 GameCore 與存檔；列車程式不動，只換 `lift` 的來源 | 3 |
| 美術 | 用既有的混凝土、鋼、深色三色；斷面照工作室的車量，遠景不另做 | 4 |
| 音樂 | 無 | 1 |

### 沒選的選項

- **選項 2：GameCore 加一種軌道（導軌）**。鋪線時選軌道種類，梁是世界的一部分，混跑由規則擋下。要升存檔版本、加遷移與存檔樣本，改鋪線介面、成本與 golden；玩家已有的導軌車路線要遷移後才看得到梁。作者要的是「看起來是梁」，現在的推法不需要這些，留到哪天導軌要有不同的造價或速度時再做。
- **後來**：派工的主規劃 2 在這個 PR 開了以後（訊息晚到）定了選項 2 為下一步（TRACK-SYSTEM，`docs/handoff/GUIDEWAY-BEAM.md`）。這裡的畫法照用，只把「哪段是梁」的來源換成軌道自己的屬性，這裡的推法改做舊存檔的遷移。
- **永遠高架**：真實的單軌多在高架上。現在梁跟著軌道的高度（地面的軌道就是貼地的梁、高架就在橋上），要整條抬高得動橋的規則，沒做。

## 3. 找過什麼

| 參考 | 用到哪裡 |
| --- | --- |
| `Railway/rail-reference/regions/taiwan/source/rail-3d/garage-scenes/metro-kit.js` 的 `guideway()`、`strips()`（斷面沿線掃出） | `Map3DGuideway.sweep` |
| `OpenWorld/reference_snapshot/play/src/world/taiwan-maglev-world.js` 的墩（柱 1.1 m；它的墩距 125 m、墩帽 7.9 m 是高鐵式的寬橋，沒用） | `Map3DGuideway.column(of: .maglev)` |
| `Railway/rail-reference/regions/world/source/tools/fleet/t_special.py` 的 `monorail_skirt` | 車的裙板已在決策 930 的模型裡，這裡只對齊梁 |
| `Simulator/`、`MapBuilder/` | 沒有單軌、磁浮或導軌的東西 |

外面的開源專案：OpenTTD、Simutrans 有單軌與磁浮的軌道種類，但都是 GPL，只參考了「軌道種類」這個做法（選項 2），沒有抄程式。梁的斷面與推法是這個專案自己的。

## 4. 留下的

- 不在路線行程上的段（機廠的股道）仍是一般軌道。
- 地下（隧道內）車站的月台沒有升降。
- 懸吊式的車站沒有門形架撐梁（月台旁的腳都省了）。
- 兩段軌道接縫兩側的墩可能靠得很近。
- 一般路線只看和導軌線共站的那些（不共站卻共用一段的極少見）。
- 預覽工具只鋪得出直線（三點的路線有轉角，車開不過去），彎道沒有拍圖；彎道和鋼軌走同一條掃出的線。
