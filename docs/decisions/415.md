### 415. 「這版新增」卡：更新後第一次打開時說這版多了什麼

2026-10-25，遊戲規劃 session_01KvN8GrLosqRswrXMQgVQir 派工（`docs/research/NEXT_PRIORITIES_2026-10-12.md` §22.2 第 19 名；來源 §15.2 第 4 名、§16 第 5 項），實作 session_01J7edxy3rWsd9gKqSFMyPa4。號碼依 #1041：決策 415；存檔版本、golden schema 不動。GameCore 不動，只動 GamePresentation、App 與測試。放空模式是決策 414，另一個 PR（#1261）。

**做了什麼**：

- 更新過的 App 第一次打開時，開始畫面跳出一張「這版新增」卡：「新增」幾行、「修好的」幾行，兩種語言，照遊戲的語言顯示。按「完成」關上，之後不再跳。
- 新安裝不跳（什麼都是新的）。
- 想再看一次：「說明」第二列「這版新增」（第一列仍是資料來源與授權）；說明的搜尋找得到它的名字和這版的內容。
- 卡片底下接著列更早幾版的（「更早的」），只要還留在清單裡。

**什麼時候跳**（`GameLauncher.showsWhatsNew`）：

| 情況 | 跳不跳 | 怎麼判斷 |
| --- | --- | --- |
| 新安裝（沒有 `launcher-preferences.data`） | 不跳 | 第一次啟動就把 `whatsNewSeen` 記成最新一則的 id |
| 從沒有這張卡的舊版更新上來 | 跳一次 | 舊的偏好檔沒有 `whatsNewSeen`（讀成 `nil`） |
| 看過上一則，這版加了新的一則 | 跳一次 | `whatsNewSeen` 不等於最新一則的 id |
| 看過最新一則 | 不跳 | 相等 |
| 卡片跳出來但沒按「完成」就關掉 App | 下次再跳 | 關上卡片（`onDismiss`）才記下 |

偏好檔多一個可省略的欄位 `whatsNewSeen`，舊檔照讀（`WhatsNewTests.testPreferencesFromBeforeTheCardStillRead`）；這不是存檔，存檔版本不動。

**內容從哪裡來、發版時怎麼更新**：

- 內容寫在 `Sources/GamePresentation/WhatsNew.swift` 的 `WhatsNew.entries`，最新的在最前面；每一則有 `id`、`items`（新增）、`fixes`（修好的），每行英文與中文各一句。
- `id` 用日期（`2026-10-25`）。只要最前面那一則的 `id` 變了，所有更新上來的玩家都會再看到一次。
- **每次發 TestFlight 前**（遊戲規劃 session 寫 `.github/testflight-whats-new.md` 的同時）：
  1. 上一則已經發出去了（它的 id 出現在某個已發佈 build 裡）：在最前面加一則新的，id 用當天日期，不改舊的那則。
  2. 上一則還沒發出去（兩次發版之間又加了東西）：直接改最前面那一則的內容，id 不動。
  3. 內容從 `testflight-whats-new.md` 的「新增的」「修好的」挑玩家看得懂、會在意的，改寫成一兩句「能做什麼」；請測試者看的項目、測試版才有的開關、內部名稱不放（`docs/UI_THEME.md` 玩家看的文字）。中文一行不超過 60 字（測試會擋）。
  4. 清單只留最近三則，第四則刪掉。
- 兩者分開是因為讀的人不同：`testflight-whats-new.md` 給測試者，只有中文、要寫請他們看什麼；這張卡給玩家，兩種語言、只說新功能。
- 這版（2026-10-25）的內容是 88.1（`c4fc5b6`）之後合併的：捷運收購（#1239）、自有建築第 2 批（#1232）、成就圖（#1249）、EMU3000 重做（#1229）；修好的：高鐵示範開局卡住（#1260）、N700S-G 後半列與長編組車尾（#1259、#1245）、高鐵高架馬上換樣子（#1247）。放空模式（#1261）後合併，由它加進最前面那一則。

**五方**：

- 玩家：更新後一眼知道能玩什麼新東西，只跳一次，關了就不煩；想再看在「說明」。
- 鐵道迷：新的路線、車款（捷運收購、EMU3000）寫在第一眼看得到的地方。
- 開發：只動畫面層；規則在 GamePresentation，Linux 測試；偏好檔多一個可省略欄位，不升存檔；內容跟程式碼一起進 build，不用網路。
- 美術：系統的清單樣式，一個圖示（sparkles／wrench），不另畫圖。
- 音樂：無。
