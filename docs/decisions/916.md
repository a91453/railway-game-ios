### 916. 芬蘭露天汽車運輸車 Gfot 掛在羅瓦涅米夜車倒數第二節（FINLAND-CAR-CARRIER-GFOT）

2026-11-21，雲端工作串「把今天審過的模型接進遊戲」（協調者派工）。號碼依 #2118 的登記。接著決策 914 §3 留下的第一項。

存檔版本、golden schema、GameCore、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/` 都不動。

## 1. 來源

工作室任務 `finland-car-carrier-gfot`（`a91453/railway-assets-private-2` #252，合併 `6fd33a4`，第 2 輪審查通過），`game-art-previews/docs/art/finland-car-carrier-gfot-2026-11/revision-2`。經驗檔：`docs/studio/lessons/finland-car-carrier-gfot.md`。近景 5,336、遠景 2,448 個三角形，長 26.40 m、寬 2.60 m、高 4.535 m，用 `tools/train-models/glb_to_swift.py --materials white,green,interior,rail,mask,hardware,dark,taillamp` 寫進 `Map3DFinlandCarCarrierGfotMesh.swift`。

## 2. 規則

1. **夜車車尾的兩節汽車運輸車，前一節換成 `Gfot`**：決策 914 照 Digitraffic 一週的編組（`Gd` 40 節、`Gfot` 42 節）掛兩節，當時 `Gfot` 沒有模型，兩節都借 `Gd`。現在一節一種：倒數第二節（`centreCars`）是 `Gfot`，最後一節仍是 `Gd`，尾燈點亮。
2. 最後一節留 `Gd`：它的尾燈已在決策 914 檢查過點亮的位置，改尾車要重驗一次，對玩家沒有差別。
3. 顏色全是遊戲已有的色：`white`、`green`、`mask`、`hardware`、`dark`、`taillamp` 是芬蘭雙層客車同名的格；`interior` 是 `Map3DPalette.hallWalls[2]`，`rail` 是 `Map3DPalette.mastSteel`（派工單第 4 節指定）。沒有新顏色、沒有玻璃。
4. 整列長 19.02 + 26.40 × 5 + 26.70 = 177.7 m（決策 914 是 178.0 m，原本 177.4 m）。夜車鎖檔 `tools/train-models/locks/finlandNight.json` 只換倒數第二節的四個模型與它們的燈，和整列燈的雜湊；`hashes.lock.json` 不變。

## 3. 留下的

- 上層載的汽車沒有做（派工單排除）；空車在照片上也常見。
- 每班掛幾節、哪種在前，仍是一週平均，不是逐班照 Digitraffic。

## 4. 五方

- 玩家：夜車車尾兩節長得不一樣，一節是封閉的長箱、一節是凹腰加欄杆，比較像真的車隊。
- 鐵道迷：芬蘭夜車實際上兩種都掛，數量差不多，現在兩種都有了。
- 開發：只改 GamePresentation 的夜車 set 與它的鎖檔，換一節車的模型。
- 美術：全用現有色票，派工單指定的格，沒有新色。
- 音樂：無。
