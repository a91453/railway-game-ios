### 426. 3D 的普悠瑪號接上 TEMU2000

2026-10-26，遊戲規劃 session_01CWaJGHR4DnSwosLCzJ2Tts 派工（派工單 F），實作 session_013j2ahg1x2rn8Akbc1iTm86（`claude/new-session-ueo00m`）。號碼依 #1041：決策 426；存檔版本、golden schema 不動。GameCore、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/` 不動，只動 GamePresentation、測試與文件。

**為什麼**：#1292（Codex）做了新的 TEMU2000 普悠瑪模型，但只當靜態模型註冊（`Map3DModels.swift`）。3D 地圖上跑的普悠瑪車組 `puyuma` 還是舊的通用電聯車（場景套件的 `01_TRA_modern_3x2-02`，每節拉成 20 m），玩家看到的不是新車。太魯閣號已經用同樣的方式接上 TEMU1000 與它的遠景版（決策 420），這次照做。

**做了什麼**：

1. **遠景版 TEMU2000**（`Map3DTEMU2000.model(_:far:)`）：照 `Map3DTEMU1000.model(_:far:)`。`model(_:)` 就是 `far: false`，近景逐位元和 main 一樣（`Map3DTEMU2000Tests.testTheNearUnitsAreUnchanged` 釘了 main 的三角形數與頂點雜湊）。遠景版只減細節，外形、配色與長度不變：
   - 車頭 13 個截面留 7 個（車頂的下降、肩線、下唇與鼻尖）；
   - 車頭前面的色塊（額頭、擋風玻璃、頰面）行數隔一行、欄數減半；燈座與三顆上燈的圓改 6 邊；
   - 每側的客窗從一片一片改成門與門之間一片長玻璃（門還是白色門板蓋在上面）；拿掉門上的小窗與銀邊；
   - 拿掉輪轂、轉向架側樑、冷氣箱上的白色薄蓋；集電弓與雨刷的管子 4 邊。輪子仍是 8 邊，輪底還在軌面（6 邊時輪底離軌面 5.8 cm）。
2. **營運的 `puyuma`**（`Map3DTrainSets.temu2000(far:)`，照 `temu1000(far:)`）：
   - key `puyuma`／`puyumaFar`；`ownLengths: true`、`fixedCars: 8`，每節用 TEMU2000 單元自己的長度首尾相接；
   - 順序照靜態編組（`Map3DTEMU2000.order` 反過來，車頭在前）：TED、TEMA、TEP、TEMB、TEMB、TEP、TEMA、TED。集電弓在第 3、6 節（`pantographCars: [2, 5]`）；前面那節 TEP 轉 180°（`rotations[5] = π`，本作 `turned`），兩個集電弓都朝外，和靜態編組、參考庫的編組表一致；
   - 新增一個很小的接點：`centreCars: [3, 4]`（`Map3DTrainSet.centreCars`、`Cars.centre`、`Map3DModelPack.modelIndex(of:carIndex:count:)` 多一行）。TEMA 與 TEMB 的車底設備不同（TEMB 是藏青色的），只有一個「中間車」的話第 4、5 節會畫成 TEMA。其他列車的 `centreCars` 都是空的，行為不變；
   - 車頭燈白、車尾燈紅：兩顆發光的燈放在端車的實際鼻端前 2 cm（`model.maximum.x`，頭車 10.99 m 處），高度 1.10 m、離中線各 0.30 m，落在鼻端的彩色面上；
   - 舊的 `multipleUnit("puyuma", asset: "01_TRA_modern_3x2-02", …)` 換成 `temu2000()` 與 `temu2000(far: true)`；
   - `puyuma` 加進 `nearOnly`（和 `taroko`、`emu800` 一樣）：500 m 內完整，500–900 m 換 `puyumaFar`，900 m 外盒子。選用的程式（`Map3DModelPack.model(_:forType:count:at:)`、`Map3DTrains.swift`）沒改。
3. **沒動**：普悠瑪的營運資料、車種（`TrainPerformanceCatalog`）、`TrainLivery.puyuma` 的用途（2D 與路線色）、列車包解鎖與回退規則、其他列車（太魯閣、E500、PP、EMU3000、高鐵）。

**三角形數**（Linux x86_64；整列八節，`pack.layout(forType:count: 8)`，一節一個模型，含兩顆燈各 24 個；`Map3DTEMU2000Tests.testTheEightCarSetCostsAboutAsMuchAsTheTaroko` 釘住）：

- 近景比太魯閣多 7 %（TEMU2000 單元是 #1292 的，不是這張 PR 的）；遠景和太魯閣一樣（5,500 對 5,510），不放寬任何列車的上限。
- 模型包裡存的頂點資料：普悠瑪近景六種模型（頭、尾、TEMA、TEMB、TEP 兩個方向）11,600 個三角形約 1.39 MB，遠景 4,368 個約 0.52 MB（頂點 40 bytes、三個一個三角形）。TEMA／TEMB／TEP 各有一份，TEP 前後朝向各一份，所以比太魯閣（近景 8,134、遠景 3,198）多。
- 遠景一列比近景少 9,360 個三角形。畫面上普悠瑪在 500 m 外時，三角形從 14,860 降到 5,500。
- 整列長度：每節首尾相接 163.76 m（靜態編組含車間縫是 168.39 m）。和太魯閣一樣，車體相接、不留縫。

**回歸測試**：

- `Map3DTEMU2000Tests.testTheOperatingPuyumaIsMadeOfTEMU2000Units`：八節都是 TEMU2000 單元（名字、頂點逐一相同，不是舊的 `01_TRA_modern_3x2-02`）。**在 main 上是紅的**：main 的 `puyuma` 不是自己長度的車組，`pack.layout(forType: "puyuma", count: 8)` 回 `nil`（把這支測試單獨放到 main 的程式上跑：`XCTUnwrap failed: expected non-nil value of type "Array<LaidCar>"`）。
- 集電弓只在第 3、6 節且朝外；燈在端車實際鼻端前、白在前紅在後、中間車沒有燈；500 m 內近、500–900 m 遠、900 m 外盒子；遠景和近景同一個外框、輪底在軌面、顏色是近景的子集、三角形少於近景 45 %；整列近景不超過太魯閣 1.10 倍、遠景不超過太魯閣加 50；近景單元和 main 逐位元相同。
- 原有的測試跟著改了三處：`Map3DTrainSetTests` 的 `reach(of:)`（普悠瑪現在和太魯閣一樣 500 m）、`Map3DMotionBudgetTests` 的「沒有遠景模型的車」（原本拿普悠瑪當例子，改拿 `dieselExpress`）；靜態註冊的測試改成「仍然註冊」（原本寫著「沒有接進營運」）。

**沒選的**：

- 不加 `centreCars`，TEMA 當全部的中間車：少改共用程式，但第 4、5 節的車底設備畫錯；`#1292` 的 README 自己寫了 TEMA／TEMB 的差別「資料不足」，所以也不是大差，但接點只有三行，值得。
- 輪子遠景用 6 邊：每節少 64 個三角形，但輪底離軌面 5.8 cm；改回 8 邊，整列多 512 個（5,500，仍等於太魯閣）。
- 把兩顆燈做在斜面上的下燈座（真車的位置）：發光的是一片垂直薄板，放在斜面上會埋進車殼；放在鼻端的彩色面上才看得見。
- 用 Decision 420 的自動簡化器做遠景：同決策的結論（25 % 以下每款要逐款看，程式版遠景車用 40 % 就比自動 50 % 乾淨）。
- 補上車間縫、讓整列長 168.39 m：要改 `LaidCar` 的間隙或加模型長度，是別的決策。

**五方**：

- 玩家：地圖上的普悠瑪是 #1292 的新車（白車身、綠松腰線、彩色車頭與兩個朝外的集電弓），不是舊的通用電聯車；500 m 外換成輕版本，外形、顏色相同，列車多了不會比之前重。不改任何操作。
- 鐵道迷：八節 TED–TEMA–TEP–TEMB–TEMB–TEP–TEMA–TED、集電弓在第 3、6 節朝外，和日本車輛製造的車體尺寸、TTSB 事故報告的編組順序一致（#1292 README）；TEMB 的藏青色車底設備在第 4、5 節。車頭燈白、車尾燈紅。真車的紅色塗裝遊戲不用（#1292 的決定：專案配色，不複製商標與紅色塗裝）。
- 開發：沒有新依賴；遠景版用已有的 `far:` 接法，選用的程式沒改；共用程式只多了 `centreCars`（預設空，其他列車的模型與測試沒動）；有 Linux 測試，近景和 main 逐位元相同。
- 美術：遠景版保留近景的外形、窗帶、綠松腰線與彩色車頭；只拿掉細節。**實機的樣子與 500 m 換遠景時跳不跳，作者在 TestFlight 看（UNVERIFIED）**。
- 音樂：無。

**參考與前例**：

- 本作決策 420：`Map3DTEMU1000.model(_:far:)`、`temu1000(far:)`、`nearOnly` 的接法，數字沿用（500 m、八節、`fixedCars: 8`）。
- 參考庫 `Railway/taiwan-rail-reference-clean/source/memories/tainan-2026-09-12/fleet/catalog.json` 有 TEMU2000：TED（連結長 22.095 m、車體 21.745 m、寬 2.9 m）、中間車（20.7 m／20.0 m）、TEP，以及近景／遠景兩個等級的網格（TED 近 6,642／遠 1,076，中間車 4,692／636，TEP 4,944／660 個三角形）和 8 節編組表（TED、TEMA、TEP、TEMB、TEMB、TEP、TEMA、TED；第 3 節的 TEP 翻轉、第 6 節不翻，集電弓朝外）。本作的編組順序與朝向和它相同；它的網格是程式放樣出來的 `.bin`，形狀不同於 #1292 的原生單元，所以沒有搬進來。遠景單節的三角形（本作 560–1,010）和它的（636–1,076）同一個量級。缺口：參考庫沒有「發光的車頭燈位置」，燈位是本作自己算的（實際鼻端前 2 cm）。
- 開源：沒有搜尋。這次沒有演算法或資料來源要找：做法是把本作已有的接法（決策 420）用在另一款車，程式是本作自己的。
