## 2. 改了什麼

1. **map 的類別（`MapInteractionTests`）併回 build job**，matrix 只剩 second、lessons，兩個同時跑；iPad 在它們跑完時開始。同一時間最多仍是 3 台 macOS（build job＋兩個 partition，之後 build job＋iPad），決策 582 不變；測試一支都沒少，只是少了一次建置、開機、暖機（約 18 個 runner 分鐘）。
2. build job 的 full lane UI 步驟上限 90 → 120 分、整個 job 115 → 145 分：UI 測試變成約 55 分（31＋24），慢的 runner 約 1.8 倍。上限只是抓卡住，單支測試仍是 8（最多 10）分。PR 的上限不變。

預估 full lane：build job 約 15＋6＋55＋3 ≈ 79 分；second、lessons 約 53–60 分後 iPad 再 30 分 ≈ 85–90 分。從 124–135 分降到約 90 分。

## 3. 沒採用的

- **模擬器和建置同時做**：決策 658 量過，模擬器開著時建置從 9 分變 16–19 分。
- **iPad 改成等 build job**：PR 改到教學檔時 iPad 會多等 build job 約 23 分。
- **只建一次、分給各 job**：各 job 同時開始，等建置做完再開始，關鍵路徑一樣長；PR 只有一個 job，用不到。
- **跨 run 快取 DerivedData**：checkout 每次都換新檔案時間，Xcode 照樣全部重編；Xcode 26 的編譯快取另案評估。
