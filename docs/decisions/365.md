### 365. 只玩 2D：3D 畫質「關」、舊機型預設關、省電不做多重取樣

2026-10-23，遊戲規劃 session_01H5RHAwnA69n8EfAUSUrH52 派工（NEXT_PRIORITIES §22.2 第 10g 名），實作 session_019Bw7UpU3qxsXycSCyXbK9s。作者原話（2026-10-22）：「2d要跟3d切割明確一點嗎 讓弱的機型可以順暢玩2d」→「好 照你的做」。存檔版本、golden schema、SaveFixtures、ReplayFixtures、GameCore 都不動。

**之前**：設定的「3D 畫質」三檔（決策 238 的後記：自動、省電、高畫質）。不管哪一檔，地圖右下都有 3D 鈕，2D 拉近到門檻附近停 0.4 秒就在背景先蓋 3D 場景（決策 269 後記，`MapView.buildAheadIfResting`，幾秒的 CPU、幾十 MB）。3D 一律每個像素 4 個樣本（MSAA）。

**這次做了什麼**：

1. `Map3DQuality.off`（存成 `"off"`）。選了以後：
   - 地圖的 3D 鈕、跟車列的 3D 鈕、車站時刻表點列車開 3D，都收起來；
   - 2D 拉過最近還繼續拉不會開 3D，也不在背景先蓋 3D（`buildAheadIfResting` 一開始與等完 0.4 秒都再看一次）；
   - 設定的「拉近自動變 3D」變灰；設定裡「這一局的 3D 地圖」仍可打開，畫法和省電一樣（`Map3DQuality.drawn`）。
2. **預設**：還沒選過畫質的裝置，GPU 是 Apple 7（A14，iPhone 12）以上照舊「自動」，更舊的（iPhone 11、XR、XS 以前；iPad 一樣看 GPU）預設「關」（`Map3DQuality.startingChoice(gpuFamily:)`，App 的 `Map3DQuality.forThisDevice`）。已經選過的玩家照 `map3D.quality` 存的值，不變；舊的三個值讀回來一樣。模擬器不算舊手機，預設「自動」，UI 測試照舊找得到 3D 鈕。
3. **省電不做多重取樣**：`Map3DQuality.samplesPerPixel` 省電（與關）1，其他 4。樣本數在 3D 打開時定下（管線建好就不能換），畫質只能在設定裡改，3D 開著時改不到。
4. 不做滑桿面板（決策 238 後記「三檔、沒有滑桿」照舊）。

**五方**：
- 玩家（30）：舊手機一開就是順的 2D，不會誤觸 3D 卡住；想看 3D 隨時在設定打開。新手機不受影響。
- 開發（25）：只動 App 與 GamePresentation；邏輯（預設、要不要顯示、樣本數）在 GamePresentation，有 Linux 測試；不升存檔。
- 美術（15）：省電少了防鋸齒，細的鐵軌邊緣會有鋸齒，但省電本來就是「較柔和」的那檔；其他檔一樣。沒有新圖示。
- 鐵道迷（15）：無（不改任何路線、車輛或資料）。
- 音樂（15）：無。

**沒選的**：
- 舊機型只把預設改成「省電」：3D 鈕還在、拉近仍先蓋場景，弱機型 2D 還是會被背景工作拖慢。
- 依 RAM 判斷：Apple 6 以前的 GPU 正好是 3D 地圖幀數最差的一群（決策 259 也用 GPU 家族分街景），一個門檻就夠。
- 把 3D 搬到網頁（WebGL）：比 Metal 慢、資料兩份、離線不能用（§22.2 10g 列）。

**要在舊手機實機量的畫面**（UNVERIFIED，Linux 與模擬器都量不到）：
1. iPhone 11 或 XR（A13／A12）新裝：設定的 3D 畫質是「關」，地圖沒有 3D 鈕；2D 拉到最近、停一下、放手，不開 3D，2D 幀數不掉。
2. 同一台把畫質改「自動」：3D 鈕回來，拉近開 3D；再改回「關」，鈕收起。
3. iPhone 12 以上新裝：預設「自動」，和 83 版一樣。
4. 任一台「省電」開 3D：鐵軌邊緣的鋸齒、3D 幀數與 GPU 時間（角落的數字）和「自動」比。
5. 從 83 版升級、原本選過「高畫質」或「省電」的裝置：選的那檔不變。
