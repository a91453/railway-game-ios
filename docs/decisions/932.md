## 2. 規則

1. 目錄的菁桐、車埕畫自己的模型與自己的遠景版，做法和決策 929 的平溪、日南一樣：`house()` 依目錄 id 改畫，月台淨空線（模型 Y +6）放在月台後 7 m，月台與月台雨棚照舊由遊戲畫。阿里山線其餘 `timber` 站不變。
2. **目錄的站型沒有改**：派工單第 9 節寫照決策 705 的集集、保安給各自的站型並改 `tools/station-kit/catalog.py`。這裡照後來的決策 929（依 id，不加站型）：兩站在目錄仍是 `.timber`，`catalog.py` 與產生的目錄檔不動，少一個只給一站用的站型與它的遠景色塊。
3. **顏色**全是遊戲已有的：

   | 模型材質 | 遊戲的顏色 |
   |---|---|
   | `wallWhite`、`trim`、`roofTile`、`woodDark`、`dark` | `Map3DPalette.tankWhite`、`tileWhite`、`arcade`、`cityRoofs[2]`、`dark` |
   | `brickBase`（菁桐牆腳） | `Map3DContainerWagon.rust` #9A4A36（工作室第 1 輪後由 `hallWalls[3]` 改的） |
   | `glazingDark` | `Map3DDepotFacilities.glass` #26313D（和日南同一個） |
   | `roofTerracotta`、`metalRoof`、`concrete`、`timberBoard`（車埕） | `Map3DPalette.cityRoofs[5]` #B85A42、`steel`、`concrete`、`timber` |
   | `timberWall`（車埕的牆） | `Map3DPalette.timberSiding` #4E392F |

   `timberWall` 的 #4E392F 原本只寫在第二批站房的木板牆那一行，不是色票的格位。平溪的欄杆（決策 929）遇到同一個顏色時改用 `cityRoofs[2]`；車埕整面牆若也這樣，牆和柱、封簷板就是同一色，工作室審過的深褐牆也變灰。所以把這個**已經在遊戲裡的顏色**收進 `Map3DPalette`（決策 891：真的沒有格位才寫進色票，不寫進 `baseline.txt`），第二批那一行改用它，`tools/palette-guard/baseline.txt` 少一行。沒有新顏色。
4. 菁桐外廓不對稱（X −11.46 到 +7.56，−X 端是門廊），`addHouse` 照整體外廓置中，主屋因此往 +X 偏約 2 m；和平溪一樣沒有另外處理。
5. 兩站都沒有字：菁桐的五塊菱形牌與車埕簷下的木匾只是色塊（派工單）。決策 705 替集集、保安另畫的站名筆畫，這次沒有做。
6. 派工單與交件 README 不一致的地方以 GLB 為準：菁桐菱形牌外對角是 0.84 m（派工單的更正寫 0.88 m）；車埕迴廊 8 根柱、7 開間。

## 3. 五方

- 玩家：平溪線、集集線劇情的終點站認得出來：菁桐是白牆灰瓦的小站，車埕是深褐長屋、紅褐瓦與屋脊上的氣窗屋頂，不再是阿里山線的咖啡牆青綠屋頂。
- 鐵道迷：兩站照真實站房的照片做（菁桐的菱形站名牌位置與門廊、車埕的越屋根與迴廊柱列）；瓦色、牆色取遊戲色票裡最近的，車埕的瓦比陰天的照片亮一些。
- 開發：沿用決策 929 的 `Map3DStudioStation`，多兩個 case 與兩個網格檔；不加站型、不動 GameCore、不進 `Map3DModelPack` 與雜湊鎖檔。
- 美術：工作室對照片審過兩輪（做的人不審自己），不另截圖（model-look §1）；顏色全是已有的，`timberSiding` 只是替既有顏色取名。
- 音樂：無。
