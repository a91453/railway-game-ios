### 866. 車站鈴聲：玩家替每站選到站鈴與發車旋律

2026-11-18，雲端工作串「讓每站自選發車鈴聲」，分支 `claude/project-thread-03vjjz`，協調者派工（優先清單最高分：私有素材庫 `docs/priorities/DEPARTURE-MELODY.md` 第 2 項，3.05）。決策 219 第二階段的另一半：決策 853 讓每條路線有自己的發車旋律，這裡讓玩家替每一站挑到站鈴與發車旋律。號碼依 #2118 的登記。

動 GameCore（`Station` 兩個欄位、`GameWorld` 兩個指令，新檔 `StationSounds.swift`）、存檔版本 108 → **109**（加 `SaveFixtures/v109-station-sounds.json`）、GamePresentation（`StationChime`、`DepartureMelody` 改成 GameCore 型別的擴充；`PlayerCommand.Edit` 兩個指令；新檔 `StationSoundsText.swift`；`StationPanelPart.sounds`）、App 的車站面板。golden schema、replay 不動。

## 1. 做了什麼

1. **GameCore 只記選擇**：`Station.chime`（`StationChime?`：小站鈴、轉乘站鈴、觀光站鈴）與 `Station.departureMelody`（`DepartureMelody?`：三首之一），`nil` 是「自動」。`GameWorld.setStationChime(_:to:)`、`setStationDepartureMelody(_:to:)` 免費、只檢查車站存在；**沒有任何規則讀它們**（測試：設與不設的世界跑半小時後相同）。存檔只在有選時寫 `"chime"`、`"departureMelody"`，不認得的值整個存檔拒讀。
2. **兩個列舉搬進 GameCore**：`StationChime`、`DepartureMelody` 的 case 原本在 GamePresentation（決策 219、853），存檔要記它們，所以宣告搬到 GameCore，GamePresentation 留原本的函式（`of(_:in:)`、`of(lineNamed:)`、`closings` 等）當擴充。原始值（`local`／`metro`／`tourist`、`a`／`b`／`c`）不變，音檔名照舊。
3. **到站鈴**：`StationChime.of(_:in:)` 先看玩家選的，沒有才照原本的規則（觀光 > 轉乘 > 小站，改名為 `automatic(_:in:)`）。在看的列車到站、其他列車到站、配樂閃避（`MusicDuck` 看的是 `.metro`）都跟著玩家選的走。
4. **發車旋律**：`DepartureMelody.Closing` 多記列車停在哪一站；`of(_:at:in:)` 先看那一站選的，沒有才照路線名稱的雜湊（決策 853）。觸發時機（在看的列車、60 倍以下、終點不響）不變。
5. **車站面板**：「營運」一組最後加「車站鈴聲」一段，兩個選單：到站鈴（「自動（小站鈴）」會寫出自動時現在響哪一種）、發車旋律（「依路線」、旋律一～三）。選了之後馬上播一次給玩家聽（「依路線」播停靠這站的第一條客運路線的那首）。機廠沒有這一段（不載客）。說明文字只講做什麼：「到站鈴在列車進站時響；發車旋律在你看著的列車關門時響（60 倍速以下）。選好會先播一次給你聽。」
6. **指令記錄**：兩個指令走 `PlayerCommand.Edit`，指令記錄與重播照樣保存；復原照一般編輯。

## 2. 五個角度

| 角度 | 理由 | 分數（1–5） |
| --- | --- | ---: |
| 玩家 | 自己的大站、觀光站可以挑喜歡的鈴；選的時候就聽得到，不用跟車去試 | 3 |
| 鐵道迷 | 一站一曲是日本、台北捷運的文化（各站自己的發車旋律）；旋律仍是原創的三首，不抄真實的 | 4 |
| 開發 | GameCore 只多兩個沒有規則讀的欄位與兩個指令，照 `setLineColor`／`setLineCode` 的寫法；存檔一版、fixture 一個；判斷都是純函式，在 Linux 測 | 2 |
| 美術 | 面板多一段兩個系統選單，沿用現有 Form 的樣子；沒有新圖 | 2 |
| 音樂 | 讓三首旋律與三種到站鈴有被挑選、被記住的地方；之後的自製旋律（第 4 項）接在同一個欄位 | 5 |

## 3. 其他選項

- **只做到站鈴、發車旋律之後再加**（評分檔原本的寫法）：協調者派工時要的是發車旋律，兩個一起做只多一個欄位與一個選單；沒選。
- **一個合併的「車站音」選項**（到站鈴與旋律綁成一組）：組合少、選單短，但兩種聲音響的時機不同（進站、關門），玩家可能只想改一種；沒選。
- **存在 App 的偏好設定、不進存檔**：不動 GameCore，但同一站的選擇不會跟著存檔走，換裝置或讀舊檔就不見，也不在指令記錄裡；照評分檔「GameCore 一個只給畫面讀的欄位」。
- **放在「周邊與土地」一組**：那一組講的是車站外面；聲音是車站本身的設定，跟「車站更名」比較近。放在營運一組的最後，前面的列不動位置。
- 面板的截圖：一般 UI 改動（現有面板多一段），依決策 482 的修訂不拍。
