### 818. 羅瓦涅米開放：新遊戲清單一開始就列，不靠航班；第 3 週在它的地圖上是「連到聖誕老人村」

2026-11-17，雲端 session_01JMHz9bckVEprLBmpgpVmVQ，分支 `claude/rovaniemi-open`，派工 ROVANIEMI-OPEN（遊戲規劃，冬季活動 11/30 開放）。
接著決策 789（地圖資料線）、776（分包下載）、810（D2：備用車擋夜車）、814（WINTER-FIX）。

存檔版本不動（107）；golden schema 不動；`GameCore`、`GoldenScenarios/`、`ReplayFixtures/`、`SaveFixtures/` 都沒動。

## 1. 做了什麼

1. **開關**：`OverseasMaps.open` 加 `.rovaniemi`。遊戲一啟動就讀它的鐵道、地形、人口（和香港一起），資料來源頁列出「羅瓦涅米的鐵道」一節（決策 789 寫好的五條）。
2. **新遊戲清單直接列**：`OverseasMap.opensByFlights`（香港 `true`、羅瓦涅米 `false`）。`AirRoutes(cities:)` 不把羅瓦涅米當航點，所以：
   - 第一次選地圖就選羅瓦涅米，不會記成「第一張地圖」，台灣與香港照決策 712 的航班規則；
   - 已經選過台灣的玩家，香港照舊鎖著等航班，羅瓦涅米照樣開著。
   - 清單的列由 `GameLauncher.overseasMapRows(in:)` 給（有 Linux 測試），`RealWorldPicker` 只畫。羅瓦涅米的圖示是雪花，香港照舊是飛機。
   - 讀不到它的地形（地圖包壞了）就不列，也開不了局。
3. **地圖說明改成兩條線**：「從穆羅拉一路到凱米耶爾維……可以收購往凱米耶爾維與往穆羅拉的路線」。決策 789 之後主線到穆羅拉那一段才加進來，舊說明只寫一條。
4. **分包下載的清單** `RailwayGameApp/AssetPacks/rovaniemi.json`（照 `hongkong.json`），`testflight.yml` 會自己打包上傳（`tools/asset-packs/package.sh` 讀整個資料夾）。
   - **地圖包照舊隨 App 帶**（規劃 11-17 補充，見第 4 節）。所以下載下來的和 App 裡的一樣才會用（決策 776 的 `differsFromBundled`），和香港相同。
5. **第 3 週任務在羅瓦涅米的版本**（企劃 §2.4，WINTER-FIX「還留下的」第 4 點）：地圖上有聖誕老人村（`Map3DWinterLights` 的 `santa-claus-village`，66.54355 N、25.84730 E，OSM）時，第 3 週改成「讓一條路線連到北極圈上的聖誕老人村」。
   - 算法：有一條營運中的客運路線停靠村子一個車站服務圈（`Land.catchmentRadius`）內的車站，就達成。
   - 其他地圖照舊是一天 1,000 人。
   - 徽章、id（`arctic`）、週次都不變，所以已經拿到的徽章照舊算。
   - `WinterSantaVillage`、`WinterMissionFacts.reachesSantaVillage`（不在這張地圖上是 `nil`）、`WinterMission.how(in:facts:)`；活動卡的說明照當下的地圖寫。
6. **網站** `credits.html` 加「羅瓦涅米的鐵道／Rovaniemi's Railways」中英兩節：`a91453/railway-reference-private` #145（draft，發版之後才合）。

## 4. 沒有做的：把地圖包移出 App

派工單原本要把羅瓦涅米的地圖包移出 App、只靠下載（也順便解掉 WINTER-FIX 說的「開關關著也帶 13 MB」）。這個分支一度做了（commit `4967086`），**後來照規劃 11-17 的補充收回**：
- 作者在 136 實機的設定裡，香港地圖一直顯示「使用內建資料」，下載的地圖包沒有用上。
- 136 封存時有一條警告：`MapPackDownloader.appex is an ExtensionKit extension and must be embedded in the parent app bundle's Extensions directory`，原因還沒確定。
- 只靠下載的話，下載修好之前，11/30 開放時玩家拿不到羅瓦涅米的地圖。

所以 `project.yml` 照舊把整個 `Resources/MapPacks` 帶進 App，Xcode 專案沒有重產。開關打開之後，那 13.4 MB 就是玩家玩得到的地圖，WINTER-FIX 第 1 點的「白帶」不再成立。

下載修好、實機看到「已下載」之後，**另開一張單移出去**。`4967086` 裡現成的做法可以拿來用（`docs/handoff/ROVANIEMI-OPEN.md`「還留下的」）。

## 5. 五個角度

- 玩家：冬季活動那個月一打開新遊戲就看得到羅瓦涅米，不用先蓋機場、等航班；第 3 週在那裡有自己的目標（蓋一條線到聖誕老人村），不是換個地方載 1,000 人。
- 鐵道迷：兩條線都是 Fintraffic 的真實時刻；聖誕老人村真的沒有鐵路（企劃 §2.4），要玩家自己蓋，和現實一致。
- 開發：GameCore、存檔、golden、replay 都沒動；清單的邏輯放 GamePresentation，有 Linux 測試；地圖包照舊隨 App 帶，不把開放押在還沒修好的下載上。
- 美術：清單的雪花和香港的飛機分得開，用的是 SF Symbols，沒有新圖。
- 音樂：無。

## 6. 沒選的做法

- **只靠下載**（派工單原案）：見第 4 節，等下載修好。
- **Debug 帶、Release 只靠下載**：模擬器與 UI 測試都還玩得到，但 Release 一樣押在下載上，理由同第 4 節。
- **羅瓦涅米也用航班開**：要先在台灣蓋機場、載夠人，冬季活動只有五週，第 3 週就要用到它，太晚。
- **第 3 週在羅瓦涅米照舊載 1,000 人**：不用改程式，但第 3 週和地圖沒有關係，企劃 §2.4 寫的是連到聖誕老人村。
