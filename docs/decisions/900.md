### 900. EMU900 換上工作室的駕駛車車臉，腰帶改真車的亮綠（EMU900-FACE-INTO-GAME）

2026-11-20，雲端工作串「把今天審過的模型接進遊戲」（協調者派工）。改決策 435（#1339 的 EMU900）。號碼依 #2118 的登記。

存檔版本、golden schema、GameCore、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/` 都不動。

## 1. 來源

工作室任務 `tra-emu900-face-r1`（`a91453/railway-assets-private-2` #217，`game-art-previews/docs/art/tra-emu900-face-2026-11/revision-2`），第 2 輪審查通過的最終交件，之後沒有再開下一輪。經驗檔：`docs/studio/lessons/tra-emu900-face.md`。`emu900-ed.glb`（7,045 個三角形）與 `emu900-ed-far.glb`（3,502）用 `tools/train-models/glb_to_swift.py` 寫進 `Map3DEMU900Mesh.swift`。

## 2. 規則

1. **駕駛車（ED）近景換成工作室的車臉**：整片黑色後傾斜面、每側兩顆直排圓燈、下緣白燈條兩端紅、腰帶在車頭翹起。車身斷面、車長（21.58 m）、門窗位置照舊，和中間車接得起來。`far` 一級用工作室的遠景版。
2. **`light` 一級（遠處行駛的列車）照舊用 #1339 的程式車頭**：工作室遠景版 3,502 個三角形，超過遠處列車駕駛車的上限 2,467（`Map3DEMU900IntegrationTests.testTheFarTriangleBudget`）。在那個距離一節車只有幾個像素，車頭形狀看不出差別；腰帶顏色跟著換。
3. **腰帶改成真車的亮綠 #5CB82E**，登記成 `Map3DPalette.emu900Green`（作者 2026-11-20 定，EMU900 專屬，不借台中捷運的綠），`Map3DEMU900.band`。中間車的腰帶跟著變。原本遊戲自己的青綠（`Map3DEMU900.teal`，`shopAwnings[0]`）留著，給之後玩家可選的塗裝用；讓玩家選塗裝的功能這次沒有做。
4. **頭尾燈**：近景用工作室模型自己的燈：前車車頭的頭燈（`headlamp`）亮白，後車車頭的尾燈（`taillamp`）亮紅（決策 449 再從這些燈點每節的前後燈）。遠處的 `light` 車頭照舊。
5. 工作室車頭的窗玻璃自己標成玻璃（材質 `glass`），和福岡、港鐵、芬蘭的工作室列車一樣。
6. 車輪輪緣在軌面下 25 mm（工作室模型的實際形狀），測試照這個量。

## 3. 五方

- 玩家：台鐵最常見的區間車車頭認得出來，綠腰帶和真車一樣亮。
- 鐵道迷：車臉照照片做（後傾量、燈位都在照片上量過），腰帶色照真車。
- 開發：只改 GamePresentation；近景車頭從 9,256 降到 7,045 個三角形，遠處的上限不變。
- 美術：顏色全是色票，唯一的新色 #5CB82E 是作者定的、已登記。
- 音樂：無。

## 4. 留下的

- 遊戲自有的青綠塗裝留作玩家可選的塗裝：要做「讓玩家選塗裝」的功能才會用到，另排。
- `light` 一級要不要另做一個 2,467 面以內的工作室車頭，等看過實機再決定。
- 沒有搬進列車登錄制（決策 782）：照「舊的不強搬」。
