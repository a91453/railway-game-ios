## 問題

## 做了什麼

1. **頁籤**：列車、渡輪、纜車（`FerryCollection.Page`，多了 `.cableways`；`exhibit` 說哪一頁開哪個 3D 展示）。
2. **渡輪頁**：文字照舊（兩艘船、兩條航線），最上面多一個「近看渡輪」，打開和列車同一個 3D 展示台（`TrainShowcaseScreen` 加 `exhibit` 參數）：一指轉、兩指捏近、兩指移動，時段（白天／黃昏／夜晚）、近景／遠景、轉台、三個鏡頭（船頭特寫／側面／俯瞰）、拍照、隱藏按鈕都一樣，只少了「選車」。展示的是 3D 地圖畫的那兩艘（決策 585 PR-3 的 `Map3DFerry`：順風 166 號、旗鼓二號），船頭對齊並排浮在水上，水面是 3D 地圖的水（`makeWater`）。
3. **纜車頁**：「近看纜車」打開同一個展示台：兩段纜線各掛在兩座塔柱之間，前一段是貓空纜車的一般廂與水晶廂（決策 575），後一段是日月潭纜車的紅、黃、藍一般廂與綠色水晶廂（決策 615），都是 3D 地圖畫的那些模型（`Map3DModelPack.standard`）。下面兩條真實資料（見下表）。說明文字只說怎麼在遊戲裡蓋纜車。
4. 邏輯在 GamePresentation：`Map3DCollectionShowcase`（排法、地面／水面、實例、鏡頭、按鈕與提示文字）、`Map3DShowcaseContent`（展示台顯示列車或展品，列車的部分原樣交給 `Map3DShowcase`）；`FerryCollection.cableways(in:)`、`cablewayNote(in:)`。Linux 測試：`CollectionShowcaseTests`、`FerryCollectionTests`。UI 測試只問頁籤在、點得到、按鈕打開展示台（`TrainShowcaseUITests.testTheCableCarPageOpensItsStage`，full lane）。截圖：`WebsiteScreenshotTests.testCollectionFerriesAndCableCarsIn3D`（手機橫拿：頁面、白天特寫、白天側面、夜晚特寫、夜晚俯瞰，渡輪與纜車各一輪）。

第二輪截圖（run 42381739446）三件事都好了；總覽圖 `docs/art/collection-ferry-cable-2026-11-07/overview.png`（左：渡輪頁、白天特寫、白天側面、夜晚特寫、夜晚俯瞰；右：纜車同樣五張）。

展示台的 Metal 畫面本來就畫 `Map3DTrains.Frame` 的實例，船和吊廂在 3D 地圖裡也是放進同一個 frame 的 prop（`Map3DFerries.frame`、`Map3DCableways.frame`），所以不用改 Metal；日月潭吊廂近景的透明玻璃也照 3D 地圖的路徑畫。纜線用 3D 地圖的「一公尺纜線」拉直（`Map3DCableways.rope`），沒有垂度。

## 五個角度

- 玩家：渡輪頁終於能看到船、纜車有自己的一頁，操作和列車頁一樣不用重學。
- 鐵道迷：兩條纜車的長度、站數、車廂數、通車日都附出處，官方沒有的才用維基並標 UNVERIFIED。
- 開發：沿用車庫的展示台和 3D 地圖的模型與畫法，不改 Metal、不多一份模型；邏輯放 GamePresentation 有 Linux 測試。
- 美術：船浮在 3D 地圖的水面上、吊廂掛在纜線與塔柱之間，看得出各自在哪裡用；沒有新畫的圖。
- 音樂：none。

沒選的：

- A **共用車庫的展示台，加 `exhibit` 參數**（採用）：按鈕、手勢、拍照全一樣，程式只多一個分支。
- B 另寫一個展示畫面：重複約 200 行的按鈕與手勢，之後兩邊會走樣。
- C 把船與吊廂放進列車車庫的選車清單：選車是「列車」的節數與分類，船和吊廂不合；作者要的是各自一頁。
