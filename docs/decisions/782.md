### 782. 新車型自己註冊，兩款車同時做不再衝突

2026-11-15，雲端 thread session（「讓列車車型 PR 不再互相衝突」工作串，主規劃派工），分支 `claude/project-thread-4o3olx`。號碼依 #2118（780 被 #2267、#2268 同時登記，781 是 #2261）。

不動 GameCore、存檔版本、golden schema、golden、replay；模型、雜湊、燈、畫面一個值都不變。

## 1. 問題

決策 780（#2268）照以前的做法，加一款車要改 `Map3DScene.swift`（色票）、`Map3DTrainSets.swift`（`all`、`nearOnly`、set 函式）、`Map3DShowcase.swift`、`tools/train-models/hashes.lock.json`，以及 `Map3DModelPackSizeTests`（模型數、頂點數）、`Map3DModelPackLockTests`（整包的摘要、燈數）、`Map3DTrainSetTests`（三角形、長度的範圍）。每款車都改同一幾行，兩款同時做一定衝突，只能一次接一款。

## 2. 做了什麼

1. **`Map3DTrainRegistration`**（`Map3DTrainRegistry.swift`）：一款車的 `id`、它的 set（近、遠依序）、列車展示的列、`Map3DTrainSetTests` 對它每節車的三角形與長度範圍，與 `owns(_:)`（`set-<key>-…`、`light-set-<key>-…` 是它的模型）。
2. **`Map3DTrainRegistryList.swift`**：一行一款車的清單，檔裡沒有別的。`.gitattributes` 設 `merge=union`：兩個分支各在最後加一行，git 合併時兩行都留。`Map3DTrainRegistryTests` 掃 `Sources/GamePresentation/` 裡的 `Map3DTrainRegistration(id: …)`，擋忘了加、加兩次、少了鎖檔或多了鎖檔。
3. **讀清單的地方**：`Map3DTrainSet.all` 在手寫的 set 之後接 `Map3DTrainRegistry.sets`；`nearOnly` 加上註冊車有遠景 set 的；`Map3DShowcase.catalog` 在手寫的列之後接註冊車的列。
4. **鎖檔拆開**：註冊車的模型雜湊寫在 `tools/train-models/locks/<id>.json`，另記它的燈組數（`lampCount`）與燈、窗模型的摘要（`lamps`，用模型名字而不是位置算，前面加車也不會變）。`export.swift --lock` 照 `owns` 分開寫；`check.mjs` 讀 `hashes.lock.json` 時一起讀 `locks/*.json`。
5. **測試**：`Map3DModelPackSizeTests`、`Map3DModelPackLockTests.testTheOrderAndTheLampsAreAsBefore` 不算註冊車的模型，位置也照「沒有註冊車」重算，所以加註冊車不用改它們的數字；新增 `testEveryRegisteredTrainIsAsLocked` 比對每款註冊車的模型清單與燈。`Map3DTrainSetTests` 對註冊車用它自己的範圍。
6. **決策 780 的兩款車搬進新格式**：七個 `Map3DPalette.mtr*` 色票、`mtrAirportLine`／`mtrAirportExpress`／`mtrTungChung` 三個 set 函式、兩列展示都移到 `Map3DMTRAirportLine.swift`，一字不改。因此 `Map3DScene.swift`、`Map3DShowcase.swift`、`hashes.lock.json`、三個測試的數字都回到 #2268 之前（模型數 896、頂點 6,600,432、摘要 `45d52b8e433922ec` 等）。

## 3. 為什麼不變

註冊車的 set 和 #2268 一樣接在 `all` 最後、順序相同，所以整包的模型順序、每個模型、燈、窗、站牌都與 #2268 相同：搬之前與搬之後在 Linux 上的整包摘要相同（PR 裡記）。

## 4. 五方

- 玩家：沒有改變；之後車型能並行做，新車來得快。
- 鐵道迷：無。
- 開發：加一款車只新增檔案加一行清單；兩款同時做不衝突；測試仍釘住每個模型與燈。
- 美術：無（模型一個頂點都沒變）。
- 音樂：無。

其他選項（沒選）：SwiftPM build plugin 自動產生清單（Xcode 要信任外掛、CI 要加旗標，macOS 上驗不到）；清單照字母排（相鄰兩款仍會衝突）。
