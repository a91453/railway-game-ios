### 953. 環島之星的客車改用莒光客車的車身，粉紅塗裝

2026-11-24，雲端工作串 STAR-COACH-LIVERY（加權 3.10，協調者第 3 任派工），分支 `claude/star-coach-livery`。號碼依 #2118 的登記。來源：素材庫 -2 `game-art-previews/docs/art/tra-steam-coach-2026-11/README.md`（Mac 工作室指揮第七手 2026-11-24：環島之星不搬舊版，改用遊戲已有的 `Map3DChuKuangPassenger` 換色，沿用粉紅塗裝，不新增色票）與 #2118 comment 7118623395。

不動存檔版本、golden schema、golden 值、存檔樣本與重播。只動 3D 的模型，GameCore 不變。

## 1. 做了什麼

1. **車身**：`STAR`（環島之星）的客車原本是場景套件的通用客車殼（`05_TRA_classic_3x2-05`）漆成粉紅（決策 286「後來（第三次）」）。真車是 10500／10600 型莒光客車改裝（決策 286 的出處：`rail-3d/integration/FORMATIONS.md`；新頭殼 2019-02-22），所以改用莒光號已在用的客車 `Map3DChuKuangPassenger`（#1306，決策 430）：同一個車身、窗、轉向架、冷氣罩，最後一節照莒光號在後端點兩盞紅燈（`chuKuangTail`）。
2. **塗裝**：莒光客車的配方多一個 `Paint`（車身色、線色）。莒光號的 `Paint.chuKuang` 是原來的深藍與米白，模型逐頂點不變（雜湊與鎖都沒動）。環島之星的 `Paint.formosaStar` 直接讀 `TrainLivery.formosaStar` 的兩個顏色：車身 #F3D3DF 淡粉，原本米白的地方（窗帶、腰線、車門的線）#D9467E 深粉。**沒有新色票**。車頂、窗框、玻璃、貫通道、台車與車底的顏色是莒光客車自己的。
3. **近景與遠景**：`STAR` 原本沒有自己的遠景客車（近遠同一個通用殼）；現在和莒光號一樣，500 m 外用莒光客車的遠景版（4,008 面，最後一節 4,032）。E500 機車頭不變。
4. **真車的角色彩繪不畫**：環島之星的外觀是三麗鷗授權的角色與台灣景物彩繪（TVBS 2025-01-17「列車塗裝採繽紛的粉嫩配色」，萌旅號；食尚玩家 2019 的 Hello Kitty 版，6 節、每節一個主題）。公開遊戲不放角色、文字與標誌，所以只取「粉嫩」的主色，畫成淡粉車身配深粉帶。報導沒有寫車身、車頂與帶的確切顏色與位置，所以位置照莒光客車原本的分色（推估）。

## 2. 數字

- 面數：近景客車 6,476、最後一節 6,500（原本通用殼約 1,528）；遠景 4,008／4,032。近景一節 ≤ 20,000 的預算內。
- 模型包：模型數不變（973），頂點多 46,512（每份約 1.9 MB）：四個客車模型與它們的夜燈模型。`Map3DModelPackSizeTests`、`Map3DModelPackLockTests` 與 `tools/train-models/hashes.lock.json` 照測試印出的 Linux 值更新，只有 `set-STAR(Far)-car／tail` 與 `light-set-STAR(Far)-car／tail` 八項變。

## 3. 五個角度

| 角度 | 理由 | 分數（1–5） |
| --- | --- | ---: |
| 玩家 | 環島之星不再是方盒子，和莒光號同一款客車但一看就是粉紅的觀光列車 | 4 |
| 鐵道迷 | 真車就是莒光客車改裝，E500 牽引；角色彩繪不畫，只取主色 | 4 |
| 開發 | 只多一個塗裝參數，莒光號的模型逐位元不變；不必另做一款車 | 4 |
| 美術 | 沿用已審過的莒光客車與既有色票；深粉窗帶在遊戲大小也認得出 | 4 |
| 音樂 | 無 | 1 |

另一個做法（不採用，預覽在素材庫 -2 `game-art-previews/docs/art/star-coach-livery-2026-11/candidates.jpg`）：B，深粉車身配淡粉窗帶。遊戲大小更顯眼，但把 `TrainLivery.formosaStar` 的車身色與線色對調，和 2D 的列車卡、圖示不一致。
