### 475. 宣傳影片的素材：截圖與錄影由 workflow 拍，不進本庫

2026-10-29，派工單 VID（`claude/promo-material`），遊戲規劃第 28 任 session_01YGNNumk6UqdBm6JrBhsdZY 派。作者：「拿新的圖片做影片素材，越多越好」，選了「截圖＋錄影」、「現在並行做」。號碼依 #1041：決策 475；存檔版本、golden schema 不動，不碰 GameCore。

**做法**（接決策 165 的官網截圖）：
- `RailwayGameApp/UITests/PromoMaterialTests.swift`：每個測試開一個場景（簡單示範圖的白天、黃昏、夜晚；各面板與建造模式；貨運與車場場景；高鐵與臺鐵宜蘭線示範；實景示範；真實地圖上的臺北、板橋、新竹、臺中、臺南、高雄、花蓮），留 `XCTAttachment` 截圖，再做鏡頭動作：2D 地圖放大、平移、縮小，3D 地圖開啟、轉向、雙指放大到街景、停住讓列車開過。哪一步的畫面不在就跳過，不讓一個場景改動就丟掉其他畫面的圖。
- `website-screenshots.yml` 加 input：`kind`（website／promo，預設 website，原本的行為不變）、`device`（iphone／ipad）、`appearance`（dark／light／both）、`tests`（只跑指定的測試）。promo 時一個測試跑一次 `xcodebuild test-without-building`，前後用 `xcrun simctl io <udid> recordVideo --codec=h264` 錄整個畫面，輸出一個 artifact `promo-material`：`<外觀>/<測試>/<名稱>.png`、`video/<測試>.mp4`、`MANIFEST.txt`（模擬器、commit、每段影片鏡頭動作從第幾秒開始）。錄影只在第一個外觀錄；淺色只補截圖。
- `ios-build.yml` 的完整 lane 用 `-skip-testing` 跳過 `PromoMaterialTests`，gate 本來就不列。不加任何自動觸發；`testflight.yml` 不動。
- 素材很大，**不進本庫**：從 artifact 下載後整理到 `a91453/railway-assets-private` 的 `promo-material/2026-10-29/`（PNG、MP4 與說明每個檔案的 README），在那邊開 PR 由作者合。

**限制**：模擬器沒有真正的 GPU，3D 地圖的幀率比實機低，錄影可能卡頓；實際情形寫在 PR。macOS 機器全帳號 5 台，一次只按一個 run，只在自己的分支上按，不在 main 上按（並行群組以分支分開，不會取消 main 上別人的官網截圖）。

**五方**：
- 玩家：無；遊戲不變。
- 鐵道迷：素材取真實地圖（臺鐵各站周邊）與高鐵、宜蘭線示範，畫面裡的列車、路線都是遊戲本身的資料；沒有加任何新的資料。
- 開發：只動 UI 測試與 workflow；官網截圖的流程原樣保留，用 input 分開，不複製一份 workflow。
- 美術：截圖取遊戲現在的畫面，深色與淺色、白天、黃昏、夜晚都拍，供作者剪片時挑。
- 音樂：無；錄影不含聲音。
