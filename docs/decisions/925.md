## 2. 規則

1. **位置**：輪軸放在遊戲景點 `hk16` 的座標（22.28545, 114.16172），中環九號碼頭旁的海濱。**沒有用 OSM 外框對準**（趕版本，UNVERIFIED）；若之後看到偏，照 OSM 的 `attraction=big_wheel` 改經緯度，模型不用動。
2. **方向**：不轉（登錄制 0°）。工作室照照片把輪面法線定在方位 250°，輪面沿北北西—南南東，正面朝岸線兩頭（工作室 README 第 5 條，推估 ±15°）。
3. **落地**：照一般地標取外框四角最低的地面（`sink` 0、`baseHeight` 0）；海濱是填海地，平。
4. 顏色全是色票（派工單第 5 節）：`white` = `tileWhite`、`hub` = `Map3DPalette.mastSteel`、`cabinRed` = `mtrRed`、`glass` = `glazing`、`base` = `granite`、`dark`、`rim_lit` = `tunnelLamp`（外圈內側的暖白燈帶）。吊廂上贊助商的字與標誌不做。
5. 輪不轉：模型分 `wheel`、`cabins`、`stand` 三個節點留著以後轉，這次照一個網格畫。
