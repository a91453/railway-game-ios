### 440. 早期的台灣實景存檔也能打開道路與公車

2026-10-27，遊戲規劃 session_01YGNNunheBBBwyekk4Pq7b4 派工（派工單 AE），實作 session_01YGNNupMuLMyw9biXB952o2（`claude/old-taiwan-roads`）。號碼依 #1041：決策 440；存檔版本（不動）、golden schema 不動；`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/` 不動。補決策 428 的一個缺口。

**為什麼**：作者 2026-10-27 用「非常舊的存檔」測試，地圖是台灣實景（瑞芳、四腳亭一帶，就是實景示範與平溪挑戰的地圖）。公車工具只有一行「這張地圖讀不到道路，不能開公車。」，沒有按鈕。

原因：決策 428 的 `GameSession.roadsOffer` 只要 `geoAnchor != nil && landBlocks == nil` 就判 `.unreadable`。決策 428 寫這一類是「台灣以外的城市、早期的實景示範」，但土地一開始就全給的台灣實景地圖（`SaveFixtures/v4-real-world-demo-90-minutes.json` 在臺北車站；實景示範 `RealWorldDemo` 在瑞芳，現在開新的也一樣）也落進這一類。台灣有打包的底圖道路，只是 `GameSession.readRoads` 只讀 `landBlocks` 裡的地塊，`landBlocks == nil` 就什麼都不讀。

重現（Linux，`RoadsTurnOnTests`）：`v4-real-world-demo-90-minutes.json` 讀進來、裝上實景資料，`roadsOffer` 是 `.unreadable`，期望 `.available`；按下去世界不變。

**做了什麼**（只動 GamePresentation，GameCore 不動）：

1. **哪些地圖讀得到**：`roadsOffer` 改看地圖在不在台灣：`geoAnchor` 的國家（`CountryLookup.country(at:)`，和天氣、假日用的同一個）是 `TW` 就 `.available`，不管有沒有 `landBlocks`。台灣以外、沒有 `landBlocks` 的照舊 `.unreadable`。看國家而不看「底圖有沒有那一格」，是因為底圖可能還沒讀完（`baseMap == nil`），按鈕不該因為讀檔快慢而時有時無；底圖晚到時，下一次編輯就補上（和決策 428 的 `landBlocks` 地圖一樣）。
2. **讀哪些地塊的路**：`readRoads` 在 `landBlocks == nil` 時，讀「車站周圍的地塊」：`GameSession.blocksRoundStations(of:)`，就是邊用邊讀土地的地圖在同樣的車站會讀的地塊（每座站 2 km、高鐵站的腹地、買下的地圖塊；從 `readLand(roundStationsOf:)` 抽出來，原本的讀法不變）。每塊地的道路格只由底圖和那一塊決定，所以和 `landBlocks` 地圖在同樣地塊得到同樣的格子（有測試比對 `RealRoadCells.read`）。之後蓋新站，同一個編輯就讀進新站周圍的路。
3. **不改土地**：`landBlocks` 照舊是 `nil`，土地一格都不動；只寫 `roads`（`setRoads`，和原本一樣）。
4. **指令**：照決策 428 的 `PlayerCommand.Edit.turnOnRoads(towns: [])`，實景地圖不帶城鎮；路在同一個編輯的 `performEdit` 裡讀。記進指令紀錄、讀得回、重播得到同樣的世界（有測試）。舊的指令紀錄不受影響：改的只有「已經有道路、`landBlocks == nil` 的實景世界」，在這之前不存在（這種地圖的新遊戲沒有道路，`.unreadable` 也不會送出指令）；`ReplayFixtureTests`、`SavedGameTests` 照跑。
5. **玩家看到的**：讀得到的，和其他舊存檔一樣有說明和「打開道路與公車」按鈕。讀不到的改說原因：「台灣以外的地圖還沒有道路資料，不能開公車。」／“Maps outside Taiwan have no road data yet, so buses can't run here.”

**實景示範與平溪挑戰**（土地一開始就全給、在瑞芳）：開新的也沒有道路（決策 400 續篇第 4 點），現在也可以從公車工具打開，和舊存檔一樣。新開時不自動打開：示範與挑戰的數字是在沒有公車時量的。

**沒選的**：

- **讀檔時自動補路**：決策 400、428 都不做，理由照舊：玩家的舊檔會突然多出路，3D 街景跟著變；要不要由玩家按。
- **讀整張地圖的路**：16 km 見方的地圖約 256 塊、每塊要解底圖，比車站周圍慢好幾倍，也和 `landBlocks` 地圖的範圍不同（同一座站兩種地圖得到不同的路）；公車從車站開，車站周圍就夠。
- **看底圖有沒有那一格來判斷台灣**：底圖還沒讀完時會判錯，按鈕時有時無；Linux 測試沒有底圖時也判不出。
- **把土地改成邊用邊讀（補 `landBlocks`）**：等於重寫玩家的城市，土地的數字會變；派工單寫明不改土地。

**五方**：

- 玩家：作者那種早期的台灣實景存檔（和現在的實景示範）不用開新局就能開公車；台灣以外的地圖說清楚為什麼不行，不再是一句「讀不到」。
- 鐵道迷：路就是 OpenStreetMap 的真實街道，和邊用邊讀土地的地圖同一份、同一個讀法。
- 開發：只改 GamePresentation 兩處、抽出一個函式；GameCore、存檔、golden、replay 不動；重播一致有測試。
- 美術：none（沿用決策 428 的說明列與按鈕，只改一句話）。
- 音樂：none。
