### 762. 航線回本天數（AIR-BALANCE）：旅客照票價算價錢、大飛機每座公里比較便宜、十九座的成本降一些

2026-11-15，AIR-BALANCE（雲端 thread session「調整航線回本天數」，`claude/project-thread-ralqzq`），主規劃派工。作者 11-15 問 A2（#2226，決策 759）量出的回本「有疑慮」要在哪裡改；照「一串一件事」，A2 照原樣合併，數值在這張調。只改決策 758 的數值與一條算法，存檔格式、golden、replay 不動。

## 量到的問題（改之前，main `2c038b9`）

決策 759 的回本表（`AIR_ROUTE_REPORT=1 … testThePaybackTable`）：

1. **主要航線太快**：72–150 天，比收購真實鐵路線（決策 315 的目標「3–12 個月」；量過的內灣 118 天、深澳 214 天、文湖線約 354 天、平溪 592 天）還快。買航線會變成最快的賺錢法，鐵路反而不划算。
2. **越遠越便宜**：「旅客」那一項每位一律 NT$10 萬。桃園—曼谷的旅客一位付 NT$16,128，桃園—香港 NT$6,022，價錢卻一樣，所以遠的線回本最快（曼谷 72 天、新加坡 76 天）；短的離島線一位只付 NT$2,000 上下，同樣 NT$10 萬就慢（200–540 天）。
3. **窄體每座公里比七十座貴**：窄體 NT$1,000／公里 ÷ 186 座＝ NT$5.4，七十座 NT$350 ÷ 70 ＝ NT$5.0，飛機越大反而越貴，和真實（越大越省）相反；長程線的毛利只剩一成五。
4. **十九座的小線幾乎都不賺**：十九座每天維持 NT$2 萬，比它一天載的人付的錢還多（高雄—七美 1,271 天、臺中—花蓮約 8.7 萬天）；四條連十九座都虧。

## 決定

1. **旅客的價錢照票價**：收購時每位「平均一天的旅客」值這條航線 **65 天的票錢**（`AirRoute.valueDaysOfFare`），取代一律 NT$10 萬。桃園—香港一位約 NT$39 萬、松山—澎湖約 NT$17.9 萬、臺東—蘭嶼約 NT$11.4 萬。旅客帶來的錢越多，買下他們越貴，這是收購真實鐵路線（決策 315：旅客值多少照真實人數）的同一個想法，只是按票價。
2. **每公里成本**：窄體 NT$1,000 → **NT$600**、廣體 NT$2,000 → **NT$1,200**、十九座 NT$120 → **NT$100**；七十座 NT$350 不變。每座公里約 NT$5.3（十九座）、NT$5.0（七十座）、NT$3.2（窄體）、NT$2.7（廣體）：飛機越大越省。
3. **十九座每天維持** NT$2 萬 → **NT$1 萬**（小飛機的機組與保養本來就少）。七十座、窄體、廣體不變。
4. 其餘（票價 NT$1,200 ＋每公里 NT$6、飛機價錢、起降費、班數、過站、颱風）照決策 758。

舊存檔：已買的航線記著買的時候的價錢（`value`），不重算；改的只有之後每天的成本。`SaveFixtures/v103-air-routes.json` 不動，照樣讀得回來（`AirRouteTests.testTheVersion103SaveKeepsItsAirRoutes` 改成檢查它讀回自己的價錢與第一天、之後每天照這一版算，不再要求和這一版重做出來的世界一模一樣）。

## 五個角度

- 玩家：大航線要存到後期才買得起、三到八個月回本，和收購鐵路線同一個量級，不會一買航線就把鐵路比下去；小離島線也有機會在兩年內回本，只剩幾條真的沒人坐的線會虧，卡上看得到。
