### 349. 地圖的範圍、3D、縮放鈕：四種拿法一條規則，範圍鈕一直跟 3D 在一起

2026-10-22，遊戲規劃 session_01CHQg7B6JqzbScGSjyDwHos 派工（作者實機回報），修正 session 實作。號碼依 #231：決策 349；存檔版本、golden schema 不動。GameCore 不動。

**作者原話**：「iPad 直立的時候 3d跟範圍按鈕不見了」「手機在第一層介面的時候3d還是在上面 要進入客流第二層之後才是我想要的 在下面 是不是 bug 而且他的3d旁邊也沒有範圍按鈕」

**原因**（origin/main 26b38f7）

- iPad 直立（820 點寬）：路線、車站、經營面板 410 點，超過寬度的三分之一，決策 123 的「旁邊的卡片太寬就讓開」把縮放鈕藏起來，3D 鈕跟著縮放鈕（`Map3DShortcut`），一起不見。iPad 橫拿（1,180 點，面板 420）也一樣超過三分之一，面板開著時同樣看不到。決策 123 本來是為手機寫的：手機上那排鈕會站在地圖正中間。
- iPhone 橫拿：決策 300 只在「面板」（路線、車站、經營，第二層）開著時把鈕排到面板下面的一列；建設的「細節卡」（第一層）不算面板，鈕留在右下角那一欄，那一欄的底要讓過左邊站長那一排的高度，所以浮在卡片左邊、畫面一半高的地方。
- 範圍鈕（決策 292、311）只在鋪軌、放月台、挑路線的站時出現，所以第二層看不到。

**規則**（`MapCornerButtons`，`Sources/GamePresentation/MapFocus.swift`，Linux 測試 `MapFocusTests.testTheMapButtonsStandTheSameWayHoweverTheDeviceIsHeld`）

- **手機橫拿**（compact 高度；iPhone 只能橫拿，`project.yml`）：右邊有細節卡或面板時，鈕都排在畫面底邊的那一列（決策 300 的位置），卡片和面板一樣讓出那一列的高度。右邊什麼都沒有時，在右下角。
- **iPad 直立與橫拿**：在右下角，卡片或面板的旁邊。只有地圖剩下的寬度放不下這排鈕（240 點，iPad 最窄的分割畫面）時才讓開（決策 123），兩指照樣縮放；教學中不讓開，它要指這排鈕。
- **範圍鈕一直跟 3D 鈕在一起**，3D 鈕跟縮放鈕在一起，教學中兩個都不出現。範圍鈕不建造時也在：按一下顯示或收起「哪裡人多」（或玩家選的範圍），開始建造時照決策 311 自動顯示，離開工具時收起。

**五個角度**

- 玩家：同一個鈕每次都在同一個地方，iPad 直立也找得到 3D；手機上不再擋住地圖中間要點的車站與軌道。
- 鐵道迷：無。
- 開發：規則從兩個 View 的條件搬進 GamePresentation，四種拿法都有 Linux 測試；不改存檔、golden、replay。
- 美術：沒有新的圖或外觀，只改位置；底邊那一列沿用決策 300 的膠囊鈕。
- 音樂：無。

**不採用的選項**

- 手機橫拿時右邊沒東西也排到底邊那一列：位置更一致，但右下角已經在底部，作者指的是第一層與第二層不一致；而改它會移動大部分 iPhone UI 測試按的縮放鈕，風險大於好處。
- iPad 照手機一樣排到面板下面：iPad 的面板旁邊本來就有空間，排到下面要讓面板變短，沒有必要。
