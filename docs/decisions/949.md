### 949. 腳踏車架與車棚放上 3D 地圖，腳踏車停進去（BIKE-RACK-PLACE）

## 2. 規則

1. **兩個 kit 零件進模型包**（`Map3DBikeParking`，平交道柵欄桿之後、路線公車之前）。和站牌、郵筒一樣是街道設施的實例：只有鏡頭附近才畫，沒有遠景版。
2. **公車站**：決策 918 散放的腳踏車改成停在車架上。人行道寬 2.5 m 以上才放；車架中心沿街 6.2 m（第一個車架管在 5.2 m，避開候車亭的站牌與 3.4 m 的販賣機），離人行道後緣 1.0 m，車架管排成一列順著街，腳踏車橫過人行道、前輪朝建築，每個車架管旁 0.3 m 停一台。窄人行道不再放單台。
3. **車站出口**：地下車站的出口、高架車站的樓梯口旁，背向軌道那一側（出口的右邊），出口側面外 0.4 m 再加半台車長，靠進出口那一半。車架管順著出口排，腳踏車前輪朝出口。
4. **一架停幾台**：公共自行車一律 3 台（像一座租借站）；一般車 2 或 3 台。公車站的車架 40%、車站出口的 50% 是公共自行車，只在台灣的地圖。
5. **各地比例**（`Map3DStreetRegion.stopRackShare`、`exitRackShare`）：

   | 地區 | 公車站 | 車站出口 |
   |---|---|---|
   | 台灣 | 35%（和決策 918 一樣） | 70% |
   | 福岡 | 35% | 60% |
   | 羅瓦涅米 | 20% | 30% |
   | 香港 | 10% | 15% |

   香港市區的路很少有車架，多在新市鎮；台北、高雄的捷運出口多半有車架或 YouBike 站；福岡車站周邊有大片腳踏車停車場。
6. **公司蓋的學校與夜市**（`PlacedKitLayout`）：國小的體育館和看台之間一座車棚，三個擋輪各停一台、前輪朝裡；幼兒園門口一個車架停 2 台（接送的家長）；兩種夜市前面各一個車架停 3 台。車架、車棚算進 layout 的網格；腳踏車畫成實例（`addLayoutBicycles`），所以 layout 的三角形只多 108 或 132，仍在 7,500 以內。地點是照各零件的外框算的空地（國小車棚 x −8.9…−3.1、右 4.35…9.65；夜市車架在各攤位前方）。
7. 腳踏車立在 layout 地墊上 0.1 m（地墊高 0.1 m）。

## 3. 預算

- 模型包多 2 個模型、720 個頂點（一份約 29 KB）。
- 街上：車架 108 三角形，腳踏車和以前一樣是近處實例；公車站的腳踏車數量大致不變（窄人行道的單台沒了，寬人行道一樣 2–3 台）。車站出口每座最多多一個車架和 3 台車，約 2,900 三角形，只在鏡頭附近。
- `Map3DMotionBudget` 不受影響：它管會動的東西，車架與停著的車不動。
- 沒有用到只有 Metal 才有的功能：都是一般的模型與實例。

## 4. 五方

- 玩家：捷運出口與公車站旁的腳踏車停在車架上，台灣看得到一排橘色公共自行車停在出口；香港街上少見，和真的一樣。
- 鐵道迷：車站出口的停車架與租借站是台灣捷運站口的日常風景；擺放比例照各地的習慣；沒有資料來源問題。
- 開發：kit 零件照原樣進模型包；擺放是可測的純函式（`exitRack`、`parked`、`inRack`、`shed`、`rack`）；不加依賴、不動 GameCore。
- 美術：kit 的零件與工作室的腳踏車，顏色都在色票；車架和車棚讓腳踏車有地方停，不再散在路邊。
- 音樂：無。

## 5. 留下的

- 公共自行車沒有自己的租借柱（YouBike 站每台一根柱子與一台機台）；現在借用一般車架。要工作室做一個零件（未評分）。
- 校門口、市場前的人行道：街道資料裡沒有學校與市場的位置（底圖只有道路、水、土地覆蓋），所以只放在公司自己蓋的學校與夜市；真實的學校、市場要先讀 OSM 的 `amenity=school`、`marketplace` 才擺得上（未評分）。
- 車站出口的車架沒有檢查和道路或建築重疊（出口本身也沒有檢查）；實機看有沒有壓到路。
- 機車：台灣車站出口多半是機車停車格；機車模型另有（決策 446），這次沒放。
