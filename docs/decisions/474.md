### 474. 公車走單行道的方向、穿隧道，找不到路不畫直線

2026-10-29，遊戲規劃 session_01YGNNumk6UqdBm6JrBhsdZY 派工單 BUS，實作 session_01YGNNupkE1PnsnNDofKd6rJ（`claude/bus-oneway-tunnel`）。號碼依 #1041：決策 474；存檔版本、golden schema 不動，GameCore 不動。接在決策 424（公車沿真的道路走）之後，424 的「下一步：單行道」由這份做。

**為什麼**：`docs/research/PLAYER_FEEDBACK.md` 2026-10-29 那張表的第 1–3 列：
1. 92.1（iPad）：萬華一帶新遊戲，一條接萬華站的路線有幾段是斜直線穿過街廓。
2. 93.1：穿山的公路「這兩個站牌之間沒有公車能走的路。」——`BusRoadNetwork` 不收 `brunnel == tunnel` 的路，隧道兩邊斷開。
3. 93.1：苗栗豐富站旁分隔島兩側各一條的道路（新港三路），公車兩邊都雙向走、停在對向——底圖沒有 `oneway`，每段路都當雙向。

#### 做了什麼

**底圖**（`tools/basemap/build_basemap.py`，`taiwan.pmtiles` 重切，資料見 `tools/basemap/README.md` 的 2026-10-29 一節）：
- `transportation` 加 `oneway`：OSM `oneway=yes/true/1` 與沒寫的圓環是 1；`-1/reverse` 把線倒過來再寫 1，所以圖磚裡單行道一律順著線的方向；`oneway:bus`／`oneway:psv` 是 `no` 的不寫（公車可以雙向，例如公車專用的逆向道）。
- 接線時單行道只頭接尾，不把方向相反的兩段接成一條。

**路網**（`Sources/GamePresentation/BusRoadNetwork.swift`）：
- 單行的一段只有順向一條邊（有向圖）；兩條一樣端點的段合併時，一條是雙向或兩條方向相反就是雙向。最短路仍是 Dijkstra，同長時依節點號碼決定，結果穩定。
- 隧道的路收進來，每一段帶著「在隧道裡」；站牌的索引不放隧道段，所以站牌一定不在隧道裡（點在隧道上方會被拒，和點在街廓中間一樣）。`BusStopLabels` 本來就不拿隧道的路名，不必改。
- 一段路（腿）在同一段上時，單行而終點在起點後面就不直走、繞回來。

**站牌放哪一側**（`BusRoads.place`）：點到的最近一段是單行時，看附近最多 `placesTried`（6）段（分隔道路的另一側、旁邊的匝道），每段放一個點，算到下一個站（或車站）的路，選最短的；同長取最近的。所以站牌停在公車那個方向的車道上。存檔讀進來、改路線時也一樣（從車站往回放）。

**腿的兩端**：車站與站牌各試最近的 `endsTried`（4）段路，取第一條找得到的。台北車站最近的路是單行的匝道，只試最近一段會斷。

**回程**（`BusRoads.wayBack`、`Map3DBuses`）：去程與回程各自找路，所以單行道與分隔道路上，回程走另一側。3D 裡回程公車沿回程的線開、停回程的站；隧道段不畫車（車開到隧道口消失、另一頭出來），線不貼車道。

**找不到路不畫直線**：
- 以前：存好的路線若有一段在底圖上找不到路，整條改走格子的路（`BusRoadPath`），格子也不通時畫兩點直線；3D 也一樣退回格子。這是萬華那種斜線唯一會出現的地方。
- 現在：底圖上找不到路就照底圖畫，斷的那一段畫紅虛線（和編輯中「這兩個站牌之間沒有公車能走的路。」同一個樣子）；只有玩家自己鋪的路（決策 438）接得起來時才走格子。3D 不畫這條路線的公車。

**萬華（第 1 列）沒有在 Linux 重現**：92.1（`e17eb67`）到現在公車只多了 `ec37f13`（決策 438 PR2）。在萬華站四周放了 139 個站牌、49 對兩兩相接、12 條四站的路線，用遊戲裡的底圖與新遊戲的地區地圖，沒有一段斷、沒有一段離開道路。會畫斜線的路只有上面那幾條退回格子與直線的路，所以把它們拿掉；`BusOneWayAndTunnelRealMapTests.testASavedLegNoRoadJoinsIsDrawnBrokenNotStraight` 在萬華用一個點在河上的站牌做出斷的一段：修之前畫直線，修之後畫紅虛線、其餘每個點都在路上、3D 沒有車。實機請再看一次。

#### 舊存檔讀進來

- 存檔版本不變；GameCore 的路線（站牌的格子、`legMetres`）一個字都沒改。
- 畫的時候重新貼路：站牌在單行道上的會換到順向那一側；線改走單行道的方向與隧道。
- `legMetres`（乘車時間、票價用的長度）讀檔不重算；玩家打開編輯再存，才用新的路算（去程的長度；GameCore 每段一個長度、兩個方向一樣，不改）。
- 有一段找不到路的：地圖上那段紅虛線；打開編輯看到「這兩個站牌之間沒有公車能走的路。」，改好才能存；3D 不畫車。GameCore 照舊開這條線（照存檔裡的長度）。

#### 沒選的

- **每個方向一個 `legMetres`**：GameCore 與存檔都要改，要升存檔版本；兩個方向的差別在乘車時間上不大。
- **找不到路時改走格子或直線**（舊做法）：就是斜線穿過街廓的原因。
- **隧道裡也能放站牌**：真的公車不在隧道裡停；隧道的路在 2D 地圖下方看不到。
- **轉彎限制**（`restriction` 關係）：底圖不帶，要另外存一份；這次的三個回報都用不到。下一步。
