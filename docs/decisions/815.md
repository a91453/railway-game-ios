### 815. 冬季曲：12/1–1/6 的背景音樂換成自己編的〈Jingle Bells〉（MUSIC-WINTER）

2026-11-17，MUSIC-WINTER（雲端 session_01JMHz9cGsvfsJaQrxo2Y89Z，`claude/music-winter`），遊戲規劃 session_01JMHz9Yps9xJyFfDFR4mUed 派工，接冬季活動企劃 `docs/research/WINTER_EVENT_2026-11-15.md` §2.5 與決策 219（鐵道聲音、MML Studio 的產製流程）。GameCore、存檔（107）、golden（77）、SaveFixtures、ReplayFixtures 不動。主題曲改版（MUSIC-REFRESH）是本決策的補充，另一張 PR。

## 決定

- **什麼時候播**：裝置日期 12/1 00:00 到 1/6 23:59，就是冬季活動的日期（決策 788 的 `WinterEvent.isOn(at:)`，照裝置的時區）。新的 `MusicTrack`（GamePresentation）回答哪一天播哪一首；App 的 `GameAudio` 在音樂開始播與 App 回到前景時問它，換了就換檔。其他時間照舊播主題曲 `music-loop.caf`。
- **開關與音量照舊**：音樂開關、音樂音量、跟車進轉運站時淡出（`MusicDuck`）、夜間跳過時壓低，都作用在同一個播放器上，所以對冬季曲一樣有效。不跟「節慶裝飾」開關：那個開關說的是地圖上的燈飾；不想聽的玩家關音樂。
- **曲子**：〈Jingle Bells〉（James Lord Pierpont，1857 年出版，公有領域），主歌與副歌的旋律自己重新編曲。沒有用任何錄音、MIDI 或別人的編曲。
- **產製**：照決策 219 的流程，第一次用在配樂上。旋律、和聲、節奏三份 MML（`tools/audio/mml/winter-*.mml`，瑪奇六格）→ `mml_to_score.mjs`（MML Studio 的核心）→ 三份 `role: stem` 樂譜 → `make_game_audio.py` 的 `stems_loop()` 用同一套合成器混成一個循環 → `music-winter.caf`（IMA4）。
- **編曲**：C 大調、120 bpm、4/4，56 小節、112 秒，可無縫循環（5,376,000 個取樣，IMA4 封包的整數倍）。

  | 段 | 小節 | 和弦 | 旋律與伴奏 |
  | --- | --- | --- | --- |
  | 前奏 | 4 | C Am F G7 | 鐘琴輕輕預告「E E E、E E E」；高音鐘一聲；撥弦琶音 |
  | A 主歌 | 16 | C C C F │ Dm G G7 C │ C C C F │ F C G7 C | 撥弦唱主歌；和弦墊、撥弦低音（一、三拍根音與五音）；雪橇鈴在二、四拍 |
  | B 副歌 | 16 | C C C C │ F C D7 G7 │ C C C C │ F C G7 C | 鐘琴唱副歌；琶音回來；雪橇鈴八分音符、二四拍重 |
  | 間奏 | 4 | Am F Dm7 G7 | 只有和弦墊與鐘慢慢唱一句，雪橇鈴一小節一下，喘口氣 |
  | B′ 副歌 | 16 | 同 B | 鐘琴唱副歌，撥弦低三度合唱，高音鐘拉長音當高聲部；結尾落在 C，接回前奏 |

  每小節第三拍一對鐵軌接縫聲（相隔十六分音符），和主題曲一樣是鐵道的記號。和弦墊照主題曲的做法每個和弦多響 0.6 秒疊到下一個；回聲用主題曲那個附點八分的左右回聲。
- **兩種新音色**（決策 219 §2.1 允許的上限）：`glock` 鐘琴（鐵琴的前三個模態，比 `bell` 亮、短）、`sleigh` 雪橇鈴（35 毫秒內四個小鈴，固定種子，音高選搖法）。`score.py` 與 `mml_to_score.mjs` 的音色表各加這兩個。現有的樂譜與音檔一個位元組都沒變（`--check` 通過）。
- **響度**：照 ITU-R BS.1770-4 量整首的 LUFS（`loudness_lufs()`，自己用 numpy 寫，K 加權用兩個雙二階濾波器的頻率響應繞一圈），冬季曲調到和主題曲一樣：主題曲 −15.95、冬季曲 −15.94 LUFS（manifest 的 `loudnessLufs`；ffmpeg 的 `ebur128` 量主題曲 −16.0，相符）。冬季曲的峰值 −1.27 dBFS（主題曲 −3.09）：撥弦、鐘琴的起音比和弦墊尖，同樣響度峰值就比較高，仍在 0.9 以下。
- **分軌的混音規則**（研究文件 §2.5 的「分軌不各自正規化」）：分軌裡一個音的大小是 `velocity ÷ 127 × gain ÷ 100`，不除以各自最大的力度。

## 量到的

- 各段響度（LUFS）：前奏 −18.8、主歌 −16.5、副歌 −15.5、間奏 −18.2、副歌再一次 −15.0。前奏與間奏比較安靜，循環一圈有起伏。
- 旋律比伴奏大約 4 dB（主歌 −17.0 對 −21.2、副歌 −16.8 對 −20.5），雪橇鈴與接縫聲在旋律下約 13–15 dB。
- 頻譜：主題曲有 72%（−1.4 dB）的能量在 120 Hz 以下，冬季曲只有 5%（−13.2 dB），能量在 250 Hz–1 kHz。低音放在 E2–D3，不用主題曲兩個八度下的和弦墊低音。這也是 MUSIC-REFRESH 要處理的「主題曲太壓抑」的一個量得到的原因。
- 循環接縫 0.023，比最大的相鄰落差 0.242 小很多，不會「喀」。
- 檔案 5.7 MB（IMA4 立體聲，112 秒）。

## 參考檢查

- 參考庫（`gh api search/code`，`railway-reference-private`）找 jingle、christmas music、sleigh：沒有。有背景音樂的只有 `island_city` 的 `musicTick`（生成式，決策 219 已讀過）與 `town-scene` 的 `music.js`（沒有授權文字，不用，`docs/HANDOFF.md` §2）。冬季曲沒有可以搬的。
- 外部：BS.1770-4 是 ITU 的公開標準，照公式自己寫，沒有抄程式；用 ffmpeg 的 `ebur128` 濾鏡只做對照（不是依賴）。
- 曲子的公有領域：1857 年在美國出版（"One Horse Open Sleigh"，Oliver Ditson），1929 年以前出版的作品在美國是公有領域；現在通行的副歌旋律也在 1929 年以前的出版品裡。

## 五個角度

- 玩家：12 月一打開遊戲就知道活動開始了；曲子人人會哼，112 秒、前奏與間奏較輕，長時間聽不會一直撞到同一句；開關、音量、跟車淡出都照舊。
- 鐵道迷：每小節的鐵軌接縫聲留著，像坐在冬天的列車上；雪橇鈴與鐘琴是冬天的音色，不是鐵道的，但主題曲的鐵道記號沒有丟。
- 開發者：只多一個 GamePresentation 的小 enum 與 App 換檔的幾行；音檔是決策 219 的 MML → 樂譜 → 合成器流程，第一次用在配樂，產生器可以重做、`--check` 逐位元組比對；沒有新依賴。
- 美術：無畫面；檔名、清單照現有的規矩。
- 音樂：和主題曲、到站鈴同一套合成器（撥弦、和弦墊、鐘、接縫聲）加兩種新音色，到站鈴的五聲音階在 C 大調上照樣和諧；響度量過和主題曲一樣，不會一換季就突然變大聲。

## 其他選項（給作者之後看）

| 選項 | 沒選的理由 |

| 其他公有領域的冬季歌（〈Deck the Halls〉〈We Wish You a Merry Christmas〉〈O Tannenbaum〉） | 〈Jingle Bells〉的雪橇與「出發」最接近鐵道遊戲；它自己有主歌、副歌兩段，A/B 段不必拼兩首。之後要換季更替時可以加 |
