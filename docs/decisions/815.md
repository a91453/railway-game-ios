### 815. 冬季曲：12/1–1/6 的背景音樂換成自己編的〈Jingle Bells〉（MUSIC-WINTER）

2026-11-17，MUSIC-WINTER（雲端 session_01JMHz9cGsvfsJaQrxo2Y89Z，`claude/music-winter`），遊戲規劃 session_01JMHz9Yps9xJyFfDFR4mUed 派工，接冬季活動企劃 `docs/research/WINTER_EVENT_2026-11-15.md` §2.5 與決策 219（鐵道聲音、MML Studio 的產製流程）。GameCore、存檔（107）、golden（77）、SaveFixtures、ReplayFixtures 不動。主題曲改版（MUSIC-REFRESH）是本決策的補充，另一張 PR。

## 決定

- **什麼時候播**：裝置日期 12/1 00:00 到 1/6 23:59，就是冬季活動的日期（決策 788 的 `WinterEvent.isOn(at:)`，照裝置的時區）。新的 `MusicTune`（GamePresentation）回答哪一天播哪一首；App 的 `GameAudio` 在音樂開始播、一首播完與 App 回到前景時問它，換了就換檔。（名字不叫 `MusicTrack`：AudioToolbox 有同名的型別，App 同時匯入兩邊時 Xcode 認不出是哪一個。）其他時間照舊播主題曲 `music-loop.caf`。
- **冬季曲與主題曲輪流**（遊戲規劃聽過後要求：同一首 112 秒的〈Jingle Bells〉連播 37 天最容易聽膩）：活動期間冬季曲一遍、主題曲一遍、再冬季曲，每首只播一次（`numberOfLoops = 0`），播完由播放器的 delegate（`MusicEnd`）告訴 `GameAudio` 換下一首；`MusicTune.play(at:continuing:)` 與 `play(after:at:)` 決定下一首（`MusicPlay`：哪首、會不會自己循環）。回到前景時接著原來那一輪；11 月起循環的主題曲在 12/1 回到前景時馬上換冬季曲；1/7 起不管輪到哪一首都換回循環的主題曲。活動以外主題曲照舊自己無縫循環。
- **開關與音量照舊**：音樂開關、音樂音量、跟車進轉運站時淡出（`MusicDuck`）、夜間跳過時壓低，都作用在同一個播放器上，所以對冬季曲一樣有效。不跟「節慶裝飾」開關：那個開關說的是地圖上的燈飾；不想聽的玩家關音樂。
- **曲子**：〈Jingle Bells〉（James Lord Pierpont，1857 年出版，公有領域），主歌與副歌的旋律自己重新編曲。沒有用任何錄音、MIDI 或別人的編曲。
- **產製**：照決策 219 的流程，第一次用在配樂上。旋律、和聲、節奏三份 MML（`tools/audio/mml/winter-*.mml`，瑪奇六格）→ `mml_to_score.mjs`（MML Studio 的核心）→ 三份 `role: stem` 樂譜 → `make_game_audio.py` 的 `stems_loop()` 用同一套合成器混成一個循環 → `music-winter.caf`（IMA4）。
- **編曲**：C 大調、120 bpm、4/4，56 小節、112 秒，可無縫循環（5,376,000 個取樣，IMA4 封包的整數倍）。

  | 段 | 小節 | 和弦 | 旋律與伴奏 |
  | --- | --- | --- | --- |
  | 前奏 | 4 | C Am F G7 | 鐘琴輕輕預告「E E E、E E E」；高音鐘一聲；撥弦琶音 |
  | A 主歌 | 16 | C C C F │ Dm G G7 C │ C C C F │ F C G7 C | 撥弦唱主歌；和弦墊、撥弦低音（一、三拍根音與五音）；雪橇鈴在二、四拍 |
  | B 副歌 | 16 | C C C C │ F C D7 G7 │ C C C C │ F C G7 C | 鐘琴唱副歌；琶音回來；雪橇鈴八分音符、二四拍重 |
  | 間奏 | 4 | Am F Dm7 G7 | 只有和弦墊與鐘慢慢唱一句，雪橇鈴一小節一下，喘口氣 |
  | B′ 副歌 | 16 | 同 B | 鐘琴唱副歌，撥弦低三度合唱，高音鐘拉長音當高聲部；結尾落在 C，接回前奏 |

  每小節第三拍一對鐵軌接縫聲（相隔十六分音符），和主題曲一樣是鐵道的記號。和弦墊照主題曲的做法每個和弦多響 0.6 秒疊到下一個；回聲用主題曲那個附點八分的左右回聲。
- **兩種新音色**（決策 219 §2.1 允許的上限）：`glock` 鐘琴（鐵琴的前三個模態，比 `bell` 亮、短）、`sleigh` 雪橇鈴（35 毫秒內四個小鈴，每個是 2.5–7 kHz 之間幾個不諧和的分音，固定種子，音高選搖法）。
- **亮度**（遊戲規劃量過後要求：第一版 300 Hz–1 kHz 占 71%，1 kHz 以上只有 5%，鐘琴與雪橇鈴像悶在箱子裡）：量了各分軌，鐘琴寫在 C5–G5，98% 的能量在 1 kHz 以下；雪橇鈴 90% 在 4 kHz 以上，手機喇叭放不太出來，且只占整首能量的 0.9%。改成鐘琴高八度（C6–G6，真的鐵琴本來就比記譜高兩個八度發聲），增益 55 → 42（照 K 加權的響度，高八度同增益會大 1.3 dB，再收 1 dB 讓它亮而不刺）；雪橇鈴的分音從 3.5–8.5 kHz 移到 2.5–7 kHz，增益 50 → 90。整首仍調到 −15.95 LUFS。`score.py` 與 `mml_to_score.mjs` 的音色表各加這兩個。現有的樂譜與音檔一個位元組都沒變（`--check` 通過）。
- **響度**：照 ITU-R BS.1770-4 量整首的 LUFS（`loudness_lufs()`，自己用 numpy 寫，K 加權用兩個雙二階濾波器的頻率響應繞一圈），冬季曲調到和主題曲一樣：主題曲 −15.95、冬季曲 −15.94 LUFS（manifest 的 `loudnessLufs`；ffmpeg 的 `ebur128` 量主題曲 −16.0，相符）。冬季曲的峰值 −1.27 dBFS（主題曲 −3.09）：撥弦、鐘琴的起音比和弦墊尖，同樣響度峰值就比較高，仍在 0.9 以下。
- **分軌的混音規則**（研究文件 §2.5 的「分軌不各自正規化」）：分軌裡一個音的大小是 `velocity ÷ 127 × gain ÷ 100`，不除以各自最大的力度。

## 量到的

亮度修改之後（`music-winter.caf` 解碼後量）：

- 整首 −15.94 LUFS（ffmpeg `ebur128`：−15.9 LUFS、LRA 3.4 LU、true peak −2.2 dBTP），峰值 −2.26 dBFS。
- 各段響度（LUFS）：前奏 −18.8、主歌 −16.2、副歌 −15.8、間奏 −17.6、副歌再一次 −15.1。前奏與間奏比較安靜，一圈有起伏。
- 頻譜（能量占比）：300 Hz 以下 28%、300 Hz–1 kHz 36%、1–4 kHz 33%（第一版 4.1%）、4 kHz 以上 2.5%（第一版 0.8%）；手機喇叭的 1–6 kHz 占 35%（第一版 4.5%）。120 Hz 以下 3%（主題曲改版前 73%）。
- 循環接縫 0.024，比最大的相鄰落差 0.362 小很多，不會「喀」。
- 檔案 5.7 MB（IMA4 立體聲，112 秒）。

## 參考檢查

- 參考庫（`gh api search/code`，`railway-reference-private`）找 jingle、christmas music、sleigh：沒有。有背景音樂的只有 `island_city` 的 `musicTick`（生成式，決策 219 已讀過）與 `town-scene` 的 `music.js`（沒有授權文字，不用，`docs/HANDOFF.md` §2）。冬季曲沒有可以搬的。
- 外部：BS.1770-4 是 ITU 的公開標準，照公式自己寫，沒有抄程式；用 ffmpeg 的 `ebur128` 濾鏡只做對照（不是依賴）。
- 曲子的公有領域：1857 年在美國出版（"One Horse Open Sleigh"，Oliver Ditson），1929 年以前出版的作品在美國是公有領域；現在通行的副歌旋律也在 1929 年以前的出版品裡。

## 五個角度

- 玩家：12 月一打開遊戲就知道活動開始了；曲子人人會哼，和主題曲輪流，37 天下來不會一直聽同一首；鐘琴與雪橇鈴在手機喇叭上聽得到亮；開關、音量、跟車淡出都照舊。
- 鐵道迷：每小節的鐵軌接縫聲留著，像坐在冬天的列車上；雪橇鈴與鐘琴是冬天的音色，不是鐵道的，但主題曲的鐵道記號沒有丟。
- 開發者：只多 GamePresentation 的小 enum、一個 `MusicPlay` 與 App 換檔、接下一首的幾行（輪流的規則有 Linux 測試）；音檔是決策 219 的 MML → 樂譜 → 合成器流程，第一次用在配樂，產生器可以重做、`--check` 逐位元組比對；沒有新依賴。
- 美術：無畫面；檔名、清單照現有的規矩。
- 音樂：和主題曲、到站鈴同一套合成器（撥弦、和弦墊、鐘、接縫聲）加兩種新音色，到站鈴的五聲音階在 C 大調上照樣和諧；響度量過和主題曲一樣，不會一換季就突然變大聲。

## 補充：主題曲改版（MUSIC-REFRESH，2026-11-17）

同一個 session，`claude/music-refresh`，接在冬季曲之後。作者問「現在的音樂是不是太壓抑了」。改的是決策 79 的主題曲 `music-loop.caf`（ARCHITECTURE 決策 79 第 1 點對音樂的描述由這裡取代）。只換音檔與產生它的程式；GameCore、存檔、golden、App 的程式都不動。

### 為什麼壓抑（量到的）

- 沒有旋律：和弦墊、撥弦琶音、接縫聲，8 小節（19.2 秒）的內容重複兩次成 38.4 秒，一直重複。
- 低頻太重：和弦墊整個低八度（C3–B3），下面再墊一個低兩個八度的低音（F1–C2，43–65 Hz）。整首 **72% 的能量在 120 Hz 以下**；iPhone 喇叭放不出這一段，聽到的是悶，耳機裡是一團低音。

### 三個候選

都用同一套合成器（撥弦、和弦墊、鐘琴、鐘、接縫聲），都調到改版前的響度 −15.95 LUFS，玩家設的音樂音量意思不變。

| **1（選定）** | 保留決策 79 的和弦（Cmaj7–Am7–Fmaj7–G7 各兩小節、100 bpm）與撥弦琶音、接縫聲；加旋律：A 段撥弦唱「E G A G E」開頭的一句兩次（第一次停在 G 等著，第二次落下），B 段鐘琴高一點、長一點地回答兩次；低音改成撥弦、放在 E2–D3，和弦墊三個音放在 G3–F4 | 76.8 秒、32 小節 | 4% | +3.4 dB |

### 選候選 1，五個角度

- 玩家：有一句聽一兩次就記得、會跟著哼的旋律，低頻不再悶；100 bpm 的速度沒變，長時間開著不會變吵。

- 美術：無畫面；介紹影片的配樂仍是改版前那首，兩者和弦、速度、音色相同，放在一起不違和。
- 音樂：和到站鈴、冬季曲同一家族；旋律只用 C 大調音（A 段幾乎是五聲音階），到站鈴響在上面照樣和諧；候選 3 低頻好了但仍沒有旋律，候選 2 旋律最搶耳但比較像另一首曲子。

## 後來：主題曲配合畫風，配樂改用取樣樂器（THEME-PLAIN，2026-11-18）

新專案「鐵道遊戲主規劃 2」的工作串「讓主題曲不再俗氣」（雲端，`claude/project-thread-egadbe`，#2394）。作者聽了上面補充的主題曲說「怎麼覺得新版歌曲變的很俗氣」「不符合我呈現出的美術風格」。結果：主題曲換成一首新寫的小步舞曲，兩首配樂都改用真實錄音的樂器取樣演奏，冬季活動期間兩首輪流時各播一遍「會自然收尾」的版本。`MusicTune` 的輪流規則、開關、音量、跟車淡出照舊；GameCore、存檔、golden 不動。

### 為什麼俗氣

- **和弦**：I – vi – IV – V（Cmaj7–Am7–Fmaj7–G7）是 1950 年代流行歌、早期手機遊戲最常用的一組，每兩小節就由 G7 推回 C，聽起來甜、熟、像罐頭配樂。
- **旋律**：「E G A G E」這種五聲音階、照拍子排好的短句，像兒歌；B 段換成閃亮的鐘琴再唱一次，更像童趣小遊戲。
- **伴奏**：撥弦八分音符琶音一直跑，加上左右回聲，整首熱鬧、塞滿。
- **對照畫風**：遊戲是扁平、實心色塊、圓角、色票收斂、留白多的畫面（art-style §1）。音樂上對應的是：音色圓潤、音少、伴奏不塞滿、不靠洗腦旋律。

### 主題曲：D 小步舞曲

C 大調、3/4 拍、150 bpm，64 小節 76.8 秒（3,686,400 個取樣，64 的整數倍）。低音在第一拍，第二、三拍輕點兩個和弦音；旋律走在一條一步步往下的低音上（C B A G F E D G C），中段轉到 F 與 D 小調再回來，最後一小節落在主音。亮來自大調與音域，不靠高頻：2–5 kHz 0.26%、能量重心約 590 Hz。三份 MML 分軌（`mml/theme-*.mml`）照舊：旋律、和聲（低音、兩個和弦音、長音）、節奏（鐵軌接縫）。

### 取樣樂器（偏離研究文件 §2.2 與決策 219 的「不用音色庫」）

研究文件與決策 219 寫配樂全用自己的合成器、不用取樣。作者第四輪指出的粗糙感來自合成器本身，合成器上修不好，所以這裡偏離它：

- **音色庫**：GeneralUser GS v2.0.3（S. Christian Collins），釘在 commit `684543d5…`，SHA-256 核對；授權允許用於音樂創作與軟體（`tools/audio/sampled/GeneralUser-GS-LICENSE.txt`）。只是工具，第一次用時下載，不提交、不進 App；做出來的音檔是遊戲自己的。
- **演奏器**：npm `spessasynth_core` 4.4.10（Apache-2.0），新增的工具依賴（作者第四輪要求找 GitHub 專案，第五輪同意這個做法）。關掉它自己的效果，輸出可重現（`--check` 逐位元組相同）。
- 看過沒用的：a91453/mml-tools 帶的 FluidR3Mono（檔內寫「DO NOT REDISTRIBUTE」，不用）；自己寫物理模型的鋼琴（做不到取樣的質感）。
- **流程**（`sampled_music.py`）：MML → 樂譜 → MIDI（整首兩遍）→ SpessaSynth → 取第二遍當循環 → 鐵軌接縫（合成器）→ 小廳殘響（1.9 秒、固定種子，繞圈）→ 母帶（60 Hz 以下切、9 kHz 以上緩降）→ 繞圈的峰值限制（`MUSIC_CEILING` 0.85）→ `MUSIC_LUFS`。
- **演奏人性化**（`played()`）：樂句（4 小節）往中間漸強、句尾收，第一拍稍重；伴奏前後差幾毫秒；鋼琴延音踏板只踩第一拍之後一兩拍；固定種子。
- **格式**：循環檔改成 ALAC（16-bit 無損）。IMA4 在安靜的鋼琴底下有約 43 dB 訊噪比的嘶聲。

### 輪流播的換曲

上面的補充是一首的循環檔設成只播一遍、播完立刻接另一首。循環檔的開頭帶著上一圈的餘音（接在另一首後面會憑空冒出一聲），結尾截斷在餘音中間；兩首拍子速度不同（3/4 150 bpm、4/4 120 bpm），交叉淡化會亂；在終止式上淡出聽起來像被調小聲。所以每首另做「播一遍」的版本：從安靜開始演奏一遍，最後的和弦與殘響再響 3 秒、最後 1.5 秒收到零，AAC 192 kb/s（不循環，編碼延遲無所謂）。App 播完一首停 1.5 秒（`MusicTurnChange.rest`）再播下一首，像唱片換曲。冬季曲只會播一遍，所以只有 `music-winter.m4a`，沒有循環檔；`MusicPlay.resource` 依「曲＋是否循環」選檔。

| 檔 | 用途 | 大小 |
| --- | --- | --- |

| `music-theme.m4a` | 主題曲播一遍（AAC） | 1.9 MB |

鋼片琴、管鐘、鈴鐺沿用 GeneralUser GS（VSCO 沒有鋼片琴；它的管鐘只有四個音，不夠冬季曲的音域）。做法在 `tools/audio/README.md`「室內樂音色庫」：`chamber_bank.py` 照 `sampled/chamber.json` 從兩個 repo 釘住的 commit 下載取樣、逐檔核對 SHA-256、組成一個 SoundFont（約 400 MB，只在本機快取，不提交、不進 App），`render.mjs` 把它放在 GeneralUser GS 前面。

看過沒選的：VCSL（Versilian，CC0）的 Steinway B 與 Kawai 鋼琴（取樣多，但沒有比 Salamander 更多人用過、驗證過）；Sonatina Symphonic Orchestra（CC Sampling Plus，已停用的授權，商業遊戲有疑慮）；FluidR3（不比 GeneralUser GS 好）；自己寫 SFZ 取樣器（SpessaSynth 已經做好包絡、踏板與音高，換成 SoundFont 就好）。

### 為了不改變定案的聲音而做的

- **鋼琴只用一支麥克風**：Salamander 的兩支麥克風相距約 12 公分，兩聲道的相關從音到音在 −0.8 到 +0.6 之間跳；手機單喇叭聽到的是兩聲道相加，旋律會一個音大一個音小。只取右邊那支（旋律音域較大聲），等於 GeneralUser GS 原本幾乎是單聲道的鋼琴（相關 0.99）。這支在 1–2 kHz 較暗，加一個 1.5 kHz +4 dB 的等化，能量重心 724 Hz（原版 721 Hz）。
- **逐音拉平**：VSCO 是一個音一個音錄的，相鄰取樣差到約 10 dB；同一層力度調到中位數。
- **混音照舊**：每一軌單獨演奏的響度和換之前一樣（`arrangements.json` 的 `volume` 重算），所以旋律對伴奏的比例、各樂器的平衡都是作者聽過的那一版。

### 判斷：音質明顯更好嗎

量測只能說「沒有變壞、混音照舊」，說不出好聽。判斷「更好」靠的是取樣本身的差距，這是錄音規格上的事實，不是猜：鋼琴從一層力度變 16 層（輕彈與重彈是不同的錄音，不只是大小聲）、從 31 kHz 的循環變 48 kHz 的完整衰減；撥弦從四個音拉五個八度、22 kHz，變成真的三個聲部、每 2–3 個半音一個音；弦樂長音從合成循環變真人揉弦。這幾項正是作者說「粗糙、像電腦」的來源。作者的耳朵仍是最後一關：試聽頁有改前改後、整首與獨奏片段，聽了覺得不如前一版，把這次合併 revert 即可（只動工具、音檔與資料來源頁）。

### 五個角度

- 玩家：同一首曲子，鋼琴的輕重有層次、撥弦是真的琴弦聲，開著經營幾小時更耐聽；音量、混音不變，不會突然覺得吵或小聲。
- 鐵道迷：無直接關係；鐵軌接縫聲照舊。
