### 914. 芬蘭封閉式汽車運輸車 Gd 掛在羅瓦涅米夜車車尾（FINLAND-CAR-CARRIER）

存檔版本、golden schema、GameCore、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/` 都不動。

## 1. 來源

工作室任務 `finland-car-carrier`（`a91453/railway-assets-private-2` #246，合併 `15f20c2`；工作室分支 `studio/finland-car-carrier-r1` 的 `71c05f0`，第 3 輪審查通過），`game-art-previews/docs/art/finland-car-carrier-2026-11/revision-1`。經驗檔：`docs/studio/lessons/finland-car-carrier.md`。近景 4,560、遠景 2,190 個三角形，長 26.70 m、寬 2.90 m，用 `tools/train-models/glb_to_swift.py --materials white,roofSilver,green,mask,hardware,dark,taillamp` 寫進 `Map3DFinlandCarCarrierMesh.swift`。

## 2. 規則

1. **掛在夜車車尾兩節**：羅瓦涅米的夜車（`PYO` 264–267、273、274，時刻表裡的夜車就是這六個車次）照 Digitraffic 2026-11-10～17 的編組，車尾掛 1–5 節汽車運輸車（一週 `Gd` 40 節、`Gfot` 42 節，約每班兩節）。遊戲的夜車是 7 節（機車＋6 節），所以改成機車、4 節雙層臥鋪車、2 節汽車運輸車，最後一節的尾燈點亮。`Gfot`（開放式雙層）還沒有模型，照派工單先借這台。
2. 沒有另開一個 set 或登錄：汽車運輸車是夜車 set（`finlandNight`、`finlandNightSr3` 與兩個遠景）裡的車，模型名 `set-finlandNight-centre`（倒數第二節，`centreCars`）與 `-tail`，雜湊照決策 782 寫在 `tools/train-models/locks/finlandNight.json`，`hashes.lock.json` 沒有一行變動。
3. 顏色全是芬蘭雙層客車已有的色（`Map3DFinlandDoubleDeck.meshPalette` 同名的那幾格），沒有新顏色；沒有玻璃，夜裡沒有窗燈。
4. 夜車原本的車尾是倒轉的臥鋪車，現在換成汽車運輸車；臥鋪車少兩節（6 → 4），整列長 19.02 + 26.40 × 4 + 26.70 × 2 = 178.0 m（原 177.4 m）。

## 3. 留下的

- `Gfot`（開放式雙層汽車運輸車，上層放車）另排工作室；做好後兩節裡換一節。
- 每班掛幾節是照一週平均定的兩節，不是逐班照 Digitraffic。

## 4. 五方

- 玩家：羅瓦涅米的夜車車尾多了兩節運車的車廂，和白天的城際列車分得出來。
- 鐵道迷：照 Digitraffic 一週的編組掛在夜車車尾，是真的會在羅瓦涅米看到的車。
- 開發：只改 GamePresentation 的夜車 set；舊的模型、雜湊表都沒動，只有夜車自己的鎖檔多了汽車運輸車的模型。
- 美術：全用現有色票，綠帶、綠斜板和雙層客車同色。
- 音樂：無。
