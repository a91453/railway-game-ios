### 508. 還沒有路線時：路線面板說缺什麼、站長先問要不要教學、「我自己來」指名按鈕

2026-10-30，派工單 ONBOARD1（session_01YGNNunyK17BipMcwxwfpTK，遊戲規劃第 35 任派），分支 `claude/onboard1-empty-route-panel`，目標 100.1。存檔版本、golden schema、SaveFixtures、ReplayFixtures、GameCore 都不動。

## 問題

98.1 玩家回報：「版面真的太複雜了，指引也看不懂。顯示點開路線，點開之後沒東西可以按。」作者補：「他根本沒去新手教學」。同一天另一位玩家問「建設要怎麼按，找不到」（`docs/research/PLAYER_FEEDBACK.md` 98.1 第 1、3 條）。

在 Linux 照 `LinesPanel` 與 `GamePresentation` 對過，還沒有路線時：

- `linesPanelListsLinesFirst` 是 false，面板是一張表單，最上面是新路線那段：「選路線的起點和終點，沿途經過的車站會依軌道自動找出。」、「在地圖上選站」、「加入選取的車站」、「移除最後一站」。**沒有車站時這些都按了沒用**：沒有站可以選，「加入選取的車站」沒有反應。下面是整個路網的開關（交通控制等）、空的路線清單、進階。
- 站長的第一句是「歡迎！點「建設」，再選「路網」，鋪一段軌道吧。」，但「建設」按下去已經選好「路網」（決策 114）；有站沒線時說「打開路線」，沒有引號，和按鈕上的「路線」對不起來。
- 開始畫面的「第一次玩？」卡（決策 177）可以按 × 關掉，關了之後遊戲裡沒有第二次問。

## 做法

邏輯在 GamePresentation 的 `FirstLineGuide.swift`，Linux 測試 `FirstLineGuideTests`；App 只畫。

1. **路線面板**（`FirstLineNeed`、`GameSession.linesPanelFirstLineNeed`）：沒有路線、沒在選站、沒在教學時：
   - 少於兩座車站：新路線那段換成一張卡，標題「先蓋兩座車站」（有一座時「再蓋一座車站」），一句怎麼做，一顆「到「建設」」（鐵鎚圖示）：關掉面板、打開建設（已選「路網」）。
   - 兩座以上、沒有路線：新路線那段照舊在最上面，原本的說明換成標題「把車站連成路線」加一句，下面就是「在地圖上選站」。
   - 有路線之後面板和以前一樣（#1560 的 iPhone 線在前不受影響：那是有路線時的排法）。
2. **站長的第一句**（`FirstLineGuide.offers`、`GameLauncher.chooseFirstLineGuide`）：自由遊戲（不是教學、關卡、挑戰）、還沒有路線、這台裝置沒完成教學、也還沒回答過時，站長旁邊出現一張卡：「第一次蓋鐵路嗎？我可以帶你做 5 分鐘教學，你也可以自己來。」兩顆鈕：「跟我做 5 分鐘教學」開第 1 關（同開始畫面的卡，目前的局照舊自動存檔）；「我自己來」記下來（`LauncherPreferences.firstLineGuide`，存在裝置上，像「第一次玩？」卡）。卡片一直在，直到回答；它在的時候站長不另外說話。
3. **「我自己來」之後**（`FirstLineGuide.hint`）：到第一條線開通為止，站長的第一條線那幾句換成指名按鈕的版本，泡泡前面有那顆鈕的圖示，那顆鈕套上教學的光圈（`TutorialOverlay` 的同一個框，抽成 `TutorialRing`）。依現在畫面上開著什麼決定下一步：

   | 現在 | 站長說 | 光圈 |
   | --- | --- | --- |
   | 沒軌道、沒在建設 | 點左下的鐵鎚「建設」，開始鋪軌道。 | 建設 |
   | 建設、路網、鋪設 | 在地圖上點軌道的起點，再點終點，然後按 ✓。 | 無（在地圖上） |
   | 有軌道、沒在建設 | 點左下的鐵鎚「建設」，在軌道上蓋車站。 | 建設 |
   | 路網、不是月台 | 點「月台」，再點軌道上要蓋車站的地方。 | 路網的模式列 |
   | 路網、月台 | 點軌道靠近一端的地方（第二座：另一端），再按 ✓。 | 無 |
   | 建設中選的不是路網 | 點左邊工具裡的「路網」。 | 路網 |
   | 兩座車站、還在建設 | 兩座車站好了。點左邊工具最下面的「完成」結束建造。 | 完成 |
   | 兩座車站、面板關著 | 點左下的「路線」，開一條路線。 | 路線 |
   | 路線面板開著 | 按「在地圖上選站」，再點你的兩座車站。 | 在地圖上選站 |
   | 選站中 | 在地圖上點一座車站，再點另一座，然後按 ✓。 | 無 |

   有比這更急的事（負債、颱風等）時站長照舊先說那件事。每一步變了就說一次（7 秒，同原本的泡泡）；光圈一直在，直到下一步。
4. **用字對齊按鈕**：站長「打開「路線」」加上引號（`createLine`、`lineWithoutTrains`），`buildTrack` 改成「點左下的鐵鎚「建設」」；說明（HelpGuide）「如何建造第一條路線？」改成照實際按鈕的順序寫（建設已選好路網、點起點終點、月台、完成、路線、在地圖上選站），並提路線面板最上面的那張卡。

UI 測試（`-ui-testing`）開的時候站長的教學卡關著，像開始畫面的「第一次玩？」卡（決策 177），要看的測試加 `-show-first-line-offer`。

動態：卡片進出用 `MotionRule.pop`（`.pop(anchor: .bottomLeading)`，同挑戰故事卡）；減少動態時只淡入淡出。泡泡沿用原本的彈簧；光圈不動。

## 五方

- 玩家：跳過教學的玩家打開「路線」不再是一張按了沒反應的表；第一眼知道缺什麼、按哪顆。不想看教學的人一按「我自己來」就不再被問，之後每一步都指出畫面上的那顆鈕。
- 鐵道迷：無（只是介面的指引）。
- 開發：何時顯示、說哪句、光圈在哪、按鈕帶去哪都在 GamePresentation，Linux 測試 9 個；App 只多一張卡、泡泡多一個圖示、光圈共用教學的那個；沒有升存檔，偏好檔多一個可省略的欄位，舊檔照讀。
- 美術：沿用站長泡泡、玻璃卡、主色膠囊鈕與教學的琥珀色光圈，沒有新圖；鈕的圖示就是 dock 上的圖示。
- 音樂：無。

## 沒選的

- **空狀態只放一張卡、新路線表單照留在下面**：iPhone 橫拿面板約 272 點，卡加表單會把「在地圖上選站」推出畫面；少於兩站時表單本來就沒用，所以換掉；兩站以上時把卡的字放進表單頂端。
- **站長的提問用系統的 alert**：會擋住整個畫面、搶走地圖操作，且每局都跳；改成站長旁的卡，不擋地圖。
- **「我自己來」只對這一局**：玩家說過不要教學，換一局又問很煩；記在裝置上，和開始畫面的卡一樣。
- **開始畫面的卡按 × 也算「我自己來」**：× 可能只是想先看看開始畫面；遊戲裡再問一次，玩家選了才算。
- **在地圖上畫箭頭指到要蓋的地方**：要算城鎮與軌道的位置，範圍大；這次只指按鈕，地圖上的步驟用文字說。
