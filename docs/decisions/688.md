### 688. 教學的膠囊站穩後不再搬家：第一次量到版面大小不算「螢幕變了」

2026-11-11，TUTORIAL-CAPSULE（Mac 本機，`claude/tutorial-capsule`），遊戲規劃第 61 任派工（#1579 留言 6794219917）。號碼依 #1579 登記；存檔版本、golden schema、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/`、GameCore 都不動。接決策 679「下一步」的第一項。

## 看到什麼

iPad Pro 13 吋模擬器（橫放、英文），照 `TutorialUITests.testBuildingTrackEnablesNextAndSkipEnds` 走到第 5 步「Tap Station」，不按膠囊，每 0.3 秒量一次它的位置：

- 改之前：前 2.3 秒在 (726.5, 876)，之後在 (94, 104)，一次跳過去，沒有動畫。和決策 679 記下的兩次 full lane 一樣。
- App 的記錄：這一步的卡片一排好，就被忘掉位置（`bounds.size (0, 0) -> (1376, 980): placed = nil`）；跳的那一刻，控制清單少了地圖上緣那一條 (82, 60, 944 × 62)，就是「軌道蓋好了」的狀態訊息。

## 原因

- 卡片留在原位靠 `TutorialCardSlot.placed`（`TutorialCardPlacement.previous`，`claude/tutorial-card-steady` 加的）。
- 「螢幕轉向或改大小就重新放」是 `.onChange(of: bounds.size) { placed = nil }`（Review I）。
- 每一步的卡片都是新的（`.id(tutorial.index)`），`bounds` 從 `.zero` 開始。第一次排版量到真正的大小，也算一次改變，`placed` 馬上被清掉。
- `placed` 只在卡片的框改變時才寫回去。所以從那一刻到卡片第一次移動之前，卡片沒有「原位」，每次排版都從頭挑位置。
- 「Tap Station」這一步開始時，狀態訊息佔住地圖上緣（膠囊本來就要讓開它，Mac playtest 2026-11-08 A2），膠囊放在地圖右下角。訊息約 3 秒後自己消失，左上角空出來，在候選順序裡排在右下角前面，膠囊就搬過去。
- 不只 iPad、不只這一步：任何一步，只要第一次放好之後有控制出現或消失，都會這樣跳一次。iPad 上兩個角離得遠（630 點），所以最明顯。

## 決定

1. **第一次量到版面大小不算螢幕變了。** 規則放在 GamePresentation：`TutorialCardPlacement.placesAfresh(boundsFrom:to:)`，舊的大小是空的就回答否；App 的 `onChange` 照它決定要不要清 `placed`。轉向與改視窗大小照舊重新放。
2. **Linux 測試兩個**（`TutorialCardPlacementTests`）：
   - `testAFoldedCardStaysWhenTheMessageOverTheMapGoes`：用模擬器量到的那一步的數字，訊息在時膠囊在右下角；訊息走了、從頭放會到 (94, 72)；帶著原位就不動。
   - `testOnlyAChangedScreenPlacesTheCardAfresh`：第一次量不算，轉向算。
3. **UI 測試多一段**：`testBuildingTrackEnablesNextAndSkipEnds` 在「Tap Station」先看膠囊 5 秒（10 次）位置都一樣，再打開它。改之前這一段會紅。
4. **決策 679 的「沒按到再按一次」留著**：它不放寬斷言，慢的 runner 上還有別的原因會讓一次觸控落空。
5. **沒有新的動畫**：膠囊不動了，不需要 `MotionRule`；「減少動態效果」沒有差別。
6. **順手改的一行**：`Map3DPreviewScreen` 的 `feed.manualDrive = { [weak session] … }` 前面加 `let session = session`。本機的 Xcode 27.2 把它報成錯誤（`ImplicitStrongCapture`），不改就建不起來；和上一行 `audio` 的寫法一樣，行為不變。

## 找過什麼

- 擁有者的參考庫：沒有 SwiftUI 版面的東西可搬。
- 外面的專案：沒有找。是這個專案自己的狀態在第一次排版被清掉。
- 所以：nothing usable，程式是這個專案自己的。

## 五個角度

- 玩家：膠囊不會在手指要按下去時跳到畫面另一角；想按它卻按到地圖的情況少一種。
- 鐵道迷：無。
- 開發者：iPad full lane 七天紅兩次的那個測試，原因修掉了，不只靠再按一次；規則有 Linux 測試。
- 美術：無（膠囊的樣子、位置的挑法都沒變，只是不再重挑）。
- 音樂：無。
