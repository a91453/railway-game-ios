### 640. UI 測試只留「看得到、按得到」：已在 Linux 測的一半移走，同一個起手的合成一支

2026-11-08，CI-SLIM（session_01YGNNuoyM27Qk37v9D2GPR3，`claude/ci-slim-ui`），遊戲規劃第 55 任派工。號碼依 #1579 登記；存檔版本、golden schema、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/`、GameCore、App 程式都不動，只改 UI 測試與 GamePresentation 的 Linux 測試。Swift 分片的部分是[決策 639](639.md)。

## 為什麼

擁有者覺得 CI 越來越久。full lane（run 42417467175）UI 測試合計約 130 分、149 支；最長的 job 是 build 68 分、lessons 61 分。`LessonUITests` 12 支 27 分，單支 2–4 分：每一次「開 App → 打開課程 → 開始第 N 課」約 1.5–2 分，而好幾支開兩次 App，一次看「第 N 課**沒有**某個按鈕」，一次看「第 N+1 課按得到」。「沒有」那一半是邏輯：畫面照 `GameSession` 的一個判斷顯示或不顯示，而那個判斷在 Linux 已經測過（CLAUDE.md：邏輯放 GamePresentation 的 Linux 測試，UI 測試只留 Simulator 才答得出的「看得到、手指按得到」）。`LineRoutePreferenceUITests` 兩支各約 175 秒，都是開即時世界示範、打開路線面板；`RealWorldMapUITests` 有兩支也都只開即時世界示範看一件事。

## 決定

逐支列出（「涵蓋」= 那支 Linux 測試斷言的，就是畫面用來決定顯示與否的同一個值）：

| 原本的 UI 測試 | 改成 | 移走的部分由誰涵蓋 |
| --- | --- | --- |
| `LessonUITests.testTheFourthLessonOpensOnlyAfterTheThirdHasStars`（開兩次：3,3,0 鎖住、3,3,1 打開） | `testTheFourthLessonOpensOnceTheThirdHasAStar`（開一次，3,3,1，Start 按得到） | 鎖住與否是 `GameLauncher.isOpen`（`GoalsPanel` 用它）：新的 `LessonTests.testTheFourthLessonOpensOnlyAfterTheThirdHasStars` 用同樣的星數檔；鎖住的卡片怎麼寫，`testAFreshInstallShowsTenLessonsAndOnlyTheFirstCanStart` 照舊看第 2–10 課 |
| `testAddATrainIsAbsentInTheFirstLessonAndReachableInTheThird`（`first.fare` 一次、第 3 課一次） | `testAddATrainIsReachableInTheThirdLesson`（第 3 課） | 路線卡只在 `session.allows(.addTrain)` 時有加開按鈕（`LinesPanel`）：`LessonTests.testALessonHasOnlyItsTools` 斷言第 1 課 false |
| `testDoubleTrackIsAbsentInTheFourthLessonAndReachableInTheFifth`（第 4、5 課） | `testDoubleTrackIsReachableInTheFifthLesson`（第 5 課） | 軌道卡只在 `canDoubleSelectedTrack` 時有複線按鈕（`InspectorView`）：`LessonTests.testDoubleTrackFromLessonFive` 在第 4、5 課點同一條最長的軌道看它 |
| `testDepotModeStartsInTheSeventhLesson`（第 6、7 課） | `testDepotModeIsReachableInTheSeventhLesson`（第 7 課） | 鋪軌工具列的模式是 `NetworkToolMode.allCases.filter { session.allows($0) }`（`NetworkControls`）：新的 `LessonTests.testDepotModeFromLessonSeven` 用同一個 filter 看第 6、7 課。PLAYER_FEEDBACK 記的那次真 bug（機廠模式捲到畫面外點不到）是第 7 課那一半抓到的，留著 |
| `testFreightYardsStartInTheEighthLesson`（第 7、8 課） | `testFreightYardsAreReachableInTheEighthLesson`（第 8 課） | 車站面板只在 `session.showsFreight` 時有貨運（`StationPanel`）：`LessonTests.testTheLaterLessonsGames` 斷言第 7 課 false、第 8 課 true |
| `LineRoutePreferenceUITests.testTheAdvancedSwitchFoldsTheTracksAndTheServiceDay` 與 `testALineLegCanSelectAPhysicalPlatform` | 合成 `testTheAdvancedSwitchShowsTheTracksAndALegCanSelectAPhysicalPlatform` | 不刪任何檢查：先關「進階」看軌道收起、再打開，接著原本第二支的選月台、改回自動 |
| `RealWorldMapUITests.testTheRealWorldDemoShowsMovementAuthorityOnTheMap` 與 `testTheMapCreditOpensTheDataSources` | 合成 `testTheRealWorldDemoShowsMovementAuthorityAndItsCreditOpensTheDataSources` | 不刪任何檢查：先等行車許可，再點角落的資料來源 |

沒有刪掉任何「唯一抓某個 bug」的檢查：移走的都是「沒有某個按鈕」，而那個按鈕顯示與否只看一個 Linux 已測的值；留下的都是「按得到」。PR gate 的 smoke（`StartSaveFlowSmokeTests` 等）沒動。

看過但沒改的：

- `LessonUITests` 的三支成績卡測試（下一課、再玩一次、繼續玩）各自用 UI 過第 1 課，約 3 分一支。按下其中一顆成績卡就消失，合不起來；要快只能加一個直接開在成績卡的啟動參數（改 App），這次不做（下一步）。
- `MapInteractionTests` 34 支多半用 `-demo-layout` 直接開局，開 App 只要十幾秒；同樣開 `demo.simple` 的幾支，點選會改變後一支要看的狀態（點中央選到的站再點一次會取消），合了容易互相干擾，省的時間少。
- `TutorialUITests` 的英文、中文、大字三支是不同語言的啟動，不能合。
- `FinanceCompositionUITests` 一支 204 秒、`RealWorldMapUITests.testThePlatformConfirmStaysAboveTheDockUnderATallBanner` 179 秒：各只有一支，時間在等場景載入與拖動，沒有可合的對象。

預計 full lane 少開 App 7 次（約 9–12 分），lessons job 約少 6–8 分。前後時間見 PR。

- 音樂：無。
