### 945. 內灣線合興、內灣換成工作室照真實站房做的車站（tw-stations-hexing-neiwan）

2026-11-23，雲端工作串 HEXING-NEIWAN（協調者派工，號碼照 #2118 的登記）。本機工作室第 3 輪過審（codex pass）的兩座站房接回遊戲：台鐵內灣線的合興與終點內灣。兩站在目錄是 `halt`（招呼站），原本畫決策 899 的工作室通用招呼站；內灣線其他站（竹中、竹東、九讚頭、富貴、榮華…）照舊。

存檔版本、golden schema、GameCore、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/` 都不動。只是畫法。

## 2. 規則

1. 目錄的合興、內灣畫自己的模型與自己的遠景版，做法和決策 929、932、937 一樣：`house()` 依目錄 id 改畫，月台淨空線（模型 Y +6）放在月台後 7 m，月台與月台雨棚照舊由遊戲畫。目錄的站型仍是 `.halt`，`tools/station-kit/catalog.py` 與產生的目錄檔不動（派工單第 10 節寫改對照表，這裡照決策 932 2.2：依 id，不加站型）。
2. **遠景**：`addHouse` 原本先看站型是不是 `regional`／`halt`（決策 899 的工作室通用站遠景），再看是不是工作室專屬站房。以前的六站都不是這兩種站型，順序沒差；合興、內灣是 `halt`，照舊順序遠看會變回通用招呼站。所以先看專屬站房。招呼站的擴建翼（`expansion`）不畫在專屬站房旁，和其他六站一樣。
3. 合興月台側披簷的屋頂與紅封簷出淨空線 0.24 m（底面 2.84 m），6 根紅柱都在線內；內灣沒有零件出線。內灣的白方塔前突到模型 Y −7.60，外廓 X ±12.18。
4. **顏色**全是遊戲已有的，沒有新格位：

   | 模型材質 | 遊戲的顏色 |
   |---|---|
   | 合興 `wallWhite`、內灣 `towerWhite` | `Map3DPalette.tankWhite` #E4E2DC |
   | 合興 `trimRed` | `Map3DContainerWagon.rust` #9A4A36（菁桐的牆腳同一個） |
   | 合興 `fasciaDark`（前山牆封簷與 +X 主簷邊） | `Map3DPalette.cityRoofs[2]` #5A4E4A |
   | 合興 `roofTile` | `Map3DPalette.arcade` #6F6A64 |
   | 合興 `skirtBlue`、`signBlue` | `Map3DPalette.hallRoofs[0]` #2D68AC |
   | 內灣 `tileGreen` | `Map3DPalette.park` #C8DFC0 |
   | 內灣 `frameGreen` | `CableParts.Paint.green` #5E8F86 |
   | 內灣 `timberSiding`（正面大門與相鄰開間的框） | `Map3DPalette.timberSiding` #4E392F（決策 932） |
   | 內灣 `concrete`、`steel`、`canopyGlass` | `Map3DPalette.concrete`、`steel`、`glazing` |
   | 兩站 `glazingDark`、`dark` | `Map3DDepotFacilities.glass` #26313D、`Map3DPalette.dark` |

5. 兩站都沒有字：合興前山牆的四塊藍牌是色塊；內灣塔正面是平的白牆，沒有浮雕壁畫（派工單）。
6. 屋頂對比測試（`Map3DRoofContrastTests`）依站型與種子分組，每組拿目錄裡第一站代表；內灣原本是 `halt-v0` 的第一站，換成專屬站房後就不是那組的配方了。分組從此略過有專屬站房的站，`halt-v0` 由下一個招呼站代表，結果和以前一樣（仍在 `known`）。

## 3. 五方

- 玩家：內灣線終點認得出來：淡綠磁磚、前面一座白方塔與 2024 年的波浪雨庇；合興是白木板牆、紅框藍腳的小站，不再是通用的白色招呼站。
- 鐵道迷：照兩站真實站房的照片做（合興的 L／T 折頂與前山牆四塊藍牌、內灣的塔樓與雨庇）；內灣塔的壁畫與雨庇的花紋玻璃沒做，照片上有。
- 開發：沿用決策 929 的 `Map3DStudioStation`，多兩個 case 與兩個網格檔；遠景分支換順序，一個測試的分組略過專屬站房；不加站型、不動 GameCore、不進 `Map3DModelPack` 與雜湊鎖檔。
- 美術：工作室對照片審過三輪（做與審是不同的模型家族），不另截圖（model-look §1）；顏色全是已有的格位。
- 音樂：無。
