### 780. 香港機場鐵路的兩款列車：機場快綫與東涌綫

2026-11-15，雲端 thread session（「做機場快綫與東涌綫列車」工作串），分支 `claude/project-thread-cxptdx`。優先清單 §29.9 MTR-1（3.35）。

不動 GameCore、存檔版本、golden、replay。

## 1. 做了什麼

1. **模型由本地工作室做**（作者 2026-11-15：建模一律先交本地工作室；`model-look` §1）：照片、尺寸（駕駛室車 24.6 m、其他 22.5 m、寬 3.096 m、高 3.7 m）、色票材質名寫成派工單，工作室在 Blender 做近景與遠景各 7 款、共 14 個 GLB，每個三角形一個材質（＝一個色票色），窗、門、車帶都是獨立的面，沒有貼圖。審查第 1 次退回、第 2 次通過。重檔與各輪紀錄在 `a91453/railway-assets-private` 的 `game-art-previews/docs/art/mtr-airport-line-2026-11/`；這裡只留總覽（`docs/art/mtr-airport-line-2026-11/`）。
2. **一套共用車殼、兩種塗裝**：機場快綫（寶藍、第一個轉向架後開始的青綠帶與珍珠白下半、深色連續窗帶、每側兩門，機場端一節沒有窗、五個貨櫃門的行李車）與東涌綫（銀灰、紅線上米色下半、每側五對門）。**不畫港鐵標誌**，名稱只用路線（不用車隊暱稱，作者 2026-11-15）。
3. **新工具 `tools/train-models/glb_to_swift.py`**（只用 Python 標準庫）：把工作室的色票 GLB 寫成 Swift 裡的編碼網格（每頂點 Int16 公釐、每三角形一個色票索引），由 `Map3DRedCommuter.decodedMesh(_:named:palette:)` 解碼；它擋下有變換的節點與不在清單的材質。之後工作室做的車都用它接進遊戲。
4. **兩套八節編組**（`Map3DTrainSet.mtrAirportExpress`、`mtrTungChung`，各有遠景版，`nearOnly`、`ownLengths`）：前端駕駛室車、中間依 `.middle ×2, .pantograph, .middle ×3`，尾端機場快綫是行李車、東涌綫是另一節駕駛室車。解碼失敗時退回通用車殼。新色票 7 個（`Map3DPalette.mtr*`）。
5. **還沒接到香港地圖的各綫**：港鐵各綫畫哪款車的表在另一個工作串（PR 2261，先借通用捷運車）；它合併後，把機場快綫、東涌綫兩格改成這兩個鍵。

## 2. 五個角度

| 角度 | 理由 | 分數（1–5） |
| --- | --- | ---: |
| 玩家 | 香港最常坐的兩條機場線有自己的車，不再是通用捷運車 | 4 |
| 鐵道迷 | 尺寸、門數、行李車、兩種塗裝照實車與照片；不放商標 | 5 |
| 開發 | 一支通用轉檔工具，之後工作室的車都走同一條路；記憶體多 31 個模型、約 4.9 MB | 3 |
| 美術 | 色票平塗、窗門切面，和作者新版列車同一做法；工作室依遊戲角度看過四輪 | 4 |
| 音樂 | 無 | 1 |

其他選項（沒選）：雲端 session 手寫 Swift 配方（作者說工作室成品較好、也省額度）；借桃園機場捷運 2000 型（紫色五節，不像）。
