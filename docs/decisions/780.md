### 780. 公開 repo 只用中性名稱，正式遊戲名稱在建置前注入（GAME-BRAND）

2026-11-15，GAME-BRAND（雲端 thread session「Remove game name from public repo」，`claude/project-thread-jubv0f`）。作者怕公開的 GitHub 被抄襲：GitHub 上維持「railway game ios」，遊戲裡維持原本的名稱。存檔版本、golden schema、`GoldenScenarios/`、`ReplayFixtures/`、GameCore 不動。

## 決定

1. **中性品牌**：`GamePresentation.GameBrand`（`english`、`chinese`、`saveExtension`、`website`、`contactEmail`）。公開 repo 只有 `GameBrand.neutral`：「Railway Game」／「鐵道遊戲」，副檔名 `railwaygame`，沒有官網、沒有信箱。`GameBrand.current` 讀 App 裡的 `GameBrand.json`，讀不到就是中性。
2. **用到名稱的地方都讀它**：開始畫面、明信片署名、3D 展示署名、問題回報主旨、存檔檔名與錯誤訊息、資料來源的「英文站名由…整理」與 ODbL 索取信箱、設定的官網與 3D 城市預覽（`GameWebsite.home`、`CityViewPage`，沒有官網就不顯示）、存檔類型（`SharedNetwork.fileExtension`、Info.plist 的類型名稱與副檔名、InfoPlist.strings 的主畫面名稱）。String Catalog 裡三個帶名稱的字串拿掉，改用 `DisplayLanguage.app.text`。
3. **注入**：正式品牌的母本在私有 `a91453/railway-assets-private` 的 `branding/game-brand.json`，CI 用 repository secret `GAME_BRAND_JSON`。`tools/brand/apply_brand.py` 在建置前改工作目錄（不提交），每個值在 Actions 記錄裡遮掉（`::add-mask::`）。`testflight.yml` 的 preflight 檢查、release 套用，沒有 secret 就紅；`website-screenshots.yml` 有就套用。`ios-build.yml`、full lane、`release-archive.yml` 建中性版；`SettingsUITests` 的 3D 城市預覽測試在沒有官網的建置跳過，UI 測試的名稱比對讀測試包裡同一份 `GameBrand.json`。`GameBrandTests` 守住提交的檔案是中性的。
4. **3D 城市網頁**：原始碼用中性名稱，官網連結改成相對的 `/`；`build_city_view.sh` 從私有品牌檔把名稱寫進建好的網頁。
5. **文件與註解**：遊戲名稱換成「railway game ios」，官網、信箱、副檔名換成 `<website>`、`<mailbox>`、`.<saveExtension>`；一般用語的「沿線」（沿線城鎮等）與英文 along the line 不動。`Web/CityView/ALONG_THE_LINE.md` 改名 `GAME_ADAPTATION.md`。本機工作室路徑改讀環境變數 `STUDIO_ROOT`。
6. **不做**：不改寫 git 歷史（舊 commit、舊 PR 與 issue 標題仍有名稱）；圖片裡的字不改；Bundle ID 與存檔類型識別碼本來就中性。

## 五方評比

- 玩家：遊戲裡看到的名稱、存檔副檔名、官網都和以前一樣（發版時注入）；舊存檔照樣開得了。
- 鐵道迷：無。
- 開發者：多一步建置前注入與一個 secret；中性建置少了官網與 3D 城市預覽的 UI 測試覆蓋，換來公開 repo 搜不到名稱。
- 美術：無（圖片不動）。
- 音樂：無。
