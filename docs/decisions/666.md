### 666. 沒閉塞的行車控制下，擋路又回不了機廠的沒班車，空車開到最近能讓路的月台

2026-11-09，派工單 TYMC-DEADLOCK（session_01JMHz9YNXe37AdFMrHsD4nF，遊戲規劃第 58 任派），分支 `claude/tymc-deadlock`。號碼依 #1579：決策 666。存檔版本、golden schema 不動。量測與查到的經過在 `docs/research/TYMC_AFTERNOON_2026-11-08.md` 最後一節。

**為什麼**：機捷「簡單＋行車控制」（新局預設）第 2 天下午的環北↔機場第一航廈沒發（門檻測試 `AirportShuttleDepotTests`，`TYMC_AFTERNOON=1`，main 紅）。TYMC-AFTERNOON-3 的探針看到：一列從蘆竹出來、趕不上 run 的車（列車 22）停在體育大學往台北的月台上，沒有班；後面要進那個月台的營業車都在等它。它的線想送它回機廠，但它面向台北，回機廠的路要先往台北、再折回，在班距幾分鐘的線上一次拿不到整段，於是它就一直停著。`deadlock(memo:)` 只算在等的車和（有閉塞時）線上的備用車：它不在等任何東西，所以也不算死結，死結出口從來不動。main 上也有這個漏洞，方向 2（897ae6bc）只是讓它常發生。

原先以為是 12、17 擋住它進機廠的路、形成一個環；再查的結果，擋它的是往台北方向正在走的 2、15、18，是一直拿不到路（餓死），不是環。所以不是把它算進死結就好，而是要給它一個出口。

**做法**：每分鐘，在死結出口（`resolveDeadlock`）與決策 278 的換月台都沒有動作之後：

- 只在行車控制開、沒有閉塞時。
- 有 run、有機廠的線，照 `runDepotEntryCandidates` 的順序，找一列「線要送它進機廠，只是它出發的路現在被擋」的車（`runDepotEntry(of:index:memo:)`，和 `runTrainEnteringDepot` 用同一個算法）。
- 它擋到某列在等路的車（`waitingRoute`，和 `deadlock(memo:)` 一樣排除還沒到時間的 run）時，用備用車讓路的同一套找法（`standingAside`，決策 212 的 `spareStandingAside` 抽出來的部分），找最近一個任何站的月台：路現在就拿得到，而且停在那裡就能讓一列等路的車走。
- 它照空車（決策 172）的樣子開過去：時刻表兩站、不載客、用自己的性能盡快開（`run(of:length:)`），算進線的空車里程。到站以後就和任何停在站上的沒班車一樣，線再送它進機廠或出 run。

沒班車原本用 `movement.rate` 慢慢爬（每分鐘 512 單位）。如果它照原樣慢慢爬，會一路拿著很長的一段路（約 300 個資源），後面的營業車反而被它擋更久。所以這裡讓它照空車的時刻走。

`runTrainEnteringDepot` 抽出 `runDepotEntry(of:index:memo:)`，行為不變。

**沒選的**：
- 有 run 的線、沒閉塞時，把沒班的車都當成備用車（`isSpare` 放寬），再加一個「站到任何站」的最後出口：機捷第 2 天 00:30 起興南、領航、高鐵桃園一帶卡了 14 列，36 小時時 31 列。多出來的偵測觸發了別的出口，新出口一次也沒用到。`RunServiceStandAsideAnyWayTests`、`RunTrainDepotDeadlockTests` 也紅了。
- 只把「等進機廠的路」的沒班車算進死結：回歸測試抓得到，但機捷的 22 抓不到，因為擋它的不是環。
- 讓開的車用沒班車的速度慢慢爬：見上。
- 只讓到「停在那裡不擋任何一列等路的車」的月台，減少一列車連讓好幾站：門檻測試紅（17:49 機場第一航廈→環北沒發），而且還是會跳。現在的寫法兩天讓路 65 次、146 km，有一次一列車連讓 15 站；減少跳站留給之後（研究文件最後一節）。

**五個角度**：
- 玩家：機捷新局第 2 天，沒發的 run 從 12 班降到 5 班，下午的環北↔機場第一航廈都有發。一列車停在月台上整天不動、後面全線等它的情形不會再發生。
- 鐵道迷：調度員會讓擋路的回送車先開到最近能停的地方，讓營業車先走，再找時間回機廠；這裡就是這樣做的。讓開的車照回送車的速度開，不在線上慢慢爬。
- 開發者：規則對所有有 run、有機廠的線都一樣，沒有線別的特例（HANDOFF §3「行車規則統一」）。台鐵、高鐵、文湖線的報告和 main 逐行相同。golden、存檔、replay 都沒動。
- 美術：無。
- 音樂：無。

**驗證**（Linux debug、最高倍速、簡單＋行車控制，`DepotReturnReportTests`；表在 `docs/research/TYMC_AFTERNOON_2026-11-08.md` 最後一節）：機捷第 2 天沒發 12/333 → 5/333，最多死結 7 列（main 也是 7 列；時刻從第 2 天 05:30 的 1 格變成第 1 天 18:10 的 2 格），空車 341 → 667 km（讓路的空車約 146 km，其餘是多發的 run 與進出機廠）；門檻測試 `TYMC_AFTERNOON=1 AirportShuttleDepotTests` 綠。台鐵、高鐵、文湖線報告和 main 逐行相同。golden、存檔、replay 在本機是綠的，沒有改任何期望值。回歸測試 `RunSpareInTheWayTests`：在 main 上是紅的（E 的車沒動、C 的 run 沒發、也沒報死結），在這裡是綠的。
