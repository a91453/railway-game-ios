### 651. MapLibre Native 升到 7.0.0（globe 版先不換）

2026-11-08，派工單 MAPLIBRE-7（遊戲規劃第 56 任派，作者要求：「把地圖 MapLibre 升級，順便看有沒有新功能可用」），分支 `claude/maplibre-7`。號碼依 #1579 的登記：決策 651。存檔版本、golden schema、GameCore 都不動。接 `docs/research/STALE_AUDIT_2026-11-08.md` §1 的 MapLibre 那列，與決策 97（MapLibre 進專案）、決策 151（遊戲自己的底圖）。

## 改了什麼

- `RailwayGameApp/project.yml`：`maplibre-gl-native-distribution` 的 `exactVersion` 6.31.0 → **7.0.0**（套件倉庫的 tag 就叫 `7.0.0`，2026-10-28；product 仍叫 `MapLibre`；二進位是 `ios-v7.0.0/MapLibre.dynamic.xcframework.zip`，sha256 `64f2472a…1734` 由套件清單核對）。
- `RailwayGame.xcodeproj` 用 XcodeGen 2.46.0（照 CLAUDE.md 從原始碼建，commit `8445e778`）重產，只多一行版本號變化。
- `project.xcworkspace/xcshareddata/swiftpm/Package.resolved`：CI 用 `-disableAutomaticPackageResolution`，不會自己解析（決策 97 第 1 點），所以手改成 7.0.0、revision `c2e6e6bd24efa037a8ab13463d8ad047b929eb9f`（tag `7.0.0` 剝開後的 commit，和 6.31.0 時記 `13e41ab3` 的方式相同，`git ls-remote` 核對）。XcodeGen 不產這個檔。
- 程式碼一行都不用改（下面「破壞性改動」）。`Resources/Licenses/MapLibre-iOS-LICENSE.md` 在 6.31.0 與 7.0.0 之間沒有變（`git diff ios-v6.31.0 ios-v7.0.0 -- platform/ios/LICENSE.md` 是空的），不用換；`tools/basemap/build_basemap.py` 照抄的 `allowsFixedWidthGlyphGeneration` 範圍表（`src/mbgl/util/i18n.cpp`）也沒變。

maplibre-native 的 ios-v6.31.0、7.0.0-pre0、7.0.0-pre1、7.0.0-pre-globe.0、7.0.0-pre2、2026.10.19-globe、7.0.0、2026.11.2-globe 的 GitHub 發佈說明，`platform/ios/CHANGELOG.md`（main 的 `## main`、`## 7.0.0`、`## 6.31.0`），#4753、#4718、#4817、#4533 四個 PR，套件倉庫的 tag 與 `Package.swift`；再用 `git diff ios-v6.31.0 ios-v7.0.0` 看公開標頭（`platform/ios/src/*.h`、`platform/darwin/src/*.h`）實際改了什麼。

### 安全修正

發佈說明裡沒有標成安全修正的項目（和 STALE_AUDIT 的結論相同）。

## globe 版為什麼先不換

- 2026.10.19-globe、2026.11.2-globe（與 7.0.0-pre-globe.0）是**另一條線**：從還沒合進 main 的 PR #4533 的分支建的，全是 pre-release；7.0.0 是 main 上的正式版。globe 版還帶著 main 上還沒發佈的東西（`MLNSource.isVolatile`、symbol guard 改成要設環境變數才開），說明裡也確認不了它有沒有 7.0.0 的全部修正。
- 這個遊戲的地圖只畫台灣與一個城市大小的範圍，相機完全跟著遊戲（`FollowingMapLibreView` 關掉了所有手勢，也不傾斜），看不到地球的弧度；globe 投影對玩家沒有可見的好處，卻要接受未合併分支的風險。
- 注意：套件倉庫的 `main` 分支的 `Package.swift` 現在指向 2026.11.2-globe 的二進位，所以一定要用 `exactVersion: 7.0.0` 釘 tag，不能改成跟 branch。
