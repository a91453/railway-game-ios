### 744. 設站時確認框讓開路線；施工卡不再重複金額，高度提示併進施工卡

2026-11-14，雲端 thread session（「讓車站設置時看得到路線」工作串），分支 `claude/project-thread-vvcnch`。作者 2026-11-14 自己玩回報：「我要改車站怎麼直接給我擋在路線上嗎，這樣我根本看不到要在哪裡設站」「鋪設介面好像還是太雜」（附兩張 iPhone 橫拿的截圖）。

不動 GameCore、存檔版本、golden。

## 1. 查到什麼

- 車站模式（決策 108）選了一個點，地圖上的確認框（決策 107 的 ✕ ✓ 小框，上面一行 800 公尺內居民與工作、一行坡度整平）先放在點的下方 18 點；手機橫拿時下方有底部按鈕列放不下，就翻到點的上方。框只躲開地圖四角的按鈕（決策 384、568），不管路線，所以路線往上斜的時候，框剛好壓在要設站的那段線上。
- 鋪軌時地圖上同時浮著：施工卡（長度、離地、金額，加一行「延續既有軌道」）、施工卡下面另一個膠囊的高度提示（`HeightSlideHint`）、✕ ✓ 框（金額又一次）、圖層的圖例。金額出現兩次。

## 2. 改了什麼

1. **確認框讓開設站點與附近的軌道**：車站模式時，`GameSession.trackLines(near:within:)` 找出點附近已鋪軌道的中心線，`BuildConfirmLayout.siteObstacles` 把設站點（24 點見方）和最近的 16 小段軌道（每段最多 48 點、左右各留 6 點）當成障礙，交給原本躲按鈕用的 `BuildConfirmLayout.keepingOff`。框先試原本的位置，蓋到就移到最近的不蓋任何東西的地方；真的沒有地方時，選蓋最少的。只在車站模式；鋪軌、買地塊等不變。
2. **施工卡不再寫金額**：✓ 上就有同一個金額，施工卡只留長度與離地。
3. **高度提示併進施工卡**：原本施工卡下面另一個膠囊，改成施工卡裡的一行（在「延續既有軌道」的位置；有提示時那行先不顯示，問題訊息照樣最優先）。字、✕、何時出現、何時不再出現都不變。

參考庫：`Ci/` 的施工卡（`.place-distance-hud`、`.metro-cost-preview-pill`）是這張卡原本移植的來源，沒有「框讓路線」的做法；OpenTTD 觸控建造只在拖完時問一次，也沒有。讓路的算法是本專案自己的，沿用決策 568 的 `keepingOff`。

## 3. 五個角度

| 角度 | 理由 | 分數（1–5） |
| --- | --- | ---: |
| 玩家 | 設站時看得到線和點；鋪軌時少一張浮卡、少一個重複的金額 | 5 |
| 鐵道迷 | 看得到站設在哪段線上（彎道、坡道）才設得對 | 3 |
| 開發 | 只動畫面層；躲避沿用已測過的 `keepingOff`，新增的部分有 Linux 測試 | 4 |
| 美術 | 地圖上同時浮的東西少一點 | 4 |
| 音樂 | 無 | 1 |

其他做法（沒採用）：把確認框固定貼在螢幕邊（手指要移很遠，決策 107 原本就是要框在手指旁）；框變半透明（字讀不清楚，也還是擋線）。

## 4. 沒在裝置上驗證

新位置是 Linux 測試算的；實機、模擬器上的樣子要看截圖。
