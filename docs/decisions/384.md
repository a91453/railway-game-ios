### 384. 開新路線時，比較兩站的抽屜不再蓋住地圖上的 ✓

2026-10-23，遊戲規劃 session_01H5RHAwnA69n8EfAUSUrH52 派工（最優先），session_013WiLkQHTAxZL85F5PYxJuL。只動 GamePresentation 與 App；GameCore、存檔版本、golden schema、SaveFixtures、ReplayFixtures 都不動。

**作者的回報**（TestFlight 85.1，iPhone 橫放，2D，挑了小港 → 順苓）：「會擋到字，沒辦法按打勾」，新路線開不起來。

**原因**：選了兩站以上，畫面下方中間出現比較兩站的抽屜（`StationPairDrawer`，決策 224 的 3B）。地圖上開線的 ✕／↶／✓ 膠囊（`MapBuildConfirm`，決策 100 之後、107）放在最後一站旁邊；截圖上抽屜上面露出的小膠囊「2 站 · 596 m · 約 1 分」就是這個膠囊的說明，✓ 在它下面，被抽屜蓋住。抽屜畫在地圖之上，膠囊在地圖裡，所以蓋住就按不到。另外抽屜只讓開「地圖旁邊的面板」，沒有讓開細節卡和右下角那一組（小地圖、哪裡人多、3D、縮放）；截圖右邊那張有向下箭頭、有鎖的小卡是小地圖（向下箭頭收起，鎖是還沒買的地），抽屜右端壓在它上面。

手機橫放（iPhone 17 Pro，安全區域內 750 × 381）量得：抽屜展開約 130 pt 高，底在離畫面底約 112 pt（出處條、站務員、兩個邊距）；它上面到圖層列下緣只剩約 55 pt，放不下約 76 pt 高的膠囊，兩旁也放不下（抽屜 460 寬，置中）。

**改了什麼**：
1. ✓ 膠囊避開抽屜：抽屜在畫面上的位置記在 `GameScreenState.stationPairFrame`，`MapView` 換成地圖的座標交給 `MapBuildConfirm` 的 `avoiding`。避開的規則（先往上，沒位置再往旁邊）原本是 `MapBuildConfirm` 的私有函式，搬到 GamePresentation 的 `BuildConfirmLayout.keepingOff`，行為不變，有 Linux 測試。
2. 抽屜讓開右下角那一組與細節卡：`StationPairDrawerLayout.trailingInset` 取面板、細節卡（在工具列旁時）、右下角那一組三者最寬的（站務員的泡泡本來就這樣讓）。
3. 手機橫放（高度 compact）時抽屜一開始收起，只留第一行（兩站名、距離、時間），按一下展開長條比較；每點一站就再收起，所以要按 ✓ 時它是收著的，膠囊上面有位置。iPad 與直放照舊展開。
4. 最寬 460 改讀 `StationPairDrawerLayout.maximumWidth`，值不變。

**還有的限制**：手機橫放時玩家自己把長條展開，抽屜又高回 130 pt，膠囊在抽屜上面放不下時還是會被蓋住；點下一站或收起就回來。要完全不蓋，得把長條比較移到別處（例如膠囊裡或細節卡），那是決策 224 3B 的版面改動，留給之後（`docs/HANDOFF.md` §7.1）。

**沒選的做法**：
- 手機上拿掉抽屜的長條比較：決策 224 3B 的功能在手機上就看不到了。
- 抽屜移到畫面上方：上方有狀態列、圖層列與橫幅，膠囊在站的下面時一樣會撞。
- 抽屜蓋住時自動收起、讓開時自動展開：收起後膠囊就有位置，又會展開，來回跳。

**五方**（權重照 NEXT_PRIORITIES §19）：
- 玩家：開新路線按得到 ✓；比較長條一按就展開。
- 鐵道迷：兩站的距離與時間在收起時也看得到。
- 開發：版面邏輯在 GamePresentation（`StationPairDrawerLayout`、`BuildConfirmLayout.keepingOff`），有 Linux 測試；`MapInteractionTests` 加開新路線按 ✓ 的 UI 測試（full lane）。
- 美術：無新素材；抽屜收起時畫面中間少一大塊。
- 音樂：無。

**參考**：作者參考庫沒有對應的抽屜與確認膠囊（兩者都是本專案的設計，決策 224、107）；外部專案沒有找，nothing usable。
