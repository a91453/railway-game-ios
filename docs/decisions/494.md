### 494. 防照搬的標記

2026-10-30，遊戲規劃第 32 任（session_01YGNNuon2Njt6B8dAanT7j5）派工（派工單 AT），實作 session_01YGNNun7qBjETMyX91yhN94（`claude/anti-copy-marks`）。GameCore、存檔版本、golden schema、replay、玩法與畫面都不動。

**為什麼**：作者發現有人把公開的 repo clone 去重新打包成 App（`docs/HANDOFF.md`「防搬」）。`docs/research/PRIVATE_ASSETS_SPLIT_2026-10-29.md` 的結論是先不把資料搬到私庫，改做兩件便宜的事：陷阱資料與非正式版標示。這一則是前者。

**做了什麼**：在 App 打包的資料裡加了防照搬的標記，細節在私庫。標記不改任何資料讀進遊戲後的值，玩家看不到，也不影響效能。被整包照搬時，可以從對方的 App 或 repo 驗出來；哪幾筆、怎麼驗、埋在哪個 commit，只寫在私庫，公開 repo 不寫。

**沒做的**：非正式版標示（自己編的 App 顯示「不是正式版本」）公測後、上 App Store 前再做：它要讀發版時注入的值，判斷錯了會擋到正當的測試者。

**限制**：標記擋的是整包照搬的人。公開 repo 的歷史看得到每個 commit 改了什麼，有心逐行比對的人找得到並拿掉；對那種人只有私庫（A 案）或改私人（C 案）有用，見上面那份研究。

**五方**：

- 玩家：看不到任何差別；資料讀進遊戲後和以前一模一樣。
- 鐵道迷：車站、路線、班表、運量的值都沒有變；標記不在任何會被當成鐵道資料讀的地方。
- 開發者：只動 App 打包的資料，不動程式；GameCore、存檔、golden、replay 不動；讀到這些資料的測試照常通過。之後重新產生或改寫資料時，照私庫的說明保留標記。
- 美術：無。
- 音樂：無。

**其他選項**：把標記放在程式碼裡（重新編譯時容易被改掉，也會被 diff 一眼看到）；放在圖片或音效的位元裡（要另外的工具讀，重新壓縮就沒了）；一個看得出是浮水印的欄位或檔案（一搜就刪）。都沒選。

**驗證**：Linux 本機 `swift build --build-tests -Xswiftc -warnings-as-errors` 與讀這些資料的測試類；App 的打包沒有在 Xcode 驗過（Xcode 照原樣複製這些資源）。
