### 336. 找不到的四個入口：收購真實支線、車站面板、貸款與票價、擴建地圖

2026-10-22。作者：「我找不到收購畫面」。遊戲規劃 session_014rYHMtmqA5bEMkBBuKu6PV 的可發現性稽核（`docs/research/NEXT_PRIORITIES_2026-10-12.md` §22.9，§22.2 第 2 名）派給實作 session_01MsTCquc1D1FqFiEdn6j3fz。號碼依 #231：決策 336；存檔版本、golden schema 不動；GameCore 不動。只改入口與文字，規則都沒變。

**規則**：

1. **收購真實支線**（決策 315）
   - 路線面板的「可收購的真實路線」不再收在「新路線…」裡：有線時排在「新路線…」那一列下面；一條線都沒有時（`listsLinesFirst` 為假的分支）排在新路線表單下面。
   - 沒有可買的線時，同一段只列一行說明為什麼（`GameSession.realLinesForSaleNote`），依序判斷：
     1. 不是實景地圖：真實支線只在實景地圖上可以收購。
     2. 實景地圖但真實鐵路還沒載入：還在載入。
     3. 有支線只有一部分車站在地圖框裡（`RealLineSale.partlyOnTheMap`）：說出線名，整條線的車站都在地圖上才可以收購。地圖框是開局時定的（`world.bounds`），擴建地圖買的是框裡的地塊，所以這一行不叫玩家去擴建。
     4. 框裡的支線都買了：都是你的了。
     5. 其他：這張地圖上沒有可以收購的真實支線。
   - 教學與課程（決策 266）裡不顯示這一段。
   - 算法和決策 328 的快取同一份：`buyableRealLinesMemo` 改存 `RealLineSale`（可買的、只框到一部分的、有沒有買過），同一個鍵。
   - 車站面板的收購鈕移到面板最前面，自成一段，字改成「收購平溪線…」（說出線名）；識別碼 `station.acquireLine` 不變。「真實車站」段只剩資料。
   - 說明頁加一條「怎麼收購真實支線？」（`buyRealLine`）。
2. **車站面板**：詳細卡的「客源」（Ridership）鈕改名「車站…」（Station…），VoiceOver 提示改成「打開車站面板：月台、商店、轉乘、客源、機廠等」；識別碼 `inspector.ridership` 與教學目標不變，教學那一步的標題跟著改成「點「車站…」看誰在搭車」。說明頁照實寫：點車站，再按詳細卡上的「車站…」，或長按車站；站牌上的鉛筆直接打開面板改名（點站牌本身只開詳細卡，`MapStationTagView`）。建材那一條的「再點它的標籤」也照實改。
3. **貸款與票價**
   - 資料面板的貸款、票價與一日券排在「今天」（與挑戰目標）下面，不管簡單或寫實規則都不收起。破產泡泡（`MapAlertBubbles` 的 `.insolvency`）打開資料面板時，借款鈕就在第一屏。
   - 收起的鈕從「顯示其他報表」改成「更多報表與設定」（收起：「收起其他報表與設定」）：裡面還有趨勢、餘額與模式（切換自由模式）、報表、資產負債表、年度與帳目。
   - 寫實規則本來就全部展開；現在貸款與票價也排在趨勢之前，兩種規則的順序一樣，展開時東西不會換位置。
   - 說明頁的「經濟明細」改成底部鈕的實際名稱「資料」（貸款、票價、為什麼虧錢、年報四條）。
4. **擴建地圖**（決策 160、167）
   - 地圖左下的圓鈕加字「擴建地圖」（Expand Map），膠囊形，和「正在擴建地圖 ✕ 結束」同一個位置；VoiceOver 標籤與識別碼 `map.expansion` 不變。
   - 建造時遇到「這塊地還不是你的」（`GameError.mapTileNotOwned`），在那句話旁邊給一顆「擴建地圖」：地圖上的 ✕／✓ 小卡（軌道與建物，`map.build.expandMap`）與狀態列的訊息（`banner.expandMap`，月台的 ✓ 按下後的拒絕走這裡）。按下去就是 `startChoosingMapTile()`：結束建造工具、進入選地塊，照舊暫停。條件在 `GameSession.offersMapExpansion(for:)`：分區購買的地圖、不在選地塊中、不在教學中、文字是那句拒絕。
   - 建造工具旁邊的那顆圓鈕**不加回來**（TestFlight 56.1 誤觸，`showsMapExpansionButton` 不變）：新的鈕只跟著那句拒絕出現。
   - 英文的拒絕從「Expand the Map」改成鈕上的「Expand Map」；中文不變。說明頁的「打開建設工具，選擴建地圖」改成實際的路。

**參考對照**：

| 參考 | 本專案 | 說明 |
| --- | --- | --- |
| 無 | `realLinesForSaleNote`、`offersMapExpansion(for:)`、各面板的入口 | 參考庫沒有收購支線（決策 315 的對照表），也沒有分區買地的入口設計；Ci 的建造 HUD（`MapConstructionHUD` 的來源）沒有「去別的工具」的鈕 |

外部專案：沒有找；這是本專案自己面板的排列與文字，沒有演算法要借。

**五方理由**：
- 玩家：作者自己找不到收購；新玩家破產時看不到借款、建造時被叫去用一顆看不到的鈕，會直接卡關。現在每個入口都在玩家正在看的地方，而且說得出它做什麼。
- 鐵道迷：收購臺鐵支線是給鐵道迷的功能，找不到就等於沒做；說明「地圖只框到平溪線的一部分」也讓人知道要怎麼開局才買得到。
- 開發：只動 App 與 GamePresentation，不動 GameCore、不升存檔、golden 與 replay 不動；說明的條件在 GamePresentation，Linux 測得到（`DiscoverableEntriesTests`）；既有的 UI 測試識別碼都沒改。
- 美術：不加新圖，只用既有的 SF Symbols（`signature`、`plus.square.dashed`）；字照 `docs/UI_THEME.md`，膠囊與狀態列的小鈕照既有樣式。動畫沒有新增（`MapBuildConfirm` 的 pop 照舊）。
- 音樂：無。

**沒選的**（§22.9）：(A) 只改說明頁：玩家不會先去讀說明。(B) 加一個「所有功能」總表頁：又多一層，入口還是藏著。(C) 收購另開底部第四顆鈕：底部三顆是固定版面，收購只在實景地圖有，常駐一顆對多數地圖是空的。(D) 擴建地圖的圓鈕在建造時也顯示：就是 TestFlight 56.1 誤觸的那顆。(E) 地圖只框到一部分時叫玩家去擴建：擴建買的是框裡的地，框不會變大，會把玩家帶錯路。

**驗證**：Linux 的 `swift build --build-tests -Xswiftc -warnings-as-errors` 與相關測試 VERIFIED；面板的排列、鈕的大小、手機橫放時左下那排會不會擠到別的鈕 UNVERIFIED，交給 `ios-build.yml` 與實機。

### 336（續）. 不明顯的四個入口：車隊總覽與時刻表、路線「進階」、景點鈕、長按軌道

2026-10-22，同一個 session，NEXT_PRIORITIES §22.2 第 26 名（§22.9 的「不明顯的四個」）。仍是決策 336，不另取號；存檔版本、golden、GameCore 不動。

**規則**：

1. **車隊總覽、時刻表、賣車**：本來只在「建設 → 列車 → 詳細卡」。
   - 地圖上點列車的詳細卡多兩顆小鈕：「時刻表」（選這列車、打開它的時刻表，`inspector.train.timetable`）與「車隊總覽」（`inspector.train.fleet`；賣車在車隊總覽裡）。只在選取工具下。
   - 資料面板在票價與一日券下面多一列「車隊總覽…」（`economy.fleet`），不收起。
2. **路線「進階」**：開關下面一直列一行它收著什麼（`AdvancedDetails.contentsText`：時段、停靠模式、各段股道、目標班距與行車控制），不只給 VoiceOver；收起時的摘要照舊在下面。VoiceOver 提示只留「收起時照常運作」。
3. **景點鈕**：有景點的遊戲（新遊戲預設就有，決策 174）在狀態列多一顆星（`hud.sights`），打開觀光景點；選單「更多」裡那一列照留。教學與課程裡沒有（`GameSession.showsSightsButton`）。狀態列本來就是 `ViewThatFits` 的四種排法，多一顆照樣往下一種退。
4. **長按軌道**：點到有路線經過的軌道時，詳細卡在路線鈕下面列一次「提示：長按路線的軌道，可以打開這條路線和它最熱門的旅程」（`TrackHoldHint`，`inspector.track.holdHint`）。卡片收起後就算看過（`@AppStorage` 的 `hints.holdTrack.seen`），真的長按過路線的軌道也算；教學裡不顯示。

**五方理由**：
- 玩家：經營的東西（時刻表、車隊、賣車）不該只藏在建設底下；景點一顆星就到；長按軌道只要知道一次。
- 鐵道迷：時刻表就是鐵道迷最常看的東西，從列車本身就打得開。
- 開發：只動 App 與 GamePresentation；條件與文字在 GamePresentation，Linux 測（`LessObviousEntriesTests`）；既有識別碼不改，只加新的。
- 美術：只用既有的 SF Symbols（`calendar.badge.clock`、`list.bullet.rectangle.portrait`、`star.fill`）與詳細卡的膠囊樣式；沒有新動畫。
- 音樂：無。

**沒選的**：(A) 選單「更多」的景點那列拿掉：既有的 UI 測試與玩家的習慣都在那裡，多一個入口不衝突。(B) 長按軌道的提示用狀態列訊息：會蓋住別的訊息，而且幾秒就消失；放在軌道卡上，看到的時候就是要用的時候。(C) 列車卡只放一顆「列車…」打開建設的列車工具：會切到建設、拿掉選取，玩家又要找路回來。

**沒查證**（§22.9）：選單第一層「明信片／成就」那排在手機上會不會只剩圖示，要在實機或模擬器看；寫在 `docs/HANDOFF.md` §7.5。
