### 464. 跑不到設定倍速時，持續跟不上就在倍速旁跳一次提示

2026-10-28，遊戲規劃 session_01YGNNuqBYkjv4r12NahDH4X 派工單 BV，實作 session_01YGNNumnQtaMdPM5echyBfu（`claude/speed-lag-hint`）。號碼依 #1041：決策 464；存檔版本、golden schema 不動。GameCore、存檔、GoldenScenarios、SaveFixtures、ReplayFixtures 都不動；只動 GamePresentation、HUD 一個 View 與測試。

**問題**：決策 226 的點（倍速旁，點了才看到「遊戲現在只跑得到 ×290」）是被動的，很多玩家不會去點；決策 460 讓大地圖上跟不上時遊戲迴圈刻意休息，點會更常出現。玩家一直回報「加速跑不到設定的倍數」（PLAYER_FEEDBACK 79.1 #2、#4，80.1–82.1 的 iPad (A16)）。

**做了什麼**（`Sources/GamePresentation/SpeedLagHint.swift`，測試 `SpeedLagHintTests`）：

1. `SpeedLagWatch`：實際速度低於設定的 70% 連續 20 秒（真實時間，暫停不算）就出一個 `SpeedLagHint`；回到 80% 以上（點消失的同一處）、換倍速、暫停就收掉。
2. 同一局同一個倍速只出一次；玩家按「知道了」（或點到外面）後這一局不再出。不存檔，不進 UserDefaults：新的一局就是新的 `GameSession`，提示自然重來。
3. 一般：「這張地圖在這台裝置上大約只跑得到 ×2000。」附「改成 ×1200」（比設定慢、且跑得到的最快一檔，`GameSpeed` 沒有 ×2000 這一檔）與「知道了」。比最慢一檔還慢時只有文字。
4. 發燙（`TickPace` 的 serious／critical，`GameSession.tickPace.heat`）：「裝置有點燙，遊戲先放慢。」只有「知道了」，不叫玩家改倍速。提示顯示中溫度變了，字跟著變。
5. 顯示：HUD 的點原本就有 popover；同一個 popover 在提示出現時自己打開，內容換成提示卡（`SpeedLagHintCard`）。系統 popover 的動態跟系統的「減少動態效果」，沒有新的動畫或 `MotionRule`。文字用 `DisplayLanguage.text`（和 `lagText` 一樣，是動態字串，不在 String Catalog）。
6. 不限制玩家選的倍速（決策 460）。

**數字**：70% 和 20 秒是依 `GameSpeedMeter` 的 3 秒窗與決策 460 的量測（大地圖 6000× 每個 tick 平均 0.24 秒、約四成速度；小地圖 600× 跟得上）定的：一天第一次乘客計畫那種單次拖慢不會連續 20 秒低於 70%。手機上實際多久跳一次沒量到（UNVERIFIED，見 HANDOFF）。

**五方**：玩家：知道為什麼慢，一鍵換到順的速度；鐵道迷：無（時刻與結果不變）；開發：規則在 GamePresentation 有測試，App 只顯示，不加設定；美術：用現有的點與 popover 樣式，不新增圖示；音樂：無。

**其他選項（沒採用）**：狀態列上多一條常駐提示（版面很擠，決策 226 才把兩行改成一個點）；限制可選倍速（決策 460 已判不限制）。
