### 450. 列車的車窗反光與不鏽鋼光澤

2026-10-27，遊戲規劃 session_01YGNNunBu1rxrPwN6bsA7g2 派工（派工單 AS，決策 439「下一步」第 3 項），實作 session_01YGNNupiBioisz2ArD4VFyW（`claude/train-material-as`）。號碼依 #1041：決策 450；存檔版本、golden schema 不動。GameCore、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/` 不動，只動 GamePresentation、著色器、App 的 uniform、測試、`tools/train-models/` 與文件。

**為什麼**：決策 439 給了列車遮蔽陰影。城市的玻璃與水面已經會反光（決策 356），列車還是全霧面：車窗和車身一樣不映天空，EMU500、EMU800、EMU900 這些不鏽鋼車和塗漆的車看不出差別。

**做了什麼**：

1. **做 pack 時標材質**：`Map3DTrainMaterial.marked`，在 `Map3DModelPack.init` 裡、決策 439 的烘焙之前，對每個列車模型跑一次。配方都不用改。
   - **玻璃**：三角形的顏色是配方玻璃色的某個深淺。玻璃色有三種：`Map3DPalette.glazing`、`Map3DTrainStyle.glass`（#26313D）、TEMU 的 #405560。深淺要在 0.35 倍以上、亮度至少 0.11，否則 R200 的深色百葉會被當成玻璃。面不能朝下（法線 z ≥ −0.3）。
     - 標成 `Map3DVertex.trainGlass`（−13）；本來就發光的窗標成 `trainGlassLit`（−15）。
     - `glows` 對 −2 和 −15 都是 true：夜裡照樣亮，決策 449（夜裡統一亮燈）的配方照舊用 `glowing`。
   - **不鏽鋼**：依車種判斷，不依顏色。`stainlessSets` 收 EMU500、EMU800、EMU900、C341（兩套）、C381、DR1000、DR3100。這些車淺色（亮度 ≥ 0.55）、中性（三色差 ≤ 16）、不朝下的面，標成 `trainSteel`（−14）。
     - 塗了漆的白車（EMU3000、普悠瑪、太魯閣）不算。
     - 塗裝帶（alpha < 1）、深色車底、彩色車頭都不標。
   - 各車被標到的比例（near 車頭，側面面積）：
     - 玻璃：2%（蒸汽機車）～17%（程式畫的 express 款）。
     - 不鏽鋼：57%（C341）～84%（DR3100）。其他車 0。
2. **遮蔽也存進 `u`**（決策 439 沒選的 (F) 只取一半）：烘焙時，把玻璃、不鏽鋼頂點的遮蔽值也寫進它的 `u`（列車本來不用 `u`）。
   - 著色器把反光乘上 1 − u，車間、窗框旁被遮住的面映得少，不會在暗處反而發亮。
   - 顏色照 439 烘焙，塗裝帶的那一份照樣不變暗。這部分沒改，原因見「沒選的」(F)。
3. **instanced 頂點著色器**（`map3dInstancedVertex`）：
   - 頂點格式不變（40 bytes），layer 本來就有。
   - 原本只把 −2 傳下去，現在 −13、−14、−15 也傳；這三種另把 `u` 放進 `surfaceAt.x`。
   - 街道設施、行人、汽車不受影響：它們沒有這些 layer。
4. **片段著色器**（`map3dShade`，和城市共用）：
   - **玻璃**：照決策 356 的車窗 Fresnel `0.1 + 0.9 (1 − c)⁴`，乘上 0.9（參考庫車庫模型的玻璃 metalness 0.26、roughness 0.19，近似鏡面；車窗有色，比辦公大樓玻璃少一點）。
     - 映出的天空用 `map3dSeen`（地平線＝霧色到天頂；朝下是變暗的街）。
     - 太陽亮點和城市玻璃一樣，是三層 glint，只在面朝太陽、太陽露出時出現。
     - 亮著的窗夜裡映得少：乘 1 − 0.85 × lights，亮的房間蓋過倒影，和城市的窗一樣。
   - **不鏽鋼**：參考庫車庫的 metal（metalness 0.64、roughness 0.38）。
     - 反光的份是 `0.22 + 0.4 (1 − c)⁵`，映出的天空乘上鋼板自己的顏色 × 1.2，所以是染色、模糊的金屬反射。
     - 太陽是寬的光澤，不是亮點：`pow(s, 40) × 0.25 + pow(s, 6) × 0.05`，乘鋼板的顏色。
   - 常數在 Swift（`Map3DReflection` 的 trains 一節）與 `.metal` 的 `trainMaterial`、`steelSheen`、`trainLitGlass`，測試檢查兩邊一樣。
5. **可以關**：`Map3DReflection.trainStrength` 照決策 357 太陽陰影的規則決定 0 或 1，0 時著色器整段跳過。
   - 省電畫質：關。
   - 自動畫質：低耗電模式、或手機熱到 `serious` 時關。
   - 高畫質：快要降頻（`critical`）時關。
   - 值放在 uniform `mirror.w`（決策 356 留空的那一格，uniform 不加大小），由 `Map3DMetalView.applyQuality` 每次換畫質、低耗電、發熱時更新。
6. **順手修的錯**：決策 439 的 `Map3DTrainOcclusion.isTrain` 只排除 `prop-`、`life-`，把決策 445 的行人號誌（`walk-*`，28 個模型）也當列車烘了遮蔽：9 個被變暗。現在排除 `walk-`，號誌回到配方的顏色。這個函式也決定哪些模型標材質。

**改了的雜湊**（`tools/train-models/hashes.lock.json`，405 個模型）：
- 346 個列車模型變了：layer 與 `u`，三角形數、位置、顏色都沒變。
- 31 個不變：街道設施、車輛、行人，以及沒有玻璃也沒有不鏽鋼的煤水車。
- 新增 28 行 `walk-*`：main 的鎖還沒有它們，這次一起鎖進去，鎖的是不烘焙的版本。
- Swift 測試：

  - 其他釘的值一個都沒改。
  - 配方的雜湊（各車測試釘的）不變，因為配方沒改。

**五方**：
- **玩家**：斜看列車時，車窗映出天空，迎著太陽會一閃；EMU800、EMU500、EMU900、捷運 C341／C381 的不鏽鋼車身帶一點冷色的金屬光，和白漆的自強號、普悠瑪分得出來。省電時自動關掉。
- **鐵道迷**：「白鐵仔」（不鏽鋼車）和塗漆車終於不一樣。哪些車是不鏽鋼，照實車：EMU500／800／900、北捷 C341／C381、DR1000、DR3100 是；EMU3000、TEMU1000／2000 是塗漆。材質參數取自參考庫車庫的 62 款精修模型（玻璃、金屬兩組）。
- **開發**：
  - 頂點格式、uniform 大小、draw call、pass 都不變。標材質在 Linux 上測得到，配方都不用改；新車照玻璃色畫窗就自動反光。
  - Metal 只能在 macOS CI 編譯：UNVERIFIED LOCALLY。
- **美術**：還是霧面平塗。
  - 正面看幾乎不變：玻璃 9%、鋼板 22%。斜看、從上往下看才看得出。
  - 顏色都從既有的天空、霧、陽光色來，不加新色。
  - 鋼板的光澤寬而淡，不起亮斑；玻璃的亮點和城市一樣，壓在決策 349 的肩部以下。
- **音樂**：無。

**沒選的**（預覽在 `docs/art/train-material-450/overview.png` 的第三欄）：
- (A) **較強**：鋼板 0.45 起、玻璃 `0.3 + 0.7 (1 − c)²`。不鏽鋼像打磨過的鏡面，從上往下看整台偏藍，車頂反得比車側還亮，和霧面畫風不合。
- (B) **每款車在配方裡自己標材質**（在 `Map3DTrainShell` 和各車檔案的玻璃、車身呼叫加 layer）：最準，但要改二十多個配方檔、動到每款車的配方雜湊。和決策 449 同時改同一批檔案也會衝突。改成做 pack 時依顏色與車種判斷。
- (C) **用顏色判斷不鏽鋼**（不看車種）：白漆的 EMU3000、普悠瑪、太魯閣也會變成金屬，不對。
- (D) **拉絲不鏽鋼的方向性光澤**（沿車長的 anisotropic）：要車的方向或切線，頂點格式要加欄位，每像素多算一次。先不做。
- (E) **夜裡映出城市的燈**（決策 356 的玻璃夜景）：要知道玻璃離地多高。列車在走，城市燈的格子會在車窗上掃過、閃爍。先不做。
- (F) **遮蔽完整放進 `u`、在著色器另外乘**（決策 439 沒選的那一項）：好處是塗裝帶也會跟著暗。壞處是要把 439 的烘焙從顏色裡拿出來，SceneKit 預覽與 `tools/train-models` 的 WebGL 也得各自補一個乘法，439 的測試要整組重寫。這次只取一半：遮蔽同時存進 `u`，只用來壓低反光，顏色仍照 439 烘焙。
