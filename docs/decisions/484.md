### 484. 營運的普悠瑪改用 TEMU2000 revision-2，舊模型刪掉

2026-10-29，遊戲規劃第 31 任（session_01YGNNukxseY7eMCvXhjtc4X）派工（派工單 PUY），實作 session_01YGNNuoy1fcM99AJFAieNat（`claude/puyuma-revision2-operation`）。只改 GamePresentation、它的測試與雜湊鎖；GameCore、存檔、golden、replay 都不動。

**為什麼**：作者說新的普悠瑪（#1456 的 TEMU2000 revision-2 studies，producer `2cb46a36`）比較好看，要接進遊戲；舊的不知道要拿來做什麼。規劃決定營運列車改用新模型、舊模型刪掉。

**做了什麼**：

1. `Map3DTEMU2000` 只剩一份配方，就是 revision-2：`model(_:far:)` 現在畫的是原本 `studyModel` 的東西。舊的營運配方（16 點斷面、青綠與藏青腰帶、舊燈座、舊屋頂罩）、`study` 旗標、`studyModel`、`studyFormation`、`teal`／`navy` 刪掉；顏色改名 `red`、`band`、`dark`。git 歷史留著（刪之前的 main 是 `197f642`），跟 #1234 刪 Classic 舊版同一個做法。
2. 營運 `puyuma`／`puyumaFar`（`Map3DTrainSet.temu2000(far:)`）的八輛照實車：TED、TEMA、TEP、TEMB、TEMB、TEP、TEMA、TED，第二個 TEP 轉 180°，近景 500 m 內、遠景 500–900 m，一節換一節（決策 426 的接法不變）。
3. 燈：舊版在車鼻前面另外加兩個發光小方塊（高 1.10 m）。新版不加東西，頭尾車用自己的燈鏡片（`model(_:far:lamps: true)`）：上燈與下燈座外側的大燈改成頭燈色並發光，下燈座內側的小紅燈改成尾燈色並發光，決策 449 的 `Map3DTrainLights` 從這些鏡片找頭燈與尾燈。studies 的單元不帶 `lamps`，雜湊不變。
4. studies（`Map3DModelPack.studies`）的 `temu2000-*` 十一項照舊註冊，只是改呼叫 `model`／`formation`；它們的雜湊與 #1456 一樣。

**數字**（Linux 量的）：

| | 舊 | 新 |
| --- | --: | --: |
| 近景一列（八輛） | 14,860 三角 | 25,040 三角 |
| 遠景一列 | 5,500 | 10,400 |
| 近景頭車／尾車 | 2,418／2,370 | 6,980／6,932 |
| 近景中間車 | 1,624–1,776 | 1,800–1,952 |
| 遠景頭車／尾車 | 962／1,010 | 2,812／2,860 |

- 預算（`tools/train-models/budgets.json`）：近景一節 ≤ 20,000、遠景一節少於近景一半、遠景一列 ≤ 120,000，都過（`check.mjs --new-set puyuma` ok）。比太魯閣（近景一列 14,184）多約八成，所以拿掉了決策 426「跟太魯閣差不多」那條測試，改成預算的測試。
- 模型包：模型數不變（593），頂點多 45,612（每份約 1.8 MB）；`testWhatTheMapKeepsInMemory` 量的模型從 135.0 MB 到 136.8 MB。
- 雜湊：`hashes.lock.json` 只改 24 項：`set-puyuma-{head,car,panto,centre,pantoBack,tail}`、`set-puyumaFar-` 同六項，以及它們的 `light-` 窗模型 12 項。前 12 項變是因為整台車換成 revision-2；窗模型變是因為 revision-2 的客室窗是分格的（三角形數約多一倍）。其他 685 項與 main 一樣。

**五方**：

- 玩家：只看到好看的那一台。
- 鐵道迷：新版的燈位（上燈、左右水平下燈座）和紅色雙帶比較貼近實車照片；尾燈用實車下燈座裡的紅燈。
- 開發：少一套要維護的配方和雜湊；燈從鏡片來，不再另外加方塊。
- 美術：兩版並存會讓畫風不一致；studies 與營運同一份配方。
- 音樂：無。

**為什麼不把舊版放進列車包**：照決策 338（續二），列車包賣的是外國車和另一套塗裝，不賣比較舊、比較醜的版本。

**另外考慮過的**：

- 舊版留著當列車包或展示：見上一段，不採用。
- 營運另外降面，回到太魯閣的量：預算還很寬，作者看的是外型；先不降，等 TestFlight 的幀數再說。
- 沿用舊的發光小方塊：位置在車鼻下緣前面，跟 revision-2 的燈座對不上，不採用。

**驗證**：Linux（Swift 6.4）`swift build --build-tests -Xswiftc -warnings-as-errors`、`Map3DTEMU2000Tests` 等相關測試類別 VERIFIED。iOS 上 Metal 的樣子、夜裡亮燈的位置、幀數 UNVERIFIED。截圖驗收照作者 2026-10-29 的指示延到下一次發版前（`docs/HANDOFF.md` §4.25）。

**下一步**：

- TestFlight 的幀數如果因為這台變差，再照決策 417 加中間版或降面。
- 外觀仍待改善的地方（車側大幅圖形、白頰曲率、屋頂設備）在 `docs/art/temu2000-2026-10-29/README.md`；改的是同一份配方，營運會一起變，雜湊鎖要一起更新。
