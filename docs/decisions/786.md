### 786. 香港市區綫列車（荃灣、觀塘、港島、將軍澳綫）

2026-11-15，雲端 thread session（「Build MTR urban line train model」工作串），分支 `claude/project-thread-wrzcrk`。優先清單 §29.9 MTR-1～5 的「城市綫那款」（3.35）。

不動 GameCore、存檔版本、golden、replay。

## 1. 做了什麼

1. **選哪一款**：四條綫 2026 年是新舊兩代車並行。做 2022 年起的新車：93 列訂單、2026 年中已 54 列載客（觀塘綫 2022、港島綫 2024、荃灣綫 2026-03-29），2027–28 年取代全部舊車（英文與中文 Wikipedia，2026-11-15 讀）。遊戲裡叫「香港市區綫列車」，不用車隊暱稱；不畫港鐵標誌、車號、目的地字幕。
2. **模型由本地工作室做**（`model-look` §1）：派工單（照片 8 張、尺寸、編組、色票材質名、機場快綫第一次被退回的五個毛病先寫明）在 `a91453/railway-assets-private` 的 `game-art-previews/docs/art/mtr-urban-line-2026-11/`。做的人自看三輪；審查第 1 次退回三點（車輪面朝內、遠景門板凸 6–7 cm、集電弓懸空）、第 2 次剩遠景集電弓支柱離車頂、第 3 次通過（revision-5，Khronos 驗證 6 檔 0 錯誤）。中途做的人換過一次（Antigravity 兩次被 Gemini 回 400，改由 Codex 接手）。這裡只留不含照片的總覽（`docs/art/mtr-urban-line-2026-11/`）。
3. **三種車、近景與遠景**：駕駛室車 24.6 m（近 5,915／遠 2,157 三角形）、中間車 22.55 m（4,418／1,578）、集電弓車 22.55 m（4,562／1,674）。`tools/train-models/glb_to_swift.py` 轉成 `Map3DMTRUrbanLineMesh.swift`。
4. **八節編組 A C B C B C B A**（`Map3DTrainSet.mtrUrbanLine`，`cycle: [.pantograph, .middle]`、`cycleFromFront`、`ownLengths`，遠景 set，解碼失敗退回通用捷運車）。集電弓在 C 車是推估：同系列前一代市區綫車的 C 車是集電弓車，照片看不清。
5. **照決策 782 註冊**：只新增自己的檔（`Map3DMTRUrbanLine.swift` 含色票、set、註冊；`Map3DTrainRegistryList.swift` 一行；`tools/train-models/locks/mtrUrbanLine.json`）。新色票 3 個：`mtrFrontSilver`（車頭外框）、`mtrRoofSilver`（淺色不鏽鋼車頂）、`mtrCharcoal`（門與窗區）；車身銀與紅線沿用決策 780 的 `mtrSilver`、`mtrRed`。
6. **香港地圖各綫**（決策 781 的表）：荃灣綫、港島綫、觀塘綫、將軍澳綫（含康城支綫）改畫這款，其他綫照舊借通用捷運車。將軍澳綫 2026 年底新車還沒上線，仍畫新車：舊車兩年內退役，一條綫一款車較單純。

## 2. 五個角度

| 角度 | 理由 | 分數（1–5） |
| --- | --- | ---: |
| 玩家 | 香港最常坐的四條市區綫有自己的車，不再是通用捷運車 | 4 |
| 鐵道迷 | 尺寸、門數、編組、黑車頭紅描邊照實車照片；選的是這幾年會留下來的新車 | 5 |
| 開發 | 照註冊表只加自己的檔，不和別款車衝突；模型包多 16 個模型 | 3 |
| 美術 | 色票平塗、門窗切面，和機場快綫同一做法；工作室照遊戲角度看過五輪 | 4 |
| 音樂 | 無 | 1 |

其他選項（沒選）：做舊車（1979 年起的英國製車，兩年內退役）；雲端 session 手寫 Swift 配方（作者說工作室成品較好、也省額度）。
