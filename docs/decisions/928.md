## 2. 規則

1. **位置照 OpenStreetMap**（2026-11-22 由 OSM API 讀各建物外框，取外框中心）：

2. **落地**：
   - 慈恩塔、歌劇院、路思義教堂、衛武營、赤崁樓：`sink` 0（取外框四角最低的地面，決策 927 的做法）。
   - 拉魯島：石岸做到水面下 0.5 m，`--raise 0.5` 加 `sink: 0.5`，島的 Z = 0 落在潭面（遊戲把潭畫在地面高度）。
   - 文武廟前後殿：石基做到地坪下 2 m（山坡上），`--raise 2` 加 `sink: 2`，殿的地坪落在殿中心的地面（決策 913 凌霄閣的做法）。中殿仍是舊的 `Map3DSunMoonLandmarks`（`wenwu-temple`）；它的註解改寫成前後殿已是登錄地標。登錄地標的模型蓋住的實測建物外框不再畫（`landmarkPlans`），所以前後殿原本的一般建物不會和模型疊在一起。
3. **顏色全是遊戲已有的顏色**，照各資料夾 README 的色票表：

4. **兩個顏色搬進色票**（決策 891：登錄地標的顏色要寫在 `Map3DPalette` 裡）。兩色遊戲本來就有，只是寫在各自的檔裡：
   - `Map3DPalette.shadedGlass` #26313D：陰影裡的深色玻璃（機廠 `Map3DDepotFacilities.glass`、街上的店 `Map3DStreetLife`、舊模型 `Map3DModels` 都自己寫了同一個值）。衛武營大屋頂底下的玻璃用它。
   - `Map3DPalette.bracketGreen` #1D4A44：N700S 的深綠（`Map3DN700SG.green`）。文武廟簷下的彩繪斗栱帶用它。
   - `tools/palette-guard/baseline.txt` 因此少四行（那三個檔的 #26313D、`Map3DN700SG.swift` 的 #1D4A44：現在是色票裡的顏色，不再算色票外）。畫出來的顏色沒有任何一處改變。
5. **資料來源**：八座都是工作室為遊戲手做的，照片（Wikimedia Commons，各自的授權記在工作室 `SOURCE.md`）只拿來比對與取色、不當貼圖，沒有 AI 生成的零件；資料來源頁不加項目。位置來自 OpenStreetMap（已列）。

## 3. 留下的

- **關渡大橋**（素材庫 #299）與**夜市三件**（素材庫 #275）不在這份決策的這一批裡：關渡大橋要先定橋面和遊戲公路橋的關係（決策 391／873：只跨河的橋目前貼在河面，模型的橋面在水面上 16 m），夜市三件是街景小物（`.m3dmodel`）不是登錄地標。接續寫在 `docs/handoff/MODELS-145-tw-landmarks.md`。
- 路思義教堂的入口朝東南（134°）是工作室的假設（OSM 只有長邊方向）；若實際在另一端，`--turn 180` 重轉並更新鎖檔。平面前後近乎對稱，遊戲大小差別很小。
- 文武廟後殿工作室沒有照片（形狀照前殿與 OSM 外框）；慈恩塔的門朝北、拉魯島浮草排的方向也沒有獨立驗過。
- 赤崁樓的轉角用海神廟的 9.3°（文昌閣的外框是 11.2°，兩樓連線在模型裡和 OSM 差 7°）：取了前面那棟的角度，兩樓各自偏離 OSM 中心約 1 m。

## 4. 五方

- 玩家：日月潭多了山上的慈恩塔、湖心的拉魯島與文武廟完整的三殿；臺中多了歌劇院與路思義教堂，高雄多了衛武營的大屋頂，臺南多了赤崁樓。
- 鐵道迷：衛武營就在高雄捷運橘線衛武營站旁，赤崁樓、歌劇院是從臺南站、臺中站出發的景點；位置與方向照 OSM 的建物外框。
- 開發：只加 GamePresentation 的檔與鎖檔，匯入工具、測試、舊地標的位置與雜湊都不變；兩個既有顏色搬進色票，色票外清單少四行；台灣地圖 44,216／60,000 個三角形。
- 美術：工作室對照片過審（model-look §1）的模型原樣接入，沒有新顏色。
- 音樂：無。
