## 3. 規則（`Sources/GameCore/Railway/FairSingleTrack.swift`）

`turnOwedFor(_:memo:)` 裡，比自己先等、進路對向重疊的那一班：

- 現在就能走 → 照舊讓它（決策 718）。
- 被擋，而且擋它的全是行進中的列車 → **只有在它的車門關好（`departureDue(of:)`）已經滿 `turnOwedToHeldAfter`（60 秒）時才讓**；不滿就照舊不讓、能走就走。
- 被站著的列車擋 → 照舊不讓。

60 秒是調度員看一次的間隔（決策 571 的「下一分鐘」）。不存任何東西（從車門關好的時刻與現在的時鐘推），所以沒有存檔版本；批次與逐步一樣（只讀那一刻的世界）。測試的參考模型（`Tests/GameCoreTests/ReferenceFairSingleTrack.swift`）照這段文字補同一個條件。
