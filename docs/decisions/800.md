### 800. 鋪軌被拒絕的原因放在 ✓ 旁邊；手機橫拿時卡片變矮、避開正在拉的那一段；0 元不寫價格

2026-11-16，派工單 BUILD-CARD-PHONE（session_01JMHz9YujMeYht6HenKN43i，`claude/build-card-phone`）。作者在 0.6.0 (134) iPhone 橫拿的截圖：拉了一段 130 公尺、地面的軌道，這段太陡不能鋪。上方那列「130 公尺｜地面」下面的警告，被地圖上那張有兩顆建議按鈕與 ✕ ✓ 的卡片整個蓋住，讀不到為什麼不能鋪；那張卡片也蓋住正在拉的那一段；兩顆建議都寫「NT$ 0」。

不動 GameCore、存檔版本、golden、fixtures。

## 1. 查到的原因

1. **蓋住警告**：卡片排在「上方那一欄」（狀態訊息、長度那一列與警告）下面到底部工具列上面之間。手機橫拿時這一段只有一百多點高，卡片（兩顆建議一列、✕ ✓ 一列）放不下，照決策 190 的退路往上疊到上方那一欄的下緣，正好是警告那一行。警告越長、上方那一欄越高，卡片的空間越少。
2. **蓋住軌道**：卡片本來排在終點下面；被底部工具列擋住時往上推，推到那一段軌道上。決策 744 只讓選月台位置時避開軌道，鋪軌時沒有。
3. **NT$ 0**：不是算錯。那一局開了「資金無限」（決策 200），GameCore 不收錢，報價（在世界的副本上真的蓋一次、看餘額少多少，決策 245）本來就是 0，按 ✓ 也真的是 0。`BuildConfirmLayoutTests.testAFreeFixWritesNoPrice` 記下這件事：資金無限時兩顆建議的價格是 0，一般的局大於 0。公車路線、道路、渡輪的卡片本來就不寫 0 元；鋪軌的建議與 ✓ 沒照做。

## 2. 改了什麼

1. **原因放在 ✓ 旁邊**：這一段不能鋪的原因（三角形圖示開頭那一行）改放進地圖上 ✕ ✓ 那張卡片，在建議按鈕上面；上方那一列只留長度與高度，不再重複。✓ 灰掉時，原因就在它旁邊。手指還在拖的時候卡片在手指下面，原因照舊在上方那一列；放開後才移到卡片。原因的字不設行數上限，最寬 340 點（`BuildConfirmLayout.wordsWidth`），放大字級時往下換行。
2. **手機橫拿時卡片變矮**（`BuildConfirmLayout.arrangement`）：畫面矮（`verticalSizeClass == .compact`）而且鋪軌的卡片有字要說時，字與建議在左、✕ ✓ 在右，高度約少一半；直拿、iPad、只有 ✕ ✓ 的卡片、其他建造照舊上下排。建議按鈕的寫法照舊由寬度決定（並排完整的字、並排短的字、上下排）。
3. **卡片避開正在拉的那一段**（`BuildConfirmLayout.stretchObstacles`）：終點、兩端的旗子、這一段靠近終點的部分都當成要避開的東西，用決策 744 同一個找位置的方法（`keepingOff`）；長的描線先抽成約 128 點再切。
4. **0 元不寫價格**（`BuildConfirmLayout.priceText`）：建議按鈕與 ✓ 上的價格是 0 時不寫（VoiceOver 的名字也不念）。價格仍然只來自 GameCore 的報價，畫面沒有另算。買地塊的 ✓ 同一條規則。

參考庫：作者 `Ci/` 的建造 HUD（`.place-distance-hud`、`.metro-cost-preview-pill`）只有長度與價格，被拒絕時沒有原因與建議的卡片；`Simulator/` 的版面規劃器有起終點高度，沒有手機橫拿的排法。沒有可搬的，排法是本專案自己的，沿用決策 107、384、744 的 `BuildConfirmLayout`。外部專案沒有找：這是本專案兩張卡片之間的排版。

其他做法（沒採用）：

- **上方那一列也搬進卡片，整個併成一張**：長度與高度要在還沒有卡片時（手指正在拖）就看得到，而且高度那一格是按住上下滑的控制（決策 646），跟著終點移動的卡片不適合放它。
- **只把卡片排到上方那一列旁邊**：警告長的時候上方那一列幾乎和地圖一樣寬，旁邊沒有位置。
- **0 元寫「免費」**：資金無限的局每個價格都是 0，寫了只是多一個字；照道路、公車已有的做法不寫。

## 4. 沒在裝置上驗證

- 卡片在手機橫拿、直拿、iPad 的樣子，放大字級時的換行，VoiceOver：Linux 看不到，交 CI 的 UI 測試與截圖（`WebsiteScreenshotTests.testTrackHeightFixes`，iPhone Pro 橫拿、深色），實機沒看。
- 輔助使用的最大字級加手機橫拿：卡片可能比上方那一列與底部工具列之間還高，這時仍會照決策 190 的退路往上疊。沒有截圖可看，列在 `docs/handoff/BUILD-CARD-PHONE.md`。
