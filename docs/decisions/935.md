## 2. 規則

1. **寫成 Swift 網格**（決策 918 的做法）：`tools/train-models/glb_to_swift.py` 轉成 `Map3DMeshyMarketTempleMesh.swift`，`Map3DMeshyMarketTemple` 解碼；石獅另一個 enum `Map3DTempleStoneLion`（`--materials stone,plinth,shade`），因為它的 `shade` 和天公爐的不同色。派工單 §9 寫的 `.m3dmodel`、`Map3DSceneryProp` 與 `tools/meshy/models.json` 不用：工作室的 GLB 已是遊戲色票的單色材質，`glb-to-m3dmodel` 的橋接也不收 AI 來源。遠景版這次不用（和攤子、香爐一樣只在近景畫）。
2. **不進模型包**：它們是夜市與廟的網格的一部分（和 kit 的攤子、香爐一樣用 `StationKitBuilder.add` 拼進去），不是一個個實例，所以模型包的數目與總雜湊不動，和 #2603 不在同一行衝突。
3. **夜市**（兩處都是 `Map3DCommercialKit.Example.nightMarketAlley` 的排法）：大車站前的商圈（決策 331，`commerceModels`）與玩家自己蓋的夜市第一款（決策 361，`placedKitLayouts[.nightMarket][0]`）。兩排攤子前各掛兩段燈泡串（共 4 段、48 顆燈泡，沿走道 −6 到 6 m），右排兩攤之間放一座帆布棚、棚下一台推車，正面都朝走道。玩家夜市的這幾件放在 `ground` 那一段，遠處不替它們畫方盒（一條 4 m 的燈泡串不是一棟房子）。第二款（civic kit 的市場棚）不動。
4. **燈泡晚上亮**：只有 `warm_lit`（= `Map3DPalette.tunnelLamp`）的頂點設 `Map3DVertex.glowing`，和冬季燈飾（決策 794）一樣由 shader 點亮、`Map3DGlow` 給光暈；其他材質不發光。
5. **天公爐**：一般廟（`.temple`，正殿前 2 m）與土地公廟（`.small`，偏殿前 4.5 m）的 kit 香爐換成天公爐，玩家蓋的廟也跟著換（`placedTempleModels`）。大廟（`.large`，kit 的 `templePlaza`）**不加**：加了會超過 5,000 面（4,808 + 510），一個 512 m 區塊（`templeChunkTriangles` 10,000）就只放得下一座大廟，台北這種大廟密的地方會少畫。
5a. **石獅**：同兩種廟，左雄右雌（廟往外看的左邊是踩球的雄獅；右邊先用鏡像，工作室已知缺點），面朝外。一般廟在廟門前（門的地坪 5–9 m，石獅在 9.9 m、相距 3.5 m）；土地公廟在偏殿與天公爐之間（2.6 m、相距 4.4 m）。每座廟多 1,200 面，一個場景 `templeTriangles`（60,000）內放得下的廟跟著少一些；大廟同樣不加。顏色照工作室的照片判定：`stone` = `Map3DPalette.portal` #8B9096、`plinth` = `Map3DPalette.cityRoofs[1]` #6C7279、`shade` = `Map3DPalette.dark` #2B2F36（派工單 §4 原寫 `concrete`、`arcade`，協調者照照片更正）。
6. **紅燈籠不接**（總表第 44 列「和燈籠串並排比，看不出差別就不接」）：遊戲鏡頭斜俯視時，0.6 m 的燈籠和既有 `lanternString` 的 0.46 m 紅圓柱燈籠都只有兩三個像素的紅點，白天分不出來；晚上的差別只在亮不亮，那由既有燈籠串的燈籠設 `glowing` 就做得到，不需要新模型。而且 kit 的一般廟與土地公廟本來沒有掛燈籠的簷下位置，要掛得先量 `templeHall` 的簷。`red-lantern` 與 `red-lantern-night` 留在素材庫。
7. 顏色全是既有格位（派工單 §5）：`pole` = `steel`、`foot` = `dark`、`warm_lit` = `tunnelLamp`、`stripeRed` = `lantern`、`stripeWhite` = `awningCream`、`steelTop` = `mtrSilver`、`glazing` = `glazing`、`cylinder` = `tankWhite`、`pedestal` = `templeWall`、`bronze` = `gold`、`shade` = `arcade`。
8. 三角形：站前商圈的夜市 1,790 → 4,554，四個商圈合計仍在 `commerceTriangles`（40,000）內（`Map3DStationCommerceTests` 釘住）；一般廟與土地公廟各換掉 kit 香爐的面、加 510 面。

## 3. 五方

- 玩家：夜市晚上有一串串亮點，一眼認得是夜市；廟前是紅台金爐的天公爐與一對石獅，不再是灰色鐵爐。
- 鐵道迷：大車站前的夜市與廟埕更像台灣的街景；無資料來源問題（Meshy 生成，資料來源頁已註明）。
- 開發：一個 enum、兩處擺放表各加一段；不進模型包、不動鎖檔、不加依賴與資源檔。
- 美術：工作室審過的模型，顏色全在色票；燈泡是夜市最好認的一樣，只有它發光。
- 音樂：無。
