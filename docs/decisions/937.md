### 937. 山佳、十分換成工作室照真實站房做的車站（tw-stations-shanjia-shifen）

2026-11-23，雲端工作串「山佳＋十分專屬站房收件與接回」（協調者派工，號碼照 #2118 的登記）。本機工作室第 2 輪過審（2026-11-21，codexb pass）的兩座站房接回遊戲：縱貫線北段的山佳、平溪線的十分。兩站原本和平溪、日南共用 `heritage` 配方（`StationKitBuilder.historic()` 的紅磚站房），決策 929 換掉平溪、日南後，這兩站是最後兩個；從此目錄裡的 `heritage` 站都畫工作室的模型。

存檔版本、golden schema、GameCore、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/` 都不動。只是畫法。

## 2. 規則

1. 目錄的山佳、十分畫自己的模型與自己的遠景版，做法和決策 929 一樣：`house()` 依目錄 id 改畫，月台淨空線（模型 Y +6）放在月台後 7 m，月台與月台雨棚照舊由遊戲畫。目錄的站型仍是 `.heritage`，`tools/station-kit/catalog.py` 與產生的目錄檔不動。
2. 山佳兩棟：貼月台線的是新站房的背牆（模型 X −19.5 到 −5.5），老站房在它前面 5.2 m；鐘塔到 18.5 m。外框不以原點為中心（X −20.70 到 +21.05），`addHouse` 照整體外廓置中，和平溪、菁桐一樣沒有另外處理。十分主體的牆板外皮在模型 Y +6.00，背面紅邊雨庇出到 +7.00（淨空線外只准雨庇，工作室量過）。
3. **顏色**：

   | 模型材質 | 遊戲的顏色 |
   |---|---|
   | 山佳 `stoneBase`、`wallDark`、`roofDark`、`trim`、`glassGreen`、`wallOchre`、`roofTile`、`porchRoof`、`wood` | `Map3DPalette.stone`、`cityRoofs[1]`、`dark`、`tileWhite`、`gymGreen`、`plaza`、`steel`、`arcade`、`counters[1]` |
   | 十分 `concrete`、`wallLight`、`wallDark`、`trim`、`roofDark`、`steel`、`brick` | `Map3DPalette.concrete`、`concreteWalls[2]`、`cityRoofs[1]`、`tileWhite`、`dark`、`steel`、`templeRidge` |
   | 十分 `canopyRed` | `Map3DScene.Builder.barrierRed` #D9473F |
   | 兩站 `glazing` | `Map3DDepotFacilities.glass` #26313D（和日南、菁桐同一個） |
   | 十分 `wallPink`（入口旁貼石材的矮房） | **`Map3DPalette.stonePink` #786565**（新） |

   `wallPink`：派工單給的是 `schoolWalls` #EFE5CF（奶黃），審查對照片退回（照片是灰粉紅的石材），協調者答「這一輪模型維持 #EFE5CF、做的人不自挑」，交件 README 新提格位 #786565（在照片受光較均勻的一塊量的中位數；照片在陰影裡，實物較亮）。模型的材質名不變，顏色由遊戲的 `meshPalette` 決定（`glb_to_swift.py`），所以這裡換色不用重做模型。色票先找最近的：ΔE 最小的是 `arcade` #6F6A64（6.9），但它是純灰、沒有粉色，十分的矮房就和門廊、灰瓦同色；其餘有紅色調的格位都是磚與紅漆（`brick`、`templeRidge`、`track`，ΔE > 20）。色票裡沒有灰粉紅，所以照決策 891 收進 `Map3DPalette` 一個有名字的格 `stonePink`（不寫進 `tools/palette-guard/baseline.txt`，那裡只能刪）。值照工作室量的 #786565，不自己調亮；作者看了 TestFlight 覺得太暗，只改這一格。
4. 兩站都沒有字：山佳鐘面沒有數字與指針，十分屋頂的白牌是色塊（派工單）。

## 3. 五方

- 玩家：山佳一眼看得到綠玻璃鐘塔和前面的老站房，十分是長長的灰白站房、紅磚門樓與紅邊雨庇，不再和平溪線其他站共用同一棟紅磚房；天燈節劇情的十分認得出來。
- 鐵道迷：照兩站真實站房的照片做（山佳 1931 年老站房與新站房並存、十分的門樓與月台側雨庇）；矮房的石材照照片改成灰粉紅，不是派工單的奶黃。
- 開發：沿用決策 929 的 `Map3DStudioStation`，多兩個 case、兩個網格檔、一個色票格；不加站型、不動 GameCore、不進 `Map3DModelPack` 與雜湊鎖檔。
- 美術：工作室對照片審過兩輪（做的人不審自己），不另截圖（model-look §1）；新色只有 `stonePink` 一格，用在十分一棟矮房。
- 音樂：無。

## 4. 沒做的

- 沒有在遊戲的 Metal 畫面看過（等 TestFlight）；`stonePink` 的亮度等作者看。
- 工作室列的已知缺點照收：山佳老站房的土黃牆在遊戲大小只是一條細帶、新站房四坡頂在 45° 俯視近黑；十分的雨庇柱站在窗洞裡（淨空線不准柱子站到月台上）、紅磚門樓和紅邊同一種紅、屋頂白牌原寸只是亮點。
