**做了什麼**：

1. **放置規則在 GamePresentation**（新的 `MapLabelPlacement`，Linux 測試 `MapLabelPlacementTests`）：每個標籤試幾個位置，取第一個不碰任何站名、別站的站點標記（含等待人數的小藥丸）與先放好的標籤的；都碰到就取蓋得最少的。字寬照中日韓字一個字號、其他 0.6 個字號估。
   - 警示泡泡（決策 109／210）：站上方 → 右上 → 左上 → 自己的藥丸上 → 自己名字下 → 再高一個泡泡。同站兩個泡泡上下多留 8 點，觸控區（44 點）不相碰（取代原本固定往上疊 46 點）。
   - 票價（決策 256）：站上 22 點（原位）→ 44 點 → 右 → 左 → 名字下。
2. **擴張地圖的價錢**（決策 160）：價錢放在「格子 ∩ 地圖沒被蓋住的部分」的中間；那部分不夠高、也不到價錢一半寬就不畫（格子還在、點了照樣能買）。沒傳可見範圍時（其他畫面）照舊畫在格子中間。
3. **景點標記讓價錢**：擴張地圖開著時，蓋到某格價錢的景點標記不畫。
4. **底圖地名**（決策 97）：實景地圖在頂列、側欄、底列各放一塊看不見的「空位」符號（不准別人重疊、自己允許重疊），MapLibre 的碰撞就把地名擠到看得到的地方。和車站名字讓底圖地名的作法（決策 97 的 room）同一招。
5. **「整個臺灣」放第一**：真實地圖選單把它移到所有地點之前（決策 88 的那一列，內容不變）。
6. **點「缺建材」泡泡直接看到建材**：以前點了打開車站面板的最上面，說缺什麼建材的那一列（`station.materials`）在最後一組「貨運與拆除」，要捲到底。現在泡泡打開面板就展開並捲到那一組（`StationPanelGroup.answering(_:)`，Linux 測試 `StationPanelFocusTests`；App 的 `GameScreenState.stationFocus`，和工具列「跳到…」選單同一個動作）。決策 472（CJ，#1467）合併後由規劃派給本 PR。其他泡泡照舊打開在最上面。
