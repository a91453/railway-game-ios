### 428. 舊存檔可以打開道路與公車

2026-10-27，遊戲規劃 session_01CWaJGHR4DnSwosLCzJ2Tts 派工（派工單 I），實作 session_01JMHz9ak2m1w5LYWDgoQWqS（`claude/new-session-8vlwcp`）。號碼依 #1041：決策 428；存檔版本（74）、golden schema 不動；`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/` 不動。

**為什麼**：90.1 的兩則回報（`docs/research/PLAYER_FEEDBACK.md`，`docs/research/NEXT_PRIORITIES_2026-10-12.md` §22.13）：

- 測試者：「舊存檔找不到公車功能，只有新檔能用」。
- 作者：「道路功能找不到」。

原因：公車要道路（決策 400），`GameWorld.roads` 只有新開的遊戲會打開，決策 400 寫明「舊的存檔不補開」。`GameSession.allowsBusTool` 是 `roads != nil && tutorial == nil && lesson == nil`，所以舊存檔的工具列直接沒有「公車」，也沒有任何說明；說明頁也沒提道路。

**做了什麼**：

1. **GameCore**：`GameWorld.turnOnRoads(towns:)`（`RoadGrid.swift`）＝`enableRoads(towns:)` 加 `seedBoughtTilesRoads()`；已經有道路就丟新的 `GameError.roadsEnabled`，世界不變。不收錢（新遊戲也不收）。一個新的錯誤名稱 `roadsEnabled` 加進 golden 的讀寫（`GoldenScenario.swift`），schema 不動，沒有 golden 用到它。
2. **玩家指令**：`PlayerCommand.Edit.turnOnRoads(towns: [PlanPoint])`，照 `.buildStationRoad` 的寫法經 `GameSession.apply(_:to:)` 執行、記進指令紀錄、讀得回、重播得到同樣的世界。城鎮位置是按下按鈕時算好、寫進指令的，所以之後改了推算的規則，舊紀錄照樣重播。
3. **GamePresentation**（`RoadsTurnOn.swift`）：
   - `GameSession.offersBusTool`：教學與課程以外都是 true。`allows(.bus)` 改看它，所以舊存檔的工具列也有「公車」。`allowsBusTool`（畫路線、車站面板的公車卡）照舊要有道路。
   - `GameSession.roadsOffer`：沒有道路、不在教學與課程時，`.available`（可以打開）或 `.unreadable`（這張地圖讀不到路）；其他時候 `nil`。
   - `GameSession.turnOnRoads()`：教學、課程中拒絕（訊息「教學與課程中不能打開道路。」，世界不變、不記指令）；`.unreadable` 拒絕；其他照指令執行。已經有道路時照樣送出指令，由 GameCore 拒絕並記成被拒絕的指令（「The session does not pre-check game rules」）。
4. **App**（`ControlPanel.swift`，沒有新檔）：沒有道路時，公車工具只顯示說明和一個按鈕「打開道路與公車」，按了先確認一次（「打開後不能關閉，路會每個月長一點。不用花錢。」）；動作鈕不出現。讀不到路的地圖只顯示一行原因，沒有按鈕。
5. **說明頁**：`HelpGuide` 的「城市」多一則「道路從哪裡來？怎麼開公車？」：路是城市自己長的（空白地圖從城鎮往車站長、實景地圖是真實街道）、車站還沒接上路時在車站面板鋪站前路、公車從車站沿路開、沒有道路的舊存檔在「公車」工具裡打開。公車工具第一行提示沒改：點到沒接上路的車站時，原本就會說「先在車站面板鋪站前路」。

不在讀檔時自動打開；不做玩家自己鋪路、不接車站的公車（NEXT_PRIORITIES §22.13，另外派）；公車路線的編輯、找路、票價、需求的算法沒動。

**空白地圖的舊存檔**（`geoAnchor == nil`）：

- 種子道路放在這個世界自己原本的城鎮（`GameWorld.startingTowns()`），不新抽亂數。
- 舊世界沒有直接記下城鎮的種子，但新遊戲的城鎮、需求事件、天氣與城市的請託都用同一個 `eventSeed`（`NewGame.swift`），買地圖的遊戲還記在 `MapExpansion.townSeed`。所以依序試 `mapExpansion.townSeed`、`demandEvents.seed`、`disruptions.seed`、`cityRequests.seed`：第一個「畫出來的第二、三個城鎮中心那格都有土地」的種子，就用 `Land.townCentres(seed:in:)` 的三個城鎮（和新遊戲完全一樣，有測試比對 `newGame(eventSeed: 42)` 的 `towns`）。
- 都不符合（存檔沒有這些種子，或土地不是那個種子畫的）：只用世界正中央。每張空白地圖的第一個城鎮都在正中央（`Land.sites`），路從那裡每個月長向車站；決策 400 的續篇讓每座車站都等得到路，所以只有一個起點也會長到所有車站，只是比較慢。
- 買過的地圖塊：照 `seedBoughtTilesRoads()`，每塊買過、還沒有城鎮道路的地塊，用 `MapExpansion.townSeed` 開它的城鎮道路，和買的時候道路已經開著一樣。

**實景地圖的舊存檔**（`geoAnchor != nil`）：

- 土地邊用邊讀的（`landBlocks` 不是 `nil`：全台灣、台灣的地點、挑戰、示範）：指令不帶城鎮；同一個編輯的 `performEdit` 讀土地之後，`readRoads` 就把讀過的每塊土地的底圖道路讀進來。量到的：全台灣的存檔在臺北車站蓋一座站，打開道路後 21 塊土地、4,374 格有路（和決策 400 續篇表上的 2 km 一樣），公車可以開。App 的底圖還沒讀完時，之後一讀到就補上（`readBlocks`）。
- **讀不到路的種類**：
  - 一開始就給全部土地、或完全沒有土地的實景地圖（`landBlocks == nil`）：台灣以外的城市、`SaveFixtures/v4-real-world-demo-90-minutes.json` 那種早期的實景示範。`readRoads` 要 `landBlocks`，底圖也只有台灣，打開了也長不出路。玩家看到：公車工具裡一行「這張地圖讀不到道路，不能開公車。」，沒有按鈕。這些地圖的新遊戲本來也沒有道路（決策 400 續篇第 4 點），沒有另做一套讀法。
- 存檔裡的實景地圖 fixture 只有 v4 一個（沒有 `landBlocks`），所以「讀得到」的那種用全台灣新遊戲存檔、拿掉 `roads` key 來代表 72 版以前的存檔。

**決定性**：城鎮由存檔裡的值算出、寫進指令；GameCore 的開路與每月成長沒有亂數；實景的路由底圖與讀過的土地塊決定，重播得到同樣的世界（有測試）。

**回歸測試**（Linux，`RoadsTurnOnTests`、`RoadGridTests.testAGameWithoutRoadsTurnsThemOnOnce`）：

- `v40-map-expansion`（空白、買過一塊地）、`v12-land-towns`（空白、沒有種子）：讀進來 → 打開 → 有道路、`allowsBusTool` 變 true、在城鎮道路上蓋一座站、開一條公車路線 → 存檔讀回一樣。
- 全台灣新遊戲拿掉 `roads`：打開後讀到臺北的路，指令紀錄重播得到同樣的世界。
- `v4-real-world-demo`：`.unreadable`，按了世界不變。
- `SaveFixtures` 裡每一個沒有道路的存檔：空白地圖都打開得了、城鎮照 `startingTowns()`；實景的說讀不到。
- 教學與第 3 課（拿掉 `roads`）：拒絕，世界不變。已經有道路：GameCore 丟 `roadsEnabled`，世界不變，紀錄是被拒絕的指令。
- 指令寫進讀回（也加進 `CommandEditTests` 的每種指令）。
- 在 main 上：新測試用到的 `turnOnRoads`、`roadsEnabled`、`roadsOffer` 不存在，編不過；`BusRouteEditorTests` 改成沒有道路時 `allows(.bus)` 是 true，main 上是 false。

**沒選的**：

- **讀檔自動打開**：玩家的舊檔會突然多出路與每月成長，城鎮道路一長，3D 的街景也跟著變；決策 400 當初不補開就是這個原因。派工單也寫明不做。
- **維持不補開、只加說明**：舊存檔的玩家永遠開不了公車，只能開新局；90.1 兩則回報都是「找不到」，說明只解決一半。
- **收費打開**：新遊戲的道路不收錢；收費會讓舊存檔比新局吃虧，價格也沒有依據（道路屬於城市，不是公司蓋的）。

**五方**：

- 玩家：舊存檔不用開新局就能玩公車；按鈕就在公車工具裡，按之前說清楚不能關、不花錢；不想要的玩家什麼都不會變。
- 鐵道迷：空白地圖的路從原本的城鎮長出來，和新局同一套規則；實景地圖讀的就是 OpenStreetMap 的真實道路。
- 開發：GameCore 只多一個指令和一個錯誤，不升存檔、golden 與 replay 的值不動；城鎮寫進指令，重播不受之後推算規則改變影響。
- 美術：none（只有一個說明列與按鈕，沿用公車工具的字級與 `road.lanes` 圖示；路與街照決策 400 畫）。
- 音樂：none。
