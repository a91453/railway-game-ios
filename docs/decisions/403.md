### 403. 3D 跟車的駕駛資訊：上方資訊列、車速卡、進站提示

2026-10-24，遊戲規劃 session_013dJ7tvDYJnhe7XjXCE5cNi 派工，實作 session_01XztRUELu6E7BzspLuGpk9w。號碼依 #1041：決策 403；存檔版本、golden schema 不動。GameCore 不動。接在決策 333（3D 跟車）、337（駕駛室）之後。

作者 2026-10-24 問「可以幫我看以下遊戲值得研究嗎」（韓國的高鐵駕駛遊戲《고속열차 기관사》），傳了錄影問「那這樣呢」，最後說「都可以五方評估決定」。錄影的畫面：最上面一條半透明卡（線名、「停車・首爾 → 大田」、大字的下一站、右邊「+8.5 秒」與「3.8 km」），左下一張車速卡（「304 km/h」、紅框圓牌「300」、黃框小圓牌「270」下面寫「1.5 km」），中間偶爾一行提示（「快到站了，請減速」）。規劃選了方案 E，分三個 PR，這是第 1 個。

**做了什麼**：3D 地圖跟著一列車時（後方、上後方、駕駛室三種視角都一樣），畫面多三樣東西：

| 東西 | 內容 | 沒有資料時 |
| --- | --- | --- |
| 上方資訊列 | 線的徽章與名稱（或服務名稱與起訖站「A → B」）；「下一站」或「停靠」加站名；右邊是誤點（「準點」「晚 8 秒」「晚 3 分」「早 12 秒」）與到下一站的距離（「3.8 km」「640 m」） | 停站時不寫距離；沒有時刻表的車不寫誤點 |
| 車速卡 | 現速（km/h）；紅框圓牌是現在的彎道限速；琥珀框小圓牌是前方 3 km 內下一個限速，下面寫多遠 | 不在彎道限速裡、前方沒有、或彎道限速關掉時，那一塊不畫，不編數字 |
| 進站提示 | 剩 1 km 內「下一站 B，剩 640 m」；停穩後 30 秒（遊戲時間）內「準點」或「晚 n 分」 | 從第一站出發時不顯示到站結果 |

| 項目 | 值 | 為什麼 |
| --- | --- | --- |
| 進站提示的距離 | 1 km | 派工單的例子；也是 130 km/h 自強號的煞車距離（`curveLimitLookahead`） |
| 前方限速看多遠 | 3 km | 錄影是 1.5 km 前就顯示；300 km/h 的高鐵煞到 0 約 3 km |
| 到站結果顯示多久 | 30 秒遊戲時間 | 3D 跟車最快 10×（決策 360），也就是至少 3 秒；1× 時 30 秒 |
| 到站結果的準點 | 早晚一分鐘內都說「準點」 | 和列車卡、`Punctuality` 一樣；上方資訊列照錄影寫到秒 |
| 前方限速 | 只算這一段運行（到下一站為止）裡、比列車最高速低的；和現在這段相連而且一樣的不算 | 一樣的限速接著出現不是「前方的新限速」 |

- **計算**：`Sources/GamePresentation/Map3DDriverHUD.swift` 的 `GameWorld.map3DDriverHUD(of:in:)`，每次畫都從世界讀，不存。距離是這段運行的長度減去已走的（`ServiceRun` 的 running curve），和列車卡算法一樣；誤點是 `lateness(of:)`；現在的限速是 `curveLimit(of:)`（決策 217）；到站結果用 `ServiceTimes.arrival` 對時刻表的到站時間。Linux 測試在 `Map3DDriverHUDTests`。
- **擺在哪**：直放時資訊列在上面按鈕的下一排，車速卡在跟車條的上面靠左；iPhone 橫拿（`verticalSizeClass == .compact`）時資訊列放進最上面那一排、在 2D 鈕和速度控制之間，畫面中間留給前方的路。卡都是半透明（`.regularMaterial`）、圓角 12，和跟車條一樣。
- **顏色**：限速牌的紅框是 `Theme.error`、前方的框是 `Theme.warning`（錄影是黃色，但 `Theme.accent` 的暖黃在白底上不到 3:1），牌子裡面是 `Theme.panel`，數字 `Theme.textPrimary`。誤點用 `Theme.warning`，準點與早到用 `Theme.success`；字本身也寫著，不只靠顏色。沒有新圖示、新色碼。
- **動態**：資訊列、提示從上面進來，車速卡從下面進來，都是 `.card(from:reduceMotion:)`（`cardIn`／`cardOut`）；版面讓位用 `MotionRule.change`。減少動態效果時不滑、只淡入淡出（motion skill 第 3 節）。
- **真實列車**（決策 304、339）：3D 的真實列車現在不能跟車（`Map3DRealTrains` 只畫，不給點、不給跟），所以這次沒有接；能跟之後再接（下一步）。沒有改 `Map3DRealTrains.swift`。
- **VoiceOver**：車速卡讀成一句「120 km/h，限速 75 km/h，1.5 km 後限 60 km/h」。

**沒選的做法**（文字預覽；App 畫面要 macOS 才拍得到）：
- **資訊列和車速卡合成一張大卡**（A、D 的儀表板樣子）：直放時會擋住前方一大片。
- **車速卡放在右下**：右下是跟車條的「取消跟隨」，手指常在那裡，會擋到。
- **到站結果照遊戲時間 10 秒**：10× 時只閃 1 秒，看不到。
- **沒有限速時顯示列車最高速當限速**：那不是軌道的限速，是編出來的數字（派工單：不要編數字）。
- **中間點提示**（「中間點，晚 7.7 秒」）：派工單說可以不做；誤點已經在資訊列一直看得到。

**驗證**：Linux 的 `swift build --build-tests -Xswiftc -warnings-as-errors`、`swift test --skip-build --filter Map3DDriverHUDTests` 都跑過（VERIFIED，Linux）；這個測試在 origin/main 上編不過（沒有 `Map3DDriverHUD`）。App 的部分（三張卡的版面、橫拿的位置、轉場）是 UNVERIFIED LOCALLY，要等 macOS CI 與實機。
