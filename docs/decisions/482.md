#### 續篇：列車用圖標還是車型（2026-10-29）

作者問「列車元素要不要改成圖標」，又說新的圖表「以前好像有列車元素」（規劃查過 #1443、#1467、#1471、#1472、#1470 的 diff，沒有刪掉列車圖形，是新圖表少了鐵道味）。規劃轉達後，`ui-review` 加第 10 節：

- 小、遠、多的地方（拉遠的地圖、清單列、泡泡、狀態列、通知、圖表標題與圖例）用圖標或簡化記號，車種用形狀分（高鐵箭頭，決策 168）。

- 以 2D 地圖的 `projection.detail == .full` 分級為範例。
- 圖表的資料照 dataviz 維持素的長條與線，鐵道感放在標題記號、圖例、空狀態與「最滿的一班」。
