6. 推算：決策 386 第 5 點的表，GHSL 比那段中位數高一層以上取 p75、低一層以上取 p25、其他取中位數；沒有 GHSL 值時用座標雜湊

國土測繪中心的三維建物還沒接（作者還在考慮）。格式留了位置：每棟記樓層來源（3 位元：推算、OSM 標記、市府建物圖、臺北建照、國土測繪中心），之後換來源或加來源只要改工具的順序、重跑 `storeys` 與 `build`，App 不用改。結果：有實際樓層的建物從 3.9% 升到 12.5%（市府建物圖 181,666 棟、OSM 59,167、臺北建照 4,866），其餘 1,719,246 棟推算。

**4. 3D 地圖怎麼放**（`Map3DFootprints.swift`）：

- 只在實景地圖：`RealWorldFrame` 有值、App 給了足跡檔。空白地圖與沒有檔時照舊。
- 讀 chunk 範圍碰到的 z16 格，Mercator 對錨點線性換算（同 `RealWorldFrame.worldPosition`）。
- 順序：決策 239 的城市圖塊、廟、站前商業、公園先放；接著足跡；最後 `addCity`。near 與 far 兩趟都放，兩趟用同一組「之前已占用」的格，結果一樣。
- 一棟的重心落在已占用的 64 m 格就不畫；外環任一點碰到車站的格也不畫。
- 畫了的足跡，它外框蓋到的 64 m 格都不再放程序房子（`addCity` 的 `takenBy`），決策 385 沿街的程序房子也一樣讓開。沒有足跡的格照舊程序生成，所以玩家的城市成長在空地上還看得到。
- 外觀用決策 239 的 `addRealBuilding`：高 = 樓層 × 3.2 m，樓層 0 當 2 層。用途對應：工業、農業、附屬建物 → 工業；公務、教育、醫療、軍事、服務 → 公共；商業、娛樂 → 5 層以下店屋，以上辦公；宗教 → 廟；交通 → 交通；住宅與不知道的 → 5 層以下新加的 `house`（透天：沒有一樓店面、住家陽台與窗），以上公寓。

**5. 和決策 385 一起定的**（session_01AgFLCW9xSb9fyLr8k57iZ1，PR #1127）：

- 不蓋區（機場、軍營、墓地、高爾夫、鐵路用地、港區）裡的 Overture 建物**照畫**：它們是真的，只有程序房子不該蓋在那裡。
- 決策 385 的 `addAirportBuildings` 畫機場內 OSM 的建物。有足跡時跳過它，因為 Overture 已經有 OSM 的航廈與機庫；它只留作沒有足跡時的退路。誰後合併誰加：`if footprints == nil` 才呼叫。用途對應同 385：航廈 `.transport`、機庫 `.industry`。

**6. 預算**（決策 238、267）：足跡在 near 與 far 取代程序房子，close 不加。板橋高鐵示範加底圖：near 三角形 2,995,987 → 2,059,377（−31%），far 3,253,932 → 1,844,340（−43%），網格 640 MB → 440 MB。量法：`MAP3D_FOOTPRINT_REPORT=1 swift test --filter Map3DSceneMemoryTests`（約 5 分鐘，所以 CI 不跑）。原本的 `Map3DSceneMemoryTests` 不讀底圖，不受影響。

**五個角度**

- 玩家：車站周圍是那裡真的房子的形狀、疏密與高低，認得出自己家附近；鄉鎮不再冒出假高樓。
- 鐵道迷：車窗外的街廓、工廠與大樓照實際的足跡，樓層多半有出處（臺中市府圖、OSM、臺北建照），出處寫在署名裡。
- 開發：一個 29.6 MB 的資源檔，沿用 `PMTilesArchive`，GameCore 不動。三角形與記憶體比程序房子少約三成。工具輸出是決定性的，換來源只要重跑。
- 美術：足跡房子只有牆、頂、立面貼圖，沒有程序房子的招牌（斗六車站一帶的招牌從 81 塊變 0 塊），街景比較素；用途與樓層決定外觀，天際線像台灣（鄉下低、市區高）。
- 音樂：無。

**沒有選的**

- Background Assets 每縣市一包：不加 App 大小，但要 extension、App Group、帳號步驟，`AssetPackManager` 要 iOS 26（App 最低 iOS 17）。留作退路。
- 一棟一棟讓開程序房子（只空出足跡本身，不空整格）：程序房子會擠在真房子的縫裡，和足跡重疊；而且決策 385 的沿街房子是以格為單位擋的。
- 足跡也放進 close（決策 267 的騎樓、遮雨棚）：先看 near／far 在實機的樣子再說。
- 給足跡房子加招牌：要知道一樓是不是店面，資料沒有；以後可以依用途（商業）與臨街加。
- 從 GitHub Actions 下載內政部 20 m DSM：要新加一個 workflow 檔，範圍外。
- 7z 用 py7zr（LGPL）、RAR 用 unrar（授權有限制）：遊戲規劃指定 bsdtar。
