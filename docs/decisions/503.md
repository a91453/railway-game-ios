### 503. The data sources screen does not lead to the game's GitHub project

Owner, 2026-10-30: the player must not be able to find the GitHub project from the game; the game's name and every other in-app text stay as they are.

**What changed.** `DataSourceCredits` no longer has `repositoryURL`, `baseMapToolURL`, or links into this repository (`notoSansLicenseURL`, `mapLibreLicenseURL` now point at the upstream licence pages: openfontlicense.org's OFL text and maplibre-native's `LICENSE.md`). The words "source repository" / 「原始碼儲存庫」 and "the game's public repository" are gone from both languages. Links to upstream projects (OSM, Overture, MapLibre's project page, earcut, puff, jeantimex/tokyo) stay: they are not ours.

**Why ODbL 1.0 §4.6 is still met.** §4.6 requires that the derived database (or its modifications, or the algorithm that produced it) be *provided* to anyone who receives it; the licence lets a licensee satisfy this with a written offer to supply it. The derived data files ship inside the app, and the notice now also says a machine-readable copy of the complete files, under the same licence, can be had by writing to hello@alongthelinegame.com (OpenStreetMap, Overture and base-map entries each carry the sentence, in both languages).
