### 679. CI 第七輪：鋪軌道不再每個點複製整個 Builder、兩個類別補權重、教學的膠囊沒按到就再按一次

2026-11-11，CIOPT-7（session_01YGNNuqLntc6Wem467zU1ac，`claude/ciopt-7`），遊戲規劃第 60 任派工。號碼依 #1579 登記；存檔版本、golden schema、`GoldenScenarios/`、`SaveFixtures/`、`ReplayFixtures/`、GameCore 都不動。數字在[量測](../research/CI_MEASURE_2026-11-11.md)。

## 為什麼

照 11-07 量測 §6 的四條門檻量最近 7 次完整 run 與 7 次完整 tier 的 PR run：

- **完整 tier 牆鐘超過 25 分**：PR run 25.0–27.4 分（7 次有 5 次超過）。Linux 排隊只有 2–4 s。時間是慢 runner 的 build 約 12 分，加慢 runner 上最慢的一片 rest-1 約 14 分。
- **一個類別超過 150 s**：`Map3DStationExteriorsTests` 172–289 s（rest-1）、`Map3DSceneMemoryTests` 202–257 s。
- 任何一片超過 15 分：沒過（rest-1 14.0 分）。GamePresentation PR tier 差一倍：在線上，是 runner 的快慢（三種，1.0／1.35–1.4／1.7–1.87 倍，11-07 到 11-11 比例沒變）。
- build 變長（7–9 分 → 11–12 分）不是程式：本機從頭建置 11-07 的 commit 392.8 s、現在 386.9 s。
- full lane 有一個測試七天內紅兩次、訊息相同、沒有程式原因：iPad 的 `TutorialUITests.testBuildingTrackEnablesNextAndSkipEnds`「The folded card did not open」。

## 決定

1. **`Map3DScene.Builder.addTrack` 問「這個點在不在區域裡」時只帶區域。** 原本對每條取樣線的每個點呼叫 Builder 的 `contains(x:y:)`；Linux 測試的 GamePresentation 沒開最佳化（決策 544），每問一次就複製並釋放整個 Builder（45 個取樣裡 7 個在這裡）。改成先取出 `region`，用同樣四個比較式的區域函式問。結果一樣；iOS 的建置開 -O（決策 624）本來就沒有這份複製，App 不變。`testClearOfTheTrackAndThePlatforms` 本機 210.5 → 167.4 s（−20%）。
2. **`RealLineRebuildTests` 106、`RealLineListingTests` 100 進 `CLASS_WEIGHTS`**（各輪裡最慢的秒數，決策 620、639 的取法）。它們是決策 639 之後新加的、每一輪 `time_warnings` 唯二點名「沒有權重」的類別；沒有權重時 `RealLineRebuildTests` 和 `Map3DStationExteriorsTests` 同在 rest-1。加了之後兩個都在 rest-2。`Map3DStationExteriorsTests` 的權重 231 不動（慢 runner 上改後估約 240 s）。
3. **`TutorialUITests.openCard`：按了膠囊 3 秒內卡片沒開、膠囊還在，就等它站穩再按一次。** 兩次紅的 App 記錄一樣：膠囊在 (726, 876) 站了 1 秒，XCTest 按它的中心 (870, 898)，手指落在地圖上（「touch began … view MapGestureView」，沒有「action tutorial.unfold」），之後膠囊在 (94, 104)。按在旁邊不是按了沒反應；真的按到卻沒開，後面的斷言照樣紅。做法同 #1951、#1966 對 ✓ 與「縮小」的再按一次。斷言與等待時間都沒放寬。
4. **沒有改的**：
   - `Map3DSceneMemoryTests`：時間平均散在 7 個測試（最大 69.6 s），這一輪沒有取樣；它自己一片（campaigns-1，7.3 分）不是最慢的。
   - build 的 12 分：是 runner。要動它只有快取（決策 545 已經用在 PR 與 push）或換 runner，都不是這張單的範圍。
   - PR 的 iOS gate：UI 步驟約 6 分，四個測試都只有模擬器能答，160 s 以外是開模擬器。
   - 沒有跳過、停用、隔離任何測試，沒有縮小 campaign，沒有加片（完整 tier 仍是 19 個 job），`Swift CI (gate)` 沒動。
5. **門檻改兩處**（量測 §7）：完整 tier 的牆鐘看 5 次的中位數；新增 build 的門檻（本機從頭建置超過 430 s，或 CI 快的一群超過 500 s）。

## 找過什麼

- 擁有者的參考庫：沒有 CI 分片或 XCTest 的東西可搬（它是網站與資料）。
- 外面的專案：沒有找。問題是這個專案自己的測試在自己的建置設定下多複製了一個結構、與自己的分片權重。
- 所以：nothing usable，程式是這個專案自己的。

## 五個角度

- 玩家：無（App 的建置本來就沒有那份複製；規則、畫面都沒變）。

- 美術：無。
- 音樂：無。
