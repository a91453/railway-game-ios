### 594. 台灣機場與飛機原生 3D studies

2026-11-05，依遊戲規劃第 48 任預留的機場素材工作製作。編號 593 已由主線客運塗裝 draft PR 使用；本次使用者文字指定 593 與主線登記衝突，採用現有機場預留 594。只是 studies，還沒接營運：GameCore、存檔版本、golden、SaveFixtures、ReplayFixtures 均不動，也沒有把模型註冊到地圖。

四型飛機、城市航廈、離島單層航廈、十種可組合零件與兩個組景各有近遠景。公尺制 M3DM、GLB、日夜七方向透明 PNG、可離線 viewer 放在私庫 `game-art-previews/docs/art/airport-aircraft-2026-11/`，每款近遠景各一資料夾，只保留最新一輪；規格、比例估計、授權與來源見私庫 SOURCE.md。公開庫只放配方、producer、測試及一張總覽。近景最高三角數與驗證紀錄見[總覽](../art/airport-aircraft-2026-11/README.md)。依現有原生車輛的分段封閉曲面與色彩節奏、車站套件的窗帶和斜屋頂方法修訂第一輪外觀；色帶、尾翼色塊只用通用配色，無業者名稱、標誌或註冊號。

外部 x 前、y 左、z 上，地面 0。停機位的機鼻停止點、方向與最大翼展，跑道兩端的頭端、方向及零件長度，滑行道連接點，空橋伸縮與機上關節寫入 metadata。跑道段、停機坪格距只作組裝，不能宣稱真實機場工程尺度。這些資訊不構成自動航班權威狀態；未來若做機場樞紐與自動航班，仍需另設營運規則及測試。實景地圖保留 OSM 航廈與機棚、不蓋住宅，遵守決策 385，這批示意航廈不覆蓋真實圖資。

五方理由：
- 玩家：先辨得出短場、國內線與兩級噴射機，以及城市和離島登機方式。
- 鐵道／交通迷：尺度對照製造商公開規格，並把未量測的艙門、翼根和機位格距標為估計。
- 開發：獨立按需配方和 native 契約，未增加存檔、常駐地圖或權威航班狀態。
- 美術：近遠景同時保留高單翼與尾翼輪廓；作者看外觀後再修訂比例和細節。
- 音樂：沒有音效或音樂交付，不使用缺授權文字的參考音樂。
