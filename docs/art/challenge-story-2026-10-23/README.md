# 挑戰劇情的角色頭像（決策 387）

`portraits.png`：站長（決策 122，不變）和平溪線劇情的三個新角色：阿松伯（`StoryAhSong`）、小葳（`StoryXiaoWei`）、Mia（`StoryMia`）。art-style skill 的預覽：120／64／44／28 點，面板與地圖的淺色、深色底，最後兩格是模糊與灰階。

SVG 在 `RailwayGameApp/Resources/Assets.xcassets/Story*.imageset/`，用 scratchpad 的 Python 腳本產生（不放進 repo），只用 `svg`、`path`、`circle`、`ellipse`、`rect`。顏色見 `docs/UI_THEME.md`「挑戰劇情的角色」。

改了兩輪：
- 第一版：小葳的天燈在圓的邊上被切掉，往裡移；Mia 的背包肩帶原本是綠松色，和小葳的圍裙像，改成藍灰。
- 第二版（遊戲規劃看過後）：三人原本只有頭髮不同、臉一樣，改成阿松伯臉略方、粗眉、眼角紋與法令紋；小葳齊瀏海、笑瞇的弧形眼；Mia 上揚的細眉、雀斑、張口大笑。小葳的天燈改到圍裙胸前、放大，整盞在圓裡；Mia 的背包從兩肩後面露出，肩帶加黃色扣環。28 點的灰階也分得出三個人。
- 第三版（遊戲規劃放大看過後）：阿松伯原本看起來兇，改成親切的樣子：眉毛改成細短的藍灰弧線，露出和其他人一樣的圓點眼；八字鬍縮小、兩端上翹，下面露出上揚的笑嘴；臉頰兩側的灰色三角拿掉，改成帽緣下貼著耳朵的一小撮灰髮；眼角紋每邊一條，法令紋拿掉。小葳胸前的天燈原本像黃色口袋，改成上寬下窄的天燈形，三條直骨，底部一點橘色暖光。Mia 和站長不動，沒有新顏色。

## 劉銘傳鐵路與集集線（第二批，給遊戲規劃與作者看）

`liu-jiji-portraits.png`：六個新角色的第三版（遊戲規劃看過前兩版後的修改見下），同一套畫法（扁平、藏青外框、圓點眼帶白色反光、淺綠松底），沒有新顏色。記取平溪線三輪的教訓：每個人的臉與輪廓各不相同（28 點的灰階也分得出），年紀大的人看起來親切（弧形眉、笑嘴、上翹的鬍子），道具整個在圓裡。
- 阿水（劉銘傳，清代鐵路的築路工頭）：寬斗笠（暖黃、橘色編紋），短藏青眉、咧嘴笑，藏青短衫配白立領，一條辮子從右肩前面垂下（藏青、藍灰編紋、黃色繩結，在藏青短衫上加一圈淺色邊才看得見）；28 點靠斗笠的三角輪廓認得出。
- 華師傅（劉銘傳，騰雲號的英國司機）：藍灰司機帽配黃色帽徽、藏青連鬢鬍與上翹的八字鬍，鬍子下面露出笑嘴，黃色領巾，藍灰外套。
- 葉掌櫃（劉銘傳，大稻埕茶行掌櫃）：藏青瓜皮帽、頂上黃色帽結，一條辮子從右肩前面垂下，圓眼鏡，細的上翹八字鬍和一小撮山羊鬍，綠松色大襟長袍、黃色布扣。
- 林師傅（集集，車埕木業工廠退休的老師傅）：禿頭、兩側灰髮、灰色濃眉往上彎，笑瞇的弧形眼帶眼角紋，張口笑，右耳後夾一支琥珀黃的鉛筆（斜向後上方穿過耳朵上緣，削過的筆頭與藏青筆尖朝前下露在臉旁，尾端藏在一撮灰髮下），白襯衫配藏青背心。
- 秀蘭（集集，站前小店的老闆娘）：藏青捲髮（燙髮），黃色小耳環，溫和的笑，黃色上衣配白色圓領。
- 阿坤的家書（集集）：阿坤不出場，頭像是一封直式的中式信封（橘色的地址框、直寫的字、黃色郵票），後面露出一張信紙。

第一版之後的修改（遊戲規劃，2026-10-23）：
- 阿水選 A（斗笠），B（白頭巾）刪掉。理由：斗笠是臺灣做工的人真的戴的東西，這是臺灣人做的臺灣遊戲，不算刻板印象；B 的白頭巾會被看成日本的鉢卷，放在清代反而錯。
- 清代的男人留辮子：阿水和葉掌櫃各加一條，從肩膀前面垂下，正面看得到。華師傅是英國人，不加。
- 林師傅的鉛筆原本是黃色、貼著灰髮，看起來像亂翹的頭髮：改成琥珀黃筆身、深色筆尖，移到灰髮上方留出空隙。
- 華師傅、秀蘭、阿坤的信封不動；只有華師傅的鼻子原本用了色票外的深膚色 `#E9B994`，改成一條藏青短弧。沒有新顏色。

第二版之後的修改（遊戲規劃，2026-10-23）：
- 林師傅的鉛筆在第二版浮在灰髮右上方，像插在頭頂：改成夾在右耳後，筆身穿過耳朵上緣斜向後上方，筆尖朝前下露在臉旁，尾端蓋在一撮灰髮下，長度約耳朵高度的 1.5 倍。
- 華師傅臉兩側的橘色連鬢鬍在 120 點像橘色頭髮或耳罩：改成和其他人頭髮一樣的藏青；上翹的八字鬍也一起改藏青，不然鬍子和連鬢鬍顏色不同。
