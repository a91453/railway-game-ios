# 決策 481：路線面板拆兩層的三個做法

`overview.png`：左 A（採用）、中 B、右 C，由同一資料夾的 `mock.html` 用 Chromium 拍成（`node` + Playwright，寬 1500 點）。是示意圖，不是 App 的截圖：顏色照 `Theme` 的藏青、白、淺灰底與圖表藍，字是系統字。

- **A 清單 → 推進一條線的詳細頁**：採用。左是清單頁（搜尋、篩選、排序固定在上面；整個路網、進階、新路線、可收購路線四個入口；每條線兩行），右是點一條線後推進去的詳細頁。
- **B iPad 左右兩欄**：沒採用。地圖旁的面板只有 min(420, 半個畫面)（決策 106）。
- **C 同一張表，每列可展開**：沒採用。展開一條線後，下面的線又被推遠。

理由見 [決策 481](../../decisions/481.md)。
