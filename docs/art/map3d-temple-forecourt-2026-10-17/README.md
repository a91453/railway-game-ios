- `temple.jpg`：廟，90 m。
  - 上半就是沒有選的「照舊朝南、沒有廟埕」：台基站在地塊中間，前面是一片空地。
  - 下半：廟朝向旁邊的主要道路，台基後退，前面是石鋪的廟埕，人行道邊立牌樓，兩角各一棵榕樹，簷下 4 盞紅燈籠。
- `temple-close.jpg`：同一座廟，45 m。燈籠在前面的牆上，夜裡會發光（預覽是下午，看不到）。
- `back-yards.jpg`：透天厝街區，170 m。兩排背對背的透天厝之間的後院，七成鋪了草地、種了 1–3 棵樹；從這個角度只看得到沒被房子擋住的幾塊。
