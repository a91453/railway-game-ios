## 推薦與理由

- **地圖圖示 A（1、2、3 個購物袋）＋位置 M2（站名牌左邊的暖黃方章）**：照 art-style §2「等級用同一種形狀的數量」；不碰站徽、高鐵的第二圈與選取圈。
- **插圖 I（月台上的店）**：便利商店、車站雨棚下的商店街、拱頂商場，和既有的建造卡同一種畫法，三級一眼分得出來。

## 沒選的

- 圖示 B（店面長大）：小店和城市的「商店」圖示太像，三個圖要各自學。
- 圖示 C（雨棚層數）：1 級幾乎就是城市的「商店」；3 級在 16 點糊成條紋。
- 位置 M1（右上角圓章）：蓋到站徽裡的列車與高鐵第二圈；M3（上方的弧）：和高鐵、選取的「圈」混在一起。
- 插圖 II（站徽）：和地圖同一套、好認，但三張只差袋子數，看不出商店街與商場的差別。

## 顏色與 SVG

只用 `docs/UI_THEME.md` 已有的顏色：藏青 `#262C57`、白 `#FFFFFF`、`#ECEEF6`、暖黃 `#FFC86B`、綠松 `#12A08F`，建造卡底 `#BDEFE7`；地圖的方章是 `Palette.playerBuilding`（暖黃）配 `Palette.ink` 外框，圖形是 `Palette.buildingGlyph`（藏青）。商業是玩家的東西，一律暖黃（作者 2026-10-13）。SVG 只用 `path`、`rect`、`circle`，屬性與指令在 art-style §3 允許的範圍內。

參考庫：`Ci/reference_snapshot/station-icon-shopping…png` 是「購物站」的車站種類圖示，只取用途；購物袋與店面全部重畫（art-style §7），沒有一張和參考庫的檔案相同。
