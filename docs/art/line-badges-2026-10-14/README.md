# 線號徽章與色盲色票的預覽（決策 216）

2026-10-14 給作者看的兩張預覽。作者請 session 從玩家、開發、美術三方考慮自己定案：**徽章 B、色票甲（加淺灰 `#BBBBBB`）**。規則與數字在 `docs/UI_THEME.md`「線號徽章與色盲配色」。

- `badges.png`：徽章 A 色塊方牌（北捷式）、B 白底色條牌、C 色環圓牌（東京地鐵式），在淺色、深色地圖與面板上，各三欄：一般、灰階、綠色盲（deutan）模擬。示意的紅 R 與粉紅 PK 共線、藍 BL 分岔。
- `palettes.png`：現在的 20 色與三組候選（甲 Okabe–Ito 7 色、乙 Paul Tol muted 9 色、丙 從現有色票挑 6 色），各五欄：一般、紅色盲、綠色盲、藍黃色盲、灰階，上半淺色地面、下半深色地面。

色盲模擬用 Machado 等（2009）嚴重度 1.0 的矩陣，在線性 RGB 套用（SVG `feColorMatrix`）；產生預覽的腳本在 scratchpad，不進 repo（art-style §3）。
