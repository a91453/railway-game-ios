# C371／C381 原生靜態車型研究（2026-10-27）

本批由兩份獨立配方和共用基本幾何原語製成。C371 與 C381 都是六輛標準高運量編組；C371 另有三輛支線版，本批**只**製作六輛一般版本。沒有車號、商標或廣告。模型屬霧面玩具風格，不是工程數位孿生。

## 建模特徵與資料界線

| 項目 | C371 | C381 |
|---|---|---|
| 正面、俯視 | 近直立的平前面、雙駕駛窗、無中央玻璃；單條較寬藍腰帶 | 長一些的分站曲面、圓黑罩、中央逃生窗；雙細藍線及下緣分色、前裙 |
| 側面 | 四組雙開客門；駕駛側窄門與分離客窗；高位單藍帶 | 四組雙開客門；相近側殼，但駕駛端 0.21m 長度差，低位兩條細藍帶 |
| 下部與車頂 | 四軸／每車兩台車，第三軌下接觸集電；T 與動力車底部箱件數區分。空調單元、車底具體站位為比例推估 | 同規格系統；前裙不同。空調與未見側設備仍為比例推估 |
| 排列 | DM1–T–M2＋M2–T–DM1；端車朝外；六車中心距 23.5m；殼間示意間隙 0.36m | 同排列；中心依 23.710m DM 和 23.5m 中間車計；端車朝外；殼間示意間隙 0.36m |

原廠尺寸採「連結面間」，不當作最外鼻端長。台車中心距、軸距及輪徑由原廠規格直接取。窗尺寸、門站位、車頭截面、燈與屋頂設備的局部尺寸是照片與插畫比例推估。左右對稱、隱藏側設備也是補全假設；本批未證實受電靴確切站位。照片不能區分所有 C321／C341 相似角度，本批只引用明確標識目標車型的照片。

## 遊戲接點

`Map3DModels` 只註冊獨立單元。`metroC381` 仍是共用營運接點：`Map3DTrainSets` 用於多個路線字母，`PerformanceText` 明列 C371／C381，且既有 C341 依車號分派。沒有足以確定 C371 與 C381 專用編組的分派，因此本批**不改營運映射**。兩個 PR 合併並重建 App 後，資產可被查到，但**不會自動出現在營運列車**。Simulator、真機、Metal、效能及動畫皆未驗證。

## 重建與版本

從公開庫相同 producer 提交，以 Swift 6.4：

```sh
PATH=/workspace/scratch/swift/usr/bin:$PATH tools/c371-c381/export.sh OUT
node tools/c371-c381/render.mjs OUT
node tools/c371-c381/clay.mjs OUT
node tools/c371-c381/standalone.mjs OUT
```

輸出目錄的 manifest 記錄每件三角與 bounds；私包保存原生、GLB、七向 PNG、viewer、SHA 及 ZIP。原生座標 +X 前、+Y 左、+Z 上，軌面 Z=0；GLB 只做規定的軸轉換。兩款完整編組若超過 M3DM 15,000 三角上限，工具支援合法 M3DAssembly；本批實際兩組均低於上限，故輸出單件 M3DM。合併前需以 PR 最新 head 的 CI 為準，Linux 建置不能代表 iOS 真機。

| C381 正面 | 幾乎與 C371 同輪廓 | 包覆式圓黑罩、中央玻璃、藍色 V 下緣、獨立燈座與下裙 | 主要可辨差異成立；弧鼻截面與燈腔仍比實車平 |
| 左右側／屋頂 | C381 側藍帶過薄、屋頂兩片平板 | C381 主藍帶及下細線、車頂肋條與空調格柵 | 節奏改善；不表示已查明設備精確站位 |
