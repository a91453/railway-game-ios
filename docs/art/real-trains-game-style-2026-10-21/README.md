## 三、設計風格與組合性規範

1. **等角微縮透視（Isometric 3D Diorama）**：全系列採用統一的 3/4 等角透視角度，方便在遊戲地圖視角（Map3D）與城市檢視（CityView）中作為視覺資產與參考。
2. **純色塊與玩具模型質感**：嚴格落實 `art-style` §7，移除 AI 照片噪點髒貼圖，轉為高飽和度、乾淨的頂點色塊與平滑環境光遮蔽（AO）。
3. **模組化拼裝可行性**：軌道規格、月台高度、接觸網立柱均按一致比例設計，車站、月台與不同系統列車可無縫組合為生動的台灣鐵道小鎮與都會路網場景。
