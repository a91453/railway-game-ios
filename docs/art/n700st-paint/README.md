# N700ST 塗裝（N700ST-PAINT，2026-11-26）

玩家自己蓋的高鐵線，單號車原本畫成日本的 N700S（白車身、兩條藍線）。作者 2026-11-26：「把台灣高鐵 n700s 改成 n700st 塗裝不就解決了」「這樣也不用刪 n700s 了」。

- 模型：N700S 的同一份網格（決策 979，`Map3DN700S`），形狀、門、窗、燈都不變，只換兩條線的顏色（`Map3DN700ST.model(_:)`）：粗的那條（窗下、延伸到車頭）是 700T 的橘，細的那條（在它下面）是 700T 的黑。藍線三角面最高點低於 1.725 m 的就是細線（三節車都量過：細線最高 1.71 m、粗線最低 1.74 m）。
- 依據：台灣高鐵 2025-08 公布的 N700ST 塗裝：白色車頭與車身，橘黑雙色線條從車頭交會後平行延伸到車身側面，延續 700T 的配色。上下順序是遊戲依模型兩條線粗細定的（粗線橘、細線黑）。
- 誰畫 N700ST：「高鐵列車」車種（`HSR`，玩家的高鐵）單號車。台灣高鐵自己的車（真車與買下的）全是 700T（#2764）；西九州新幹線仍是 N700S。
- 線路頁的「700T 塗裝」選青綠帶時，N700ST 的橘線也一起換。

`overview.jpg`：700T、N700ST、N700S 的頭車，左為遊戲斜角、右為側面（`tools/train-models/run.sh OUT --ids set-n700st-head,set-n700s-head,set-highSpeed-head` 再 `render.mjs OUT --views left,isometric,front`）。

授權與來源：作者自己的舊版 N700S 模型（決策 979），沒有新的外部素材。
