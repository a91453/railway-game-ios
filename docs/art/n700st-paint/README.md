# N700ST 塗裝（N700ST-PAINT，2026-11-26／27）

玩家自己蓋的高鐵線，單號車原本畫成日本的 N700S（白車身、兩條藍線）。作者 2026-11-26：「把台灣高鐵 n700s 改成 n700st 塗裝不就解決了」「這樣也不用刪 n700s 了」；看了只換線條顏色的第一版後：「跟真實車輛一樣吧 不是長這樣」，改交本地工作室照實車重畫。

- 模型：本地工作室以作者舊版 N700S 三節（決策 979）為底重切塗裝（`railway-assets-private-2` `game-art-previews/docs/art/n700st-paint-2026-11/revision-1/`，工具 `tools/texture-palette/n700st.py`），形狀、門、窗、燈、車長、全周幌都不動；`tools/train-models/glb_to_swift.py` 寫成 `Map3DN700STMesh.swift`，`Map3DN700ST` 用自己的網格與色票（N700S 的色票，藍換成 700T 的橘）。
- 塗裝（照台灣高鐵 2025-08 公布的塗裝圖與 2026-04 日本工廠完成塗裝的實車照）：
  1. 白色車頭，駕駛窗外圍一圈黑色橢圓遮罩。
  2. 頭車第一扇門一帶一大塊橘色，從裙板到窗下，前緣往前下方斜；緊接在後一條平行的黑色斜帶。
  3. 全車窗下：細黑線在上（1.74–1.84 m）、略寬橘帶在下（1.52–1.74 m），和 700T 同順序；下面白車身、深灰裙板。
  4. 沒有標誌、字、車號。
- 面數：頭車 5,143、中間車 3,384、集電弓車 3,682（十二節約 45,000，不用遠景版）。
- 自動檢查：工作室跑 `tools/texture-palette/port_check.py` 全過（`revision-1/port-check.md`），Codex 審兩輪。
- 誰畫 N700ST：「高鐵列車」車種（`HSR`，玩家的高鐵）單號車。台灣高鐵自己的車（真車與買下的）全是 700T（#2764）；西九州新幹線仍是 N700S。
- 線路頁的「700T 塗裝」選青綠帶時，N700ST 的橘也一起換。

`overview.jpg`：遊戲畫出來的 N700ST 頭車與中間車（斜角、側面、正面），和 700T、N700S 頭車並排（`tools/train-models/run.sh OUT --ids …` 再 `render.mjs OUT --views left,isometric,front`）。和參考照片並排的總覽在上面那個資料夾的 `overview.jpg`（參考照片不放公開 repo）。

授權與來源：作者自己的舊版 N700S 模型（決策 979）與本地工作室為遊戲畫的塗裝；參考照片只在私有素材庫內比對。
