# Codex 的四款列車接進營運（決策 399）

同一個相機的前後（每組前後兩張用兩列合起來的範圍取景）。工具：`tools/codex-trains-399/`。每列都是四節的列車，照 `Map3DTrains.frame` 的排法（`TrainCars.cars`，每節拉到它那段軌跡的弦長）。

- `summer.png`：仲夏寶島號。上：之前的 CT273 代用黑色車頭；下：#1103 的蒸汽機車＋煤水車，後面三節莒光客車。左斜看整列、右前 26 m 近看；最下兩列是 120 m 半徑的彎道。
- `others.png`：蒸汽列車（方塊 → #1118 雙走行組蒸汽＋煤水車＋藍皮客車）、線性馬達捷運（C381 → #1081 四節金砂，每節 12.3 m）、輕型捷運四節（綠色電車 → #1094 七節段霧藍）。後兩者在列車包裡，沒解鎖時照舊是上面那張。
- `curves.png`：三種「之後」在 120 m 半徑彎道上從上往下看，每節照自己的長度跟著轉。

圖是 Chromium WebGL（swiftshader）畫的原生頂點，不代表 iPhone 的 Metal。
