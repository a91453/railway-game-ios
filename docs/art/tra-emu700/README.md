# 臺鐵 EMU700 原生研究 — 尚未完成驗收

本輪為獨立配方，不沿用其他EMU整殼。現有私庫Q版EMU700不具工程尺度，非已接受前稿。全部使用者外觀接受為UNVERIFIED。

正式身份：EMU700通勤交流電聯車；不是將「阿福號」當作正式型號。日本車輛／台灣車輛製造；2005採購，2007–2008交付計畫。前三個四車子單元日本製、後續台灣車輛在技轉下生產的細分，尚需原廠逐組交付紀錄。不能將採購公告的計畫年份當實際驗收日期。東芝電機系統供應責任仍待原廠文件補核。

來源：日本車輛[產品頁](https://www.n-sharyo.co.jp/business/tetsudo/pages/ztaiw_emu700.htm)、[採購公告](https://www.n-sharyo.co.jp/business/tetsudo/topics/tp050609.html)，台灣車輛[產品頁](https://www.trsc.com.tw/train/tran-58acf525031f4)，實車觀察[Blair Yu攝影文章](https://blair-train.blogspot.com/2011/09/emu740.html)，角色交叉核對[維基條目](https://zh.wikipedia.org/wiki/台鐵EMU700型電聯車)。原始照片僅本機觀察，未發布、未做貼圖、未送生成服務。文章版權所有；照片拍攝日期未知，2011-09為文章日期，不可當每張照片日期。沒有拼接成2026現役證據。

台灣車輛頁的ED／EMA／EP／EMB與其他角色原文矛盾；本輪明列此差異，採EMC／EP／ET／EM交叉定義，尚待官方編組圖補核。

候選代表為739+740，來源文章直接可讀EMC740、EM740；其餘六車號由編組表支持，沒有完整八號同日可讀照片，不宣稱已證實指定列2026營運。排除701+702京急彩繪、原型舊黑面、試車及模型照片。

八車配置：+X端← EMC739 / EP739 / ET739 / EM739 | EM740 / ET740 / EP740 / EMC740 →-X端。前四單元不旋轉，後四單元僅assembly旋轉180度一次。EP兩車為受電弓車；EMC與EM為動力車，ET拖車含無障礙設備。EM–EM中央交界屬半永久連結，不是兩個駕駛頭互接；中央端面與普通車間端的完整實物差異仍資料不足。

原生公尺，+X朝本子單元駕駛端、+Y左、+Z上，軌面Z0；左右從+X朝向定義。EMC連結面距20.743m、其他20.3m，總長163.286m，非每車平均長；連結面貼接，殼端退讓產生間距，不再額外加縫。台灣車輛頁寬2.890m，其他資料2.889m，配方採2.889m；車頂3.7m、含AC約3.95m、弓升起包絡另列，不能把含設備高度當殼高。台車中心±7.15m、軸距2.3m、輪徑新輪0.86m／磨耗0.78m、軌距1.067m；配方採新輪。輪心高度0.43m，軸位±7.15±1.15m。
