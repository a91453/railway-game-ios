# 騎樓、雨遮、曬衣、水塔與斜交平交道（決策 267）

> 2026-10-22 起這個資料夾只留這份 README、總覽圖 `rows.jpg` 和文字紀錄；其他 3 張圖搬到 `a91453/railway-reference-private: Railway/game-art-previews/docs/art/map3d-arcade-life-2026-10-17/`，檔名不變（作者 2026-10-21 的規則，`docs/HANDOFF.md` §2）。

用 `tools/map3d-preview` 畫：WebGL 照 `Map3DShaders.metal` 的算式重畫，不是 iPhone 的畫面。兩鎮地圖、下午 2 點。每張都是上半 `main`、下半新版。

- `rows.jpg`：透天厝街區，170 m。
  - 樓上一半的樓層有藍、綠、紅、灰藍的鐵皮雨遮；屋頂多了藍色或不鏽鋼的圓水塔，站在鐵架上。
  - 左邊大路旁的透天厝一樓開店。
  - 上半就是沒有選的「雨遮用灰色或不加」：牆面平平的，看不出生活感。
- `shopping-street.jpg`：大路旁的商店街，40 m（這個距離鏡頭幾乎往下看）。
  - 騎樓前的櫃台、三箱彩色貨物、低遮雨棚，樓上的雨遮與曬衣。
  - 左邊那排的店面朝著大路，從這個角度只看得到雨遮的邊。
- `close.jpg`：同一區的另一排，70 m，住家的雨遮與水塔。
- `level-crossing.jpg`：48° 斜交的平交道，40 m。
  - 上半：柵欄與警示燈站在道床上，平台短，鋼軌在路邊露出來。
  - 下半：柵欄沿軌道法線離開道床、站在路邊；平台照角度加長，坡道從平台兩端接回路面。
