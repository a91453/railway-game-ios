# 3D 地圖的實景地面（2026-10-15）

ARCHITECTURE 決策 234。3D 的實景地圖讀 App 打包的台灣底圖 `taiwan.pmtiles`（2D 地圖的同一個檔），把道路、河川、海、湖、林地、草地與公園鋪在地面上。城市的建物不蓋在真實的路上。

這裡的圖都是軟體算圖：
- 場景從 Swift 輸出（`Map3DScene`，和 App 同一份程式）；
- 用 WebGL 照 `Map3DShaders.metal` 的同一個算式，在 Chromium 裡畫；
- 光線是遊戲的下午兩點。

**不是 Metal、不是 iPhone 的畫面**（UNVERIFIED），要等 TestFlight。

## 四種做法（`options.jpg`，台北車站，900 m）

- **A**：淡暖灰的路，貼混凝土貼圖。路和米綠的地面幾乎一樣亮，看不太出來。
- **B**：深灰柏油（參考庫 location modeler 的顏色）。路網很清楚，但在明亮柔和的調色盤裡太重。
- **C**：和 D 一樣的路，但城市的建物不讓路：大樓蓋在高架道路與街道上。
- **D（選定）**：白色道路，快速道路與主要幹道暖黃，和 2D 地圖同一套顏色；不貼圖。

選 D 的理由（四個角度）見決策 234 第 5 點。
