# 狀態列的寬度（決策 251）

iPhone 只能橫放（`project.yml`），所以三種寬度是橫向的：iPhone SE 667 pt（沒有瀏海，安全區就是整個寬）、iPhone 17 852 pt（安全區 734）、iPhone 17 Pro Max 956 pt（安全區 832），各減掉左右 10 點的邊距，就是狀態列能用的寬度。

這些圖不是 App 截圖：在瀏覽器裡照 `HUDView` 的四種排法（`ViewThatFits`：一列、一列短日期、金額疊在時間上、時間自己一列）與間距、按鈕寬度畫的示意，字用 Inter 代替 SF Pro，數字一樣寬。挑排法的方式和 App 一樣：第一個放得下的。圖示是色塊代替。每種寬度畫四列：英文平常的一天（預設字級 15 pt）、英文最長的金額與日期再加連假（預設字級）、同樣在最大字級（xxxLarge，21 pt，`ContentView` 的上限）、中文最長在最大字級。

| 檔案 | 內容 |
| --- | --- |
| `a-chosen.png` | 選的 A：每一塊留它最寬時的位置（金額到 8 位數加負號、這一年的任何一天加秒、最寬的倍速），天氣與時鐘各佔 20 點，連假把時鐘換成旗子。一整年同一個寬度，所以同一種排法。 |
| `b-now.png` | 現在（main）：寫多寬就多寬。日期、星期、連假的字、天氣圖示、每分鐘出現又消失的秒數，都會讓寬度每天不同；接近一種排法的邊界時就換排法，按鈕跟著移動。SE 平常的一天是 640 pt，離 647 只差 7 點。 |
| `c-time-row.png` | 沒選的 C：手機上時間一律自己一列。不會換排法，但到處都是兩列高，而且寬度仍然每天變。 |
| `d-icons-first.png` | 沒選的 D：次要的先縮成圖示（連假變旗子），不留位置。日期和金額仍然會變寬變窄，還是會換排法。 |

跟隨列（`FollowBar`）沒有另外畫圖：規則是最後一種排法一定放得下（線號徽章加「取消跟隨」的叉），原本最窄的那一列還有兩顆倍速鈕，窄的時候會超出畫面。
