# 3D 建物的牆面材質（2026-10-15）

> 2026-10-22 起這個資料夾只留這份 README、總覽圖 `materials.jpg` 和文字紀錄；其他 4 張圖搬到 `a91453/railway-reference-private: Railway/game-art-previews/docs/art/map3d-materials-2026-10-15/`，檔名不變（作者 2026-10-21 的規則，`docs/HANDOFF.md` §2）。

ARCHITECTURE 決策 242。作者問清水模這類素材能不能用、會不會成本太高，「四方建議，考慮完適合就做」，並交代配色要調成遊戲風格、不能全部採用。

四種材質，都是灰階的細節：乘在調色盤的顏色上，所以牆的顏色仍是遊戲的；在場景裡依公尺鋪，200 m 到 600 m 之間淡出。

| 材質 | 用在哪裡 |
| --- | --- |
| 清水模 | 一部分辦公樓、診所、機關、車站與停車場；牆用冷灰色 |
| 二丁掛 | 一半的住家與公寓、學校、消防隊 |
| 馬賽克磚 | 四分之一的住家與公寓、一半的診所 |
| 洗石子 | 一部分住家、廟的牆 |

清水模的模板接縫、六個繫桿孔，與磁磚的分格都是自己畫的。網站 3D 城市的 Poly Haven 貼圖（CC0）只取灰階、拿掉大部分對比，當不規則的底紋。

圖是 `tools/map3d-preview/` 的軟體算圖（WebGL 照 `Map3DShaders.metal` 的算式）。**不是 Metal、不是 iPhone 的畫面**（UNVERIFIED），要等 TestFlight。

## 成本

- 貼圖多 4 層，每層 256 × 256：GPU 記憶體約 350 KB（含 mipmap）；App 裡的 PNG 從 705 KB 變 859 KB。
- 三角形、draw call 都沒有增加。
- 有材質的牆，fragment 多取樣一次。
