# 不同的高架橋（決策 407）

`overview.png`：左半 `main`（883bd7b）、右半決策 407。上面是平地上每種一對股道各 400 m、離地 12 m（前到後：高鐵、台鐵、捷運、台鐵過河），下面是四種近看的側面（左上高鐵、右上台鐵、左下捷運、右下過河的鋼桁架）。

用 `tools/map3d-preview` 畫（Linux 無頭 Chromium，照 `Map3DShaders.metal` 的算式；不是 Metal、不是實機，實機的樣子 UNVERIFIED）。平地的那一組是只為預覽寫的場景（`Map3DPreviewDump` 的暫時改法，沒有留在 repository），藍色的河是預覽畫的。
