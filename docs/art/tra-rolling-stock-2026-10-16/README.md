# 台鐵車款擴充的三種外觀方案（決策 252）

`options.png`：三種方案各畫在淺色、深色地圖上；每列左起原色、灰階、模糊。地圖實際大小的三倍，車寬 6 點，畫法照 `MapArt.drawCars`（車身、路線色腰帶加藏青邊、車頭照形狀）。方案 A 最後三列是既有的 EMU800、北捷 C381、EMU3000，對照用。

| 方案 | 畫法 | 取捨 |
| --- | --- | --- |
| **A（採用）** | 莒光的車身是客車的橘，車頭是機車的標誌色（E200 乳白、E500 深灰、R100 深紅、R200 藏青圓頭）；EMU100、海風號照參考調深淺 | 看得出是莒光號，四款看車頭分；顏色都和暖黃、綠松拉開 |
| B | 莒光整列用機車的車身色 | E200、E500、R100 都是橘，幾乎分不出；R200 整列變白，看不出是莒光 |
| C | 參考的 `bodyColor`／`stripeColor` 原色 | 最接近參考，但 EMU100 的米黃貼著車站暖黃（20）、海風號的海綠貼著軌道綠松（23），地圖上會混在一起 |

預覽用 scratchpad 的 Python 腳本（Pillow）畫，腳本不放進 repo（art-style 第 3 節）。
