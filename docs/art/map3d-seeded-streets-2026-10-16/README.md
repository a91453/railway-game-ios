# 空白地圖的種子道路與沿街的透天厝（決策 263）

用 `tools/map3d-preview` 畫：WebGL 照 `Map3DShaders.metal` 的算式重畫，不是 iPhone 的畫面。兩鎮地圖、下午 2 點、`MAP3D_BUSY=1`。

- `blank-map.jpg`：透天厝街區，170 m。
  - 上半是 `main`，也就是沒有選的做法：每條格線一樣的街道、透天厝背對背站在地塊中間。
  - 下半是新版：
    - 主要道路約每 5 格一條，有行道樹、路燈、人行道；
    - 其他是街或巷，巷子旁邊有電線桿；
    - 有些地塊之間沒有路，合成一個街廓；
    - 透天厝沿著街排成一列、正面朝街，街廓中間空出來當後院。
- `street-close.jpg`：同一區的近照，110 m，上半 `main`、下半新版。
- `level-crossing.jpg`：新版的平交道，90 m。
  - 街道越過地面上的軌道時，鋪面墊高蓋過鋼軌，前後有坡道、停止線，兩邊各一支柵欄（升起）與警示燈。
  - 這張是兩條街在路口同時越過斜過來的軌道。
