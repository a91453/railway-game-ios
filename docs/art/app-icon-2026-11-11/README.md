# App 圖示的分層玻璃版（決策 680）

2026-11-11。都是 Xcode 27.2 內附的 `ictool`（Icon Composer 的命令列）從 `RailwayGameApp/Resources/AppIcon.icon` 渲染的，轉成 sRGB。

- `appearances.png`：定案的圖示在主畫面的六種樣式：預設、深色、透明（淺、深）、染色（淺、深）。染色的顏色是 `ictool` 的預設色，玩家可以自己選。
- `before-after.png`：現在的平面圖示（套上同一個圓角外形）和新的並排，淺色、深色各一列；每列是 400、180、120、87 像素，再加模糊與灰階（art-style 第 5 節的檢查）。
- `options.png`：層的設定試過的四種，每列六種樣式：
  - A 系統預設的玻璃邊與中性陰影（**選這個**，再把透明／染色裡的建物改淺、窗改深）；
  - B 不要高光、陰影減半；
  - C 軌道半透明、陰影帶顏色；
  - D 不要陰影與高光，建物不用玻璃。

  這張是定案前畫的：A 列的透明與染色還是建物偏暗的樣子，定案的看 `appearances.png`。
- `home-screen.png`：Debug 版裝進 iPhone 18 Pro 模擬器（iOS 27.2）後主畫面第二頁的截圖，左邊裝置是淺色外觀、右邊深色。主畫面的圖示樣式是預設（淺色圖示），所以兩邊的圖示一樣；深色、透明、染色的圖示樣式沒有在模擬器上切換過，只有 `ictool` 的渲染。
