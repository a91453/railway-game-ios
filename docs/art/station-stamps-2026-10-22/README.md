# 車站紀念章的三種畫法（決策 348）

`options.png`：同一頁 8 枚章（擺法照 `StationStampPassport.layout`），淺色、深色各一列。用 HTML 畫的示意，不是 App 的截圖；App 裡的樣子要在 Simulator 或實機看。

- **A（採用）**：方章、外粗內細兩道框，站名、另一種語言的站名、日期。和決策 276 的每趟蓋章同一個框（`InkStampFrame`）。
- **B**：每趟蓋章的扁平長條直接放進護照。字小、像標籤，不像章。
- **C**：圓章。站名與英文名碰到圓邊，長的站名（淡水漁人碼頭）擠不下。

印泥顏色照系統取 `Theme`：台鐵藏青、高鐵琥珀、林鐵與輕軌紅、捷運綠松。
