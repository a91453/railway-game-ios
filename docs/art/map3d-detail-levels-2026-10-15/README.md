# 3D 地圖的遠近分級（2026-10-15）

ARCHITECTURE 決策 238：城市建物分近版與遠版。地面、道路、軌道、玩家的建物不分級。
- **近版**：比原本多了透天厝的陽台、冷氣、店家的直立招牌，公寓長邊每層的陽台帶。
- **遠版**：拿掉這些、女兒牆、屋頂機房、廠房的鐵捲門與貨櫃、廟的燕尾脊與香爐、公園的樹幹，但留下屋頂的水塔與鐵皮加蓋（遠看最像台灣的地方）。
