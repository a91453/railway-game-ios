# 3D 地圖的雨絲（決策 320）

`rain.jpg`：台北車站東邊的大馬路，`tools/map3d-preview` 的無頭 Chromium WebGL 預覽（`MAP3D_WEATHER`），雨絲照手機的樣子畫：把 1600 × 900 的圖當成 533 × 300 點、每點 3 像素的螢幕。

| 位置 | 內容 |
| --- | --- |
| 左上 | 晴天 14:00（和 main 相同） |
| 右上 | 下雨 14:00：決策 277 的光線與霧，加上這次的雨絲（白天用 2D 地圖的雨色 `4A5A80`，不透明度 0.35） |
| 左中 | 颱風 14:00：雨絲多一半、更斜（0.4） |
| 右中 | 下雨 20:30：參考的淡藍 `rgba(198, 215, 228, 0.24)` |
| 左下 | 右上同一張的 1:1 裁切（採用的白天顏色） |
| 右下 | 同一處用參考的淡藍畫白天的雨（沒有採用：淺色地面上幾乎看不到） |

pixelmatch（`tools/map3d-preview/diff.cjs`）比對同一張下雨的圖，有雨絲和沒有雨絲：1,440,000 個像素中有 8,057 個不同（0.56%），就是雨絲本身。

不是 Metal、不是 iPhone 的畫面；閃電（雷雨、颱風）是 2D 地圖的節奏，預覽的那一秒沒有閃。實機要看 TestFlight。
