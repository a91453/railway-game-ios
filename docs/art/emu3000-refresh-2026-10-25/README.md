本輪使用者只指出側面下巴偏長，並補ED側面示意。已實際看新ED、EM兩張及前面側照：第三版的低下巴拖長了下鼻輪廓，所以只微抬底線、收緊下角，不重做其他部分。完整第三版producer `e25474fffe42a98fd6cbc04b5f287485be72e097`／私庫`aef61a87`與`revision-3`保持，新增`revision-4`及`revision-3-vs-4.png`同相機公尺尺度比較。

建模前本輪特徵補充：端車ED／tail各一件、12節順序保持；側面下巴應短而圓、不能前下方拖長，正面白下巴仍有實體厚度；頭尾鏡轉、左右相同；門窗／設備／輪組位置不改。ED pitch21.35m、寬2.91m與總bounds不變；新圖是有署名的非工程示意，曲面修訂仍標**比例推估**，無新增工程尺寸。

只在實際原生端車 `x>7.9m、z<1.1m` 的低白殼與鼻罩縫做平順位置調整。鼻罩縫再投影貼合最終殼面，避免局部被埋；所有上部黑罩／風擋／燈／門窗／輪組／設備，以及12件近遠中間單元的原生payload全部不變；四件端車所有顏色／layers／三角順序與數量不變，受影響三角法線由最終位置重算。三角檢查不只看配方常數。最低白鼻約由0.24抬至0.48m，下角相對鼻尖的水平距離約0.875縮至0.625m，均為虛擬模型量測，不是工程規格。

外觀自檢：已符合本輪「只收側面下巴」目標，最終側／正／上／斜配色白模剪影、同尺度真前後已看；正面主要設計及已修車門保持。仍是製作方自檢，未宣稱使用者已接受本版。新低角回歸在真第三版先紅、修後綠；相關測試共50個（49通過、1原成本量測skip）。本輪三角數與第三版完全相同，沒有額外增加。

## 第三版背景與仍有效的交接契約

使用者指出「車頭比例再調一下，車身的門破圖了」，這次只修改專用 EMU 的鼻部與門框／門玻璃。白車身、細綠松線、原車寬／車長、客室窗列、輪組／車下設備、車頂設備、編組及其他列車保持；以實際原生三角差集檢查修改範圍。真正前版 `23a59907b41c6fefced0bbc7368352ab64e1e7a3` 與完整 `revision-2/` 保留，第三版完整 `revision-3/`，不覆寫舊包。

本 PR 包含**遊戲實際模型替換的接點**，不是只註冊素材。公開 PR 合併後，在使用新 set 的標準模型包中，EMU3000 近／遠景將使用本配方；尚未合併不會改變 main 或已安裝 App。本輪不修改 dispatch。規劃方另以 [#1233](https://github.com/a91453/railway-game-ios/pull/1233) 保留 `emu3000Classic` 等舊版，後續由 Claude 的列車包 PR 處理解鎖／回退分派；保留其新增清單，不把舊版刪掉。私有 GLB 不會被 App 讀取，包內是同份配方的**靜態**原生／GLB／預覽，沒有門、輪、集電弓動畫。

## 修正與外觀驗收

**車門問題已重現**：舊版近景 EM 的40個門玻璃正面三角取樣中，24個被其他表面遮住；ED／tail各36個，其他中間車各24個。舊模型即使閉合、法線正確仍會破圖。原因是大門葉／玻璃使用單一扇形三角跨越凸車側，內插表面穿進車殼／門葉；並非貼圖檔案損壞。

修正以白車殼本身作門葉，新增封閉薄門縫環與門玻璃。先在邏輯面按**實際殼面截面高度**分段，再投影到真正的分面車側，保留18mm正面偏移與背面嵌入支承；不再多疊一整片白門板遮玻璃。門位與尺寸保持，沒有靠深色大框蓋住破圖。

**車頭**：只在端車鼻部延伸白下巴／前裙下包絡並圓收，改善正面偏扁及輪架整片外露；保持車寬、pitch及輪組。黑罩改用實際正面高度／左右座標的圓U分色場，避開角度色帶在收尖截面形成中央黑尖。鼻罩縫、風擋／側窗及燈組都跟隨最終表面重建；不是用色彩掩飾幾何。模型鼻部白色最低高度約0.24m（前版約0.84m），僅為虛擬模型量測／造型估計，不宣稱工程離軌尺寸。

## 單元與組裝

真實12節：`ED1–EM1–EP1–EM2–ET1–EM3–EP2–EM4–EM5–EP3–EM6–ED2`。
輸出：`ed–em–ep3–em–et–em6–ep7–em–em–ep10–em–tail`。

ED10暗主窗；EM／ET13；EP3為12；EM6的12窗位有兩個留白（10暗）；EP7一個服務留白（11暗）；EP10為13。非12節保留遊戲1–16節的選擇，只是遊戲排列，不宣稱真實短編組。背景TRA班表的既有EMU800分類不改。

原生為公尺、`+X前／+Y左／+Z上`、輪底`Z=0`；helper用x前／y上／z右，`.flat`只轉一次。GLB為 `(native.x,native.z,-native.y)`。八角色各有近／遠景合法 M3DM v1／GLB／七向PNG；完整12節以自含合法單元的 M3DAssembly JSON 與GLB交付，不能偽造超過單件15k限制的M3DM。新組裝只平移、scale_x=1；tail已180°旋轉，不能再轉。每件實際bounds／三角與translation／gap／共同基準在manifest及組裝JSON。

主程式85d9aa35前版的原生單元也保留。舊完整組裝按實際舊renderer20m節距／19.4m顯示長重建，`scale_x`明列；不是舊App截圖。真正未提交初稿保持`history/first-pass`，不偽稱Git發版。
