# 車款外觀的三種方案（決策 243）

`options.png`：三種方案各畫在淺色、深色地圖上；每列左起原色、灰階、模糊（玩家掃一眼看到的樣子）。地圖實際大小的三倍，車寬 6 點。最後兩列是淡黃色路線上的 EMU800（腰帶加了藏青邊才看得到）與沒有車款的一般列車（照舊整車路線色）。

| 方案 | 畫法 | 取捨 |
| --- | --- | --- |
| **A（採用）** | 車身與車頭照車款，中間一條路線色腰帶（藏青邊） | 一眼分得出車款（白／銀車身＋車頭形狀與顏色），路線也還看得出來；和 3D 的白車身＋路線色帶同一個樣子 |
| B | 車身照路線色，只有車頭照車款 | 路線最清楚，但車款只差車頭一小塊，灰階下幾乎分不出 |
| C | 全車照真實塗裝 | 最像真車，但路線色只剩底下的軌道，同一條線上的列車看不出屬於哪條線 |

預覽用 scratchpad 的 Python 腳本（Pillow）畫，腳本不放進 repo（art-style 第 3 節）。
