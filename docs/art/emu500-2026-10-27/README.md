## 接手、來源與遊戲範圍

公開 base `f6c6afa3bcc5888c350ff5594c3e8f370d565f31`；私庫 base `b6b18ba48102ca38859068c1511e0d2ab2ba9f5f`。實查 TEMU2000 公開 #1292 2026-10-26 13:31:59Z 已合併，私庫 #86 12:56:37Z 已合併；main 另含 #1308 的普悠瑪營運接入。

適用 AGENTS、CLAUDE、HANDOFF、art-style skill 與原生製作手冊已查；私庫找不到 AGENTS.md / CLAUDE.md。已查工作登記 #1041 與 #231 最後頁，認領自有檔案。EMC、EP、ET、EM 都由新截面與新設備生成；不沿用既有車型幾何。

私庫 `Railway/taiwan-rail-reference-clean/source/rail-3d/README.md`、`integration/FORMATIONS.md` 及 `assets/garage-blender-v1/emu500.json` 已讀。舊模型明示 Q-proportions、engineeringDimensionsM=null（長約 9.308 m），不可拿其 bounds 當真車長。本輪不讀取、複製其 mesh 或貼圖；只引用 metadata 的資料缺口。

## 尺寸與共同基準

2026-10-27 讀取[中文維基 EMU500 車型頁](https://zh.wikipedia.org/wiki/台鐵EMU500型電聯車)，二級資料列：單車長 20.330 m、寬 2.853 m、非 EP 高 3.964 m、EP 降弓高 4.219 m、輪徑 0.860 m、軸距 2.800 m，順序 EMC–EP–ET–EM。私庫 FORMATIONS.md 亦指出 EMU500 四輛，不能由區間車班表判定車型。

沒有取得原廠工程圖。本模型採 20.33 m 為編組節距，車殼 19.88 m、台車中心 ±6.65 m、各截面、門窗尺寸位置、設備、連結器與間距都是**比例推估**。不能把引用的車輛長解讀為已確認連結面距；81.32 m 是四倍引用長度的模型配置值。EP 採展示升弓，最高處不等於資料所列降弓高度。

各件共用車身中點 X=0、對稱中心 Y=0、輪底 Z=0。單元原生 +X 前、+Y 左、+Z 上，EM 自身駕駛端 +X，編組明列：

| 次序 | 單元 | X 平移 m | 繞原生 Z 旋轉 |
|---|---|---:|---:|
| 1 | EMC | 30.495 | 0° |
| 2 | EP | 10.165 | 0° |
| 3 | ET | -10.165 | 0° |
| 4 | EM | -30.495 | 180° |

中心間距 20.33 m；車殼間隙 0.45 m，短風琴與連結器為簡化展示。全部實際 bounds、三角數在私包 manifest，不把長度推估說成工程校準。

### 第八版：遊戲色票與局部收細

使用者對真正第七版回饋「稍微好一點」，並詢問尚需修正處、要求改成遊戲風格配色；這不是對整體外觀或工程精度的認可。真第七版 producer `04500c67` 的原生／GLB／ZIP／配方與預覽先完整保留，再做第八版。

本輪判斷優先三處：貫通框的視覺重量、下裙與連結器的方硬邊、側門／客窗框厚度。收窄灰立柱／頂框、側門底座與窗框；門板和玻璃往車身收，層間接觸重新核實；下裙兩個下角與連結器外框做小倒角。黃紋以真裙板外形裁切，沒有浮在切掉的角外。保持車體主面、車頭曲面、玻璃主要輪廓、軸距／輪徑、車頂設備、單元種類、編組及全部其他列車配方。

| 用途 | 第八版實際來源與色票 |
|---|---|
| 車身／門板 | `Map3DPalette.shopAwnings[3]`，暖白 `#F2F0EA`；與現有 EMU3000、巴士一致 |
| 車頭／腰線 | `Map3DPalette.shopAwnings[0]`，低彩綠松 `#3E8C8C`；保留 EMU500 的塊面邊界、白折線、門燈節奏，採遊戲塗裝而非實車藍色 |
| 玻璃 | `Map3DPalette.glazing` 的 0.53 倍，`#535F67`；與 EMU3000 相同做法 |
| 框／輪心 | `Map3DPalette.tankStand`，`#6E747B`；縮小框厚，降低搶眼程度 |
| 膠條／裙板 | `Map3DTrainStyle.navyLine`，`#2B3356`；深藏青而非純黑 |
| 台車／車底 | `Map3DTrainStyle.under` 與 tankStand 的 0.42 倍 `#2E3134`；淡化舊藍黑底盤 |
| 車頂 | `Map3DTrainStyle.roofColour`，`#C5C9CD` |
| 燈／警戒紋 | `Map3DPalette.tunnelLamp` 的暖白 `#FFE2A6`／`Map3DPalette.player` 的暖黃 `#FFC86B` |

只引用現有調色盤及既有列車的明暗算法，沒有改全域色票或其他車型。模型仍為霧面頂點色，不使用照片貼圖、真實商標或外部生成服務。參考圖判讀沿用前述逐圖紀錄，沒有新增未查看的來源。EMU3000 端車僅匯出供同公尺尺度的色票、霧面及細節密度比較，沒有用它的車體、門窗、台車或編組。

**實際幾何／色票稽核**：以第七／八版輸出三角比較，忽略顏色後，車頂和輪組／台車座標完全相同；全部其他幾何差異限於前框／門窗層、下裙與連結器外框。排列與長／高包絡不變。實際原生色彩清單含新色票，舊實車藍 `#1D4F91`、銀灰 `#C8D0D2` 已不在最終 EMU500 中。未打光 sRGB 色票對比：暖白／綠松 **3.454:1**、暖白／玻璃 **5.758:1**、暖白／框 **4.144:1**；不是宣稱所有渲染像素都達相同值。

已親自查看第八版正／側／俯／斜配色、白模與剪影、各單元與編組、與 EMU3000 的同尺度風格及真第七→第八版前後比較。

| 判定 | 第八版外觀結論 |
|---|---|
| 已符合 | 暖白／低彩綠松／藏青／暖黃與既有遊戲列車同套色票；灰框與側門窗框較薄，下裙下角及連結器外框較柔和；圓肩淺弧車頭、平門、分離駕駛窗與燈座、白折線、三門節奏保持 |
| 仍不符合 | 局部窗角與外殼仍有低多邊形折線，台車懸吊、空調格柵、風琴摺層、前端軟管仍是簡化構造。後續細化以台車懸吊層次和空調格柵最有價值；未宣稱使用者已認可第八版 |
| 資料不足 | EMC/EM 完整左右差異、另一側精確門窗／車底箱、工程截面、原圖檔及 SHA；照片推估與引用尺寸仍分開記錄 |

最終實量：EMC/EM 各 **4,548** 三角、EP **2,944**、ET **2,840**、四車 **14,880**。各件 X ±10.165 m、Y ±1.475 m、輪底 Z=0；非 EP 頂 3.970 m，EP 升弓頂 5.000 m；編組 X ±40.660 m。輪組與車頂保持，不把車寬縮小的門窗外突誤稱為車殼規格改變。公尺與排列契約仍見前表。
