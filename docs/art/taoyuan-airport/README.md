## 實車與範圍

1000型普通車：DMC1–MC1–MC2–DMC2，4M0T；101、118–120由川崎製造，102–117由台灣車輛產製（官方證實64輛、2012年12月交車）。初期2011–2012年、增購2015年。2000型直達車：DME1–ME1–ME3–ME1–DMB，5M0T，川崎製造。兩型均為三菱IGBT VVVF牽引，DC750V第三軌下接觸集電靴，無集電弓。採購整合與各供應商責任以川崎2006原文核對，單車逐次驗收日期 UNVERIFIED。

角色代表：普通101編組1101／1201／1301／1401；直達210編組2110／2210／2310／2410／2510。2427junction逐車照片的說明確認車號，照片日期未提供，不能冒稱2026指定車號已核驗營運。官方現行列車介紹支持一般營運塗裝與4旅客＋1行李的配置；指定編組當日狀態仍 UNVERIFIED。已知來源的11列／201–210端點有算術矛盾，不能據此刪除211或捏造批次差異。

官方TRSC：連結面間頭車20.780m／中間20.250m、寬3.030m、車頂3.763m、地板距軌面1.133m、台車中心13.500m、軸距2.100m、新輪0.850m／磨耗0.775m、1435mm軌距。2000長寬高由逐車研究交叉支持，未取得同等級原廠2000輪距工程表，沿用走行量值屬合理簡化，非全部正式證實。普通總長82.060m，直達102.310m；官方約82／102m並非可反推均分單車長度。

## 尺度、方向與編組

原生公尺，+X單元駕駛端，+Y左，+Z上，軌面Z0；builder x前/y上/z右，只由Model.flat轉一次。左右指站在車內面向+X；左右車側設備對稱處是可見照片支持的簡化，未知設備不宣稱工程正確。每車輪心x=±6.75±1.05、z=.425；輪胎內側按軌距，踏面寬度為顯示模型推估。

assembly.json由正式連結面間長計中心，未額外加任意0.6m間隙。首車+X朝機場／環北方向，末端駕駛車僅assembly轉180°，單元不先反轉：

普通：+X ←1101 DMC1–1201 MC1–1301 MC2–1401 DMC2→ −X（台北）。
直達：+X ←2110 DME1–2210 ME1–2310 ME3–2410 ME1–2510 DMB→ −X（台北）。工具ID me4指第4車ME1，並非新增實車型式。近遠各自完整組裝。連結面、風擋接點及原生／GLB正反向仍需最終實際驗證。

## 實際遊戲接點
