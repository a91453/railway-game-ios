## 另外考慮過的做法

- 只在 Metal 裡把環境光調大：白天也會跟著變亮，Linux 也測不到。
- 加色調映射：要改著色器，白天的色彩也要全部重調，範圍太大。
- 地形限制坡度或壓平：軌道的高度是從真實地面量的，地形一改平，軌道就會浮起來或埋進去。
