# Meshy 第一批街道小物（決策 467）

[決策 467](../../decisions/467.md) 接進 3D 地圖的兩件：紅綠一對郵筒、公車站牌。原件是作者用 Meshy 生成的高模（`a91453/railway-assets-private` 的 `meshy-batch-2026-10/glb-hq/`），由 `tools/meshy-props/build.mjs` 簡化、換成遊戲的配色。三張圖都是檔案本身的顏色、平塗加一盞方向光；遊戲讀檔時再過 `Map3DLook.colour`，顏色會再淡一點。

| 圖 | 內容 |
|---|---|
| `overview.png` | 和遊戲現有的公車亭、販賣機並排（同比例）。上排正面、下排背面；左到右：公車亭、販賣機（程式做的）、郵筒一對、站牌（Meshy）、兩件的替身（讀不到檔時畫的） |
| `post-boxes.png` | 郵筒一對（1,724 個三角形）的背面、正面（投信口與門朝馬路）、斜上 |
| `bus-stop-pole.png` | 站牌：Meshy 原件（84,268 個三角形，原貼圖）、遊戲裡的（300 個三角形）正面與背面 |

圖由本機的簡易軟體算圖（numpy 的 z-buffer）畫，不是遊戲的 Metal 畫面；檔案都很小，放在這裡，沒有另外放素材庫。
