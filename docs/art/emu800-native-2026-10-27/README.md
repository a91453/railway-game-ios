# EMU800 藏青黃弧原生模型

Issue #1316。本批為獨立原生第一版，不是 EMU700／900 或 EMU3000 換色。
依原始藍面黃弧 EMU800（2014–2015外觀）轉遊戲藏青、暖黃與柔和灰階；沒有車號、標誌、目的地文字、紅色。改色不保證免除侵權風險。

## 查證與製作

已讀 AGENTS、CLAUDE、HANDOFF、art-style、原生手冊及 E500／EMU3000 案例；登記 #1041，base fba93033，自己的獨立worktree及codex分支。未修改已接受 E500第三版、EMU3000第五版、PP/E1000、莒光藏青或未接受的EMU3000石板藍灰。
附件逐張辨識：兩張側面插畫、六張實車（含重複）、三張模型照片、一張電腦模型。藍面黃弧與黃面藍弧為不同批次塗裝，不混用。插畫標CC BY-NC-ND，只觀察結構，不描線、不散布原圖或取圖素。商品圖不作尺寸依據。

官方來源：[日本車輛 EMU800](https://www.n-sharyo.co.jp/business/tetsudo/pages/ztaiw_temu800.htm)：車體ED21.250×2.890×3.700m，中間車19.600×2.890×3.650m、輪徑0.860m、固定軸距2.300m、軌距1.067m。這是原廠公布規格，並非本次實測。
[編組彙整](https://zh.wikipedia.org/wiki/台鐵EMU800型電聯車)：ED–EMA–EP–EMB｜EMB–EP–EMA–ED，4M4T，3/6車弓。中間節距20.300m；ED21.600m節距、轉向架中心ED(-6.75,+6.10)/中間±6.90m、門窗站位與設備尺寸為比例推估，不稱工程復刻。車高的車體／設備／升弓包絡不同，不能混稱；本批升弓約5.235m是靜態展示姿態，非接觸網工作高度認證。

私庫與既有公開原生實際查看後，既有Q比例車殼／通用弧形車頭與本次比例、微笑罩面、燈、門窗及角色不符；只沿用通用格式／渲染／驗證工具，另建專用配方。私有來源細目僅留私庫。

側面每側3組雙扇門；兩門間2大窗，端部留白及廁所小窗依ED／EP不同。ED另有乘務門和側風擋；EMB保留端部標示燈區。每車雙空調；EP弓在朝EMB端，礙子、支座、簡化走線。底部機器依角色區分、左右廁所窗及通風橫桿不同；未見側精細機器配置仍是推估。

正面短斜鼻、寬梯形風擋、上雙燈＋中央空白框、下四圓燈、黃色微笑弧與灰色連結器罩。分色直接在殼面，風擋／燈按最終殼三角裁切成薄封閉體。正常連結器由閉合罩遮蔽；未做開蓋動畫。

已符合（自檢，非使用者接受）：近遠側／正／俯／斜配色、白模、剪影，三組雙扇門與窗節奏、黃弧／藏青層次、四燈與風擋、雙空調／3與6車弓、尾半列朝向、輪貼軌及完整八輛組裝；同公尺E500第三版、EMU3000第五版風格比較。已修下鼻過方、黃線斷接、EP屋頂配置及分色T接點並重匯。

首次建立此獨立配方，沒有同車型獨立原生前版；before-emu800是真base的通用營運顯示，不冒稱EMU800前版。中途實際候選另留私庫，不覆寫接受模型。
