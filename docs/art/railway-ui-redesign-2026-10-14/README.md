## 怎麼畫的

- **尺寸**：iPhone 橫拿 844×390 點、iPad 1180×820 點。每個方案都有淺色、深色、灰階（淺色）三欄。
- **顏色**：只用 `Theme`、`Palette` 與城市建物的屋頂色。對比在 `docs/UI_THEME.md` 的「原創排版的六個畫面」一節。
- **素材**：圖示與角色都是 App 裡現有的：
  - 站長三種表情（`StationMasterTaiwan*`）；
  - 地圖圖示（`MapGlyph*`）。
- **列車**：照地圖逐節列車的畫法重畫，有兩種：
  - 路線色的車身；
  - 車種型錄用的白車身，窗是藏青，腰帶依類別換色：捷運綠松、鐵路暖黃、高鐵藏青、特殊 warning。
- **天氣圖示**：預覽裡是扁平示意，App 的面板照舊用 SF Symbols（決策 121 第 4 點）。
- **資料**：示意的。
  - 公司評等的七項與稱號照決策 181。
  - 車種的每節人數照 `TrainType`。
  - 天氣照決策 162、182：一天一種天氣，雨讓乘客 −10%、雷雨 −20%，颱風經過的站另外少；遊戲沒有氣溫，也沒有逐時天氣。
- **產生方式**：預覽用 HTML 排版，再用環境裡的 Chromium（Playwright）截圖。腳本在 scratchpad，不進 repo（art-style §3）。
