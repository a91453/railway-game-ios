# 高鐵兩款與 E200 接進營運（決策 408）

同一個相機的前後，工具 `tools/hsr-trains-408/`。每列都照 `Map3DTrains.frame` 的排法（`TrainCars.cars`，每節拉到它那段軌跡的弦長），高鐵十二節、莒光號四節。

- `overview.png`：之前（#900，每節 20 m）、700T（#1201，照原樣，每節 25.2／25.5 m，雙號的列車）、N700S-G（照作者的模型重建成平塗，每節 25.0／25.3 m，單號的列車）；最下是三列並排的近看與 120 m 半徑彎道的俯視。
- `units.png`：N700S-G 的五種單元 A–E（側面與斜看）：A 的長鼻與風擋、各單元的門位、D 的集電弓罩、E 後端的鰭、窗下的兩條深綠線。
- `e200.png`：莒光號之前（舊 E200）與之後（#1201 的 E200），及三款在彎道上。
- `assignment.png`：兩款怎麼分給營運的列車，選用的（單號／雙號）與沒有選的做法。

圖是 Chromium WebGL（swiftshader）畫的原生頂點，不代表 iPhone 的 Metal。作者的原始模型（GLB、原生 M3DM、整列預覽）只在私庫 `Railway/n700s-n700st-2026-10-24/n700s-g/`，這裡只有重建後的樣子。
