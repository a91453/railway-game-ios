# 原生車輛獨立驗收表

審查順序是：來源與比例 → 輪廓／曲面 → 分色 → 門窗／裝配 → 技術輸出。先看實際圖，再看製作者結論。新車不應靠照抄 700T 常數通過；各門檻需對應當次來源、模型尺度與目標。

每列填：

    判定：已符合／仍不符合／資料不足
    證據：來源、實際模型或原生渲染路徑、視角／位置
    動作：具體修正或需補的資料
    技術結果若有：VERIFIED／UNVERIFIED、平台、工具版本與限制

## A. 開工資料與範圍

- [ ] 最新 base／前置 PR 已查，自己的分支與檔案認領清楚。
- [ ] 規則、art-style、HANDOFF、模型格式與工具 README 已讀。
- [ ] 每張參考實際查看；讀不到的逐張標明，沒有把摘要當看圖。
- [ ] 實車／模型／插畫／工程資料／遊戲參考分類清楚。
- [ ] 長寬高／軸距等資料有來源；圖片推估明確標註。
- [ ] 未看到的另一側、隱藏輪組、設備序列沒有被宣稱已確認。
- [ ] 真前版原生／GLB／配方／來源／manifest 保存，可核對 commit／SHA。
- [ ] 本輪改動與受保護部分列出，沒有覆蓋其他人的工作。

## B. 整體比例與曲面

- [ ] **側面**：長高比、鼻長、鼻尖高度、前後懸、車頂下壓起點成立。
- [ ] **正面**：車寬／車高、肩部、頂圓角、鼻罩與前唇／裙板的關係成立。
- [ ] **俯視**：最大寬度位置、車頭收窄、圓鼻尖與下肩保寬成立。
- [ ] **斜視**：前述斷面連成完整形體，沒有接成台階或局部鼓包。
- [ ] 車頭沒有被簡化成尖錐、鏟子、厚板或一條過直的斜坡。
- [ ] 頭尾／左右有依來源保留差異，不是無條件鏡像。
- [ ] 白模與剪影能支持上述結論；沒有靠反光、陰影或貼圖遮醜。

如果此區有主要「仍不符合」，先回去修殼，不進入小細節驗收。

## C. 主色塊與遊戲風格

- [ ] 車身底色、主帶、黑罩、裙板的面積與形狀有依來源／本次風格調整。
- [ ] 鼻尖中央的主色厚度與兩側肩部區分清楚。
- [ ] 色帶接回直車身時沒有突然上下跳或方向斷裂。
- [ ] 俯視沒有因色塊過寬／過尖改變車頭的視覺比例。
- [ ] 黑罩上方留白、罩寬／罩高／圓角與下側收窄合理。
- [ ] 色票／霧面／細節密度與既有遊戲車輛同尺度比較過。
- [ ] 縮小／灰階仍能辨識車體、玻璃、設備，不靠單一色相。
- [ ] 新配色對比有實算，且未打光數值沒有被說成所有渲染像素都達標。
- [ ] 沒有照片質感、髒污、過強反光或密集細節破壞遊戲風格。

## D. 門窗、設備與走行

- [ ] 門窗數量／位置／比例有來源；門板貼殼，框與中縫薄。
- [ ] 車頭黑罩、玻璃、燈區有層次；玻璃不是浮空平面。
- [ ] 雨刷／燈／設備有支點或背板，不以穿入車身當作「有支承」。
- [ ] 轉向架中心／軸數／輪距／軸距／輪徑／前後懸各自核對。
- [ ] 實際每組輪胎貼軌／地，並有輪頂與裙板淨空證據。
- [ ] 正面裙板適當包覆，側面輪組開口仍對齊。
- [ ] 車頂大型設備與支座的位置、方向、大小成立。
- [ ] 公車門側／風擋／後懸與大設備正確；不可只看外殼像不像。
- [ ] 看不到而補全的結構有標註，沒有冒稱工程還原。

## E. 單元與編組

- [ ] 每個獨立單元有 ID、實際 bounds、三角數與共同基準。
- [ ] 單元種類、次序、朝向、長度差異、設備分布有表可查。
- [ ] 中車沒有駕駛窗／頭燈；尾車旋轉沒有重複套用。
- [ ] 平移／旋轉／間距明列，風琴／連結器能接上。
- [ ] 完整編組由交付的最終獨立單元重建，沒有使用另一份粗模冒充。
- [ ] 完整編組的重建與直接輸出有實際對照證據。
- [ ] 單檔上限與全場景預算分開，沒有把超限單一原生檔當合法輸出。

## F. 前後對照與保護範圍

- [ ] 前版是先前真交付，不是事後重造。
- [ ] 相機中心／朝向、投影、尺度／公尺每像素、材質／光／底色共同固定。
- [ ] 全車與局部圖各有清楚標示；局部截面沒有當完整車輛交付。
- [ ] 配色修訂以同殼共面覆蓋／面積／位置證明，沒有順手改殼。
- [ ] 幾何修訂有重新渲染與重新驗證，沒有沿用前版「只有配色變」結論。
- [ ] 受保護硬體／其他單元的實際 vertices／triangles／bytes 有核對。
- [ ] 改色造成共面細分增加時，沒有謊稱整個 native／GLB bytes 不變。
- [ ] 最終視圖確實來自最終模型，沒有夾雜過程中的舊預覽。

## G. 技術包與故障反例

- [ ] 原生讀回、有限數值、法線、退化面、封閉有向邊、正體積已驗。
- [ ] 缺面／反面等實際三角故障會被拒收。
- [ ] 玻璃浮空、輪胎離地、編組移位等可見問題有適用檢查。
- [ ] 使用新車合適的距離門檻，不盲用其他車的 120mm／750mm 等示例。
- [ ] GLB 用獨立 importer 匯入，核對軸向／bounds／三角／色彩／材質。
- [ ] 每件七向 PNG 完整解碼、RGBA／透明、非空、留白不裁邊。
- [ ] viewer 實際載入、切方向、旋轉、縮放；下載 native／GLB／PNG／ZIP 實際 hash 正確。
- [ ] 缺件、JS 錯誤、外部網路請求與手機寬度有檢查。
- [ ] ZIP 完整解壓／CRC／檔案集合／逐檔 bytes 正確。
- [ ] producer 是真 commit，程式、模型、圖、viewer、ZIP 的來源能互相核對。
- [ ] 私有來源、原始 mesh／貼圖、商標／個資沒有混進公開庫或外部服務。

## H. 結論必須分開

- [ ] 外觀自檢已符合／仍不符合／資料不足逐項列出。
- [ ] 使用者是否看過並認可本版，有明確時間／版本；沒有就不宣稱。
- [ ] 技術 VERIFIED／UNVERIFIED 附平台／版本，且檢查沒有誇大覆蓋。
- [ ] 最新 head CI 是實際查到的結果，未拿舊 head 或本機測試代替。
- [ ] Simulator 與真機 Metal／效能／動畫各自說明；未驗就保留未驗。
- [ ] 清楚說明本次是靜態素材、素材註冊、營運映射或已驗的遊戲接入。
- [ ] 重建文件、來源、素材、PR／issue／HANDOFF 的版本與連結一致。
