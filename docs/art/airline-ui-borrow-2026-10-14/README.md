# 航空 UI 借版型的預覽（決策 223）

2026-10-14。作者給了自己做的航空模擬器 UI 截圖。遊戲規劃 session 定的方向是：**只借版型與資訊結構，外觀照《沿線》的畫風重畫**。不借深色玻璃、細線霓虹、寫實機體照片、商標與裝飾用的細直條紋。

三個版型，每個三種方案。每張預覽都有淺色、深色、灰階（淺色）三欄，iPhone 橫拿與 iPad 各一張：

| 檔案 | 版型 | 方案 | 推薦 |
| --- | --- | --- | --- |
| `card-iphone.png`（卡寬 257 點）、`card-ipad.png`（340 點） | 列車卡（`InspectorView`）與跟隨列（`FollowBar`） | A 航班條、B 站點條、C 車體條 | **A** |
| `board-iphone.png`（面板 300 點）、`board-ipad.png`（400 點） | 車站「即將進站」看板（決策 178） | A 出發航班表（欄位）、B 方向分組＋時刻欄、C 站名牌頭＋下一班大字 | **B** |
| `roster-iphone.png`（844×390 點）、`roster-ipad.png`（1180×820 點） | 列車運用表（新畫面） | A 狀態色格、B 白格＋狀態底條、C 精簡膠囊＋點開詳情 | **A**（iPhone 可退成 C 的列高） |

- 顏色只用 `Theme` 與 `Palette`，對比在 `docs/UI_THEME.md` 的「航空 UI 借版型」一節。
- 列車圖示用現有的 `MapGlyphTrain`；車體條用地圖拉近時的逐節畫法（路線色車廂、藏青外框），沒有照片。
- 資料是示意的：站名、車次、收入都是假的，運用表的班次是亂數排的（固定種子）。
- 預覽用 HTML 排版，再用環境裡的 Chromium（Playwright）截圖。腳本放在 scratchpad，不進 repo（art-style §3）。
