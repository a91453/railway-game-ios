| 特徵 | 製作判讀 |
|---|---|
| 類別與編組 | 傾斜式電聯車；外向 TED 兩節、TEM 四節、TEP 兩節。八節次序為 TED–TEM–TEP–TEM–TEM–TEP–TEM–TED，屬展示重建假設。 |
| 側／前／俯／斜 | 長直窗帶與窄腰線；車頭頂部先下壓、兩側肩部仍寬，再收成低而圓鈍鼻。正面深色風擋下有白色鼻罩。 |
| 頭尾／左右 | 頭尾幾何對向；兩側門窗目前鏡像補全，不能當作另一側已確認。中車兩端為風琴端面，無駕駛窗／頭燈。 |

| 設備 | 各節兩具雙軸轉向架及兩個屋頂空調箱；TEP 增設支架與集電弓。精確下部設備與電氣位置資料不足。 |

配色：霧白車身、藏綠細腰帶、深色窗帶；以既有專案色票製作，沒有紅色。既有通勤車只在包內作同尺度色票與密度比較；車體結構另行建立。

完整私有包：`Railway/game-art-previews/docs/art/temu1000-2026-10-25/`。原生各四單元、八節組合及比較車註冊於 `Map3DModelPack`。`Map3DTrainSets.temu1000()` 將此原生單元接到既有 `taroko` 營運顯示；前置 #1227 已合併，合併公開 PR 後，遊戲 3D 畫面的該型列車會使用新造型。GameCore 車種、運行與存檔不變。#1227 的程序列車已在 main；本分支只更換 `taroko` 顯示模型，不覆蓋其他已接受車種。

## 外觀驗收（原生模型實際渲染）

`previews/overview.png` 與每件七向 PNG 均從最終原生 M3DM 渲染；白模／剪影為同一八節模型的顏色覆寫。首次版先保留於私庫 `history/initial/`，同相機、同公尺尺度前後比對為 `previews/before-after.png`。初版整片藍側板、內陷不可見的風擋與過尖車鼻不合格；修訂後才輸出最終素材。

| 判定 | 觀察與限制 |
|---|---|
| 已符合 | 八節、外向頭尾、中車無駕駛窗、兩具雙軸轉向架／節、TEP 集電設備、白色下半車身與窄綠線，從側、正、俯、斜四向可辨。 |
| 仍不符合 | 窗框仍是方形、車頭正面燈罩及下鼻罩簡化，風琴在全編組比例下較黑；車鼻尚非工程級曲面。這些在本版保留為遊戲風格簡化，不能宣稱照片級相似。 |
| 資料不足 | 另一側門窗、實車節長／軸距、集電弓確切車號、隱藏設備、各節功能順序。八節和 2.9 m 取自專案參考，節距 23.9 m 為比例推估。 |

技術驗證以私庫 `verification.json`、`glb-import-verification.json`、`package-verification.json` 與 CI 狀態為準。Linux WebGL／Blender 不代表真機 Metal、效能或動畫驗證。其他車種及 GameCore 未改。
