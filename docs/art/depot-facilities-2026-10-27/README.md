# 3D 機廠：檢修庫與彰化轉車台（決策 441）

`tools/map3d-preview` 拍的（WebGL，不是 Metal；14:00 的光線，有太陽陰影）。實機的樣子要在 TestFlight 看。

- `overview.jpg`：
  - 左上：改之前，機廠被當成一般車站，旁邊是旅客站房與站前商店街。
  - 右上：改之後，同一個機廠旁是三股道的檢修庫，庫門朝側線接回正線的那一頭。
  - 左下：同一處遠看，檢修庫換成一個方塊。
  - 右下：彰化新局，轉車台在扇形車庫（真實建物足跡）圍出來的空地裡，橋對著車庫中間。
- `depot-close.jpg`：右上那張的原尺寸。
- `changhua-turntable.jpg`：右下那張的原尺寸。

機廠那張的世界：測試用兩鎮地圖的一條線，在東端用機廠工具拉出 3 股側線（`MAP3D_WORLD=depot`，預覽工具的暫時世界，沒有提交）。改之前的圖是同一個世界，只把那一站設回一般車站。彰化那張：`GameWorld.newGame` 以北緯 24.0857、東經 120.5401 開局，讀 App 的底圖與建物足跡（`MAP3D_BASEMAP=1 MAP3D_FOOTPRINTS=1`）。
