# 夜裡的列車統一亮燈（決策 449）

同一個工具 `tools/train-models/` 拍的，23:00（城市的燈全亮）；左邊是改前（main），右邊是改後（`run.sh OUT --night-lights`）。

- `overview.png`：斜看。EMU800 頭車、尾車，通勤電聯車駕駛車，E500 機車，太魯閣尾車，普悠瑪中間車，C381 尾車，E500 客車尾車。客室窗亮起來了，駕駛室的窗和機車的窗不亮。
- `ends.png`：車端。頭車看前面（白色頭燈），尾車看後面（紅色尾燈）。太魯閣尾車原本後面也亮著白燈，改後只亮紅燈。

工具一次拍一節車：頭車亮頭燈、尾車亮尾燈。遊戲裡是看整列車在哪一頭，所以車子轉過來時燈也跟著換（例如通勤駕駛車掛在最後、推拉式後面那台機車），這部分由 `Map3DTrainLightsTests` 檢查。
