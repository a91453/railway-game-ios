## 修訂與外觀自檢

第一版真正模型保留，先記錄不合格處再動幾何。新版首輪四向配色／白模／剪影已實看，補修側窗中柱可見性與屋頂／走行支承後，最終全部重出再看；總覽、七向與viewer均讀同份最終原生。

- 已改善／自檢成立：兩組完整三軸側架、軸箱及彈簧支承，分區屋頂、單臂弓正面上臂、較圓的風擋／罩／燈座，端梁與連結器體積、側窗分片及扶手；長平側板及遊戲霧面色票保持。
- 仍簡化：駕駛室內裝、精細煞車／管線、輪架細部、弓頭及高壓設備機構；不稱工程復刻。
- 資料不足：精確軸距／前後懸、另一側全設備序列、隱藏接線與內構。
- 未有使用者接受本版；無相似度分數。模型與示意照片不當作實車工程尺寸。

## 真前後、保護範圍與故障反例

`revision-1-vs-2.png`／`revision-1-vs-2-far.png` 直接讀真正8127c765前版；共同相機中心、方向、尺度、材質、光照及背景。另保留原main前後、真正首輪未提交初稿比較、E200／EMU3000同尺度風格比較。`equipment-details.png` 是有標示的局部圖，不冒充完整七向。

`revision-audit.py` 檢查真正輸出：近／遠原輪胎528／336三角及中央側板4三角多重集合保持；X／Y包絡保持；真正殼連通體沿縱向201切片的上下輪廓差0m。這只證明指定輪胎／側板與側面上下包絡保持，**不等於全車頂點、全配色或全部投影像素不變**。

新可見缺陷檢查：每個轉向架外側實際三角在Z=0.84m的連續投影（第一版約0.28m散開，新版4.60m連續側架），及Z=5.10m的上弓臂正面寬（第一版約0.214m，新版0.070m）。真正第一版近遠共先紅10項；新版通過。刪除實際側架三角的反例仍會被拒收。這些是本車虛擬幾何檢查，不是照片相似度或工程公差；Swift回歸同樣讀實際三角切片。

`support-audit.py` 以真正玻璃面背襯與向外射線、12輪胎連通體輪底／上淨空、屋頂及轉向架實體取樣支承路徑分開檢查。僅排除辨識到的真正窄雨刷預期遮擋，不放寬車殼遮玻璃；真連通玻璃外移／埋入、升輪、拉長燈、移開真正輪架與缺面／反面反例拒收。支承路徑65mm／每體最多40點六方向是模型取樣容差，不是全表面碰撞或懸吊驗證。
