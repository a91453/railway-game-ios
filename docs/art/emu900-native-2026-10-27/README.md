## 來源與版本判讀

本次附件共八張：1 為側面插畫（標示 CC BY-NC-ND，只觀察，不描圖或散布圖素），2、3 為模型商品照片，4–8 為實車照片。附件實車顯示原始銀灰／綠腰帶 EMU900 外觀，最後一張標示2021首航；照片本身不足以確定每張的車組、批次或後續改造狀態。選用2021初期外觀作一致目標；商品與插畫不作工程比例依據。沒有現場量測，不稱「實測」。

與EMU800區別：EMU900寬圓立面及大面風擋、上兩圓燈與下側各兩燈、中央淺色下緣、外露連結器及排障器；腰帶在車頭兩肩升起，中央沒有EMU800黃弧。每側三組雙扇客門，端車另有乘務門。十輛5M5T、3/6/8車各一弓，並非EMU800八輛鏡像編組。不得沿用其車殼、門位或設備站位。
