## 模型與重建

獨立六設備角色近／遠／light正反36單元；ED9256/5380/2188、帶廁所EM5080/2836/908、SIV EM5040/2792/880、乘務EM4992/2780/868、壓縮EP5264/3020/1092、無障礙EP5176/2964/1052三角（近/遠/light；以最終manifest為準）。十輛59448/33800/12056三角，以M3DAssembly嵌入合法單元，無提高單件15000或共用預算。尾半單元已原生旋轉，assembly只平移，無二次旋轉與縮放。名義連結節距合計205.560m；模型車殼端車21.10、中間19.70m、空調殼頂3.990m（近景格柵細節最高3.999m）與展示升弓約5.180m為本模型幾何值，不能稱官方殼長或工作升弓規格。官方表列連結長度未有原始工程圖釐清，未稱現場實測。

第二版原始銀灰轉既有concreteWalls[2]較亮柔灰#D3D4DA（第一版#C9CCD5）；空調機殼保留concreteWalls[0]#C9CCD5、shopAwnings[0]綠松#3E8C8C、藏青#262C57罩面；glass為既有glazing shade0.62（第一版0.53），橡膠與機械保持功能深色，燈用既有tunnelLamp。無紅色、黃弧、品牌、車號與目的地文字；改色不構成免侵權保證。

真第一輪candidate2858da27保留，不冒稱已接受前版。第一版建模時沒有同車型獨立原生前版；本輪真前版是原交付8ebfd9fd，直接讀其近遠原生做revision-before-after；before-emu900另外保留base真set-emu800-head，一般通勤既有EMU800顯示，明標「接入前顯示」，不冒稱EMU900前版。E500第三版及EMU3000第五版風格比較直接讀固定私包原生，未用最新配方重造已接受色。

[重建工具](../../../tools/emu900-native/README.md)。Swift6.4、warnings-as-errors、Node/Chromium WebGL2、Python NumPy/Pillow及Blender4.3.2；原生公尺+X前/+Y左/+Z上，輪底Z=0。GLB轉+Y上僅一次。工具沿用已交付格式／渲染／驗證方法，車殼、鼻形、門窗／設備與本型順序另建。

## 外觀逐項自檢

已符合（自檢，不等於使用者接受）：近遠側／正／俯／斜配色、白模與剪影均實看；六角色三組雙門與不同端部窗、雙空調、3/6/8弓方向、頭尾與左右差異、同尺度風格與接入前顯示比較。已修下鼻過方、肩帶過窄及鼻部返回面斷帶，第一版第三輪曾全量重出；第二版進一步撤回「罩面已圓順」自評，修真正曲面色界及圓裙／凹槽，補主要輪架；玻璃射線三命中逐真三角確認為雨刷，例外只限薄橡膠與2.10–2.30m實際高度。

仍有偏差／簡化：鼻罩圓角採分面，細節密度低於工程模型；轉向架、底部機器與支座／走線簡化，沒有內裝。資料不足：全部左右管線與機器精確站位、廁所背面細節、車體殼長／轉向架中心工程尺寸、官方3.990/4.080m高度定義差異；未見區域的外觀站位只稱推估。不捏造相似度、工程精度或使用者認可。
