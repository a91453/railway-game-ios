# STATION-FOOTBRIDGE-SIGNS：跨站天橋、地下道入口、月台轉乘指示牌（決策 936）

2026-11-23，工作串「天橋與轉乘指示牌」。分支 `claude/station-footbridge-signs`。接的是 `docs/handoff/MODELS-145-stations.md` 「還沒做的」第 1、2 項。

## 做完的

`docs/decisions/936.md`：地面站的天橋（台／港／日三款）或地下道入口、月台小物避讓、島式月台的轉乘指示牌（只有色塊，沒有字）。

## 還沒做的

1. **真實車站是天橋還是地下道**：現在只看月台長短（放得下 16 m 樓梯塔就是天橋）。OSM 的 `highway=footway` + `bridge`／`tunnel` 可以分辨，要從整包擷取讀（`tools/real-world-population/README.md` 的做法），還沒有工具。
2. **轉乘說明的文字**：`StationTransfers` 的同層換月台仍寫「走天橋」；畫成地下道的站文字沒有跟著改。文字是玩家看的字，要另外決定是不是照畫的改。
3. **牌面的字**：派工說不放站名文字，現在只有箭頭與色塊。要加路線代碼的話用 `Map3DBoardGlyphs`，位置在模型的 `slots.json`。
4. **沒有頂蓋的地下道入口**（`station-underpass-stair`）沒有寫進來；月台很窄或有雨棚蓋住的地方可以用它。
5. **擴建成大廳的站**（雨棚 95%）與很短的月台沒有天橋也沒有地下道。可以考慮把入口放在雨棚下（要用沒有頂蓋的那款）。
6. **沒看過的**：這個環境沒有 Metal 與實機，天橋和電車線、號誌、月台端的相對位置只有測試量過，請在 TestFlight 上看；夜間天橋沒有亮燈（模型沒有發光面）。
7. 一般站房（月台後 7 m）不會碰到塔；研究站房的站整站不畫天橋。站房緊貼月台的新站型若出現，要把它的外框加進 `addStationCrossings` 的避讓。

以上都還沒評分進優先清單，請遊戲規劃排。
