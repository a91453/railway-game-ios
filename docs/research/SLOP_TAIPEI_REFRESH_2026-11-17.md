# 台北兩個 slop-taipei 包：還沒進遊戲的功能（2026-11-17）

作者 11-17 問：參考庫裡的 Taipei 有很多功能還沒進遊戲。指的是參考庫 `Railway/slop-taipei-reference-clean/`：兩個公開專案的清理包，都是 [mrdoob/slop-newyork](https://github.com/mrdoob/slop-newyork)（MIT，Copyright (c) 2026 Mr.doob）改成台北的 three.js 網頁場景，不是本作的東西：

- 台北市中心：[shwang1979/slop-taipei](https://github.com/shwang1979/slop-taipei) `1d70708f`（和 10-28 一樣，沒有更新）。
- 臺北盆地：[hebe13579/slop-taipei](https://github.com/hebe13579/slop-taipei)，參考庫 11-17 更新到 `6d0ff9a0`。§22.19 比對時是 `9d1a7055`、清理包是 `a467e6e7`；中間多了 445 個提交（10-28 到 11-16 的更新紀錄在包裡 `docs/release-notes/`），還沒有人評過。

照本作的規矩：只拿規則、數值與做法，模型用本作自己的零件與色票重做（地標照決策 370／457，建模先交本地工作室，見 model-look §1）；資料（OSM 等）照各自授權寫進 `DataSourceCredits`；不拿真實品牌招牌、不拿照衛星影像量的值。

基準：遊戲 `main` `3c29217`。讀了 HANDOFF、NEXT_PRIORITIES §22.19 與 §29（到 §29.20）、BACKLOG_AUDIT_2026-11-17、11-15 的未整合盤點、決策 445／446／447／457 等，並在 `Sources/GamePresentation` 逐項搜程式。全部是讀程式與文件的判斷，**沒有在遊戲或瀏覽器裡實際跑過**兩邊的畫面。

**不做**（參考包有，但不適合本作）：
- 玩家開車、碰撞、穿牆模式、手把、直升機：本作是經營鐵道，不是開車遊戲。
- 俯視鏡頭（按 V）：遊戲本來就有 2D 地圖與 3D 傾斜鏡頭。
- 車流數量與畫面距離的滑桿：遊戲照畫質設定與效能預算自己定。
- 只拉一小區的快速開機：開發工具；PERF-3D-FIRST 要量的是整張地圖。
- 真實連鎖品牌的招牌、照衛星影像量的值：§22.19 已定不拿（參考包 11-17 版本也已移除品牌圖）。
- 松山機場標線：§22.19 已定先不做。

### 3.1 五方

- **玩家**：
  - 淡水線的高架站與台北新地標，是在台北放大地圖時最先看到的東西（4）。
  - 河岸、公園、空橋、學校是背景，看得到但不會特別找（3）。
- **鐵道迷**：
  - 圓山式高架站、劍潭的龍舟站是台北捷運最有名的站體，現在 3D 裡淡水線的高架站沒有自己的樣子：沒買的站不畫（REAL-STATIONS-3D），買了的用通用站型（5）。
  - 堤防是淡水線、板南線沿河時窗外的景（3）。
  - 街道聲裡號誌的滴答聲之外，和鐵道關係不大（2）。
- **開發**：
  - 101 換色只是夜燈表加一個照星期的顏色（5）。
  - 堤防、空橋是 OSM 的線加一條牆／一條橋，和現有的路與高架同一套（4）。
  - 高架站要先交工作室建模，放置可接 REAL-STATIONS-3D 的站點（3）。
  - 地標一棟棟建模（2）。
  - 街道聲要接 `AVAudioEngine` 的即時合成（2）。
- **美術**：
  - 開花樹最能改變公園的顏色（5）。
  - 車站、地標、學校、地標橋都是辨識度高的形狀（4）。
  - 堤防、空橋是灰色長條（3）。
- **音樂**：街道聲是這批唯一的聲音項目（5），其他都沒有（1）。

### 3.2 前置與注意

- **TPE-MRT-ELEVATED**：
  - 照常設規則，先寫工作室派工單：照片、尺寸、色票格位；先找作者舊版與私有庫有沒有類似的站。
  - 參考包的四種站型只當事實清單（它們是一塊塊頂點色的三角形，不搬形狀）；外觀照 model-look 三輪。
  - 這是新外觀，總覽圖給規劃看過才合（決策 482）。
  - 可當 REAL-STATIONS-3D 的第一批，先只做淡水線高架段。
- **101-NIGHT-WEEKDAY**：
  - 顏色與星期的對應要找 101 官方或可信的來源，寫進決策。
  - 和「地標夜裡窗不亮」（§29.15，2.55）同一處，可以一起做。
- **LEVEE**：碰到決策 678（基隆河兩岸地面高度），要先讀。
- **FLOWER-TREES**：等 NATURE-BASE（811）合併，自動種樹用同一套。
- **CITY-SOUND**：照 music-review skill 量響度與聽膩；排在 MUSIC-REFRESH 之後。
