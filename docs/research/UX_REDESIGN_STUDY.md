# 研究：UI/UX 改版第二輪（地圖優先、橫向、地區外觀）

2026-10-09。作者在 TestFlight 實機上看了遊戲，覺得「玩家來玩會不想玩，而且擋住很多」，要先研究參考庫與別人的作法再決定方向。這份是當時的研究紀錄：參考庫裡可以拿的、別的遊戲與開源專案的作法、作者做的決定，以及還沒做的。實作的規則寫在 ARCHITECTURE 決策 106–113，配色寫在 [`UI_THEME.md`](../UI_THEME.md) 的「地區外觀」。

截圖不放進 repo（repo 是公開的）；下面以文字描述，並註明出處。

## 1. 實機上的問題（改版前）

作者給的三張 iPhone 直拿截圖：

- **鋪軌時地圖只剩約三分之一。** 抽屜固定佔畫面高度的 42%，地圖停在抽屜上緣（為了不擋 Apple 地圖的標誌），上面還有兩行的狀態列，和一條往下疊的提示。抽屜同時攤開十幾個工程選項（鋪設／月台／拆除、地面、高度、平順曲線、緩和坡度、清除、吸附），而最大的「鋪設軌道」在選好兩點之前一直是灰的。
- **經濟與路線一打開就蓋住半個地圖。** 路線面板像表單：在地圖上選站、加入選取的車站、移除最後一站、建立路線。
- **工具列太擠。** 一排六個工具加復原與收合，字是最小的 `caption2`，放在毛玻璃上難讀。

## 2. 結論

參考庫、別的遊戲、開源專案三方面的結論一致：

1. **地圖鋪滿畫面，介面只浮在邊緣**，沒有東西把地圖往上擠。
2. **建造時整個介面換成建造模式**：只留這個模式要的按鈕，確認、取消與費用放在手指旁邊，不放在遠處的面板。
3. **資訊直接長在地圖物件上**（狀態泡泡、選址時的腹地與人數），不必翻面板。
4. **訊息一次一則、會自己消失**，重複的不疊加。
5. **工程選項是預設值**，收進預設關閉的「進階」裡。

## 3. 參考庫（`a91453/railway-reference-private`）

用 Playwright 在 iPhone 393×852 與 iPad 1180×820 實際開了能跑的畫面，共 29 張截圖（存在研究當時的工作區，沒有放進 repo）。

### 3.1 作者的鐵道地圖網站（`Railway/site_archive_clean/`）

最接近我們要的：手機優先、全螢幕地圖、薄薄的介面浮在上面。iPhone 上地圖約佔 85%。

- **頂端約 52 px 一列**：站名牌樣式的 logo（`.plate`）、時鐘膠囊與即時資料狀態點（`#clock`、`#statBadge`）、路網選擇（`#gtabOne`）。
- **右側一欄 44 px 的方形按鈕**（`#randBtn`、鎖定、`#viewSettingsBtn`）。
- **底部五個分頁**（`.tabbar`）：查詢、探、最愛、旅、更多；上方置中一顆 `1×` 播放膠囊（`#pp`）。
- iPad 用同一套，面板改成右側約 30% 寬的側欄。

可以拿的：

1. **物件小卡取代半屏面板。** 點列車開 `.follow-panel`：手機上 240 px 寬、在左下、分頁列之上，寫車號、時速、下一站與到站時間、一顆主要按鈕、進度條；`×` 關閉，地圖照常可以操作。
2. **分頁內容用底部抽屜**（`.more-sheet`，最高 76dvh、有把手）；進階的觀看設定是分頁的彈出窗。
3. **通知**：`showToast()` 在上方置中，最多 3 則、每則 5 秒，點別處全部關掉（`dismissToastsOutside`）；另有一個低調的角落通道（`#toastsCorner`）。
4. **閒置 5 秒淡出介面**（`ambientIdleReset()`，用在沉浸模式）。
5. **第一次進入的說明卡**（`#howtoWrap`）：三列圖示說明、一顆大按鈕、「不再顯示」。
6. **收集的回饋**：完成一趟後，集章、成就、車庫的提示相隔 700 ms 依序出現（`announceCollections()`）。

視覺：米白 `#FFFDF6`、藏青 `#2A4A73`、紅 `#D23C2A`、金 `#D2A12A`；系統字；實體的硬陰影（`--shadow-navy: 0 3px 0`）讓按鈕有按得下去的質感。作者決定**借用造型元素（膠囊、硬陰影、站名牌），不用它的顏色**（第 7 節）。

### 3.2 Ci 城市捷運（`Ci/reference_snapshot/`）

Mini Metro 式的捷運建造遊戲，地圖 100%。活的遊戲開不起來（缺版本參數的檔案、要登入與地圖金鑰），只用真的 DOM 與 CSS 不跑 JS 畫出介面的佔位。

- **底部一條透明的圓形圖示列**（`#bottombar`，手機 32 px），多的收進「更多」（`#nav-btn-more`）；右側一欄指北、縮放、圖層（`#custom-zoom-control`）；尖峰時段頂端一條 2 px 的金色條（`#peak-bar`）。
- **建造回饋是浮動膠囊，不是面板**：預估費用膠囊（`.metro-cost-preview-pill`、`showMetroCostPreview`）、鋪線時的距離（`.place-distance-hud`）。不能蓋時用通知說原因，不放灰色按鈕。
- **通知只留最新一則**，旁邊顯示「+N」與展開鈕（`renderNotifBox`）；擁擠通知每站每線 10 分鐘冷卻。
- **一次只開一個面板**（`openPanel` 先 `closeAllPanels`）。
- **路線的站點條**（`renderLineInfoPanel`、`#line-info-pipeline-bar`）：路線色的直條，列車點在上面移動（`updateLineInfoTrainDots`），尖離峰列車數用加減鈕調。→ 決策 110、113。
- **聚光燈教學**（`startTutorial`、`showTutorialStep`）：12 步，框出真的控制項，卡片放在上方或下方。（本專案的教學早已照它做，決策見 `UI_INTERFACES.md`。）
- **音效**：按鈕帶 `data-metro-sfx`，12 套音效主題；照顧「減少動態效果」。

### 3.3 模型鐵道模擬器（`Simulator/reference_snapshot/`）

- **選取物件時浮出一條動作列**（`.canvas-selection-actions`：名稱、−1°、+1°、複製、貼上、刪除）。
- **進階設定預設關閉**：「控制」分頁開一個有把手的抽屜（`.mobile-sheet-handle`），高度與坡度都在裡面。這正是我們 42% 抽屜的解法。→ 決策 107 的「進階選項」。
- 零件庫是手機左側抽屜，分類標籤加卡片上的「+」；列車按鈕開彈出窗，主要動作「開始運行」是橘色。

### 3.4 MapBuilder（`MapBuilder/reference_snapshot/`）

開不起來（要 Firebase 與 Mapbox），只讀了靜態的程式與 CSS。

- **點車站旁邊跳出捷徑**（`Shortcut`，`renderButtons()`）：最多 3 個路線色鈕，最近用過的排第一、其次最近的路線，跳過已經停這站的；另有轉成經過點與刪除。→ 決策 112 做了「列出停靠的路線」，加入路線的捷徑還沒做。
- **點地圖就加一站**，新地圖延遲出現提示「點地圖加車站」。
- 路線面板：7 欄的顏色格（`.Line-colors`）、站點列表的地上地下條、反轉、複製、刪除、轉乘步行時間。

### 3.5 City-world reference（`Railway/city_world_reference/source/`）

開放世界遊戲，手機優先的 HUD。最好的通知寫法在 `notify(msg, ttl, kind)`：

- 種類與圖示（好、壞、任務、資訊）。
- **顯示時間隨長度**：`min(9, 3.2 + 字數 × 0.09)` 秒。→ 決策 106 的 6–10 秒。
- **重複的訊息不疊加**，延長並跳一下（`bump`）。→ 決策 106。
- 觸控上最多 1–3 則、和目標重複的不顯示、說明卡顯示時先排隊、保留最近 14 則紀錄、伴隨音效。
- 其他：一行持續的目標句（`.hud-obj`）、只在需要時出現的兩個動作槽（`.hud-prompts`）、超出再彈回的進場動畫。

### 3.6 RailwayCore（`Railway/railway_game_reference_clean/`）

只有模擬核心，沒有介面可以參考（唯一的介面檔是雙指縮放 `touch_pinch_zoom.js`）。

## 4. 別的遊戲

商業遊戲只參考作法，程式與美術都不拿。TheoTown 與 SimCity BuildIt 是作者提供的實機截圖（主畫面、建造選單、鋪路、放建物、點擊與長按）；其他是評論與訪談。

### 4.1 TheoTown

- **地圖鋪滿，按鈕在角落**：主畫面只有左上的錘子、左下的地球與齒輪，地圖約 95%。教學是一個小人加對話泡泡，不蓋地圖。
- **建造選單選完就關**，回到滿版地圖；大圖示配大字。
- **建造模式換掉整個介面**：左上寫目前的工具（「Dirt road, 0」）與小圖例；右側直排工具列（✕ 離開、連接道路、裝飾、橋、往上），每顆旁邊有字，開著時字變青色；**蓋過東西後才出現「Undo (n)」**。
- **只在需要時才問高度**：點下第一點，才浮出往上／往下。
- **滴管**：點現有的道路或建物，就沿用它的種類。
- **地圖上直接標示**：地形高度數字、道路依車流上色、放公車站時涵蓋範圍亮綠、放公園時整張地圖變成適合度色塊（綠好紅壞）。
- **便宜的點一下就蓋**，用復原收回；狀態列（日期、暫停、三段速度、金錢與收支、小地圖）在底部，建造時也不收。
- **只有點擊**：點建物在畫面中央跳出對話框、地圖變模糊（最擋畫面）；但對話框裡的「Influences」關掉對話框、改在地圖上用顏色畫出影響範圍，值得學。
- **不要學**：建造選單分十類、拆除八種，一件事要點好幾層；玩家評論最常抱怨介面笨重、要點太多下。

### 4.2 SimCity BuildIt

- **地圖約 85%**，元件靠四角與邊緣，中間空著。
- **狀態直接放在建物上方的泡泡**，點泡泡就處理。→ 決策 109。
- **事件用角色頭像加一句話通知**，幾秒後消失。
- 左下功能入口、右下建造盤，兩組都能用 ▼ 收起；按鈕上有數量角標。
- **建造模式**：上方置中模式標題；右側直排三顆（建造、升級、拆除），平常的按鈕全部消失；底部種類選單，開始拉線縮成一行；預覽路徑兩端插旗，**✗ 與 ✓ 就在路徑旁**。→ 決策 107（我們的 ✓ 上另外寫費用）。
- **放建物**：整張地圖褪色、只有能蓋的地方亮綠；**預覽上寫放在這裡的效果**（「+0 👥」），拖到別處跟著變；四周有可以拖動的箭頭；每個類別有自己的顧問角色。→ 決策 108。
- **點擊是看、長按是改**：點一下只在建物頭上浮出名字與加成的小標籤；長按把建物拿起來移動，同樣有亮綠範圍、效果數字與 ✓／✗。
- **不要學**：左上角指標爆版；同時十幾個紅點讓人麻木；三種貨幣與購買鈕這類付費設計；道路難拉（EA 自己說試了很多次）。

### Apple 的準則

- 按鈕的點擊範圍至少 44×44 pt；文字最小 11 pt（`caption2` 就是下限），狀態列建議 13–17 pt。
- 工具列避免擁擠，最多三組，多的收進「更多」；分頁列是切換畫面用的，不放動作，最多五個。
- 不要在畫面最底邊放拖曳手勢（會和系統手勢衝突）；遊戲要全螢幕、選單不蓋內容。
- WWDC26「Make your game great with touch」：中間留空、常用的在拇指旁、**玩家現在不能用的控制就藏起來**。

## 6. 方向的決定（作者）

1. **iPhone 只做橫向，iPad 四個方向都支援。** 一開始建議兩個方向都支援（台灣細長、直拿適合看），看了 TheoTown 與 BuildIt 的實機畫面後改建議只做橫向：這次的版面本來就是橫向設計，兩個方向等於每個功能做兩次，同類遊戲也都只做橫向。作者擔心以後不只做台灣；各國的形狀有細長、有偏寬，沒有一個方向配得上全部，玩家又多半放大在一個都市圈，所以理由反而更充分。作者同意。
2. **支援各國的五條規則**（寫進決策 106）：用前後（leading／trailing）不寫死左右；名字長短要能縮字或換行；地區的樣子只透過 `RegionStyle`；金額只透過 `moneyText`；地圖從哪裡開始由劇本決定。
3. **視覺：App 的主題色，加上網站的造型元素；台灣風格做成可替換的「地區外觀」，像以後日本有另一套。盡量不用網站的顏色**，改用查得到的那個國家的鐵道代表色，找不到才用網站的近似色。

這次沒做、做其他國家時才要做的：多語系（現在每段文字是英文與繁中寫在一起）、其他國家的人口資料（要先確認資料集的授權）、各國的建設成本與票價。

## 7. 台灣鐵道的代表色

台鐵與高鐵都**沒有公開標準色的色碼**（找不到企業識別手冊），所以下面的色值都是近似值，要在實機上確認。

| 顏色 | 出處 | 用在 |
|---|---|---|

參考庫的列車資料原本就有車種色：自強 `#C0392B`、莒光 `#E8792B`、區間 `#2E6FB0`、區間快 `#16A085`、高鐵 `#E85D0D`。這些是路線與列車的資料顏色，照原樣保留，不當介面色。

以後的日本外觀照同樣做法：例如 JR 各公司的代表色、白底加路線色條的站名牌；只換 `RegionStyle`，不動介面。

## 8. 還沒做的

依研究時的優先順序：

- **「選取」拿掉，改成一個「建設」入口**：平常在地圖上點就是選取；「建設」展開軌道、車站、建築、分區、拆除。會動到教學與 UI 測試（`tool.select`）。
- **建造模式的側邊工具列**：右側（尾端）直排最多 7 顆：鋪設、月台、拆除、橋／隧道、上／下、吸附，與有東西可以復原時才出現的「↶ n」；上方一行模式標題「鋪設軌道・$1,234 ✕」；其他收進「⋯」。
- **點擊看、長按改**：點車站或列車，頭上浮出小標籤（站名、候車人數、路線色；車次、下一站、誤點），再點才開小卡；長按進入編輯（加月台、拆除、改名，同時畫腹地圈）。長按一定要有按鈕可以代替（VoiceOver）。把蓋好的東西搬走需要 GameCore 的新指令，另外做。
- **影響範圍畫在地圖上**（TheoTown 的 Influences）。
- **點車站加入路線的捷徑**（MapBuilder 的 `Shortcut`：最多 3 個路線色鈕）。
- **放建物時不能蓋的地方變暗；便宜的點一下就蓋、貴的要確認**。
- **滴管**：點現有軌道就沿用它的構造與高度。
- **建造時地圖上標示**：坡度、現有軌道的高度與構造。
- **小地圖**（右下，點了跳過去）。
- **站長角色**：用一句話報告事件，教學也用同一個角色；需要美術素材，先用圖示代替。
- **按鈕上的數量角標**（例如「路線 2」：兩條路線沒有車），數量要節制。
- **遊戲感**：彈跳進場、硬陰影、尖峰時段的金色條、獎勵依序出現、開關與確認的音效；照顧「減少動態效果」。
- **第一次進入的說明卡**（網站的 `#howtoWrap`）。
