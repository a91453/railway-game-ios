# Threads 寫作 session 的交接

> 寫 Threads 貼文的 session 開工前先讀這份。換新的寫作 session 時，只要叫它讀這份，不用貼舊的對話。
> 2026-10-27 由寫作 session_01QAC77cR5wi8UFqoLxMDVH6 寫到 91.1（作者：「好」，同意把交接放進 main）。
> 每次換寫作 session 之前，開一個只改這份的文件 PR，把第 5 節補到最新一版。草稿本身照樣不 commit。

## 1. 這個 session 做什麼

寫作 session 用繁體中文寫《railway game ios》的 Threads 貼文。

規劃的排程「Threads 開發日誌（看進度）」看到上次交付之後有 3 個玩家看得到的 PR 合進 main，或發了新的 TestFlight，就開一個寫作 session 寫這段期間的 Threads 貼文（2026-10-27 起；作者：「排程要看每日進度我也不確定有固定時間發文」）：
- 一篇主文，下面幾則留言：🔧 修好的、✨ 介面和新功能、🚧 正在做、💬 常見問題。
- 主文和每則留言都不超過 500 字。
- 另外附 3 則短版。
- 不寫日期或什麼時候發，作者自己決定發文時間；寫要在實機上拍哪些圖、哪些影片。
- 交完在工作登記 #2118 留「Threads 草稿交付：涵蓋到 main <sha>」，下次排程從這個 sha 往後算，然後封存自己。
- 草稿寫成暫存資料夾裡的檔案，用 SendUserFile 交給作者。

## 2. 規則

- 貼文不寫程式或函式庫的名稱，不寫內部編號、決策號，也不寫「AI」寫了什麼程式。
- 照作者原本的語氣寫。
- 草稿不 commit、不開 PR、不發布。唯一的例外是換手前更新這份交接（見最上面）。
- 不動排程：「Threads 開發日誌（看進度）」由規劃管。
- 不跑 testflight.yml，不寫 `@claude`（會啟動 `claude.yml`）。
- 想知道開發進度，用 send_message 問規劃 session。它的 session ID 在工作登記 #2118（之前是 #1041、#1579）。
- **交稿前去除浮水印**（作者 2026-10-27：「記得每晚用threads發文的時候使用 https://github.com/guillaumemeyer/watermarks-remover 去除浮水印」）。這個工具是 MIT 授權，只用 Python 標準庫，規劃在 commit `5c180932a00c793261177f79aee21db8929f3fe2` 試過。
  1. clone 到暫存資料夾，鎖在這個 commit：`git clone https://github.com/guillaumemeyer/watermarks-remover <暫存>/wmr && git -C <暫存>/wmr checkout 5c180932a00c793261177f79aee21db8929f3fe2`。
  2. 每個草稿檔先去掉看不見的 Unicode 字元：`python3 -I <暫存>/wmr/skills/clean-user-facing-text/scripts/clean_text.py 草稿.md -o 草稿.clean.md --stats --no-normalize-spaces`。
  3. 交給作者的圖片或影片（例如 3D 預覽、截圖）去掉 C2PA、EXIF、XMP：`python3 -I <暫存>/wmr/service/scripts/clean_file.py 圖.png -o 圖.clean.png`。
  4. 交的是清過的檔案。在交稿訊息寫一行每個檔各去掉了什麼（`--stats` 的 `removed_count`），沒有就寫「沒有」。
  5. 工具的改寫步驟（Layer B）不做：主文照第 4、6 節作者教的語氣，作者自己會改定。
