## 0. 結論

- **下載得到。** 這台 Mac 上 curl 與瀏覽器都是 HTTP 200，不用金鑰、不用登入。雲端的 403 是雲端代理的事，不是資料關著。
- **條款允許商用、重製、散布，要標示來源，並有賠償條款；沒有寫到「改作」。** 減面、換色算不算改作，條款沒說（§2）。這一點留給作者判斷，或寫信問地政總署。
- **建議的用法：只拿「無貼圖模型」的外形做十來棟香港地標**（做法 a）。試了四棟：中銀大廈 35,329 面減到 2,488 面，誤差 0.2 m，檔案 130 KB，在遊戲鏡頭的大小下認得出來。
- **不建議**用貼圖模型或整片 mesh：一個圖幅就 0.2–5.6 GB，全港 3 TB 以上，而且貼圖是實景照片，和遊戲的畫風不合。
- **補 OSM 樓高（做法 b）不該用這一套**：要把全港 3,456 個圖幅（約 124 GB）都下載才量得到。樓高該先看地政總署的 Buildings（做法 c），那一份這次沒有下載。

網址格式（官方 Download API 頁 `https://3d.map.gov.hk/download-api` 自己產生的網址）：

```
https://download.map.gov.hk/api/3d-zip/<format>/<1:1000 圖幅號>.zip
```

`<format>`：`GLTF`、`FBX`、`MAX`（單體貼圖模型）；`GLTF0`、`FBX0`、`MAX0`（無貼圖模型）；`CESIUM`、`OBJ`、`OSGB`（航拍影像做的整片 mesh）。頁面上的網址後面還會接一個 `?key=`，不接也是 200。

### 3.2 單體貼圖模型（一個圖幅，11-SW-4A）

- 資料夾多三類：`GENERIC/`、`VEGETATION(TB)/`、`WATERBODY/`。建築與無貼圖版是同一批、同樣的面數（ID 尾碼 `C0` 換成 `A0`），多 `TEXCOORD_0` 與貼圖。
- 貼圖是 JPG：73 張裡 65 張 2,048 × 2,048、2 張 1,024²、5 張 256²、地形 1 張 7,513 × 6,013。九棟建築共 19 張、13.3 MB，約一棟 1.5 MB。
- 最重的是 `GENERIC`（街道家具、雜項合成一個模型）：776,819 面、52 張貼圖。
- 這個圖幅多半是海，代表不了市區。市區的大小看 §1 的 HEAD：無貼圖 43–57 MB 的圖幅，貼圖版是 534–954 MB。

### 3.3 整片 mesh（Cesium 3D Tiles，11-SW-4A）

- 1,390 個 `.b3dm`、274 MB，20 個子 tileset，八層細節（幾何誤差 300 → 0）。
- 每個 `.b3dm` 是一塊帶 JPG 貼圖的 glTF，`BATCH_LENGTH` 是 0：**沒有「哪一棟」**，建築、地面、樹、車都連成一張皮。
- 座標是 WGS84 的地心直角座標（ECEF），`gltfUpAxis` 是 Z。

### 3.4 座標

- 單體模型（貼圖與無貼圖）：模型自己的座標是公尺，x 向東、y 向北、z 向上；`.gltf` 的節點矩陣把原點放到 **香港 1980 方格網（HK1980 Grid，EPSG:2326）** 的 (E, 高程, −N)，高程是香港主水平基準（mPD）。例：`B345091526001063C0` 的平移是 (834510.94, 55.68, −815253.69)。
- ID 裡就有位置：`B` 後五碼是 E − 800,000、再五碼是 N − 800,000（公尺）。
- 對到經緯度：EPSG:2326 → WGS84，用標準的橫麥卡托反算加七參數基準轉換（PROJ 的 `+towgs84=-162.619,-276.959,-161.764,0.067753,-2.243649,-1.158827,-1.094246`），約 1 m 準。這次只用了粗略的平移（緯度 +5.5″、經度 −8.8″）找圖幅，中銀大廈差約 30 m，夠找圖幅，不夠擺模型。
- 整片 mesh 是 ECEF，要轉成經緯高再投到地圖。

## 4. 試做：做法 (a)，四棟地標

流程（腳本在 session 的 scratchpad，沒有進 repo）：讀 `.gltf` → 1 cm 併點、丟掉退化三角形 → 減面 → 平移到底面中心、地面 z 0 → 照面的朝向刷色（朝上是屋頂、最底下是基座、其餘是玻璃）→ 寫成 `.m3dmodel` 第 1 版 → `tools/model-look/shoot.mjs` 拍圖。

減面用的是 meshoptimizer（MIT，npm，只裝在 scratchpad）。**它沒有進 repo，也不是專案的相依**；真的要做，是作者同意加這個工具相依，或自己寫一個減面（§6）。

|---|---|---|---|---|---|
| 中銀大廈 | 35,329 | 26,424 | 14,984 | 0.01 m | 779 KB |
| 中銀大廈 | | | 6,000 | 0.03 m | 312 KB |
| 中銀大廈 | | | **2,488** | **0.2 m** | **130 KB**（加框線 692 面後 166 KB） |

| 環球貿易廣場 | 9,795 | 9,737 | 2,999 | 0.15 m | 231 KB（含框線） |

看圖改了三輪（中銀大廈；`model-look` 的規矩，圖在總覽圖下半）：

1. **第一輪**：玻璃色照高度漸層、每 3.8 m 一條深淺帶。毛病：減面後一個面很大，顏色照三角形的中心算，同一片牆被切成深淺不一的三角塊，看起來像摺紙。
2. **第二輪**：同一種朝向一個顏色，基座只算整個三角形都在底部的。牆面乾淨了，但整棟是一塊藍灰，中銀最好認的白色斜撐不見了。
3. **第三輪**：在兩片玻璃面夾角超過 18° 的稜線上加 1.2 m 寬的白色細條。中銀的三角稜線與斜邊出來了，在遊戲鏡頭的大小下認得出是中銀；另外三棟的收邊與翼牆也有線。

還不對的地方（照實寫，這是研究試做，不是成品）：

- 中銀大廈平面上的 X 形斜撐（不在稜線上的那幾條）沒有；玻璃沒有樓層線。
- 國際金融中心二期減到 3,000 面誤差 2.8 m，頂上的爪形冠變鈍；這一棟要留 5,000–6,000 面，或冠的部分單獨少減。
- 顏色是照照片目測的近似色，不是 `Map3DPalette` 的；夜裡的燈沒有做。
- 圖是 `tools/model-look` 的畫法（正投影、打平的光），不是 Metal、不是 App 裡的畫面；沒有放到香港地圖上看和周圍 OSM 建物的關係。
- 總覽圖要作者或遊戲規劃判，不是做的人自己判（決策 685）。

**建議的先後**：

1. **(a) 先做**，十來棟：環球貿易廣場、國際金融中心二期、中環廣場、中銀大廈、長江集團中心、滙豐總行、中環中心、會展中心、尖沙咀鐘樓、香港文化中心、青馬大橋（在 `INFRASTRUCTURE/`）。前五棟的圖幅與 ID 在 §3.1；其餘的圖幅要照 §1 的編號算了再認。
2. **樓高走 (c) 的 Buildings**，另開一張研究單先下載一份、看有沒有高度欄與涵蓋率，再決定。(b) 用 3D 模型量樓高是繞遠路：同一個機關已經把高度放在 Buildings 的屬性裡。
3. **貼圖模型與整片 mesh 不用。** 3D-BIT00 也先不用：無貼圖模型已經是 glTF、一棟一檔，3D-BIT00 的格式要多一道轉檔。

五個角度（這個建議）：

- 玩家：香港地圖一打開，維港兩岸有認得出來的幾棟樓；其餘建物照舊，App 只大 2–3 MB。
- 鐵道迷：外形來自地政總署的測量模型，位置是 HK1980 座標換算的，不是照照片捏的；來源列在資料來源。九龍站上面就是環球貿易廣場，機場快綫的畫面會對。
- 開發：一棟一個 `.gltf`，工具只要讀檔、併點、減面、寫 `.m3dmodel`；GameCore、存檔、golden 都不動。要決定的是減面工具（相依或自己寫）與改作條款。
- 美術：只取外形，顏色刷遊戲的調色，不帶實景貼圖，和台灣那邊的地標同一種畫法；每棟照 `model-look` 看圖三輪。
- 音樂：無。

## 6. 工作量與要作者決定的事

做法 (a) 估一個實作 session、一到兩個 PR：

1. 工具 `tools/hk-landmarks/`：讀 `.gltf`、HK1980 → 經緯度、併點、減面、刷色、寫 `.m3dmodel`；輸入是圖幅號與模型 ID 的清單，原始檔下載到 repo 外，只 commit 成品與來源紀錄（圖幅、ID、修訂日、sha256）。
2. 十來棟各自減面、刷色、看圖三輪（`model-look`），每棟 2,500–6,000 面。
3. 接進香港地圖：地標的位置表、蓋住底下的 OSM 足跡（台北地標的做法）、遠景的替身盒、資料來源一行（兩種語言）。
4. 截圖驗收是第三級（新的 3D 模型，遊戲規劃看過才合）。

要作者決定的（照 CLAUDE.md 留給作者的那幾類）：

- **改作**：條款沒有明寫可以改作（§2）。照用，或先寫信問。
- **減面工具**：加 meshoptimizer（MIT）當工具相依（像資料工具的 pyosmium），或不加、自己寫一個減面（多半天到一天，品質要另外驗）。
- 賠償條款已在 `HK_MAP_2026-11-12.md` 提過，這裡是同一條。
