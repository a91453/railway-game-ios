| 名稱 | 用途 |
| --- | --- |
| `ThemeSelectableButtonStyle(isActive:)` | 開／關按鈕：開時填 `primary`，關時只有 `panelBorder` 外框。狀態不只靠顏色區分 |
| `ThemeProminentButtonStyle(isDestructive:)` | 主要動作：`primary`，移除類用 `error`；不能按時用 `panelBorder` 底配 `textSecondary` |
| `.themeCard(padding:cornerRadius:)` | 實色 `panel` 卡片，即使放在玻璃上，文字對比也固定 |
| `.glassBackground(in:interactive:)` | 浮在地圖上的元件：iOS 26 用 Liquid Glass，iOS 17–25 用 `.regularMaterial` |

`.borderedProminent` 固定用白字，在 Dark 的 `primary`（1.85:1）和 `error` 上都不到 AA，所以主要動作改用 `ThemeProminentButtonStyle`。`.bordered` 按鈕沿用全域 tint。

## 線號徽章與色盲配色（決策 216）

2026-10-14。決策 205 讓路線附近的標記不靠路線色；這一節讓**路線本身**也不只靠顏色：每條路線有線號，畫在徽章上；設定頁可以改用色盲友善色票。作者請 session 從玩家、開發、美術三方考慮後自己定案（預覽給了徽章三種、色票三種）。

### 線號

- 玩家可以改（路線面板「線號」）：一到三個英文大寫字母或數字（`LineCode`，GameCore 的 `ServiceLine.code`，缺 key＝自動；存檔版本 55）。輸入時小寫、全形字母數字、空白都會自動轉換；留空就回到自動。
- 自動線號照路線顏色的名稱取字母（`LineBadge.automaticCode`），北捷有的顏色照北捷：藍 BL、紅 R、綠 G、橘 O、棕 BR、黃 Y；其他照英文：粉紅 PK、紫 P、淺藍 LB、淺綠 LG、青綠 T、靛 IN、灰 GY、白 W。20 個色票與 6 個自動色各有一個字母；其他顏色照色相。同一個字母的第二條線起加數字（R、R2、R3），不和玩家自己給的線號撞；玩家給兩條線同一個線號就照他的。

### 徽章（方案 B「白底色條牌」）
