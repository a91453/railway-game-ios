# 看圖再改

kit 的測試（面數、封底、接點、決定性）只查「有沒有做錯」。一個方盒子也能全過。這份規矩補的是「好不好看、認不認得出來」，它只能靠看圖回答，所以整個流程都圍著「看」。

各 kit 自己的做法（座標、入口、重建指令）仍照那個 kit 的 skill；畫風照 `art-style` 第 7 節。這裡只管看圖的迴圈。

## 1. 沒有參考不開工

- 找到這個東西的**真實照片**：至少一張正面、一張另一側或斜角；有俯視更好（遊戲是從上往下看的）。Wikimedia Commons 可以用 API 查授權。
- 記下**尺寸**：長、深、簷高、脊高。量不到就從照片裡的門（約 2.1 m）、人、車推估，並寫明是推估。
- 來源、作者、授權寫進這一輪的 README。照片只拿來比對形狀與顏色：不當貼圖，不放進公開的遊戲 repo（放私有素材庫）。
- 先用一段話寫下「**這個東西憑什麼被認出來**」（三到五個特徵，例如：灰瓦長屋頂、簷下一排白色站名牌、月台側的山牆與圓窗）。之後每一輪都拿這幾條對。找不到照片或說不出特徵，就先停下來問，不要憑印象做。

## 2. 用遊戲的眼睛看

遊戲鏡頭是從上往下斜看：近看傾 40° 左右，拉遠漸漸變成正上方；光線是故意打平的（天空光為主，太陽只加一點），所以**立體感不能指望陰影，要靠形狀的高低進出與相鄰面的顏色差**。iPhone 上一座 22 m 長的站房在中距離只有 70 點寬。

所以判斷的順序是：

1. **遊戲大小的圖最重要**：在那個大小還看得出它是什麼嗎？屋頂的形狀與顏色佔了大半畫面，先把屋頂做對。
2. 遊戲角度的放大圖：看比例與各部分的關係。
3. 和照片同方向的圖、更近的放大圖：**只用來找毛病**，不用來說服自己「細節很多所以很好」。

拍圖用 `tools/model-look/shoot.mjs`（任何 kit 匯出的 `.m3dmodel` 都能拍；車站用 `tools/model-look/export-station.sh` 匯出）。它出一張寬 800 px 的 JPG：遊戲大小、遊戲角度放大、與照片並排，有 `--before` 時每一格都是改前、改後。用法在腳本開頭。看圖前一律縮到寬 800 px 以內的 JPG（大圖只是多花力氣，看不出更多）。

## 3. 每一輪

拍圖 → **真的打開圖看** → 對著照片與清單逐條寫出毛病 → 改 → 寫下這一輪改了什麼、還剩什麼。

清單（我們常犯的；每條怎麼看、通常怎麼改在 [references/checklist.md](references/checklist.md)）：

1. 像盒子
2. 比例不對
3. 窗戶太平、沒有深度
4. 屋頂與牆接不起來
5. 零件浮空
6. 顏色灰、糊成一片
7. 光太平（面與面分不開）
8. 遠看認不出是哪一站、哪一款車

每一輪先修影響最大的（通常是輪廓、屋頂、主色），細節留到後面。一輪裡沒找到毛病，多半是沒有認真看：換一個角度、換成遊戲大小、或把第 1 節寫的特徵逐條對一次。

## 4. 什麼時候停

**清單八條都過，而且至少做滿三輪。** 測試全綠不是停的理由，「已經比原來好很多」也不是。真的過不了的那一條（例如面數預算不夠、照片看不到背面）寫進報告，不要當作沒看到。

## 5. 做的人不打分

做的人會越看越順眼，所以最後的及格與否不由自己說：

- 交**一張總覽圖**（最後一輪的 shoot 圖，寬 800 px 內）給作者（`SendUserFile`）或另一個 session 看（別家 AI 也可以；對照片檢查畫面本來就是 Antigravity 的分工，`AGENTS.md`）；不及格就退回再做。
- 自己看不了圖（沒有視覺的本地模型）就不要假裝做了這幾輪：只寫配方，明講「還沒看圖」，把看圖交給看得到的 session。
- 報告只寫事實：每一輪改了什麼、清單每條的現況、用了哪些照片。不寫「品質優良」「高度還原」。
- **報告最後一節固定是「還有哪裡不好」**，老實列出來（至少寫出最弱的兩三點）。寫不出來代表還沒看夠。

## 6. 交付

- 重檔（模型、viewer、各輪大圖、照片）放 `a91453/railway-assets-private` 的 `game-art-previews/docs/art/<資料夾>/`，照那邊的 `AGENTS.md`：先跑 `python3 tools/asset_guard.py --base origin/main`，新一輪同 PR 刪上一輪重檔。
- 遊戲 repo 的 PR 只留一張總覽圖與 README（`docs/art/<資料夾>/`）。
- 配方改了，kit 原有的測試照跑；替這次修掉的毛病留一個會在舊幾何失敗的測試（例如「屋脊高於簷口」「山牆在月台側」）。

實例：追分車站（`docs/art/model-look-2026-11-11/README.md`），從紅磚紅瓦的通用站房改成木造灰瓦，四輪的紀錄與並排圖。
