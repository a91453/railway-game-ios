# 台鐵宜蘭線的側線（OSM）

`find_tra_yards.py` 從 OpenStreetMap（ODbL 1.0）找出宜蘭線頭城到蘇澳之間的 yard、siding、spur 群聚（共用節點的算同一群），印出每一群的軌道總長、中心與名稱。用途是台鐵示範（決策 240）的側線位置。

```sh
pip install osmium            # BSD 2-Clause，決策 93
curl -LO https://osmtoday.com/asia/taiwan.pbf
python3 -I tools/tra-yards/find_tra_yards.py taiwan.pbf
```

## 2026-10-15 的結果

osmtoday.com 的整包檔，2026-10-15 下載。

| 總長 | 中心 | 在哪 | 示範怎麼用 |
| --- | --- | --- | --- |
| 5.1 km | 24.60998, 121.82703 | 蘇澳新站北側 | **蘇澳新側線**（和下一列同一個站場） |
| 4.8 km | 24.59487, 121.85162 | 蘇澳站（`宜蘭線`、`蘇澳港線`） | 不用：示範不到蘇澳 |
| 4.6 km | 24.61015, 121.82734 | 蘇澳新站東側 | **蘇澳新側線**（`TRADemo.depots` 用這一點） |
| 4.3 km | 24.75421, 121.75845 | 宜蘭站東側 | **宜蘭側線** |
| 1.9 km | 24.67768, 121.77468 | 羅東站 | 不用：羅東的列車進宜蘭側線 |
| 1.3、1.3、1.2 km（三群）| 24.70, 121.77 | 二結—中里間 | 不用 |

頭城附近沒有側線；示範在頭城以北另設「北端留置線」，代表真實列車開往臺北方向的車庫（決策 240）。

宜蘭、蘇澳新兩站的側線都在車站旁邊，和示範車站自己的待避線、渡線重疊，所以示範把側線往外移：宜蘭的往南 2.5 km，蘇澳新的往北 3.4 km（新馬以北的直線段，避開蘇澳新北邊的 S 形彎）。
