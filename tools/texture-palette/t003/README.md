# 舊材質圖 → 遊戲建築色票對照（t003 第 3 輪）

給之後「批次換一般建築」直接用。來源是本機工作室 t003 第 3 輪的色票分類（9,453 張舊材質圖；t001 的類別約有 15% 錯，t003 修了立面、屋面、地面、地圖，以它為準）。舊材質圖是作者自己的作品；這裡只放檔名和顏色，不放貼圖、不放本機路徑。

重做：

```sh
python3 -I tools/texture-palette/building_map.py --palette-map <t003/r3/palette-map.csv> --out tools/texture-palette/t003
```

| 檔案 | 內容 |
| --- | --- |
| `building-map.csv` | 建築類 1,110 張：類別、狀態、主色與第二色，以及它們在遊戲裡的位置（Swift 寫法，例如 `Map3DPalette.cityConcreteWalls[3]`） |
| `manual-review.csv` | 要人工看的 235 張：瓦／屋面 65、地面／鋪面／草地 141、磚 29。工具給的建議色只是參考，「人工判定」欄留空，不猜 |

## 狀態

| 狀態 | 意思 | 張數 |
| --- | --- | ---: |
| 可直接用 | 主色是遊戲裡已有的色票 | 557 |
| 色票未進遊戲（要提新色） | 主色是 t001 色票裡有、`Map3DPalette` 還沒有的色：鋼 #8A9099 216、深色／窗 #2B2F36 24、木頭 #9A7657 21、紅磚 #B07A62 20、洗石子 #E3DCCB 8 | 289 |
| 沒有合適色票（要提新色） | 最近的色票 ΔE > 15。工具建議的新色：#636462（114 張）、#5D412C（23）、#778265（15）、#211C16（14） | 137 |
| 主色不明（另議） | 立面主色面積比 < 0.25，不給色 | 33 |
| 人工看 | 瓦／屋面、磚整類（地面不是建築，只在 `manual-review.csv`） | 94 |

依 model-look §6：沒有接近的色，在 PR 提出要加的色票，不直接用原色。所以「要提新色」的 426 張，要等批次換建築那個 PR 先決定加哪幾個色進 `Map3DPalette`。

## 還有哪裡不好

- 類別仍未過門檻。第 3 輪只把黑底亮點的夜間圖收回「夜間燈光」（354 張，獨立審查抽 30 張 27 張確認改對），但全體抽 60 張類別錯仍有 10 張（16.7%，95% 區間 9%–28%，門檻 10%）。剩下的錯多半是立面掉進「其他」或「地圖」（60 張裡 6 張），本表沒有它們；也有 1 張俯視圖被分成立面、1 張金屬零件被分成清水模。
- 磚收得太嚴（83 → 29 張），有 5–6 張真的磚在「其他」「招牌」「木頭」；這次 29 張全列人工看。
- 同一個 hex #8A949E 在遊戲裡有兩個位置（`hallRoofs[2]` 銀灰鐵皮、`cityOfficeWalls[5]` 深灰鋁板），表照 t003 給的色名對。
