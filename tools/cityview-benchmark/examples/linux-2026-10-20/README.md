# Linux capture, 2026-10-20

These three PNGs and `measurements.json` are one run of `capture.cjs` on Linux from repository base `d316669e`, with Chromium 154.0.8037.57 and its SwiftShader WebGL renderer. The run used `--frames 12 --warmup 4`. The compiled Kaohsiung city tiles and textures were fetched from the game's public `/city/` site into ignored local directories; they are not included here. The screenshots and numbers are evidence that the script ran, not a performance target for another machine.
