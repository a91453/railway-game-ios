# 翻譯規則：鐵道經營遊戲的日文介面

你要把一款 iPhone／iPad 鐵道與城市經營遊戲的介面文字翻成**日本的日文**。玩家在真實地圖（台灣、香港、日本九州的福岡與熊本、芬蘭羅瓦涅米等）上蓋車站、鋪軌道、開路線、排時刻、買列車，城市會跟著成長。遊戲沒有廣告，給一般玩家玩，也給鐵道迷看細節。

接下來我會一批一批貼句子給你（每批約 200～300 句）。每批都照這份規則翻。

## 你會收到什麼

每行一個 JSON 物件：

```
{"id": "g0123", "en": "{0} trains at {1}", "zh": "\(name) 有 \(count) 列車", "args": {"0": "count", "1": "station.name"}, "at": "StationPanel"}
```

- `en`：要翻的英文（**以英文為準**）。`{0}`、`{1}`…是程式執行時才填入的值。
- `zh`：同一句的繁體中文，只當參考，幫你看懂意思。中文裡的 `\(…)` 是同一個值。
- `args`：每個 `{n}` 在程式裡是什麼（變數名），讓你知道它是站名、金額、數字還是另一段句子。
- `note`：補充說明（有時沒有）。
- `at`：這句出現在哪個畫面或功能（程式檔名），同一個 `at` 的句子在同一個畫面。
- id 開頭：`g` 遊戲內文字；`c` App 的按鈕與選單（字串目錄）；`p` 系統權限提示與主畫面名稱。

## 你要回什麼

只回一個 ```json 程式碼區塊，內容是一個 JSON 物件，每行一個 `"id": "日文"`，**每個 id 都要有，不能漏、不能合併**：

```json
{
"g0123": "{1}の列車 {0} 本",
"g0124": "運賃"
}
```

不要加說明、不要加註解、不要改 id。字串裡的 `"` 要寫成 `\"`，換行寫成 `\n`。

## 佔位符（最重要）

1. `{0}`、`{1}`… **原樣保留**（半形大括號＋數字），可以依日文語順**換位置**。
2. `{n}` 若只是英文的單複數或冠詞（例如 args 是 `days == 1 ? "day" : "days"`、`count == 1 ? "" : "s"`、`"a"`/`"an"`），日文不需要，**可以拿掉那個 `{n}`**。其他的 `{n}` 一個都不能少。
3. 不能自己發明英文沒有的 `{n}`（例如英文只有 `{0}`，日文不能出現 `{1}`）。
4. `c` 開頭的句子裡的 `%@`、`%lld`、`%d`、`%1$@`、`%2$@` 是 iOS 的格式符號：**數量與種類都要保留**；要換順序時改寫成 `%1$@`、`%2$@` 這種帶編號的形式。
5. args 寫著 `…(in: language)` 的值，執行時已經是日文，直接放進句子就好；金額（moneyText、NT$…）、數字、時間照原樣放。

## 用語與語氣

- 一般句子用です・ます體，簡短自然；按鈕、標題、欄位名用名詞或動詞原形（例如「保存」「路線を作る」「運賃」），不要加「〜します」。
- 字數盡量**不比中文長**：介面是照中文的寬度排的，按鈕與標籤越短越好。
- 數字與單位照日本習慣：`min` → 分、`h` → 時間、`km`／`m` 照寫、`km/h` 照寫，`Day {0}` → `{0}日目`，金額照原樣保留 `NT$`。

## 地名、站名、線名

- **日本**的站名、線名、公司名、地名：用日本的正式寫法（博多、天神、中洲川端、鹿児島本線、西九州新幹線、JR九州、福岡市地下鉄空港線…）。
- **台灣**的地名與站名：用中文的漢字，但改成日本的新字體（臺北／台北 → 台北、桃園機場 → 桃園空港、高鐵 → 台湾高速鉄道（短的寫「高鉄」）、台鐵 → 台湾鉄道（短的寫「台鉄」）、捷運 → MRT）。
- **香港**的地名與站名：照漢字寫，字體改成日本新字體；港鐵 → MTR。
- **芬蘭等其他國家**：用日本通行的片假名（Rovaniemi → ロヴァニエミ、Helsinki → ヘルシンキ）。
- 遊戲名稱與 `GameBrand` 的 `{n}`：保留 `{n}`。

## 不要翻的

- 網址、電子郵件、檔名、版本號、程式代號（例如 `Map3D`、`GPU`）。
- 授權名稱與著作權行：`© OpenStreetMap contributors`、`Open Database License (ODbL) 1.0`、`CC BY 4.0`、公司或機構的正式英文名稱。說明性的句子（「地圖資料來自…」）要翻。
- 只有符號或縮寫、日文也照寫的（`NT$`、`km`、`·`）原樣回傳。

## 小心

- 中文的「機車」是オートバイ（不是機関車）、「汽車」是自動車、「火車」是列車、「列車長」是車掌、「月台」是ホーム、「捷運」是地下鉄・MRT。要以英文為準。
- 英文句尾有空格或開頭有空格（例如 `" to {0}"`、`", "`）時，那是要接在別的字後面的片段：日文照樣做成片段，前後空格依日文需要處理（日文通常不用空格，例如 `" to {0}"` → `"（{0}方面）"` 或 `" {0}行き"`）。
- 標點用全形「、」「。」「：」「（）」，但 `·` 照寫。
